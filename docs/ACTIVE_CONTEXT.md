## 현재 목적

Spell의 터치 회로 전투, 자동화 성장, 소환수·스톡·마나 구조와 단일 명문 마법학교, 정식 신입생, 학년 승급, 현장실습, 경량 육성, 선택형 상세 서사 구조를 기획 단계에서 확정한다. 세부 밸런스와 콘텐츠 데이터는 PoC 및 후속 데이터 설계에서 조정한다.

## 현재 확정된 방향

### 플랫폼과 입력

1. Godot 기반 Android 모바일 게임
2. 터치로 마법 회로를 직접 작성
3. 회로 작성 중 전투 시간 감속
4. 성공 판정은 널럴하고 부정확 패널티는 낮게 설정
5. 정확 입력에는 손맛·효율 중심의 추가 보상 제공

### 주문 발견과 회로 문법

6. 주문은 직접 실험해 발견한 뒤 마도서 설계도로 등록
7. 한 주문의 메인 회로는 정확히 하나
8. 초반 최소 문법은 `메인 + 형상·전달`
9. 이후 보조 회로를 단계적으로 해금
10. 중반에 조건·기동 회로 해금
11. 반복 회로 자동완성은 하위 회로 스톡이 전담
12. 속성·매질의 독립 계층 여부는 미확정

### 마나

13. 마나는 기본 자동 회복과 플레이 행동 보너스를 함께 사용
14. 마나 회복 회로와 마나 절감 회로 추가
15. 마나는 직접 회로 시전에만 적용
16. 스톡 준비·발동·적용·충전에는 마나를 사용하지 않음
17. 회복·절감 조합의 무한 마나 순환 금지

### 소환수

18. 기존 동료를 소환수 같은 마법적 존재로 대체
19. 기본 소환수 1체를 전투 전에 미리 소환하고 전투 시작부터 전개
20. 고정 역할 타입 없이 능력치·적성·스탠스로 효율 결정
21. 소환수는 전투·수호와 지정 스톡 생산 지원 담당
22. 소환수의 회로 직접 작성·구간 분담·협동 작성은 `SUPERSEDED`
23. 소환수는 완성 주문·하위 회로 스톡의 생산량 또는 충전 속도를 높임
24. 소환수는 플레이어 허가 없이 충전 대상을 변경하지 않음
25. 추가 편성·교체·동시 전개 수는 미확정

### 자동화 성장과 두 종류의 스톡

26. 자동화는 직접 그리기를 제거하지 않고 새 문법에 집중하게 하는 성장 기능
27. 이미 학습·숙련했고 성장 기준 이하인 주문·회로만 스톡화 가능
28. 현재 성장 단계의 신규·상위 회로는 직접 입력 영역으로 유지
29. 조건부 자동발동은 폐기
30. 완성 주문 스톡은 저장된 주문 전체를 원터치로 기동
31. 하위 회로 스톡은 현재 주문에 회로 한 구간을 원터치 자동 배치·연결
32. 스톡이 없어도 직접 회로 시전 가능

### 공용 준비 용량과 충전

33. 두 종류의 스톡은 하나의 공용 준비 용량을 공유
34. 하위 회로 스톡 1개는 준비 용량 1 사용
35. 완성 주문 스톡 1개는 구성 기능 회로 수만큼 준비 용량 사용
36. 동일 주문·회로 반복 편성 허용
37. 주문별·회로별 별도 최대 보유량 없음
38. 플레이어 성장에 따라 전체 준비 용량 증가
39. 연결·분기·합류의 독립 회로 계산 여부는 미확정
40. 최대 마나 예약 규칙은 `SUPERSEDED`
41. 플레이어가 자동 충전할 스톡 대상 1종을 지정
42. 다른 준비 대상은 동시에 충전되지 않음
43. 플레이어 능력치와 소환수 생산 능력치가 충전 효율에 기여
44. 직접 시전·정확 입력·방어·연계는 충전을 추가 가속
45. 기준 충전시간은 `1.0 + 0.5 × (기능 회로 수 - 1)`
46. 동일 대상의 빈 스톡은 1회분씩 순차 충전
47. `1.0단위`의 실제 초 환산값은 미확정

### 충전 대상 전환

48. 전투 중 다른 준비 스톡으로 충전 대상 변경 가능
49. 대상별 다음 스톡 1회분 충전 진행도 보존
50. 대상 변경 시 전환 지연 동안 모든 충전 정지
51. 전환 완료 후 새 대상의 저장 진행도부터 재개
52. 현재 대상이 최대치에 도달해도 자동 전환하지 않음
53. 전환 지연 시간과 전환 중 재변경 규칙은 미확정

### 직접 피해·지속 피해·상태이상

54. 직접 피해가 발생해도 충전 진행도와 전환 게이지는 전부 보존
55. 최종 직접 피해가 0이면 충전·전환을 정지하지 않음
56. 직접 피해 정지 공식은 다음과 같음

```text
r = 0.25초 직접 피해 손실 합계 / 집계 시작 시 최대 체력
정지시간 = clamp(r × 3.0, 0.10초, 0.80초)
```

57. 같은 총 직접 피해라면 단발·다단 공격은 같은 정지시간을 목표로 함
58. 정지 종료 후 자동 재개
59. 지속 피해 틱은 체력을 감소시키지만 스톡 충전·전환을 정지하지 않음
60. 지속 피해 틱은 직접 피해의 0.25초 집계에 포함하지 않음
61. 마력 교란은 스톡 충전 속도만 감소
62. 기획 기본값은 충전 속도 30% 감소, 동일 상태 중첩 없음, 재적용 시 지속시간 갱신
63. 주문 봉인은 완성 주문·하위 회로 스톡 사용만 차단하고 직접 시전은 유지
64. 주문 봉인 중 자동 충전·생산 기여·대상 전환·보유량은 유지
65. 상위 마력 봉쇄는 희귀·보스급으로 스톡과 직접 시전을 모두 차단
66. 마력 봉쇄는 사전 경고와 대응 수단이 필요하며 장시간 반복 적용 금지
67. 상태이상으로 충전 진행도나 보유 스톡을 삭제하지 않음
68. 상태이상 세부 목록·수치·저항·해제는 `DEFERRED_STATUS_DESIGN`

### 마법학교·현장실습 세계관

69. 세계관 기본 틀은 `마법학교 + 현장실습 + 성장 모험`
70. 학교는 수업·교류·준비·육성·숙련의 생활 허브
71. 실제 전투·탐험·주문 발견은 학교 밖 현장실습에서 주로 발생
72. 현장실습은 생태 조사·재해 안정화·유적 해석·사고 해결·구조·봉인·복구 등을 포함
73. 적 처치만을 유일한 해결 방식으로 사용하지 않음
74. 학교 운영·건설 경영은 현재 코어에 추가하지 않음
75. 비밀학과·학교 내부 음모를 세계관 필수 중심축으로 사용하지 않음
76. 신규 콘텐츠는 숨겨진 체계보다 기존 회로의 새로운 `활용`을 확장
77. 같은 회로도 목적·대상·환경·형상·전달·보조·조건에 따라 다른 결과를 생성
78. 현장에서 유효한 활용을 증명하면 마도서 설계도로 등록
79. 반복 가능성과 안전성이 확보된 활용은 숙련과 스톡화로 연결

### 단일 명문학교·학년 승급·경량 육성

80. 플레이어가 생활하고 관계를 쌓는 중심 학교는 하나
81. 학교 주변 마을·도시·숲·유적·마법 생태 지역을 초기 실습지로 사용
82. 학년이 오르면 더 먼 지역과 고위험 실습 지역 개방
83. 다른 학교는 교류전·축제·대회·공동 실습·라이벌로 점진 등장
84. 학년은 회로 문법·현장 책임·학교 내 위치를 나타내는 큰 성장 단계
85. 승급은 수업·현장실습·시험·발표를 정리하는 사건
86. 특정 빌드나 선택 과목 때문에 메인 진행이 영구 차단되지 않음
87. 부족한 평가는 보충 수업이나 재시험으로 회복 가능
88. 매일 단위가 아니라 학기 단위의 경량 일정 선택 사용
89. 필수 수업은 핵심 문법을 보장하고 선택 수업·자율활동은 활용 성향·관계·사건·진로에 영향
90. 육성만으로 주문을 자동 획득하지 않고 현장에서 직접 활용을 성공해야 함
91. 육성 메뉴가 회로 전투와 현장실습보다 플레이 시간을 압도하지 않음
92. 학교 경영·수십 개 생활 능력치·연애·결혼 중심 시뮬레이션은 현재 코어에서 제외

### 정식 신입생·일반 가정 출신 장학생

93. 주인공은 중심 명문 마법학교에 정식으로 입학한 신입생
94. 주인공은 마법 명문가·왕족·비밀 혈통이 아닌 일반 가정 출신
95. 편입생·견습 연구생·비밀학과 학생을 기본 설정으로 사용하지 않음
96. 환생 지식·선행 상급 마법 숙련을 필수 설정으로 두지 않음
97. 입학시험의 기초 회로 이해·작성·활용·안전 판단을 통해 장학생으로 선발
98. 최고 마력량보다 제한된 회로를 상황에 맞게 활용한 잠재력이 강점
99. 주인공의 전문 분야와 정체성은 학기 선택·관계·현장실습·플레이어 판단으로 형성
100. 장학금 상실을 반복 협박이나 강제 실패 조건으로 사용하지 않음
101. 가족 구성·출신 지역·최초 입학시험 활용 사례는 추후 설정

### 마법학교 장르 벤치마킹

102. `마법학교 마법사로 살아가는 법`을 포함한 유사 장르의 구조적 장점을 참고
103. 학교생활 자체를 반복 사건 생성 시스템으로 사용
104. 수업을 기능 해금뿐 아니라 교수·관계·과제·활용 관점과 연결
105. 작은 학교 사건이 인근 지역과 마법사 사회 문제로 점진 확장
106. 관계는 호감도 숫자보다 정보·동행·연구·해결 경로를 개방
107. 학년 상승은 힘뿐 아니라 책임·자유도·문제 범위를 확대
108. 참고 작품의 고유 학교·인물·사건·마법 체계는 복제하지 않음

### 선택형 상세 서사와 DDD

109. 스토리는 `필수 핵심층`과 `선택형 상세층`으로 분리
110. 사건 발생 시 현재 상황·행동 이유·목표·위험·중요 선택 결과만 짧게 전달
111. 핵심 안내 후 즉시 조작권과 다음 목표를 제공
112. 더 알고 싶은 플레이어는 관련 NPC에게 다시 말을 걸거나 장소·기록을 조사
113. 인물의 과거·감정·학교 역사·사건의 세부 맥락은 선택층에서 제공
114. 선택 대화를 보지 않아도 메인 진행과 기본 성장에 불이익 없음
115. 임무 목표·실패 조건·필수 대응법·승급 조건·핵심 해금은 선택 대화에 숨기지 않음
116. 부가 힌트가 선택층에 있어도 필수 해결 정보는 기본 UI·현장 표현·핵심 대사에서도 확인 가능
117. 핵심 사건 요약은 기록에 자동 저장
118. 선택 대화는 관계·인물·세계관·서브 에피소드의 밀도를 높이는 용도
119. DDD는 서사를 삭제하는 것이 아니라 장문 설명이 행동과 보상 흐름을 오래 중단하지 않게 하는 원칙
120. 권장 흐름은 `짧은 사건 제시 → 즉시 목표 → 플레이 → 결과·보상 → 선택형 상세 → 다음 행동`
121. 모든 NPC·사건에 장문 선택 대화를 만들지 않고 반복 핵심 인물과 주요 사건에 우선 적용
