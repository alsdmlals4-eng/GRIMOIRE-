## 현재 확정된 코어

### 마법 글자·주문

- 주문은 `메인 글자 1개 + 보조 글자 0개 이상`으로 구성한다.
- 메인 글자 하나만으로 기본 주문이 성립한다.
- 복수 메인 글자는 허용하지 않는다.
- 보조 글자는 형상·전달·출력·규모·시간·행동·효율·안정·조건·순서를 담당한다.
- 글자가 늘면 주문 기능이 확대되지만 작성 시간·마나 부담·스톡 준비 용량·충전시간도 증가한다.
- 주문은 현장 활용에 성공한 뒤 마도서에 등록하고 숙련·스톡화한다.

### 메인 글자 계열·레벨

- 메인 글자 계열은 `현상·물질·개념 중심`으로 분류한다.
- 공격·방어·생활·구조·탐색은 계열이 아니라 활용 결과다.
- 각 메인 글자는 플레이어 전체 레벨과 별개의 독립 레벨을 가진다.
- 기획 기본값은 `Lv.0~Lv.5`다.

```text
Lv.0 미습득
Lv.1 입문
Lv.2 숙련
Lv.3 응용
Lv.4 전문화
Lv.5 전공·개인 연구
```

- 레벨은 수업·직접 작성·보조 조합·현장 활용·시험·연구로 상승한다.
- 메인 레벨은 기본 발현·안정성·마나 효율·보조 수용력·활용 범위를 성장시킨다.
- 메인 레벨이 올라가도 기능 글자 수 계산에서는 메인 1개다.
- 모든 메인 글자를 한 회차에 최고 레벨로 만들 수 있게 하지 않는다.

### Lv.4~Lv.5 전문 활용 분기 — GM-CIRCUIT-07

```text
Lv.1~Lv.3 공통 기반
→ Lv.4 전문 분야 선택
→ Lv.5 선택 분야 심화·졸업 연구
```

- 전문화는 기본 발현, 특정 보조 글자군 결합, 교수 연구실, 현장실습과 진로에 영향을 준다.
- 모든 계열에 동일한 공격·방어·지원 분기를 복사하지 않고 현상 특성에 맞게 설계한다.
- 전문화가 새로운 보조 글자를 자동 지급하지는 않는다.
- 분기 변경 가능 여부와 실제 분기명·효과는 미확정이다.

### 학년별 보조 글자 운용량 — GM-CIRCUIT-08

| 학년 | 표준 안전 운용량 |
|---:|---:|
| 1학년 | 보조 2개 |
| 2학년 | 보조 4개 |
| 3학년 | 보조 6개 |

- 1학년부터 `메인 1 + 보조 2`의 의미 있는 완성형 주문을 사용할 수 있다.
- 위 수치는 학교가 인증한 표준 안전 운용 범위의 `PLANNING_DEFAULT`다.
- 우수한 계열·회로 문법·응용 실기 성적은 현재 학년 표준보다 보조 글자 1개 이상을 추가 운용하게 할 수 있다.
- 1학년 우수 학생은 보조 3개, 특별 연구·실기 성과가 있으면 그 이상도 후보로 둔다.
- 추가 운용은 성과를 증명한 메인 계열에 적용하는 방향을 우선한다.
- 보조 운용량은 한 주문의 조합 복잡도이며 스톡 준비 용량과는 별개다.
- 보조 글자 하나는 기능 글자 1개로 계산되며 성적 보너스로 스톡 비용이 할인되지 않는다.
- 인증 범위를 넘긴 과부하 주문의 허용 여부와 패널티는 미확정이다.

### 학습·자동화·스톡

- 처음 배우는 메인·보조 글자는 직접 작성한다.
- 현장에서 조합을 성공해야 완성 주문으로 등록한다.
- 숙련된 낮은 단계 글자는 하위 글자 스톡 후보가 된다.
- 등록·숙련한 주문만 완성 주문 스톡 후보가 된다.
- 하위 글자 스톡은 숙련 글자 하나를 자동 배치·연결한다.
- 소환수는 글자를 직접 작성하지 않고 전투·수호·지정 스톡 생산을 지원한다.
- 완성 주문 스톡과 하위 글자 스톡은 공용 준비 용량을 사용한다.
- 준비 용량과 충전시간은 기능 글자 수 기준이다.
- 기준 충전시간은 `1.0 + 0.5 × (기능 글자 수 - 1)`이다.
- 스톡은 마나를 소비·예약하지 않는다.

### 마법학교·육성

- 단일 명문 마법학교, 3년제·학년당 2학기·총 6학기다.
- 주인공은 일반 가정 출신 장학생 정식 신입생이다.
- 한 학기는 자유 일정 10회와 고정 사건 4회, 총 14구간이다.
- 전투·대화·개별 활동의 미시 템포는 빠르게, 학교생활·관계·숙련의 거시 템포는 길게 유지한다.
- 수업은 현상·물질·개념 중심의 메인 글자 계열로 분류한다.
- 1학년은 여러 기초 계열과 보조 2개 조합을 학습한다.
- 2학년은 선택 계열과 보조 4개 복합 조합을 학습한다.
- 3학년은 전공 계열 전문화와 보조 6개 독립 주문·졸업 설계를 수행한다.
- 현장실습은 `1학년 학교 지정 → 2학년 지정+선택 → 3학년 학생 제안+학교 승인`으로 자율성이 증가한다.
- 수업은 완성 주문을 자동 지급하지 않으며 현장에서 직접 활용을 증명해야 한다.

### 서사와 DDD

- 필수 스토리는 목표·이유·위험을 짧게 전달한다.
- 일반 사건은 짧은 대사+목표 카드, 긴급 임무는 경고+위험 카드를 사용한다.
- 관계·승급·졸업 장면은 일반 대화창을 사용한다.
- 상세 세계관과 인물 이야기는 NPC 재대화·조사·기록으로 제공한다.
- 선택 대화를 보지 않아도 메인 진행과 기본 성장에 불이익이 없다.
- DDD는 학기와 이야기를 축약하는 원칙이 아니라 행동 결과와 보상을 빠르게 제공하는 원칙이다.
