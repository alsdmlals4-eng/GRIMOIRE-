## 한 줄 방향

> 마법학교 학생이 되어 마법 글자를 배우고 직접 조합하며, 숙련된 반복 글자는 스톡으로 간결하게 사용하고 소환수의 충전 지원을 지휘하는 Android 모바일 실시간 마법 전투·육성 게임.

## 현재 플레이어 약속

- 플레이어는 완성 스킬만 누르는 마법사가 아니라 마법 글자의 의미와 연결을 이해한다.
- 메인 글자와 중요한 변형은 직접 작성한다.
- 반복되는 숙련 보조 글자는 하위 글자 스톡으로 삽입한다.
- 긴급·반복 주문은 완성 주문 스톡으로 발동한다.
- 소환수는 글자를 직접 쓰지 않고 전투·수호·스톡 충전을 지원한다.
- 학교 수업과 현장실습을 통해 새로운 글자·활용·주문을 발견한다.

## 전투 코어

```text
상황·위험 인지
→ 메인 글자와 주문 구조 선택
→ 핵심 글자 직접 작성
→ 필요하면 하위 글자 스톡 삽입
→ 또는 완성 주문 스톡 즉시 기동
→ 주문 결과 피드백
→ 소환수가 지정 스톡 충전
→ 다음 조합·충전 우선순위 판단
```

### 책임 경계

| 시스템 | 책임 |
|---|---|
| 직접 작성 | 신규·미숙 글자, 핵심 판단, 즉석 변형 |
| 하위 글자 스톡 | 숙련 글자 하나 자동 배치·연결 |
| 완성 주문 스톡 | 등록 주문 전체 즉시 기동 |
| 소환수 | 전투·수호·지정 스톡 생산·충전·동조 |

- 소환수는 회로판에 글자·선·연결을 직접 작성하지 않는다.
- 소환수에게 보조 묶음을 장착해 자동 연결하는 안은 폐기됐다.
- 스톡이 없어도 직접 시전 가능하다.
- 소환수가 행동 불능이어도 직접 시전과 이미 준비된 스톡은 사용할 수 있다.

## 마법 글자

- 주문은 `메인 글자 1개 + 보조 글자 0개 이상`으로 구성한다.
- 메인 글자 하나만으로 기본 주문이 성립한다.
- 복수 메인 글자는 허용하지 않는다.
- 계열은 현상·물질·개념 중심이다.
- 공격·방어·생활·구조·탐색은 계열이 아니라 활용 결과다.

### 메인 글자 성장

```text
Lv.0 미습득
→ Lv.1 입문
→ Lv.2 숙련
→ Lv.3 응용
→ Lv.4 전문화
→ Lv.5 전공·개인 연구
```

- Lv.1~3은 공통 기반이다.
- Lv.4~5는 계열 특성에 맞는 전문 활용 분기다.
- 수업·직접 작성·보조 조합·현장 활용·시험·연구로 성장한다.

### 보조 글자 성장

```text
미숙
→ 숙련
→ 달인
```

- 미숙 글자는 직접 작성한다.
- 숙련부터 하위 글자 스톡 후보가 된다.
- 달인은 복합 연결·정확도·스톡 충전 효율 후보에 기여한다.
- 정확한 등급 요구량과 보너스는 플레이테스트 조정 대상이다.

### 학년별 보조 운용량

| 학년 | 표준 안전 운용량 |
|---:|---:|
| 1학년 | 보조 2개 |
| 2학년 | 보조 4개 |
| 3학년 | 보조 6개 |

- 우수한 계열·실기·연구 성과는 관련 계열의 추가 운용 인증을 제공할 수 있다.
- 보조 운용량은 최대 설계 복잡도이며 매번 전부 직접 작성해야 하는 양이 아니다.

## 1학년 전투 학습

```text
메인 글자 단독 발동
→ 보조 글자 2개 직접 조합
→ 핵심 보조 글자 숙련
→ 하위 글자 스톡 사용
→ 소환수 생산 스탠스로 지정 스톡 충전
→ 완성 주문 스톡 사용
→ 현장실습에서 세 수단 조합
```

- 완성 주문·하위 글자 스톡은 1학년부터 사용한다.
- 첫 학기 안에 직접 작성·스톡·소환수 충전 지원을 모두 경험한다.
- 1학년 전체를 직접 작성만 하는 긴 튜토리얼로 만들지 않는다.

## 학교·세계관

- 단일 명문 마법학교를 중심 허브로 사용한다.
- 주인공은 일반 가정 출신 장학생 정식 신입생이다.
- 3년제·학년당 2학기·총 6학기다.
- 한 학기는 자유 일정 10회와 고정 사건 4회다.
- 수업은 메인 글자 계열별로 구성하며 관련 메인·보조 글자를 배운다.
- 현장실습은 `1학년 배정 → 2학년 배정+선택 → 3학년 제안+학교 승인`으로 자율성이 증가한다.
- 학교 경영·비밀학과·필수 학교 음모는 현재 코어가 아니다.

## 서사·DDD

- 일반 사건은 짧은 대사와 목표 카드로 진행한다.
- 긴급 임무는 경고·목표·위험을 우선 전달한다.
- 중요한 관계·승급·졸업 장면은 일반 대화창을 사용한다.
- 상세 세계관과 인물 이야기는 NPC 재대화·조사·기록으로 제공한다.
- DDD는 학기를 압축하는 원칙이 아니라 행동과 결과 사이 반복 입력을 줄이고 보상을 빠르게 보여주는 원칙이다.
