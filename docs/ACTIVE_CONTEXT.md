# Spell Active Context

## 현재 상태

- 작업 모드: `PLAN`
- 기획 상태: `PLANNING_IN_PROGRESS`
- 프로젝트 코어 상태: `CORE_CANDIDATE`
- 구현 상태: 미착수
- 기준 브랜치: `gpt/planning-spell-20260725`
- 기준 날짜: 2026-07-26

## 현재 목적

사용자와 Grill Me 방식으로 Spell의 핵심 재미, 전투 구조, 회로 문법, 자동화 성장, 소환수 운용, 주문·회로 스톡과 마나 예약 구조를 확정한다.

## 현재 확정된 방향

### 플랫폼과 입력

1. Godot 기반 Android 모바일 게임
2. 터치로 마법 회로를 직접 작성
3. 회로 작성 중 전투 시간 감속
4. 판정 기준은 널럴하고 부정확 패널티는 낮게 설정
5. 정확 입력에는 손맛 중심의 추가 보상 제공

### 주문 발견과 마나

6. 주문은 직접 실험해 발견한 뒤 마도서 설계도로 등록
7. 마나는 기본 자동 회복과 플레이 행동 보너스를 함께 사용
8. 마나 회복 회로와 마나 절감 회로 추가
9. 회복·절감 조합으로 무한 마나 순환 금지

### 회로 문법

10. 한 주문의 메인 회로는 정확히 하나
11. 메인 회로 결합 금지
12. 초반 최소 문법은 `메인 + 형상·전달`
13. 메인과 형상·전달은 직접 학습 후 하위 회로 스톡화 가능
14. 이후 보조 회로를 단계적으로 해금
15. 중반에 조건·기동 회로 해금
16. 공격·방어·탐색·강화·절감 등의 개별 목록은 아직 예시
17. 속성·매질의 독립 계층 여부는 미확정
18. 반복 회로 자동완성은 하위 회로 스톡이 전담

### 소환수

19. 기존 동료 개념을 소환수 같은 마법적 존재로 대체
20. 기본 소환수 1체를 전투 전에 미리 소환하고 전투 시작부터 전개
21. 기본 1체를 위해 매 전투마다 동일한 소환 입력을 반복하지 않음
22. 소환수 역할 타입은 없고 능력치·적성·스탠스로 효율 결정
23. 소환수는 전투·수호와 지정 스톡 생산 지원을 담당
24. 소환수의 회로 직접 작성, 구간 분담, 협동 작성은 `SUPERSEDED`
25. 소환수는 완성 주문·하위 회로 스톡의 생산량 또는 충전 속도를 높임
26. 소환수의 생산·동조·지속 능력치가 자동·능동 충전 효율에 영향을 줄 수 있음
27. 소환수는 플레이어 허가 없이 충전 대상을 변경하지 않음
28. 마기카로기아의 마법적 구현 존재와 주문 보조 방향을 참고하되 고유 용어와 분류는 복제하지 않음
29. 추가 편성·교체·동시 전개 수와 소환 용량 공식은 미확정

### 자동화 성장

30. 자동화는 직접 그리기를 제거하지 않고 새 문법에 집중하게 하는 성장 기능
31. 플레이어 성장에 따라 자동화 가능한 주문·회로 단계가 상승
32. 일정 이하 단계이며 이미 학습·숙련한 주문과 회로만 스톡화 가능
33. 현재 성장 단계의 신규·상위 회로는 직접 입력 영역으로 유지
34. 신규 주문 발견, 즉석 변형, 상위 연결 판단, 정확 입력 보상은 직접 시전이 담당
35. 조건을 만족하면 주문이 임의로 발동하는 조건부 자동스펠은 폐기

### 두 종류의 스톡

36. 완성 주문 스톡은 저장된 주문 전체를 한 번의 터치로 기동
37. 하위 회로 스톡은 현재 주문에 저장된 회로 한 구간을 한 번의 터치로 자동 배치·연결
38. 완성 주문 스톡은 사용 시점·대상 판단을 플레이어가 담당
39. 하위 회로 스톡은 상위 회로·연결 방식·최종 기동을 플레이어가 담당
40. 같은 주문·회로에 여러 스톡을 배정하거나 여러 대상에 분산 가능
41. 플레이어 성장에 따라 전체 스톡 준비 한도 증가
42. 스톡이 없어도 직접 회로 시전은 가능

### 스톡 마나 예약과 충전

43. 스톡은 공용 게이지가 아니라 미리 지정한 주문 또는 회로별 사용량
44. 완성 주문 스톡 한 칸은 해당 주문의 기존 마나 비용 50%를 최대 마나에서 예약
45. 스톡 편성 중 예약 마나는 잠기며 실전 사용 가능 최대 마나가 감소
46. 빈 완성 주문 스톡도 예약량은 유지되고 해당 용량을 기반으로 재충전
47. 완성 주문 스톡 발동 시 동일 비용을 다시 전액 내는 이중 비용은 적용하지 않는 현행 설계
48. 하위 회로 스톡의 마나 예약 방식은 미확정
49. 플레이어가 자동 충전할 스톡 대상 1종을 지정
50. 지정한 주문 또는 회로의 빈 스톡만 전투 중 자동 충전
51. 다른 준비 대상은 동시에 자동 충전되지 않음
52. 자동 충전 속도는 플레이어 능력치와 소환수 생산 능력치에 비례
53. 직접 시전·정확 입력·방어·연계는 충전을 추가 가속
54. 소환수는 회로 작성 대신 자동 충전과 능동 충전 보너스를 강화
55. 이전의 `시간 경과만으로는 스톡이 충전되지 않는다`는 규칙은 `SUPERSEDED`

## 참고 결론 — 마기카로기아

- 제한된 전투 영역에 소환 존재가 구현되는 구조를 참고
- 술자의 이미지가 마법적 존재로 구체화될 수 있다는 정체성을 참고
- 소환 존재의 주문 보조 구조를 스톡 생산량과 충전 지원으로 변형
- 술자의 역량에 따라 소환 수가 제한되는 구조를 소환 용량 후보로 변형
- TRPG 판정, 원형 카테고리, 고유 명칭은 직접 사용하지 않음
