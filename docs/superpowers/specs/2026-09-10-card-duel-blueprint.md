# GRIMOIRE | 카드로 주문을 쓰는 결투

## 01. 대표 결투 블루프린트

문서 상태: DESIGN_REVIEW. 제한된 짧은 카드 조합 방향은 사용자 승인. 이 문서에서 새로 제안하는 턴·승패·카드 효과·수치는 검토용이며 최종 밸런스가 아니다.

### 이번 구간의 약속

마법학교 학생이 배운 카드를 단독으로 쓰거나 두 장을 엮어 주문을 만들고, 상대가 예고한 행동에 맞춰 다른 답을 고른다. 직접 그리기, 마법사 종류 카드, 군대 소환은 없다. 학생과 상대는 전투의 주체이며 카드 종류가 아니다.

대표 장면은 첫 수업 뒤의 연습 결투다. 생사를 건 전투보다 안전한 학교 연습을 보여주며, 패배하면 관계나 진행을 영구 파괴하지 않고 짧게 복기한 뒤 다시 연습할 수 있다. 온실 사건은 별도 첫 실습 후보이며 이 결투의 주제가 아니다.

### 승인 범위와 새 제안

| 구분 | 내용 |
|---|---|
| 승인된 방향 | 단독 사용 가능한 카드 + 짧은 선택 조합, 카드 결투가 메인 |
| 이번 권장 규칙 | 1~2장 주문, 한 교환에 한 번 확정, 단판 연습 결투 |
| 시험값 | 카드 4종, 각 2장으로 덱 8장, 손패 4장, 결계 16, 교환 예산 2 |
| 별도 결정 | 행동 기반 시간, 단판 승리, 덱 순환과 보존 규칙의 채택 |
| 이번에 하지 않는 것 | 기존 코드/저장 삭제, 옛 PR 흡수, production 이미지 승인, Godot 구현 |

수치들은 규칙의 빈틈을 확인하기 위한 일관된 예시다. 마력 20이나 7/7/6과 관계없으며, 옛 3서클·3라운드·2선승을 승계하지 않는다.

## 02. 이야기와 학습 흐름

### 메인 화면은 활동 선택기가 아니다

새게임 / 이어하기 / 설정 / 도감 / 종료를 제공한다. 새게임은 입학 이야기로, 이어하기는 저장된 이야기와 중단 지점으로 연결한다. 수업·실습·결투·축제는 이야기에서 발생한다.

| 순서 | 플레이어 행동 | 전달할 정보 | 다음으로 넘어가는 조건 |
|---|---|---|---|
| 수업 후 만남 | 상대 학생과 대화 | 결투 목적과 연습의 안전성 | 시작 선택. 돌아가기 가능 |
| 첫 교환 | 카드 한 장을 선택 | 단독 효과와 무소비 미리보기 | 명시 시전 또는 대기 |
| 둘째 교환 | 다른 카드 한 장을 더함 | 단독과 조합의 결과 차이 | 바뀐 결과를 확인하고 시전 |
| 독립 교환 | 방어막이 있는 상대에 대응 | 정답 클릭 대신 상황 읽기 | 힌트 없이 선택 가능 |
| 결과 | 승리/패배와 마지막 교환 확인 | 무엇을 했고 왜 결과가 달라졌는지 | 복기 후 이야기 또는 재연습 |

튜토리얼에서 강제 패배시키지 않는다. 자동으로 카드를 선택하거나 최적 조합을 표시하지 않는다. 첫 판 안내는 건너뛸 수 있고 도감의 연습 설명으로 돌아갈 수 있다.

### 장기 성장의 연결

수업은 규칙을 설명하는 팝업만이 아니라 새로운 활용을 만나는 자리다. 실습은 같은 카드를 다른 목적에 적용하는 자리, 결투는 상대 행동에 맞춰 선택하는 자리, 축제는 익숙한 원리를 다른 상황에서 보여주는 자리로 구분한다. 각각 별도 덱·별도 문법을 만들지 않는다.

도감은 인물 기록과 플레이 카드를 분리한다. 이전 WIZARD 해금 ID를 카드로 옮기지 않는다. 이번 4종의 이름·그림·효과는 학생의 학파나 직업을 뜻하지 않는다.

## 03. 카드 선택과 조합 문법

### 권장안: 순서보다 의미가 중요한 두 장 조합

한 교환에서 손패의 카드 인스턴스를 1장 또는 2장 선택한다. 첫 카드만 선택해도 시전 가능하다. 다른 두 종류를 고르면 정의된 조합으로 바뀐다. 순서를 뒤집어도 효과는 같다. 손패 위치가 주문 의미를 몰래 바꾸지 않는다.

같은 종류 두 장 조합은 이번 검토본에서 금지한다. 두 번째 카드에 사용 불가 이유를 표시하고, 첫 카드의 단독 주문은 그대로 유지한다. 3장 이상은 추가되지 않으며 마력도 소모하지 않는다. 자동 대체·자동 시전은 없다.

| 시험 카드 | 단독 효과 | 비교 역할 |
|---|---|---|
| 불씨 | 상대 결계에 공격 3 | 단순한 직접 공격 |
| 바람 | 공격 1 + 자신 방어 2 | 소규모 공방 |
| 막기 | 자신 방어 4 | 예고된 큰 공격 대비 |
| 모으기 | 공격 2 | 집중 조합의 재료도 되는 단독 행동 |

각 카드는 비용 1, 두 장 조합은 비용 2다. 이번 교환 예산은 2이며 교환 시작 때 2로 재설정한다. 남은 예산은 다음 교환에 쌓이지 않는다. 장기 마력 분배는 이 시험 규칙과 별개다.

정확한 조합 결과는 다음 페이지의 6개 정의만 사용한다. 자유 텍스트·생성형 AI·그림 인식으로 의미를 판단하지 않는다. 카드 이름과 주문 이름은 표시 텍스트이며 판정은 안정된 ID를 사용한다.

## 04. 조합 결과와 선택 이유

| 두 종류 | 설명용 주문 이름 | 시험 효과 | 고민이 달라지는 이유 |
|---|---|---|---|
| 불씨 + 바람 | 흩날리는 불씨 | 공격 3 + 이번 상대 공격 2 감소 | 단독 화력보다 지금 받을 위협을 줄임 |
| 불씨 + 막기 | 불씨의 장막 | 공격 2 + 자신 방어 3 | 공격과 생존을 절충 |
| 불씨 + 모으기 | 응축한 불씨 | 공격 5 | 상대 방어가 약한 순간에 집중 |
| 바람 + 막기 | 되돌리는 바람 | 방어 3 + 막은 양 중 최대 2를 반사 | 실제로 막아야 반사 발생. 무조건 추가 피해가 아님 |
| 바람 + 모으기 | 틈을 여는 바람 | 상대 방어 제거 후 공격 2 | 큰 숫자보다 방어가 있는 상황에 대응 |
| 막기 + 모으기 | 단단한 장막 | 방어 6 | 큰 공격을 넘기지만 상대 결계를 줄이지 않음 |

이름과 수치는 새 카드 원본 승인이 아니다. 대표 조합 중 공격 감소·실제 방어량 반사·방어 제거의 세 가지는 결과 의미가 다르도록 했다. 카드 이름만 바꾼 피해량 경쟁이 되는지 검증한다.

### 대상과 설명

이번 구간의 대상은 자신과 상대 한 명뿐이다. 공격은 상대, 방어는 자신으로 카드 정의에 명시한다. 사용자는 미리보기에서 두 대상을 확인하고 시전을 확정한다. 임의의 숨은 자동 타깃 선택이 아니라, 이 연습 카드가 허용하는 고정 대상 규칙을 화면에 공개하는 제안이다. 다중 대상 선택은 이후 별도 확장이다.

처음 등장하는 효과는 카드 상세에 한 문장으로 풀이한다. 미리보기는 '방어 제거 → 공격 → 반사 가능량'처럼 실제 처리 순서를 보여준다. 수치만 나열하지 않고 어떤 카드 때문에 바뀌었는지 표시한다.

## 05. 한 교환의 처리와 승패

### 예고 → 선택 → 확정 → 해소 → 다음 교환

1. 교환 시작: 예산을 2로 설정하고 손패를 4장까지 보충한다. 상대의 이번 공격과 방어를 공개한다.
2. 플레이어는 1~2장을 구성하고 결과를 확인한다. 읽기·카드 교체·취소에는 게임 시간이 흐르지 않는다.
3. 시전 또는 대기를 명시 확정한다. 시전한 카드만 버림 더미로 이동한다. 대기는 카드를 쓰지 않고 상대 행동을 받는다.
4. 양쪽의 이번 방어량을 먼저 설정한다. 그다음 방어 제거와 상대 공격 감소를 적용한다. 공격 감소 후 공격은 최소 0이다. 제거된 방어를 같은 교환에 다시 설정하지 않는다.
5. 양쪽 공격을 이번 방어로 막는다. 남는 양이 결계를 감소시킨다. 반사는 실제로 막은 양에서 계산하고 상대 방어에 다시 막히지 않는다.
6. 같은 교환의 결과를 모두 합친 뒤 승패를 판단한다. 결계는 0 미만으로 내려가지 않는다. 양쪽이 0이면 무승부다. 공격 중간에 상대가 0이 되어도 같은 교환의 공개된 행동은 취소하지 않는다.
7. 종료가 아니면 임시 방어·공격 감소·반사 표식을 모두 없애고 다음 교환으로 간다.

결계 16은 시험 시작값이다. 상대 결계만 0이면 승리, 자기만 0이면 패배. 점수 비교·2선승·서클 점유 승리는 이번 후보에 없다. 결계를 사건 위험 시계로 중복 표현하지 않는다.

### 손패와 덱 순환

쓰지 않은 손패는 보존한다. 부족한 만큼만 드로우한다. 뽑을 카드가 없으면 버림 더미를 섞어 다시 뽑고, 두 더미 모두 비면 가진 패만 사용한다. 저장된 난수 상태를 이어받아 재개가 새 추첨이 되지 않게 한다. 손패 교체를 위한 무료 전체 재뽑기는 없다.

플레이어가 매번 방어만 하거나 대기하면 승리가 늦어질 수 있다. 무한 반복을 시간 초과 패배로 숨기지 않고 연습 중단/재시작을 항상 제공한다. 장기전 탐지와 보상 악용은 별도 검증 항목이다. 이 구간에는 사용 횟수 기반 경험치가 없다.

## 06. 상대 행동·시계·복기

### 상대는 먼저 계획하고 화면으로 보여준다

초기 연습 상대는 고정 3교환 패턴을 반복한다. 이는 학습용이며 최종 AI가 아니다. 플레이어의 선택 패를 읽고 같은 교환에 행동을 바꾸지 않는다.

| 교환 패턴 | 상대 공격 | 상대 방어 | 학습 기회 |
|---|---|---|---|
| 견제 | 4 | 0 | 가벼운 대응과 직접 공격 비교 |
| 방어 준비 | 2 | 4 | 방어 제거와 단순 화력 비교 |
| 집중 공격 | 6 | 0 | 강한 방어·공격 감소·반사 비교 |

### 시계는 사건에서 선택적으로 사용

예시 검산: 방어 준비에 공격 5를 쓰면 결계 피해는 1, 방어 제거 후 공격 2를 쓰면 피해는 2다. 견제 공격 4를 방어 3/반사로 받으면 자신 피해 1, 상대 반사 피해 2다. 이 비교로 단순 화력과 조건부 대응이 실제로 달라지는지 확인한다.

연습 결투는 결계와 행동 예고만 표시한다. 모든 화면에 시계를 붙이지 않는다. 복잡한 실습 사건에서는 목표 진척과 위험을 별도 기록하고, 명시 행동에 게임 시간이 소모되면 위험이 증가하며 알맞은 효과로 완화되는 후보를 사용한다.

이는 실제 초가 흐르는 방식과 다르다. 행동 기반을 권장하지만 아직 새 세부 규칙 승인 전이며, 기존 '시간 경과' 의도를 조용히 바꾸지 않는다. 읽기·설정·앱 중단 때문에 패배하는 설계는 피한다. 시계의 총칸과 변화량은 사건별 선언값이며 결투 결계 16과 무관하다.

### 결과 화면

결과는 승패, 마지막 주문, 실제 막은 양/준 피해, 다음에 비교할 수 있는 선택을 보여준다. 정답 덱이나 최적 행동을 자동 지정하지 않는다. 연습 재도전과 이야기로 돌아가기를 제공하며, 승리 보상·이야기 진행은 결과 ID별 한 번만 반영한다. 패배 재연습을 반복해 보상을 복제할 수 없어야 한다.

## 07. 화면 와이어프레임과 입력

이 페이지는 정보 배치 설계다. 최종 게임 이미지·아트 방향·실행 화면이 아니다. 별도의 장식 이미지를 그려 대체하지 않는다.

| 화면 영역 | 좌측 | 중앙 | 우측 |
|---|---|---|---|
| 상단 | 내 결계 / 교환 예산 | 연습 목적 / 교환 번호 | 상대 결계 / 설정 |
| 상단 무대 | 내 학생 상반신 | 상대 이번 행동: 공격·방어 | 상대 학생 상반신 |
| 조합 영역 | 선택 카드 1 | 조합 이름 / 바뀐 효과 | 선택 카드 2 또는 추가 가능 안내 |
| 결과 예상 | 내가 받을 양 | 내가 줄 양 / 특수 효과 순서 | 사용 카드 수 / 비용 |
| 손패 | 카드 1 | 카드 2 / 카드 3 | 카드 4 |
| 하단 행동 | 선택 취소 / 카드 상세 | 대기 | 시전 |

기본 조작은 탭/클릭 선택과 해제다. 카드 상세와 시전 버튼은 분리한다. 카드 선택 직후 자동 시전하지 않는다. 드래그는 선택적 입력이며 동일한 선택 명령을 호출하도록 한다. 드래그 실패로 카드를 버리거나 마력을 쓰지 않는다.

### 상태별 UI 계약

| 상태 | 화면 피드백 | 가능한 행동 |
|---|---|---|
| 미선택 | 단독 사용 가능 안내, 시전 비활성 | 카드 선택·상세·대기 |
| 1장 | 단독 효과와 비용 | 시전·다른 종류 추가·해제 |
| 2장 | 완성 조합과 변경 이유 | 시전·개별 해제·취소 |
| 잘못된 추가 | 이유 표시, 기존 선택 유지 | 다른 카드 선택 |
| 해소 중 | 처리 중 표시, 중복 입력 잠금 | 연출 스킵·설정 |
| 앱 복귀 | 저장된 확정 결과 또는 미확정 구성 복원 | 중복 지급 없이 재개 |

1280×720은 현재 프로젝트 검사 기준이지 모바일 가독성 보증이 아니다. 실제 화면에서 손가락 가림·문자 크기·긴 한국어 이름·명암·포커스·가로 비율을 검사한다. 색만으로 사용 불가를 전달하지 않는다.

## 08. 이미지·모션 제작 명세

이전 이미지는 참고만 사용한다. 아래는 필요한 소비처를 지정한 신규 제작 목록이며 최종 승인 자산 목록이 아니다. 기능 글자와 수치는 이미지에 굽지 않는다.

| 필요한 자산 | 실제 소비처 | 필수 상태·분리 |
|---|---|---|
| 새 메인 배경 | 새게임/이어하기 진입 | 제목·메뉴·배경 분리. 빈 장식창 없음 |
| 연습 결투 배경 | 결투 무대 | 인물 없는 배경, 결과 효과 별도 |
| 학생 2명 상반신 | 자신/상대와 대화 | 기본·준비·시전·방어·결과·복귀. 동일 인물 유지 |
| 카드 공통 프레임 | 손패·선택·도감 | 기본·선택·사용 불가. 텍스트와 효과 영역 분리 |
| 카드 4종 대표 이미지 | 단독/조합 선택 | 작은 표시에서도 구분, 마법사 인물 카드 없음 |
| 조합·시전 효과 | 상태 변화의 피드백 | 준비·발동·접점·잔광, 배경과 독립 |

아트 후보는 먼저 결투 화면 한 장의 시각 방향과 정보 가림을 검토한 뒤 필요한 개별 자산으로 확장한다. 새 카드마다 수십 장씩 만들지 않는다. 학생 상반신의 나이 읽기와 의상 정체성을 먼저 확인한다.

### 모션 연결

선택 반응 → 두 카드 의미 연결 → 준비 포즈 → 확정된 주문 시전 → 공격/방어/반사 결과 → 복귀 순서다. 판정은 연출보다 먼저 확정하며, 포즈나 효과가 누락되어도 같은 결과로 끝나야 한다. 반사는 실제 판정된 반사량이 있을 때만 나온다.

새 창작 이미지는 이미지 모델로 제작한다. Aseprite는 필요 시 복사본의 레이어·프레임·시간·정렬과 내보내기에 사용한다. 픽셀 아트나 SD 이동을 자동 선택하지 않는다. 실제 상태군 처리 전 Aseprite의 기본 호출 성공을 모션 완성으로 취급하지 않는다.

자산별 원본·후보·승인·consumer·해시를 기록한다. 승인 전 후보는 runtime 정본으로 승격하지 않는다. 효과 OFF/ON, 약한 효과, 긴 텍스트, 밝고 어두운 배경에서 검수한다.

## 09. Godot 책임·저장·테스트 계약

현재 구현 재사용 가능성은 PARTIAL이다. 기존 AtomicResultLedger의 중복 방지 원리는 검토할 수 있으나, 그리기/별형 Coordinator를 새 결투에 그대로 연결하지 않는다. 미병합 #253의 CardDefinition·CardRuleset·StoryProgress는 비교 자료다.

| 책임 | 입력 | 출력·보호할 경계 |
|---|---|---|
| 카드/조합 정의 | 안정된 ID, 단독 효과, 조합 표 | 표시 이름과 판정 분리. WIZARD 제외 |
| 선택·미리보기 | 손패 인스턴스와 상대 공개 행동 | 무변경 예상 결과. 같은 정의를 확정에서도 사용 |
| 교환 해소 | command ID, 선택, state revision | 카드·예산·결계·버림·결과를 한 번 반영 |
| 연출 | 이미 확정된 결과 | 결과를 보여줌. 보상·피해 계산 금지 |
| 이야기 진행 | 최종 결과 ID | 진행·보상 한 번. 재연습의 중복 지급 금지 |

Resource는 카드의 고정 정의를 담고, 가변 손패·결계·덱·난수·처리된 명령은 매치 상태로 분리하는 안을 권장한다. 저장 버전을 새로 구분하고 기존 저장을 덮어쓰지 않는다. 잘못된 버전은 오류 이유와 안전한 진입을 제공한다.

### 구현 전 검증해야 할 사례

정상: 4개 단독 효과, 6개 다른 종류 조합, 역순 동일 결과, 버림 재순환, 미사용 카드 보존. 오류: 같은 종류 추가, 3번째 추가, 오래된 상태에서 확정, 없는 카드 ID, 비용 부족. 경계: 방어 초과 공격, 반사 0, 동시 결계 0, 드로우할 카드 없음.

복구: 미리보기 중 앱 종료, 확정 직후 종료, 연출 스킵, 결과 화면 재진입, 동일 command ID 재전송. 모든 경우 카드·피해·보상 중복 적용이 없어야 한다. 완성된 시전의 카드를 되살리는 취소는 금지한다.

첫 구현의 완료 기준은 자동 테스트와 Godot 실제 입력·화면 확인을 각각 기록하는 것이다. 사람의 재미·기기 가독성·성능·출시 판정은 별도다. 현재 이 새 규칙의 구현 및 테스트는 NOT_RUN이다.
