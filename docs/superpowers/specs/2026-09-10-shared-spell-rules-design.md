상태: SPECIFIED_RECOMMENDED_BASELINE / IMPLEMENTATION_NOT_RUN / HUMAN_NOT_RUN.
사용자 승인 방향: 글자를 조합해 주문 시전, 결투 밖 무작위 손패 없음, 실습·온실·축제에도 같은 마법 사용. 사용자 `세부규칙은 네가 권장안대로 잡아줘`에 따른 설계 기준이며 수치·재미의 최종 검증이나 구현 승인이 아니다.

## 1. 경험과 경계

마법학교 학생이 배운 글자의 작용을 이해하고, 같은 주문을 다른 대상과 환경에 응용한다. 카드는 선택 도구이지 세계 전체가 카드게임이라는 설정이 아니다. 주문은 자유 텍스트·생성형 AI·필기 인식으로 판정하지 않는다. 마법사 종류 카드·별형 회로·체스·SD 이동을 재도입하지 않는다.

관찰 → 글자 1~2개 선택 → 주문 작용 확인 → 대상·방향 지정 → 비용·예상 변화 확인 → 명시 시전 → 변화·대가·복기.

비교: 모든 사건의 카드대결화 REJECT, 별도 생활마법 문법 REJECT, 공통 작용+상황별 판정 ADOPT. 어려움은 반응속도보다 대상 선택·상태 이해·자원 사용에서 만든다. 일상·수업은 낮은 압박, 실습은 제한된 위험, 결투는 대응, 축제는 응용과 이야기 결과를 담당한다. 활동은 스토리로 연결하며 메인 메뉴의 독립 모드 선택으로 바꾸지 않는다.

## 2. 입문 문법

- 배운 글자 하나는 단독 주문이다. 다른 두 글자는 조합 주문이다. 선택 순서는 결과를 바꾸지 않는다. 조합 이름은 고정 표시 사전으로 제공한다.
- 같은 글자 중복과 세 번째 글자는 입문 규칙에서 받지 않는다. 기존 선택을 유지하고 이유를 알린다. 이는 장기 전체 마법의 영구 한계가 아니라 첫 세션 규격이다.
- 배우지 않은 글자, 정의되지 않은 조합은 시전 불가다. 비용·시간을 쓰지 않는다. 미학습 조합도 구성 글자를 배웠고 정의가 있으면 미리보기·사용 가능하다. 도감 발견은 첫 사용에 한 번 기록한다.
- 초반에는 위력 슬라이더·별도 조준 기술·실패 확률을 넣지 않는다. 단독 비용 1, 조합 비용 2, 모든 기본 시전 시간 1행동을 시험값으로 둔다. 두 글자가 항상 상위호환이 아니라 작용을 바꾼다.
- 기본 대상은 한 개다. 방향이 필요한 주문만 화면에 명시된 목적지 한 개를 추가한다. 자동 최적 대상·자동 시전 없음. 좁은 범위 주문은 미리 정의된 영역 하나를 대상으로 하며 모든 물체의 자유 물리 시뮬레이션을 약속하지 않는다.

## 3. 첫 글자와 주문 사전

기존 네 ID를 비교 가능한 어휘로 사용하되 아래 의미는 새 설계다. 기존 attack 숫자를 공통 의미로 승계하지 않는다. 명칭은 한국어 표시, ID는 안정 식별자다.

| ID / 글자 | 기본 작용 | 할 수 없는 일 |
|---|---|---|
| EMBER / 불씨 | 선택 지점에 작은 열을 준다 | 냉각·소화·무조건 살균 |
| WIND / 바람 | 가벼운 대상이나 공기를 지정 방향으로 민다 | 무거운 물체 무제한 운반 |
| WARD / 막기 | 경계 하나에서 유입·통과를 잠시 차단한다 | 이미 생긴 오염이나 손상 삭제 |
| GATHER / 모으기 | 흩어진 가벼운 물질·마력을 한 지점에 모은다 | 성질이 다른 물질의 자동 분리·정화 |

| 조합 / 설명용 이름 | 일관된 작용 | 사용 조건·대가 |
|---|---|---|
| 불씨+바람 / 온기 흐름 | 열을 기류로 좁은 영역에 전달 | 마른 물질·휘발성 대상은 과열·확산 경고 |
| 불씨+막기 / 온기 장막 | 경계 안의 열이 빠져나가는 것을 억제 | 새 열을 무한 생성하지 않음. 과열도 가둘 수 있음 |
| 불씨+모으기 / 응축 불씨 | 작은 지점에 열을 집중 | 넓은 영역 처리 불가, 민감한 대상 손상 위험 |
| 바람+막기 / 흐름 전환 | 지정 경계에서 들어오는 기류·가벼운 투사 흐름을 돌림 | 고정 장벽 관통·모든 공격 반사 아님 |
| 바람+모으기 / 모으는 바람 | 흩어진 가벼운 물질을 지정 수용점으로 운반 | 수용점이 열려 있거나 포화되면 재확산 가능 |
| 막기+모으기 / 봉합 장막 | 작은 누출 지점의 마력을 모아 경계를 봉합 | 원인이 남아 있는 큰 누출의 영구 수리 아님 |

단독 4개+조합 6개 모두 대상 적합성·범위·지속·상태 반응을 갖는다. 구현 시 레시피별 예외 문장을 난립시키지 않고 작용 ID와 조건으로 판정한다. `열 민감`, `가벼움`, `기류 이동 가능`, `누출`, `닫힌 수용점` 등의 의미를 콘텐츠에서 선언한다. 화면에 없는 성질로 즉시 큰 손실을 주지 않는다.

## 4. 사건에서 사용 가능한 글자와 마력

배운 글자 전체에서 선택한다. 즐겨찾기는 탐색 편의이며 장착 제한이 아니다. 손패·드로우·버림·글자 영구 소모 없음. 기본 글자는 시전해도 잊지 않는다. 별도 소모품은 이번 규칙 밖이다.

첫 실습의 마력 예산은 6을 시험값으로 둔다. 임무 시작 시 현재 예산과 회복 조건을 안내한다. 사건 중 자동 회복·메뉴 재진입 회복 없음. 마력이 부족하면 해당 주문만 비활성화하고 일반 행동·도움 요청·안전 중단을 제공한다. 휴식은 안전한 스토리 지점에서만 회복한다. 재연습은 결과 확정 후 별도 시도 ID로 초기화하고 보상·발견을 중복 지급하지 않는다. 초기 마력 6은 장기 성장 최대치나 하루 전체 예산을 확정하지 않는다. 7/7/6과 마력20은 고정 규칙이 아니다.

일반 행동도 타당하면 상황을 바꾼다. 예: 수동으로 덮개 닫기, 장치 조작, 교수에게 도움 요청. 마법을 안 쓰는 선택을 무조건 열등하게 만들지 않는다. 도움은 진행 교착을 해소하되 학생이 독립 해결했다는 평가로 기록하지 않는다.

## 5. 시간·판정·미리보기

읽기·기본 관찰·선택·상세·취소·설정·앱 중단에는 시간과 마력을 쓰지 않는다. 새 정보를 얻는 정밀 조사와 실제 장치 조작은 비용을 표시한 행동이다. 이미 확인한 정보 다시 읽기는 무료다. 이 구분은 화면 문구로 공개한다.

기본 결과는 결정적이다. 같은 규칙 버전·상태·대상·주문은 같은 결과다. 숨은 주사위로 맞는 접근을 실패시키지 않는다. 모르는 대상은 성질 미확인과 가능한 위험 범위를 표시하며 초반 필수 해결 정보는 무료 관찰로 제공한다. 무효 대상은 시전 전 차단, 유효하지만 역효과인 대상은 경고 후 명시 시전 가능이다.

미리보기: 주문의 작용, 대상, 마력 비용, 시간 비용, 확인된 변화, 불확실성, 위험 변화의 원인을 분리한다. 조사하지 않은 사실이나 최적 해답을 미리보기가 누설하지 않는다. 해소기는 완전한 상태를 읽고, 미리보기 표시만 발견 정보에 따라 제한한다.

시전 명령 검증 → 비용 지불 → 주문/일반행동 효과와 지속 상태 적용 → 시간 경과에 따른 위험 변화 → 범위 보정 → 목표·위험 동시 판정 → 결과 영수증 저장. 중복 입력은 같은 영수증을 반환하고 재소비하지 않는다. 오래된 상태에서의 명령은 무소비 거절 후 미리보기를 갱신한다. 연출은 결과를 보여줄 뿐 판정하지 않는다.

## 6. 사건 시계

첫 복합 사건은 위험 시계 하나를 기본으로 하고 목표는 명확한 상태 조건으로 표현한다. 여러 단계의 노력이 정말 필요한 사건만 별도 목표 시계를 추가한다. 단순 실습에는 시계를 쓰지 않는다.

- 위험 칸수 기본 후보: 4/6/8, 사건이 직접 선택. 0은 당장 위험이 없다는 뜻이지 자동 해결이 아니다.
- 기본식: 새 위험 = clamp(기존 위험 + 행동 대가 + 시간 증가 - 완화, 0, 총칸).
- 시간 증가와 완화는 같은 행동에 모두 일어날 수 있다. 표시도 `시간 +1 / 수집 -2 / 합계 -1`로 구분한다.
- 위험 증가율은 사건 상태에 종속한다. 원인을 차단했으면 그 원인의 증가가 멈춘다. 특정 주문 사용 자체가 시계를 내리는 만능 열쇠는 아니다.
- 임시 장막은 생성 행동의 시간 처리와 다음 시간 소비 행동까지 유효하다. 재시전은 남은 시간을 갱신할 뿐 중첩하지 않는다. 지속을 종료할 때 추가 시간이 들지 않으며, 종료가 위험 변화를 유발하면 미리 알린다.
- 위험이 다 차면 해당 사건의 선언된 결과로 전환한다. 초반 학교 실습은 교수 개입·시설 폐쇄·일부 재료 손실 등으로 이어지며 영구 진행 불가를 만들지 않는다.
- 목표와 위험이 같은 행동에 완료되면 성취와 대가를 함께 기록한다. 위험 결과가 목표 성공을 취소하지 않는다.
- 목표 시계가 있는 경우 표준 진척 2, 제한 1, 큰 효과 3을 시험 범위로 둔다. 환경이 요구하는 적합성에 따라 정하며 글자 개수가 자동 진척량은 아니다. 이미 처리한 대상을 반복해 진척을 복제하지 않는다.

## 7. 네 가지 사용 예와 검산

### 수업 실습: 같은 작용의 학습

찬 물이 든 실습 용기와 열에 약한 표본을 구별한다. 용기에 불씨를 사용하면 가열 상태가 된다. 표본에 사용하면 손상 경고다. 시간 압박·확률 판정 없음. 정답 조합 강제 대신 대상의 성질을 읽는 것을 배운다. 완료 조건은 용기 가열이며 재가열로 보상을 반복하지 않는다.

### 온실: 첫 실습 사건의 예시, 메인 줄거리 아님

원인: 새는 꽃가루 장치. 시작 위험2/6, 누출 중 시간행동마다 +1. 목표는 누출 차단 AND 부유 꽃가루 제거. 닫힌 수집함은 무료 관찰로 확인 가능. 마력6.

| 행동 | 사건 상태 변화 | 위험 계산 | 남은 마력 |
|---|---|---|---:|
| 모으는 바람 → 수집함 | 현재 부유 꽃가루 제거, 누출은 계속 | 2+1-2=1 | 4 |
| 장치 덮개 수동 닫기 | 누출 차단, 첫 행동 말에 다시 생긴 꽃가루는 남음 | 1+0=1 | 4 |
| 모으는 바람 → 수집함 | 잔여 꽃가루 제거, 목표 달성 | max(0,1+0-2)=0 | 2 |

다른 타당한 경로: 먼저 덮개 닫기(위험2 유지) → 모으는 바람(2-2=0), 마력4 남김. 무료 관찰을 활용한 순서가 효율적이어도 첫 경로도 해결 가능하다. 모든 경로가 동등할 필요는 없다.
모으는 바람만 반복하면 누출이 계속되어 목표가 안 끝나고 마력이 소진된다. 꽃가루가 없는 상태에는 제거량0, 가득 찬 수집함에는 운반 불가를 표시한다. 원인 해결 없는 영구 안전 반복을 보상하지 않는다. 최종 장면에서는 여러 해결 경로의 재료·시간 차이를 추가 검토한다.

### 축제: 연출과 안전의 응용

가벼운 종이 장식을 바람으로 이동하고 모으는 바람으로 지정 위치에 모은다. 막기는 관객 쪽으로 넘어가는 흐름을 임시 차단한다. 불씨는 조명용 내열 용기에만 안전하며 종이에는 경고한다. 기본 공연은 목표 조건으로 평가하고, 시간제 공연에만 별도 마감 시계를 둔다. 품질은 안전·배치 등 공개 기준으로 평가하며 주문 횟수를 점수로 바꾸지 않는다. 공연 내용·점수·보상은 별도 콘텐츠 작업이다.

### 결투: 같은 작용, 제한된 가용 글자

손패4, 각 글자2개인 시험 덱8, 1~2장 선택, 교환 예산2, 미사용 손패 보존/사용분 버림/부족분 보충을 입문 후보로 유지한다. 예산은 빠르게 제어할 수 있는 마력의 교환 한도로 표시하며 사건 마력 잔량과 혼동하지 않는다. 예산2는 장기 마력20을 7/7/6으로 분배한 규칙이 아니다.
상대 예고 → 선택·명시 시전 → 동시 해소 → 승패 확인의 구조와 결계16 시험값은 비교용으로 유지한다. 단독 모으기에 무조건 공격2, 모으는 바람에 모든 방어 제거, 흐름 전환에 모든 공격 반사를 부여하지 않는다. 대상의 `흐름 전환 가능` 같은 성질에 맞을 때만 대응 효과가 생긴다. 정확한 공격·방어 변환표와 상대 패턴 재밸런싱은 다음 결투 명세에서 작성하며, 기존 코드가 새 공통 의미를 구현했다고 주장하지 않는다.

## 8. 구조·구현 가능성과 복구

현재 `src/core/card_duel/duel_rules.gd`는 4단독/6조합을 공격·방어 배열로 반환한다. `duel_match.gd`는 손패와 결계, 명령 중복 방지, revision, 난수 상태를 소유한다. 공통 작용·대상 성질·사건 상태는 이 코드에 없다. 구현 가능성 PARTIAL, 새 공통 시스템 runtime NOT_RUN.

권장 책임: 글자/주문 고정 정의(Resource) → 순수 주문 구성기 → 상황 해소기(사건/결투) → 한 번의 상태 반영 → UI/연출. UI는 글자 선택·대상 선택·미리보기·명시 시전을 공유하되 결투만 손패를 공급한다. 하나의 거대한 만능 해소기나 사건마다 별도 글자 사전은 만들지 않는다. 초반에는 정의된 성질·작용만 지원한다.

저장에는 schema/rules version, 배운 글자, 사건 대상 상태, 마력, 시계, 남은 지속행동, 발견 정보, 처리 명령/결과 ID를 담는다. 결투는 추가로 덱·손패·난수 상태를 담는다. 이전 `GRIMOIRE_CARD_DUEL_1` 저장을 묵시 변환하지 않는다. 새 저장 슬롯/버전으로 시작하고 구버전은 보존·설명한다. 확정 직후 종료·연출 스킵·결과 재진입이 소비나 보상을 바꾸면 안 된다.

기존 코드·PDF·승인 이미지·미병합 PR은 삭제하지 않는다. 롤백은 새 규칙 버전의 사용을 멈추고 기존 저장을 그대로 유지하는 방식이다. 클라우드·유료 도구·신규 그림·Base 계약 업그레이드 불필요.
