# Frostbloom Greenhouse Route Patterns and Pre-Cast Guidance Design

## 1. 문서 상태

```yaml
project: "GRIMOIRE: 세계를 다시 쓰는 법"
decision_id: GM-NARRATIVE-MULTI-SOLUTION-SITUATION-01
status: USER_APPROVED_ROUTE_PATTERN_AND_GUIDANCE_DESIGN
approved_at: 2026-08-04T06:43+09:00
representative_situation: FROSTBLOOM_GREENHOUSE_HEART
work_mode: GPT_CREATIVE_PLANNING
implementation: NOT_STARTED
codex: DEFERRED
counter_increment: false
grill_counter: 2_of_10
```

이 문서는 `서리꽃 온실의 심장`의 다섯 해결 접근마다 네 개의 유효 주문 활용 패턴을 준비하고, 플레이어가 주문을 쓰기 전에 등장인물 대화와 예상 효과 설명으로 방향성을 참고할 수 있게 하는 설계를 정의한다.

핵심 계약:

```text
텍스트 선택 = 해결 의도와 우선순위
대화 힌트 = 관찰된 사실과 위험 관점
예상 효과 = 선택한 설계의 방향성·대가 미리보기
주문 설계 = 실제 실행 방법
```

대화와 예상 효과는 정답 조합을 직접 말하거나 성공을 보장하지 않는다.

## 2. 학습 범위

Vertical Slice 현장실습 전까지 플레이어가 사용할 수 있는 글자는 다음으로 제한한다.

```yaml
main_glyph: 흐름
support_glyphs:
  - 집중
  - 분산
safe_grammar: 메인 1 + 보조 0~1
```

의미:

- `흐름`: 이미 존재하는 마력·냉기·온기·공기·물의 이동 경로를 바꾼다.
- `흐름 + 집중`: 한 대상·한 경로로 빠르고 강하게 모은다. 과압·역류·국부 손상 위험이 커진다.
- `흐름 + 분산`: 여러 대상·넓은 구역으로 나눈다. 안전하지만 느리고 출력이 약해질 수 있다.

금지:

- 무에서 물질·열·마력을 생성한다.
- `열·보호·이동·감지·안정·고정` 등 아직 배우지 않은 글자의 효과를 숨겨서 제공한다.
- 환경 장치나 소환수의 행동을 주문 글자 효과처럼 위장한다.

## 3. 해결 패턴 계약

```yaml
approaches: 5
solution_patterns_per_approach: 4
total_reference_patterns: 20
explicit_answer_menu: false
backend_validation_patterns: true
reasonable_unlisted_solution: MAP_TO_NEAREST_MEANING_AND_EVALUATE
```

20개 패턴은 플레이어에게 정답 목록으로 노출하지 않는다. 게임이 유효한 결과를 판정하고 설명하기 위한 대표 패턴이다.

공통 판정 구조:

```yaml
solution_pattern:
  selected_approach: 해결 의도
  source_flow: 이동시킬 기존 현상
  target: 보낼 대상 또는 공간
  path: 직접 / 우회 / 순환 / 역방향 / 다중분기
  support_glyph: 없음 / 집중 / 분산
  helper: 없음 / 동반 정령 / 수호 소환수 / 인물의 물리 조작
  prerequisite_clue: 조사로 발견한 사실
  primary_effect: 기대하는 변화
  main_cost: 남는 피해·위험·시간·관계 변화
```

## 4. 루트별 유효 패턴

### A. 시설 복구

#### A1. 비상 마력 우회 점화
- 주문: `흐름 + 집중`
- 출발: 비상 마력 저장조
- 목표: 중심 핵의 온전한 보조 입력구
- 효과: 핵을 빠르게 재점화한다.
- 조건: 유지보수 도면 또는 보조 입력구 발견.
- 대가: 배관 압력을 먼저 낮추지 않으면 역류·파열 위험.

#### A2. 배관 압력 평형
- 주문: `흐름`
- 출발: 고압 결빙 배관
- 목표: 저압 회수 배관
- 효과: 냉기 마력 압력을 천천히 평형화한다.
- 보조: 관리 학생이 수동 밸브를 연다.
- 대가: 안전하지만 구조와 복구가 늦어진다.

#### A3. 온수 관개로 정밀 해빙
- 주문: `흐름 + 집중`
- 출발: 온수 관개 순환로
- 목표: 결빙된 핵심 배관 외벽
- 효과: 이미 존재하는 온수를 결빙 지점에 모아 해빙한다.
- 대가: 묘목에 공급할 온수가 부족해진다.

#### A4. 온실 전체 완만 해빙
- 주문: `흐름 + 분산`
- 출발: 본관의 따뜻한 환기 통로
- 목표: 온실 배관망 전체
- 효과: 넓은 구역의 결빙을 서서히 완화한다.
- 대가: 국부 파열 위험은 낮지만 고립 학생의 위험 시간이 길어진다.

### B. 생명 구조 우선

#### B1. 온기 탈출 통로
- 주문: `흐름 + 집중`
- 출발: 따뜻한 환기 통로
- 목표: 학생까지 이어지는 좁은 경로
- 효과: 학생이 걸어서 탈출할 수 있는 임시 온기 통로를 만든다.
- 대가: 통로 밖 묘목과 시설은 계속 얼어간다.

#### B2. 냉기 우회로 개방
- 주문: `흐름 + 집중`
- 출발: 탈출로를 가로막는 냉기 흐름
- 목표: 빈 상부 배기구
- 효과: 냉기를 다른 방향으로 빼내어 길을 연다.
- 대가: 지붕 정원 또는 외부 시설에 냉기 피해가 발생할 수 있다.

#### B3. 학생·묘목 광역 보온
- 주문: `흐름 + 분산`
- 출발: 따뜻한 환기 통로
- 목표: 학생과 핵심 묘목 구역
- 효과: 두 보호 대상에게 생존 시간을 제공한다.
- 대가: 완전한 구조·복구는 되지 않아 후속 지원이 필요하다.

#### B4. 뿌리 보온과 동반 정령 길 안내
- 주문: `흐름`
- 출발: 온수 관개수
- 목표: 희귀 묘목의 뿌리 구역
- 보조: 동반 정령이 학생에게 안전 경로를 안내한다.
- 효과: 묘목의 동사를 늦추면서 학생이 스스로 탈출한다.
- 대가: 시설은 사실상 포기하고 학생 이동 실패 위험이 남는다.

### C. 정령 안정화·교섭

#### C1. 과잉 냉기 추출
- 주문: `흐름 + 집중`
- 출발: 가장 불안정한 정령이 흡수한 냉기
- 목표: 빈 완충 결정
- 효과: 한 정령의 과부하를 빠르게 낮춘다.
- 대가: 대상을 잘못 고르면 정령에게 고통과 불신을 준다.

#### C2. 정령 무리의 마력 평형
- 주문: `흐름 + 분산`
- 출발: 과부하된 정령들의 냉기
- 목표: 정령 무리와 빈 서리꽃 화단
- 효과: 무리 전체의 폭주를 완만하게 낮춘다.
- 대가: 빈 화단이 얼어붙고 시간이 오래 걸린다.

#### C3. 안정된 냉기 순환로
- 주문: `흐름`
- 출발: 배관에서 새는 냉기
- 경로: 정령 무리
- 목표: 저압 회수 배관
- 효과: 정령이 한꺼번에 삼키지 않도록 냉기를 일정하게 순환시킨다.
- 대가: 순환이 끊기면 다시 폭주한다.

#### C4. 냉기 흔적 역추적
- 주문: `흐름 + 집중`
- 출발: 정령이 흘린 서리 마력
- 목표: 냉기가 유입된 반대 방향
- 효과: 기존 흔적을 역방향으로 밀어 균열 위치를 드러낸다.
- 대가: 냉기가 잠시 균열에 몰려 파열 위험이 높아진다.

### D. 현상 봉쇄

#### D1. 내부 폐쇄 순환
- 주문: `흐름`
- 출발: 누출 냉기
- 경로: 온실 내부 순환관
- 목표: 저압 회수관
- 효과: 냉기가 학교 외부로 퍼지는 것을 막는다.
- 대가: 온실 내부 위험은 계속 높아진다.

#### D2. 비상 배기탑 집중 방출
- 주문: `흐름 + 집중`
- 출발: 온실 내부 냉기
- 목표: 비상 배기탑
- 효과: 냉기를 빠르게 외부로 방출한다.
- 대가: 지붕 정원과 외부 시설에 냉기 피해를 전가한다.

#### D3. 완충 구역 분산 저장
- 주문: `흐름 + 분산`
- 출발: 냉기 누출
- 목표: 빈 화단·완충 결정·사용하지 않는 배관
- 효과: 한 지점의 임계치를 낮춰 파열을 막는다.
- 대가: 온실 여러 구역에 작은 피해가 남는다.

#### D4. 생존 구역 우회 공급
- 주문: `흐름 + 집중`
- 출발: 남은 온기와 마력
- 목표: 학생·희귀 묘목이 있는 안전 구획
- 보조: 관리 학생이 수동 격벽을 닫는다.
- 효과: 제한된 자원을 핵심 구역에만 공급한다.
- 대가: 나머지 온실 구역을 명시적으로 포기한다.

### E. 전투·강제 제압

#### E1. 집중 기류 밀어내기
- 주문: `흐름 + 집중`
- 출발: 환기 덕트의 공기 흐름
- 목표: 접근하는 정령 전면
- 효과: 정령을 학생과 배관에서 밀어내어 시간을 번다.
- 대가: 정령이 플레이어를 위협으로 인식한다.

#### E2. 냉기 공급선 차단
- 주문: `흐름 + 집중`
- 출발: 정령에게 흘러가는 누출 냉기
- 목표: 완충 결정 또는 회수 배관
- 효과: 정령을 공격하지 않고 폭주 동력을 약화한다.
- 대가: 너무 급격히 끊으면 정령이 반발한다.

#### E3. 냉기 공격 분산
- 주문: `흐름 + 분산`
- 출발: 정령이 발사한 냉기 흐름
- 목표: 피해가 적은 여러 방향
- 효과: 한 번의 공격 피해를 낮추고 작성 시간을 확보한다.
- 대가: 온실 여러 구역에 약한 냉기 피해가 누적된다.

#### E4. 수호 소환수 유인·순환 포위
- 주문: `흐름`
- 출발: 정령이 타고 이동하는 마력 기류
- 경로: 수호 소환수가 지키는 빈 화단
- 보조: 수호 소환수의 견제와 수동 격벽 폐쇄
- 효과: 정령을 해치지 않고 빈 구획에 몰아넣는다.
- 대가: 소환수의 방어 자원을 소비하고 정령 관계가 나빠진다.

## 5. 주문 전 힌트 구조

### 5.1 채택안: 대화 + 예상 효과 혼합형

```text
접근 선택
→ 관련 인물의 짧은 관점 대화
→ 선택 가능한 흐름·목표 확인
→ 플레이어가 주문 초안 구성
→ 예상 효과 카드 표시
→ 수정 또는 시전
```

대화는 세계와 인물의 관점을 통해 정보를 제공한다. 예상 효과 카드는 플레이어가 만든 주문 초안의 방향성과 위험을 구조적으로 정리한다.

### 5.2 힌트 층

#### 층 1 — 환경 단서
- 얼음이 퍼지는 방향
- 압력계 진동
- 환기구의 따뜻한 바람
- 정령이 특정 맥동에 반응하는 모습
- 온수 관개관의 잔열

플레이어가 직접 보고 판단하는 기본 정보다.

#### 층 2 — 등장인물 대화

등장인물은 정답 조합이 아니라 서로 다른 관점을 제시한다.

- 교수 또는 통신 지도자: 원리·안전·책임.
- 관리 학생: 시설 구조·밸브·배관·현장 상태.
- 경쟁 학생: 속도·효율·즉시 행동의 장점과 위험.
- 메인 동반 정령: 감각·정령의 반응·숨은 정서적 상태.
- 고립 학생: 내부에서만 보이는 통로와 긴급 상태.

한 인물이 모든 정보를 독점하지 않는다. 필수 생존 정보는 기본 관찰 또는 둘 이상의 경로로 얻을 수 있다.

#### 층 3 — 예상 효과 카드

플레이어가 출발 흐름·목표·경로·보조 글자를 선택하면 다음을 표시한다.

```yaml
preview:
  primary_effect: 가장 가능성 높은 직접 변화
  speed: 빠름 / 보통 / 느림
  scope: 단일 / 좁은 경로 / 다중 대상 / 넓은 구역
  pressure_change: 상승 / 유지 / 하락 / 불명
  likely_benefit: 보호하거나 개선할 대상
  main_risk: 가장 큰 대가 또는 실패 원인
  unresolved_problem: 이 주문으로 해결되지 않는 문제
  confidence: 높음 / 보통 / 낮음
```

표시는 성공 확률·정답 여부·최종 결말을 제공하지 않는다.

## 6. 대화 힌트 작성 규칙

좋은 힌트:

> 관리 학생: “핵의 보조 입력구는 살아 있어. 다만 저 압력을 먼저 빼지 않으면 안쪽에서 역류할 거야.”

이 문장은 `비상 마력 우회 점화` 가능성과 선행 위험을 알려주지만 주문 조합을 직접 지시하지 않는다.

> 동반 정령: “저 아이들은 우리를 노리는 게 아니야. 배관이 울릴 때마다 몸 안의 서리가 더 밝아져.”

이 문장은 정령과 누출 냉기의 관계를 암시한다.

> 경쟁 학생: “한곳으로 몰면 빨리 끝나겠지만, 그 힘을 받을 출구가 있는지는 확인해야 해.”

이 문장은 `집중`의 속도와 과압 위험을 함께 알려준다.

나쁜 힌트:

- “정답은 흐름+집중이야.”
- “A1 패턴을 사용해.”
- “이 선택은 완전 성공 엔딩으로 이어져.”
- “정령을 도와주는 선택이 착한 선택이야.”

### 6.1 대화의 기능 제한

한 대사는 다음 중 최대 두 가지만 전달한다.

- 사용 가능한 출발 흐름
- 연결 가능한 목표
- 경로 또는 장치 정보
- 시간 압박
- 과압·역류·광역 피해 위험
- 아직 해결되지 않을 대상
- 정령이나 인물의 관점

한 대사에서 출발점·목표·글자 조합·결말을 모두 말하지 않는다.

---

## 7. 예상 효과 카드 예시

### 예시 A — 시설 복구

플레이어 초안:

```text
비상 마력 저장조 → 중심 핵 보조 입력구
흐름 + 집중
```

표시:

```yaml
primary_effect: 중심 핵에 마력을 빠르게 공급할 가능성이 높다.
speed: 빠름
scope: 단일 경로
pressure_change: 보조 입력구 압력 상승
likely_benefit: 난방 핵 재가동
main_risk: 주 배관 압력이 남아 있으면 역류할 수 있다.
unresolved_problem: 고립 학생과 정령은 즉시 보호되지 않는다.
confidence: 높음
```

### 예시 B — 생명 구조

플레이어 초안:

```text
따뜻한 환기 통로 → 학생과 묘목 구역
흐름 + 분산
```

표시:

```yaml
primary_effect: 온기를 두 구역에 나누어 생존 시간을 늘릴 수 있다.
speed: 느림
scope: 다중 대상
pressure_change: 큰 변화 없음
likely_benefit: 학생과 묘목의 동결 지연
main_risk: 어느 쪽도 완전히 해빙되지 않을 수 있다.
unresolved_problem: 중심 핵과 배관 균열은 그대로 남는다.
confidence: 보통
```

### 예시 C — 정령 교섭

플레이어 초안:

```text
정령 내부의 과잉 냉기 → 빈 완충 결정
흐름 + 집중
```

표시:

```yaml
primary_effect: 선택한 정령의 과부하를 빠르게 낮출 수 있다.
speed: 빠름
scope: 단일 대상
pressure_change: 완충 결정 압력 상승
likely_benefit: 정령 안정화와 대화 가능성
main_risk: 과부하 대상을 잘못 판단하면 고통을 줄 수 있다.
unresolved_problem: 배관 누출은 계속된다.
confidence: 조사 정보에 따라 보통 또는 높음
```

## 8. 힌트 강도와 조사 연동

예상 효과의 `confidence`는 조사 결과에 따라 달라진다.

```text
정보 없음
→ 효과 방향만 표시, 위험 다수 불명

기본 관찰 완료
→ 출발 흐름·목표의 존재 확인

관련 인물 대화 또는 현장 조사 완료
→ 주요 위험과 unresolved problem 공개

핵심 원인 발견
→ 높은 확신의 인과 미리보기 제공
```

낮은 확신을 실패 확률로 오해하지 않도록 다음 문구를 사용한다.

- `확인한 정보가 부족합니다.`
- `이 경로의 출구 상태를 알 수 없습니다.`
- `정령이 냉기를 얼마나 흡수했는지 불명확합니다.`

숫자 성공률은 표시하지 않는다.

---

## 9. 시간 압박과 읽기 접근성

텍스트 노벨 대화와 예상 효과를 읽는 동안 실시간 전투 타이머는 진행하지 않는다.

```text
대화·조사 선택·예상 효과 확인 = 판단 정지 구간
주문 작성 시작 이후 = 사건별 시간 규칙 적용
시전·결과 해결 = 정지
```

이유:

- 읽기 속도와 접근성 차이를 처벌하지 않는다.
- 힌트를 읽지 않고 빠르게 넘기는 것이 최적 전략이 되는 것을 막는다.
- 긴급성은 선택 가능한 행동 수·사건 상태 변화·대사 연출로 표현한다.

같은 대사는 다시 확인할 수 있으며 반복 확인에 자원 페널티를 주지 않는다.

---

## 10. UI 정보 예산

주문 직전 화면에는 다음만 고정 표시한다.

1. 현재 해결 의도
2. 확인한 출발 흐름
3. 선택한 목표
4. 선택한 글자 `흐름 / 집중 / 분산`
5. 예상 효과 1줄
6. 주요 위험 1줄
7. 해결되지 않는 문제 1줄

세부 인물 대화와 조사 기록은 접을 수 있는 로그에서 다시 확인한다.

색상만으로 위험과 이득을 구분하지 않는다. 텍스트·아이콘·형태를 함께 사용한다.

## 11. 적대적 검토

### 위험 1 — 힌트가 사실상 정답을 말함
대응:
- 인물은 원리·사실·위험만 말한다.
- 예상 효과는 성공 여부가 아닌 방향성과 대가를 표시한다.
- 최종 결말과 점수는 숨긴다.

### 위험 2 — 대화를 전부 읽어야만 유일 해법을 알 수 있음
대응:
- 기본 관찰만으로 안전한 해결책 최소 하나를 제공한다.
- 핵심 생존 정보는 두 경로 이상에서 얻을 수 있다.
- 관계 선택 하나가 필수 정보를 독점하지 않는다.

### 위험 3 — `집중`이 항상 좋아 보임
대응:
- 속도와 함께 과압·역류·관계 손상·국부 피해를 항상 표시한다.
- `분산`은 다중 보호·광역 안정에서 명확한 장점을 가진다.
- 기본 `흐름`은 자원 효율과 안전한 순환에서 고유 역할을 가진다.

### 위험 4 — 미리보기가 시행착오와 발견을 제거함
대응:
- 직접 효과 하나와 주요 위험 하나만 예고한다.
- 연쇄 결과·인물 반응·최종 발견은 시전 후 공개한다.
- 낮은 확신에서는 불확실성을 명시한다.

### 위험 5 — 대화량 증가로 사건이 늘어짐
대응:
- 접근 선택 직후 필수 대화는 2~4줄로 제한한다.
- 추가 질문은 인물별 1개 핵심 주제로 제한한다.
- 반복 정보는 로그 요약으로 대체한다.

---

## 12. 통과 기준

플레이테스트에서 다음을 확인한다.

- 플레이어가 주문 전에 최소 하나의 위험을 예측한다.
- 대화가 주문 조합을 직접 알려줬다고 느끼지 않는다.
- 예상 효과를 보고 초안을 수정하는 경험이 발생한다.
- 실패 후 `왜 예상과 달랐는지` 설명할 수 있다.
- 비전투 접근이 전투보다 덜 완성된 선택으로 느껴지지 않는다.
- `흐름`, `집중`, `분산`의 차이를 자기 말로 설명한다.
- 20개의 대표 패턴을 외우지 않고도 합리적인 새 조합을 시도한다.
