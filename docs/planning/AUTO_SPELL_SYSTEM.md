자동스펠은 모바일에서 반복 드로잉으로 발생하는 피로도를 줄이기 위한 기능이다. 스톡 귀속, 최대 마나 예약, 자동·능동 충전의 최신 세부 규칙은 `STOCK_SYSTEM.md`가 우선한다.

## 2. 자동화의 세 단계

### 2.1 회로 자동화

- 플레이어가 직접 학습하고 숙련한 기초 회로를 자동으로 배치한다.
- 초반 핵심인 `메인 + 형상·전달`이 우선 자동화 대상이다.
- 플레이어는 이후 추가된 보조·조건 회로에 집중한다.

### 2.2 소환수 자동작성

- 소환수가 숙련된 보조 회로나 미완성 구간을 대신 작성한다.
- 소환수 능력치, 적성, 스탠스에 따라 속도와 안정성이 변동한다.
- 플레이어와 동시에 서로 다른 구간을 작성할 수 있다.

### 2.3 자동스펠

- 마도서에 등록되고 일정 숙련 조건을 만족한 완성 주문을 자동 운용한다.
- 전체 회로를 매번 손으로 다시 그리지 않아도 반복 사용할 수 있다.
- 자동스펠은 미리 준비한 주문별 스톡을 소비해 발동한다.

## 3. 해금 조건

```text
회로 획득·학습
→ 직접 조합 성공
→ 주문 발견
→ 마도서 설계도 등록
→ 반복 사용 또는 숙련 조건 달성
→ 자동스펠 등록
→ 전투 전에 스톡 배정
```

미발견 주문과 처음 사용하는 회로를 자동으로 해결하지 않는다.

## 4. 혼합형 발동

자동스펠마다 다음 두 방식 중 하나를 지정할 수 있다.

### 4.1 원터치 스톡

- 플레이어가 아이콘을 눌러 저장된 주문을 사용한다.
- 반복 드로잉 피로를 줄이면서 사용 시점 판단을 유지한다.
- 발동 시 해당 주문의 스톡 1개를 소비한다.

### 4.2 조건부 스톡

- 체력, 마나, 적 거리, 피격, 시간, 방어 성공 등의 조건을 설정한다.
- 조건이 충족되고 스톡이 남아 있을 때 자동 발동한다.
- 조건이 충족되어도 스톡이 없으면 발동하지 않는다.
- 조건부 슬롯과 조건 규칙 수는 제한해 완전 방치형 전투를 방지한다.

## 5. 직접 시전과 자동스펠의 역할 차이

### 직접 시전

- 전투 상황에 맞게 보조·조건 회로를 즉석 변경할 수 있다.
- 정확 판정 추가 보상을 획득할 수 있다.
- 소환수와 회로 구간을 유동적으로 분담한다.
- 새로운 조합을 발견할 수 있다.
- 스톡이 없어도 마나와 시간이 허용하면 시전할 수 있다.
- 직접 시전과 정확 입력은 지정 스톡의 충전을 가속한다.

### 자동스펠

- 반복 입력 피로를 줄인다.
- 안정적인 기본 성능을 제공한다.
- 등록된 설계도를 그대로 사용한다.
- 즉석 변형과 신규 발견 기능은 제한한다.
- 준비된 주문별 스톡만큼 사용할 수 있다.
- 원터치 또는 지정 조건으로 발동한다.

자동스펠은 직접 시전의 완전한 상위 호환이 아니다.

## 6. 스톡 최신 구조 요약

```text
자동스펠별 스톡 배정
→ 한 칸당 기존 주문 비용 50%를 최대 마나에서 예약
→ 전투 중 지정 주문 자동 충전
→ 플레이어·소환수 능력치에 따라 충전 속도 증가
→ 직접 시전·정확 입력·전투 행동으로 추가 가속
```

- 스톡은 공용 탄약이 아니라 지정 주문별 사용량이다.
- 같은 주문에 여러 스톡을 준비하거나 여러 주문에 분산할 수 있다.
- 스톡이 빈 상태여도 예약 마나는 유지된다.
- 현행 설계에서는 자동스펠 발동 시 동일 비용을 다시 전액 지불하지 않는다.
- 과거의 `시간 경과만으로는 스톡이 충전되지 않는다`는 규칙은 폐기됐다.
- 상세 규칙은 `docs/planning/STOCK_SYSTEM.md`를 따른다.

## 7. 피로도 완화 목표

```text
처음 배우는 회로
→ 직접 그림

숙련한 메인 + 형상·전달
→ 회로 자동화

새로 해금된 보조·조건
→ 직접 그림

숙련한 보조 회로
→ 소환수가 자동작성

반복 사용하는 완성 주문
→ 주문별 스톡으로 자동스펠 사용

빈 스톡
→ 자동 충전 + 직접 행동으로 가속

새로운 조합·고난도 대응
→ 직접 시전
```

## 8. 가드레일

- 자동스펠 스톡만으로 모든 전투가 해결되지 않게 한다.
- 새로운 주문 발견은 직접 회로 조합으로만 가능하게 한다.
- 정확 입력 보상과 즉석 변형은 직접 시전의 고유 가치로 남긴다.
- 스톡이 소진되었을 때 직접 시전이 불가능해지는 구조를 사용하지 않는다.
- 최대 마나 예약 비용을 전투 준비 화면에서 명확히 보여준다.
- 조건부 자동발동과 자동 충전이 무한 순환하지 않게 한다.
- 마나 회복 주문과 절감 보조로 스톡과 마나가 무한 증가하지 않게 한다.
- 플레이어와 소환수의 충전 속도 성장에 상한 또는 체감 감소를 검토한다.

| 가설 | 최소 검증물 | 통과 신호 |
|---|---|---|
| 스톡이 피로도를 줄인다 | 직접 시전과 스톡 자동스펠 각 1종 | 반복 전투에서 스톡을 편의와 전술 자원으로 인식 |
| 50% 예약이 선택을 만든다 | 다른 스톡 편성 두 종류 | 자동 편의와 직접 시전용 마나 사이에서 고민 |
| 자동 충전이 이해된다 | 지정 주문 충전 게이지 | 어떤 주문이 왜 충전되는지 즉시 이해 |
| 능동 행동 가치가 남는다 | 직접 시전 시 충전 가속 | 기다리기보다 회로를 그려 충전하려 함 |
| 소환수 성장 체감이 있다 | 충전 능력치가 다른 소환수 비교 | 충전 속도 차이를 인지 |
| 무한 루프가 없다 | 조건부 발동+자동 충전 테스트 | 제한 없이 반복되는 순환이 발생하지 않음 |

## 10. 미해결 사항

1. 자동 충전은 지정한 주문 1종만 동시에 진행되는가, 여러 종인가.
2. 충전 대상을 전투 중 언제 변경할 수 있는가.
3. 주문별 최대 스톡과 전체 스톡 한도를 어떻게 나누는가.
4. 마나 절감 보조가 스톡 예약 비용에 적용되는가.
5. 피격 시 충전이 유지·감속·중단되는가.
