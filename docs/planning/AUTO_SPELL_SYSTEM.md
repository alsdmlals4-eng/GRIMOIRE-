자동스펠은 모바일에서 반복 드로잉으로 발생하는 피로도를 줄이기 위한 기능이다. 직접 그리기를 제거하는 방치형 전환이 아니라, 이미 학습한 주문을 편하게 반복하고 플레이어가 새로운 회로·조건·전투 판단에 집중하도록 하는 운용 계층이다.

## 2. 자동화의 세 단계

Spell의 자동화는 하나의 기능으로 통합하지 않고 단계별로 구분한다.

### 2.1 회로 자동화

- 플레이어가 직접 학습하고 숙련한 기초 회로를 자동으로 배치
- 초반 핵심인 `메인 + 형상·전달`이 우선 자동화 대상
- 플레이어는 이후 추가된 보조·조건 회로에 집중

### 2.2 소환수 자동작성

- 소환수가 숙련된 보조 회로나 미완성 구간을 대신 작성
- 소환수 능력치, 적성, 스탠스에 따라 속도와 안정성이 변동
- 플레이어와 동시에 서로 다른 구간을 작성 가능

### 2.3 자동스펠

- 마도서에 등록되고 일정 숙련 조건을 만족한 완성 주문을 자동 운용
- 전체 회로를 매번 손으로 다시 그리지 않아도 반복 사용 가능
- 장착 슬롯, 발동 방식, 재사용 제약은 후속 결정 필요

## 3. 해금 조건

자동스펠 후보 주문은 최소한 다음 과정을 거쳐야 한다.

```text
회로 획득·학습
→ 직접 조합 성공
→ 주문 발견
→ 마도서 설계도 등록
→ 반복 사용 또는 숙련 조건 달성
→ 자동스펠 등록 가능
```

미발견 주문과 처음 사용하는 회로를 자동으로 해결하지 않는다.

## 4. 직접 시전과 자동스펠의 역할 차이

### 직접 시전

- 전투 상황에 맞게 보조·조건 회로를 즉석 변경 가능
- 정확 판정 추가 보상 획득 가능
- 소환수와 회로 구간을 유동적으로 분담
- 새로운 조합 발견 가능
- 숙련 플레이에서 자동스펠보다 더 빠르거나 효율적일 수 있음

### 자동스펠

- 반복 입력 피로 감소
- 안정적인 기본 성능
- 등록된 설계도를 그대로 사용
- 즉석 변형과 발견 기능은 제한
- 마나, 재사용 시간, 충전, 슬롯 등의 제약 후보 적용

자동스펠은 직접 시전의 완전한 상위 호환이 아니다.

## 5. 발동 방식 후보

아직 확정하지 않는다.

### A. 원터치 자동시전

- 플레이어가 버튼을 눌러 등록된 주문을 즉시 또는 짧은 준비 후 사용
- 피로도는 낮지만 전투 판단은 유지

### B. 조건부 완전 자동발동

- 체력, 마나, 적 거리, 피격, 시간 등 규칙에 따라 자동 발동
- 편하지만 방치형 전투로 기울 위험이 큼

### C. 혼합형

- 주문마다 원터치 또는 조건부 발동을 선택
- 자동 발동 슬롯과 조건 규칙 수를 제한
- 현재 권장 후보이나 사용자 결정 전 확정하지 않음

## 6. 자동스펠 편집 범위

후보 규칙:

- 자동스펠은 등록된 설계도 하나를 기준으로 한다.
- 자동스펠 운용 중에는 회로를 실시간으로 자유 교체하지 않는다.
- 변형하려면 새 설계도로 저장하거나 직접 시전한다.
- 소환수가 자동스펠의 일부 회로를 준비해 발동 시간을 줄일 수 있다.
- 플레이어가 직접 개입해 마지막 기동을 수행하는 반자동 모드도 후보로 둔다.

## 7. 피로도 완화 목표

```text
처음 배우는 회로
→ 직접 그림

숙련한 메인 + 형상·전달
→ 회로 자동화

새로 해금된 보조·조건
→ 직접 그림

반복 사용하는 완성 주문
→ 자동스펠로 운용 가능

새로운 조합·고난도 대응
→ 다시 직접 시전
```

플레이어는 게임이 진행될수록 더 많은 선을 그리는 것이 아니라, 이미 익힌 부분을 자동화하고 새롭게 판단해야 하는 부분만 직접 다룬다.

## 8. 가드레일

- 자동스펠만으로 모든 전투가 해결되지 않게 한다.
- 새로운 주문 발견은 직접 회로 조합으로만 가능하게 한다.
- 정확 입력 보상과 즉석 변형은 직접 시전의 고유 가치로 남긴다.
- 자동스펠에 광고 시청이나 과금이 필수인 구조를 두지 않는다.
- 자동스펠 슬롯 수로 과도한 불편을 만들어 유료 확장을 강제하지 않는다.
- 자동스펠이 마나 규칙과 회복·절감 회로를 무시하지 않는다.
- 조건부 자동발동이 집중 모드와 적 공격 대응 판단을 완전히 제거하지 않게 한다.
