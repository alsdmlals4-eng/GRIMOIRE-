# Spell 자동스펠 시스템 — 폐기된 초기 방향

## 문서 상태

- 상태: `SUPERSEDED`
- 기준 날짜: 2026-07-26
- 최신 책임 원본: `docs/planning/STOCK_SYSTEM.md`
- 관련 최신 결정: `GM-00-17`, `GM-00-18`, `GM-00-19-A`, `GM-00-20`, `GM-00-21`

이 문서는 초기 자동스펠 방향을 기록하기 위해 남겨 둔다. 현재 설계 기준으로 사용하지 않는다.

## 폐기된 초기 구조

초기에는 다음 혼합 구조를 검토했다.

```text
원터치 자동스펠
+
체력·피격·적 수 등의 조건에 따른 자동발동
```

이후 사용자 결정으로 조건부 자동발동을 폐기하고 모든 자동화 기능을 스톡으로 통합했다.

상태: `SUPERSEDED`

## 최신 구조 요약

```text
플레이어 성장
→ 일정 이하 단계이며 학습·숙련한 주문·회로 스톡화 가능

완성 주문 스톡
→ 한 번 터치로 저장 주문 전체 기동

하위 회로 스톡
→ 한 번 터치로 현재 주문에 저장 회로 자동 배치·연결

소환수
→ 회로 직접 작성 없음
→ 지정 스톡 생산량·충전 속도 강화
```

- 조건을 만족했다고 주문이 스스로 발동하지 않는다.
- 사용 시점과 적용 시점은 플레이어가 결정한다.
- 지정한 스톡 대상 1종만 전투 중 자동 충전된다.
- 플레이어 능력치, 소환수 생산 능력치와 능동 행동이 충전 속도에 기여한다.
- 완성 주문 스톡과 하위 회로 스톡은 공용 준비 용량을 공유한다.
- 하위 회로 스톡 1개는 준비 용량 1을 사용한다.
- 완성 주문 스톡 1개는 구성 기능 회로 수만큼 준비 용량을 사용한다.
- 스톡은 최대·현재 마나를 사용하지 않는다.
- 직접 회로 시전만 마나를 사용한다.
