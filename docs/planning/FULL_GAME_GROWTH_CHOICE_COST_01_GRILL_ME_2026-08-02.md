## 2. 결정 질문

다계열 수강과 전문화 판타지를 유지하면서도 모든 계열 동시 성장·반복 파밍·초기 선택 영구 손해를 막으려면 어떤 성장 비용 구조를 사용할 것인가?

## 3. A안 — 수강 슬롯 + 성장 증거 인증형 / 권장

### 구조

```text
학기·Chapter 수강 슬롯 선택
→ 수업에서 이해 획득
→ 직접 작성·통제 응용으로 숙련 검증
→ 서로 다른 현장에서 활용 기록 축적
→ 시험·교수 평가로 인증
→ 심화 수강 또는 전문화 후보 개방
```

계열 성장은 하나의 범용 경험치가 아니라 네 종류의 증거를 요구한다.

| 성장 증거 | 획득 방식 | 막는 문제 |
|---|---|---|
| 이해 | 수업·연구·기록 분석 | 전투만 반복하는 성장 |
| 숙련 | 직접 작성·통제된 응용 | 대화 선택만으로 마법 숙련 |
| 활용 | 서로 다른 상황에서 실제 해결 | 동일 표적 반복 파밍 |
| 인증 | 시험·보고·교수 평가 | 자동 레벨업·무검증 전문화 |

핵심 규칙:

- 한 진행 구간에서 수강 가능한 계열 수는 제한한다. 정확한 수는 `TEST_VALUE`다.
- 폭넓게 수강하면 여러 기초 해법을 얻지만 심화 도달이 늦어진다.
- 소수 계열에 집중하면 전문화가 빨라지지만 다른 상황의 해법 폭이 줄어든다.
- 수강하지 않은 계열도 공통 문법과 동료 협력을 통해 메인 진행을 막지 않는다.
- 전문화는 증거 기준과 명시적 선택을 모두 요구한다.
- 전문화 전에는 학기·Chapter 경계에서 수강 방향을 바꿀 수 있다.
- 전문화 후에도 완전 초기화보다 연구 방향 전환·부전공 추가 같은 제한적 회복 경로를 둔다.
- 정확한 슬롯 수·요구 증거량·전환 비용은 `TEST_VALUE`다.

장점:

- 학교 수업 선택과 실제 플레이 행동이 연결된다.
- 전투 경험치 파밍만으로 전문화할 수 없다.
- 폭넓은 수강과 깊은 전문화가 명확한 기회비용을 가진다.
- 성장 이유를 플레이어에게 설명하기 쉽다.

위험:

- 네 증거가 별도 게이지로 노출되면 관리 화면이 복잡해질 수 있다.
- 인증이 체크리스트 작업처럼 느껴질 수 있다.

보정:

- 모든 증거를 숫자 막대로 노출하지 않고 마도서 기록·교수 평가 문장으로 요약한다.
- 같은 행동 반복이 아니라 Chapter의 실제 상황과 선택에서 자연스럽게 증거를 얻는다.

## 4. B안 — 범용 학점·스킬 포인트 자유 배분형

```text
수업·전투·과제로 범용 포인트 획득
→ 원하는 계열에 자유 배분
→ 기준치에서 전문화 해금
```

장점:

- 이해와 조작이 쉽다.
- 자유로운 빌드와 재분배를 만들기 쉽다.
- 구현·밸런스 구조가 단순하다.

위험:

- 가장 효율적인 활동을 반복해 모든 계열을 올리는 파밍이 생긴다.
- 실제 계열 활용 없이 포인트만 넣어 전문가가 될 수 있다.
- 학교 수업과 현장 경험이 추상 자원으로 축소된다.

## 5. C안 — 사용 기반 자연 성장형

```text
계열 글자를 실제로 사용할수록 숙련 상승
→ 특정 사용 패턴에서 전문화 자동 발생
```

장점:

- 성장과 플레이 행동이 직접 연결된다.
- 별도 학점 배분 메뉴가 적다.
- 플레이 스타일이 자연스럽게 캐릭터 정체성이 된다.

위험:

- 같은 안전한 실습을 반복하는 최적 파밍이 강해진다.
- 성장 조건이 불투명해 원치 않는 전문화가 발생할 수 있다.
- 비전투·관계·책임 선택의 성장 가치가 약해진다.

## 6. 권장 판정

`A — 수강 슬롯 + 성장 증거 인증형`을 권장한다.

B안으로 승인된 다계열 수강 판타지를 실제 학교 구조와 연결하면서, 모든 계열 동시 성장과 반복 전투 파밍을 가장 잘 막는다.

```text
무엇을 배울지 선택
→ 이해
→ 직접 다뤄 보기
→ 다른 상황에서 책임 있게 사용
→ 결과를 설명하고 인증
→ 심화 또는 전문화
```

## 7. 승인 후 확정되는 것

A안 승인 시:

- 계열 성장은 `이해 / 숙련 / 활용 / 인증` 증거 구조를 사용한다.
- 수강 슬롯 제한이 폭넓은 학습과 심화의 기본 기회비용이 된다.
- 범용 경험치만으로 전문화하지 않는다.
- 동일 전투 반복은 다양한 활용 증거를 대체하지 못한다.
- 전문화 전 수강 방향 변경을 허용한다.
- 정확한 수치와 UI 노출 방식은 `TEST_VALUE`다.
- Grill Me counter는 `4/10`.
- 다음 설계는 `보상 경제·소모처·파밍 방지`다.

## 8. 미확정 경계

- 한 학기·Chapter의 정확한 수강 슬롯 수.
- 동시 활성 계열 수.
- 증거별 요구량과 레벨 단계.
- 전문화 진입 시점과 전환 비용.
- 부전공·복수전공·연구 방향의 포함 여부.
- 성장 상태의 Mobile UI 표현.
