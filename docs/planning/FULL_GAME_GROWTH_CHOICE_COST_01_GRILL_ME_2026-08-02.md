## 2. 승인된 성장 흐름

```text
수강 계열 선택
→ 수업에서 문자 의미·획·안전 규칙 학습
→ 짧고 안전한 직접 작성 연습
→ 축제·일상 이벤트에서 가벼운 비전투 응용
→ 현장실습에서 전투·환경 문제 해결
→ 마도서 복기와 교수의 누적 평가
→ 심화 수강 또는 전문화 후보 개방
```

별도 시험 Chapter, 시험장, 시험 전용 미니게임은 두지 않는다.

## 3. 성장 증거

| 성장 증거 | 대표 획득 장면 | 역할 |
|---|---|---|
| 기초 학습 기록 | 수업·연구·짧은 작성 연습 | 문자 의미·획·안전 규칙 이해 |
| 비전투 응용 기록 | 축제·일상 사건·구조·표현·생활 문제 | 전투 밖에서 문자를 상황에 맞게 사용하는 능력 |
| 현장 수행 기록 | 현장실습의 전투·환경 해결 | 위험 속 설계·대응·보존·책임 |
| 복기·설명 기록 | 마도서·교수 피드백·귀환 보고 | 결과·부작용·포기한 것과 다음 개선 설명 |

이 증거들은 별도 숫자 게이지 네 개를 반드시 노출한다는 뜻이 아니다. 플레이어에게는 마도서 기록과 교수 평가 문장으로 요약하는 방식을 우선한다.

## 4. 평가 구조

평가는 하나의 시험 점수가 아니라 활동 결과를 합친 포트폴리오다.

```text
수업 관찰
+
축제·일상 응용 성과
+
현장실습 성과
+
마도서 복기·책임 설명
→ 계열별 누적 평가와 심화/전문화 후보
```

평가 기준 후보:

- 상황과 조건을 이해했는가.
- 배운 문자를 직접 작성하고 의미에 맞게 사용했는가.
- 전투·비전투 상황에서 다른 해법과 대가를 고려했는가.
- 피해·부작용·보존하지 못한 대상을 설명했는가.
- 결과를 마도서에 기록하고 다음 개선 방향을 제시했는가.

정확한 항목별 가중치와 요구 기록 수는 `TEST_VALUE`다.

## 5. 수강 선택 비용

- 한 진행 구간에서 수강 가능한 계열 수는 제한한다. 정확한 슬롯 수는 `TEST_VALUE`다.
- 폭넓게 수강하면 기초 해법이 늘지만 한 계열의 심화·전문화가 늦어진다.
- 소수 계열에 집중하면 전문화는 빨라지지만 다른 상황에서 사용할 해법 폭이 줄어든다.
- 전문화 전에는 학기·Chapter 경계에서 수강 방향을 변경할 수 있다.
- 전문화 후에도 완전 초기화보다 연구 방향 전환·부전공 추가 같은 제한적 회복 경로를 둔다.
- 수강하지 않은 계열도 공통 문법·동료 협력을 통해 메인 진행을 막지 않는다.

## 6. 적대적 보호 규칙

1. 수업 연습은 낮은 실패 비용의 학습 구간이며 성적 경쟁으로 만들지 않는다.
2. 현장실습의 처치 속도·피해량·반복 횟수만으로 높은 평가를 독점하지 않는다.
3. 축제·일상 이벤트의 비전투 응용도 계열 성장과 평가에 실질적으로 기여한다.
4. 동일 현장실습 반복은 서로 다른 상황의 활용 기록을 대체하지 못한다.
5. 평가를 위해 모든 콘텐츠에서 정답 조합 하나를 강요하지 않는다.
6. 실패·부분 성공도 원인과 책임을 설명하면 유효한 학습 기록이 될 수 있다.
7. 별도 시험이 없다는 이유로 교수 피드백과 학교의 교육 기능을 삭제하지 않는다.
8. 전문화는 누적 증거 기준 충족과 플레이어의 명시적 선택을 모두 요구한다.

## 7. 기존 정본 보정

다음 표현은 이번 결정에 맞게 보정한다.

- `시험` → `축제·일상 이벤트·훈련·현장실습의 맥락 평가`.
- `실기시험` → `교내 일상 응용 이벤트`.
- `시험·교수 평가로 인증` → `활동 포트폴리오·마도서·교수 누적 평가로 인증`.

기존 `취약한 부유 수정구 이송`은 폐기하지 않고 별도 시험이 아닌 교내 일상 응용 또는 수업 후 실습 상황으로 재분류한다.

## 8. 거부한 대안

- 범용 학점·스킬 포인트만으로 전문화하지 않는다.
- 사용 횟수만으로 자동 성장·전문화하지 않는다.
- 별도 시험 Chapter나 시험 전용 콘텐츠를 추가하지 않는다.
- 현장실습 전투 성적만으로 전체 학업 평가를 결정하지 않는다.
