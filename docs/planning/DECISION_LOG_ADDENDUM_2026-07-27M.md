## 사용자 결정

첫 Vertical Slice는 단일 현장실습 에피소드가 아니라 다음을 모두 경험하는 축약 학기형으로 구성한다.

```text
첫 수업·교내 연습
→ 자유일정 A 1회
→ 첫 실기시험
→ 자유일정 B 1회
→ 학교축제
→ 자유일정 C 1회
→ 첫 현장실습
→ 귀환·마도서 기록
```

## 자유일정 해석

- 중요 일정 사이에 총 3회 배치한다.
- 각 슬롯에서는 행동 1개만 선택한다.
- `휴식`을 정식 전략 선택지로 포함한다.
- 복습·관계·축제 준비·현장 조사·보조 소환수 훈련 등의 선택을 제공할 수 있다.
- 어떤 선택도 시험·축제·현장실습 참가를 차단하지 않는다.
- 필수 정보와 정답을 특정 자유일정 선택에 독점시키지 않는다.
