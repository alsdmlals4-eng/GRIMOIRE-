## 2. 결정 질문

## 4. A안 — 제한된 의미 나선 / 권장

### 구조

각 Chapter는 기본적으로 **새 학습 부담 하나**를 도입한다.

```text
새 메인 글자 1개
또는
새 보조 글자·문법 1개
```

Chapter 1의 `흐름 + 집중/분산`은 대비 학습을 위해 두 보조를 함께 소개한 승인된 예외다.

### 핵심 규칙

1. 새 글자는 이전 글자를 최소 한 상황에서 다시 해석하게 한다.
2. 새 글자는 기존 글자의 상위 호환이 아니라 새로운 대상·조건·대가를 연다.
3. Chapter는 새 글자와 소수의 기존 글자로 구성한 `인증 조합 범위`를 가진다.
4. 배운 글자는 마도서에 계속 남지만, 인증 범위 밖 조합은 성공을 자동 보장하지 않는다.
5. 인증되지 않은 조합은 숨은 금지 목록이 아니라 의미·문법·상황·안정성 이유로 결과를 설명한다.
6. 반복 시전 횟수보다 서로 다른 상황에서의 활용 기록·부작용·평가를 숙련 근거로 삼는다.
7. 다중 보조·순서 의존·스톡은 본편 범위 Decision 전까지 자동 활성화하지 않는다.
8. 정확한 Chapter당 활성 글자 수와 본편 총 글자 수는 `TEST_VALUE`다.

### 예시 구조

```text
Chapter 1
흐름 + 집중/분산
→ 이동 방향과 정밀/안정의 대가

Chapter 2
새 메인 A 또는 새 보조 A
→ 흐름을 포함한 기존 글자와 다른 책임 질문

Chapter 3
새 메인 B 또는 새 보조 B
→ Chapter 1·2 글자 중 일부를 새 상황에서 재사용
```

구체적인 새 글자 명칭·순서·개수는 이 Decision에서 확정하지 않는다.

### 장점

- Chapter 질문과 마법 학습을 직접 연결한다.
- 이전 글자가 버려지지 않고 새 맥락에서 다시 쓰인다.
- 직접 작성과 QA 범위를 Chapter 단위로 통제한다.
- 구형 다수 계열 후보를 필요에 따라 선택적으로 재사용할 수 있다.
- 글자 수보다 한 글자의 전투·환경·관계·표현 활용 폭을 높인다.

### 위험

- 인증 범위가 좁으면 자유 조합 판타지가 약해질 수 있다.
- 많은 속성·계열을 기대하는 플레이어에게 규모가 작게 보일 수 있다.

### 보정

- 모든 상황에 단일 정답 조합을 지정하지 않는다.
- 인증 범위 안에서도 2개 이상의 의미 있는 해법과 다른 대가를 설계한다.
- 새 글자는 최소 두 콘텐츠 유형에서 활용되도록 후보 검증한다.
- 전체 글자 수는 본편 범위와 제작량 Gate에서 결정한다.

## 5. B안 — 다계열 수강·전문화 트리

```text
여러 메인 계열 수업 선택
→ 계열별 레벨 상승
→ Lv.4 전문화
→ 선택 계열 중심 현장 해결
```

장점:
- 학교 RPG와 전공 선택의 판타지가 강하다.
- 다른 계열 선택을 통한 재플레이 동기가 생긴다.
- 기존 구형 장기 문서를 가장 많이 보존한다.

위험:
- 선택하지 않은 계열의 수업·교수·상황·VFX도 제작해야 한다.
- 레벨과 전문화가 복수 해법보다 최적 빌드 경쟁으로 수렴할 수 있다.
- Vertical Slice의 글자 3개 구조가 전체 게임 대표성을 잃는다.
- Solo·Mobile 제작 범위를 초과할 가능성이 높다.

## 6. C안 — 소수 메인·다수 보조 문법형

```text
메인 글자는 소수 유지
→ 형상·전달·시간·조건·순서 등 보조 문법을 확장
→ 같은 메인을 복잡한 문장으로 설계
```

장점:
- 같은 현상을 다양하게 설계하는 회로·문법 판타지가 강하다.
- 메인 계열별 신규 Asset 제작량을 줄일 수 있다.
- 플레이어 숙련에 따라 주문 표현력이 직접 증가한다.

위험:
- 직접 작성 횟수와 화면 복잡도가 빠르게 늘어난다.
- 조건·순서 조합이 상황 해결보다 주문 프로그래밍 최적화로 변질될 수 있다.
- 입력 오류·문법 오류·상황 오류의 설명 부담이 커진다.
- Mobile 전투 시간 압박과 충돌한다.

## 7. 권장 판정

`A — 제한된 의미 나선`을 권장한다.

핵심은 글자를 많이 모으는 것이 아니라, **새 글자 하나가 이전 글자의 의미와 책임을 다시 보게 만드는 것**이다.

```text
새 글자 학습
→ 이전 글자와 비교
→ 통제된 상황에서 대가 확인
→ 자유일정·현장실습에서 실험
→ 메인 현장에서 책임 선택
→ 마도서에 활용·부작용 기록
```
