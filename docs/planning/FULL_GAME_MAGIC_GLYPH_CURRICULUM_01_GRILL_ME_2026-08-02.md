
## 4. 승인된 B안의 의미

- 플레이어는 복수의 메인 글자 계열을 수강할 수 있다.
- 메인 계열은 서로 독립된 성장 상태와 활용 기록을 가진다.
- 기초 단계에서는 여러 계열을 경험하고, 진행하면서 일부 계열을 더 깊게 선택한다.
- 전문화는 단순 피해량 상승이 아니라 해당 계열의 활용 대상·안전 규칙·책임 선택을 심화한다.
- 다른 계열 선택은 상황 해결 방식·관계·연구·마도서 기록에 차이를 만든다.
- 미선택 계열이 메인 진행을 봉쇄하지 않으며, 주요 사건은 복수 계열 또는 공통 문법 해법을 받아들인다.

## 5. 제작·QA 보호 규칙

B안의 다계열 판타지를 유지하되 다음은 승인하지 않는다.

1. 선택하지 않은 모든 계열에 완전히 별개의 메인 Chapter를 제작하는 구조.
2. 계열마다 전용 맵·교수·적·UI·VFX 세트를 필수로 요구하는 구조.
3. 특정 계열 하나가 대부분 상황의 상위 호환 정답이 되는 구조.
4. 반복 시전만으로 계열 레벨과 전문화를 무한 상승시키는 구조.
5. 계열 선택을 되돌릴 수 없는 초기 영구 잠금으로 만드는 구조.
6. Vertical Slice의 `흐름 + 집중/분산`을 전체 게임과 무관한 임시 튜토리얼로 격하하는 구조.

보정 원칙:

- 공통 문법·보조 글자·상황·장소·적 상태를 여러 계열이 공유한다.
- 동일 사건이 계열별로 다른 해법과 대가를 제공하도록 제작한다.
- 계열 전용 콘텐츠보다 공통 콘텐츠의 다중 해석을 우선한다.
- 전문화 전까지는 폭넓은 체험과 재선택 가능성을 보장한다.
- 성장 근거는 수업·시험·서로 다른 상황 활용·마도서 기록·교수 인증의 조합으로 구성한다.

## 7. Vertical Slice와의 연결

- `흐름`은 첫 기초 메인 계열이자 전체 계열 성장의 대표 사례로 유지한다.
- `집중 / 분산`은 여러 계열에서 재사용 가능한 공통 보조 문법의 첫 사례로 유지한다.
- Slice의 메인 1 + 보조 0~1은 입문 단계의 대표 범위다.
- 다중 보조·순서 문법·완성 주문 스톡은 본편 범위와 Mobile 검증 전까지 자동 승인하지 않는다.
- Slice 이후 계열 선택이 열리더라도 첫 Chapter의 학습·상황·책임 구조는 전체 게임의 축소판으로 유지한다.
