## 1. Override 목적

사용자는 A형 보상 구조를 메인으로 유지하면서 C형 재료 수집·제작 경제를 추가하고, 미니게임과 추가 콘텐츠를 실제 제작하도록 승인했다.

따라서 과거 Solo Scope 보호를 위해 설정했던 미니게임·추가 콘텐츠의 전면 금지는 더 이상 활성 정본이 아니다.

## 2. 폐기되는 이전 제한

다음 문구는 역사적 결정으로만 남고 현재 범위를 제한하지 않는다.

- 세션별 독립 미니게임·전용 프레임워크를 만들지 않는다.
- 자유일정별 독립 미니게임을 전면 금지한다.
- 별도 미니게임 프레임워크를 금지한다.
- 추가 콘텐츠를 만들지 않고 기존 슬롯 재분류만 사용한다.
- 축제·학교·탐사 콘텐츠를 대표 문제 하나로 영구 고정한다.

## 3. 새 활성 범위

### 본편

- 문자 학습 미니게임.
- 재료 식별·정제·배합·안정화 제작 미니게임.
- 축제·일상·연구실·교류·탐사·현장 추가 콘텐츠.
- 제작물을 이용한 비전투 문제와 전투·환경 준비.
- 계열·관계·장소 상태에 따른 변주 콘텐츠.

### Vertical Slice

- 제작·미니게임 시스템의 대표 사례 최소 1개.
- 우선 후보: 교내 일상 응용 또는 축제 준비에 결합한 촉매 안정화·장치 조율·재료 식별.
- 기존 작성·Situation Challenge와 결과·부작용·마도서 기록을 공유한다.

## 4. 유지되는 범위 보호

- 별도 시험 Chapter·시험장·시험 전용 미니게임은 계속 제외한다.
- 문자 의미·상황 판단·제작 결과와 연결되지 않는 장식성 반복 콘텐츠는 제외한다.
- 한 Chapter에 모든 미니게임 형식을 강제하지 않는다.
- 제작물로 누적 평가·접근 권한·전문화를 구매하지 않는다.
- 특정 희귀 재료·제작물이 필수 진행의 유일 해법이 되지 않는다.
- 정확한 미니게임 수·재료 수·레시피 수·신규 장소 수는 `TEST_VALUE`다.

## 5. 시간·제작 Gate

- 현재 Vertical Slice 46분 목표·53분 콘텐츠 상한은 우선 유지한다.
- 대표 미니게임은 기존 교내 일상 응용 또는 축제 장면 안에 배치해 먼저 검증한다.
- 추가 시간을 단순 누적하지 않는다. 53분을 넘기면 대표성 Gate에서 시간 예산과 필수 작성 횟수를 함께 재승인한다.
- 본편 미니게임·추가 콘텐츠 총량은 `FULL-GAME-SCOPE-01`에서 Chapter 수·계열 수·신규 Asset 예산과 함께 확정한다.
