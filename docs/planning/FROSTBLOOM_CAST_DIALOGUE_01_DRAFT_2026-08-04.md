## 2. 사건 발단

카시안은 결빙된 보조 배관을 빨리 해빙하려고 이미 배운 `열 + 흐름` 회로를 사용한다. 그러나 회수 밸브가 닫혀 있고 내부 압력이 높은 것을 확인하지 않는다.

```text
열 발생
→ 닫힌 배관 안으로 전달
→ 열팽창과 압력 급상승
→ 배관 균열
→ 냉기 마력 누출
→ 중심 핵 안전 정지
→ 자동 격벽 폐쇄
→ 카시안 고립·서리 정령 과부하
```

이 실패는 입력 실패가 아니라 `상황·경로·출구 판단 실패`다.

카시안은 사고를 숨기지 않는다.

- 사용한 회로와 놓친 밸브를 즉시 말한다.
- 내부 압력계·균열음·통로 상태를 전달한다.
- 플레이어가 주문을 쓰면 밸브와 격벽을 조작한다.
- 사고 원인이면서 해결 협력자로 남는다.

---

## 3. 에일린 교수

```yaml
role: 현장 대응·마력운용학 교수
core_value: 책임 있는 자립
intervention: L0_OBSERVE_L1_DIRECTION_L2_WARNING_L3_LIFESAVING
visible_safety_circuit: HEAT_PLUS_FLOW_OUTER_CONTAINMENT
```

교수는 해결법을 말로 설명하지 않는다. 사고 직후 학교 회랑으로 번지는 냉기만 외곽 회로로 막는다.

### 교수 시전 장면

1. 외벽의 한 지점에서 호박색 빛이 피어난다.
2. 빛이 유리벽 둘레의 선을 따라 이동한다.
3. 따뜻한 기운이 퍼지고 지나간 유리의 서리가 녹는다.
4. 외부로 뻗던 냉기 안개가 방향을 바꿔 온실 안쪽으로 휘어진다.
5. 내부 압력·핵 정지·카시안·정령 문제는 그대로 남는다.

교수의 허용 대사:

- “외부 확산은 막았다.”
- “내부 문제는 그대로다.”
- L2·L3 안전 경고

교수의 금지 대사:

- “열과 흐름을 사용해라.”
- “내 회로를 따라 그려라.”
- 정확한 출발점·목표·경로·보조 글자 지시
- 회로 효과에 대한 설명 강의

---

## 4. 키워드 확인 장면

회로가 펼쳐질 때 자동 인식 라벨을 띄우지 않는다. 플레이어가 텍스트 노벨 조사 선택으로 익숙한 부분을 확인한다.

### 조사 선택

```text
빛이 시작된 문양을 살핀다.
빛이 이동한 선을 따라간다.
모서리의 복잡한 문양을 살핀다.
조사하지 않고 온실 내부를 본다.
```

### 확인 결과

```text
시작 문양
→ 수업에서 익힌 `열`의 형태를 알아본다.

이동 경로
→ 수업에서 익힌 `흐름`의 연결 방식을 알아본다.

모서리 문양
→ 아직 배우지 않은 구조라 해독하지 못한다.
```

키워드 확인은 새 글자 습득이 아니라 이미 배운 글자를 실제 현장에서 다시 알아보는 과정이다.

---

## 5. 관찰 결과 표시

플레이어에게는 해석이 아니라 감각과 실제 변화만 알려준다.

```text
따뜻한 기운이 느껴진다.
회로가 지나간 유리의 서리가 녹는다.
밖으로 나가려던 냉기가 방향을 바꿨다.
온실 안쪽의 붉은 압력계는 그대로다.
```

상황에 맞는 2~4줄만 노출한다.

금지:

- `열이 흐름 경로를 따라 이동했다.` 같은 시스템 해설
- `열+흐름 회로를 확인했다.` 같은 자동 판독 결과
- 추천 주문·성공률·최종 결말
- 교수 회로 복사 또는 자동 적용

## 6. 모트

```yaml
role: 메인 동반 정령
information_domain: 정령 감정·마력 방향·온도 변화
limitation: 배관 구조와 정확한 수치 이해 불가
```

모트는 감각을 보조하지만 정답을 번역하지 않는다.

대표 화법:

- “따뜻해졌어.”
- “밖으로 가던 차가운 것이 돌아오고 있어.”
- “정령들은 화난 게 아니라 너무 많이 삼켜서 떨고 있어.”

모트의 대사도 관찰 결과를 반복 해설하지 않도록 필요할 때만 사용한다.

## 8. 적대적 검토

### 자동 판독이 정답 공개가 될 위험

- 자동 `[인식]` UI를 제거한다.
- 텍스트 노벨 조사에서만 키워드를 확인한다.
- 조사하지 않아도 봉쇄·철수 등 기본 진행은 가능하다.

### 시스템 문구가 교수 대신 설명할 위험

- 관찰 결과는 감각과 변화만 표시한다.
- 원리·추천·추론은 플레이어가 수행한다.
- 예상 효과 화면도 사용자가 선택한 초안의 경향만 보여준다.

### 카시안이 민폐 캐릭터가 될 위험

- 즉시 책임을 인정하고 정보를 숨기지 않는다.
- 밸브·격벽 조작으로 해결에 기여한다.
- 결말 뒤 재발 방지 기록을 남긴다.

### 인물이 적어 정보가 부족할 위험

- 환경 조사와 상태 변화를 강화한다.
- 필수 정보는 두 경로 이상에서 제공한다.
- 기본 관찰만으로도 안전 봉쇄·철수가 가능하다.

---

## 9. 검토 대상

1. 지속 등장 인물을 교수·동급생·동반 정령로 제한하는가.
2. 키워드 확인이 자동 UI가 아니라 텍스트 노벨 조사로 진행되는가.
3. 관찰 결과가 `따뜻함`, `서리 해빙`, `냉기 방향 변화` 정도만 전달하는가.
4. 교수와 시스템 모두 해결법을 설명하지 않는가.
5. 플레이어가 관찰과 조사로 방향을 스스로 잡을 수 있는가.
