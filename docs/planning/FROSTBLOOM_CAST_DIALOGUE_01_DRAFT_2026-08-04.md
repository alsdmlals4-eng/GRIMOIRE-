사용자 피드백에 따라 사건 인물을 줄이고 1학년 중심으로 재구성한다.

```text
평소 학교생활과 수업
= 같은 학년 학생 중심

상급생

```

## 2. 수정 결론

기존 5인 구조에서 `고립 학생 네아`를 제거한다. 동급생 `카시안`이 성급한 주문 응용으로 사고를 일으키고 안전 격벽 안에 고립된다. 카시안은 사고 원인인 동시에 밸브·격벽을 조작하며 해결에 참여하는 협력자다.

온실 관리 선배 `마렌`은 상시 동행하지 않는다. 사건 초반에 시설 설명을 제공하고, 사고 뒤에는 인접 온실의 확산 차단을 담당하면서 필요한 정보만 원격으로 전달한다. 사건의 핵심 해결은 대신하지 않는다.

최종 핵심 인물은 다음과 같다.

1. 에일린 로스베르 — 교수
2. 카시안 렌 — 플레이어와 같은 1학년, 사고 촉발자이자 현장 협력자
3. 마렌 브리어 — 가끔 등장하는 믿음직한 상급생 조언자
4. 모트 — 플레이어의 메인 동반 정령

인간 학생 기준으로는 동급생 1명과 선배 조언자 1명만 사용한다.

# 3. 주요 등장인물

## 3.1 현장 지도 교수 — 에일린 로스베르

```yaml
role: 현장 대응·마력운용학 교수
speech: 짧은 평서문과 판단 질문
core_value: 책임 있는 자립
bias: 근거 없는 자기희생과 책임 전가를 가장 낮게 평가
```

- 외곽 안전막과 생체 감시를 담당한다.
- 정답 조합은 알려주지 않는다.
- L1 방향 질문, L2 안전 경고, L3 생명 구조만 수행한다.
- 카시안이 실수했다는 이유로 사건 해결을 대신하지 않는다.

대표 화법:

- “사고를 낸 사람과 사고를 해결할 사람은 같을 수도, 다를 수도 있다. 지금 네 역할부터 정해라.”
- “없는 것을 만들려 하지 마라. 이미 흐르는 것이 어디에 있는지 보아라.”
- “도움을 요청하는 것과 판단을 넘기는 것은 다르다.”

## 3.2 동급생 — 카시안 렌

```yaml
role: 플레이어와 같은 1학년 학생
speech: 빠르고 직설적이며 실수 뒤에는 관찰 사실을 숨기지 않음
core_value: 지연보다 행동
bias: 집중과 빠른 결과를 과대평가
incident_role: ACCIDENT_TRIGGER_AND_COOPERATOR
```

### 사고 원인

예정된 온실 실습에서 카시안은 보조 배관의 냉기 마력을 빨리 회수하면 높은 평가를 받을 수 있다고 판단한다. 배관 끝과 압력 상태를 확인하지 않은 채 `흐름+집중`을 사용한다.

```text
냉기 마력 집중 이동
→ 닫힌 회수 밸브에서 역압 발생
→ 중심 핵 안전 정지
→ 서리 정령 과부하
→ 자동 격벽 폐쇄
→ 카시안이 온실 안쪽에 고립
```

카시안의 행동은 장난이나 악의가 아니다. 배운 주문을 빠르게 응용하려 했지만 `집중은 흐름의 출구가 확보됐을 때만 안전하다`는 조건을 놓친 실수다.

### 사건 중 역할

- 자신의 실수를 즉시 인정한다.
- 안쪽 압력계·균열음·밸브 상태를 전달한다.
- 플레이어가 흐름을 보내면 수동 밸브와 격벽을 조작한다.
- 구조 대상이면서도 해결에 기여한다.
- 교수의 개입 전까지 무모하게 버티는 영웅으로 미화하지 않는다.

대표 화법:

- “내가 보조관으로 냉기를 몰았어. 끝이 닫혀 있는 줄 몰랐다.”
- “변명은 나중에 할게. 오른쪽 회수 밸브는 아직 손으로 움직여.”
- “네가 흐름을 보내면 내가 출구를 연다. 이번에는 끝을 확인하고 움직이자.”

## 3.3 온실 관리 선배 — 마렌 브리어

```yaml
role: 2학년 온실 관리 보조
appearance_frequency: OCCASIONAL_CAMEO
speech: 차분하고 구체적인 시설 정보
core_value: 후배에게 판단을 남겨 주는 실무적 도움
bias: 시설 보존을 중시하지만 생명보다 앞세우지 않음
```

마렌은 믿음직한 선배다. 플레이어 일행과 계속 붙어 다니지 않으며, 다음 순간에만 등장한다.

1. 실습 시작 전 온실 설비의 기본 구조를 짧게 설명한다.
2. 사고 후 인접 온실의 확산을 막으러 이동한다.
3. 플레이어가 확인한 시설 명칭이나 도면을 해석해 준다.
4. 결말에서 후배들의 판단을 인정하고 필요한 후속 작업을 맡는다.

마렌이 사건을 직접 해결하지 않는 이유:

- 인접 온실과 지붕 정원으로 번질 수 있는 냉기를 차단해야 한다.
- 내부 상황을 가장 잘 보는 사람은 플레이어와 카시안이다.
- 교수의 교육 원칙에 따라 안전선 밖의 핵심 판단을 빼앗지 않는다.

대표 화법:

- “주 배관만 보지 마. 옆의 회수관은 압력이 비어 있어.”
- “배기탑 끝은 지붕 정원이야. 밖으로 보내는 것도 선택이지만, 사라지는 건 아니야.”
- “내가 옆 온실을 막을게. 안쪽 밸브와 정령 상태는 너희가 더 잘 볼 수 있어.”

---

## 3.4 메인 동반 정령 — 모트

```yaml
role: 플레이어의 지속형 메인 동반 정령
form: 작은 잉크빛 구체와 얇은 날개
speech: 짧고 감각적인 비유
core_value: 살아 있는 마력의 감정과 리듬
bias: 기계 구조와 인간의 장기 계획을 이해하지 못함
```

- 정령이 공격자가 아니라 과부하 피해자일 가능성을 알려준다.
- 냉기 마력이 몰리는 방향을 감각적으로 전달한다.
- 배관 구조·정확한 수치·정답 조합은 알지 못한다.

대표 화법:

- “저 아이들은 화난 게 아니야. 너무 많이 삼켜서 떨고 있어.”
- “차가운 소리가 카시안 쪽으로 몰려.”
- “길은 느껴져. 어느 길을 열지는 네가 정해.”

# 4. 정보 전달 구조

인물을 줄인 대신 필수 정보는 환경과 기록으로 분산한다.

| 정보 | 기본 경로 | 보조 경로 |
|---|---|---|
| 주 배관 과압 | 압력계 | 카시안 통신 |
| 저압 회수관 | 온실 도면 | 마렌 조언 |
| 따뜻한 환기·관개수 | 환경 조사 | 설비 표식 |
| 정령 과부하 | 행동 관찰 | 모트 감각 |
| 카시안 생명 상태 | 교수 생체 모니터 | 카시안 대사 |
| 사고 원인 | 카시안 고백 | 주문 잔향 조사 |
| 철수 가능 | 교수 브리핑 | 비상 규정판 |

한 인물과 대화하지 않아도 최소 하나의 안전한 해결과 철수 판단이 가능해야 한다.

# 5. 관계 변화 원칙

```yaml
relationship_reactions:
  professor:
    positive: 우선순위와 대가를 설명함
    negative: 책임 전가·근거 없는 자기희생
  cassian:
    positive: 실수를 비난하는 데 머물지 않고 협력을 활용함
    negative: 사고 책임을 전부 떠넘기거나 그의 정보를 무시함
  maren:
    positive: 조언을 참고하되 독립적으로 판단함
    negative: 선배가 해결해 주기만 기다림
  mote:
    positive: 정령 상태를 확인함
    negative: 정령을 이유 없이 처치 대상으로 봄
```

카시안을 용서하는 것이 정답은 아니다. 플레이어는 책임을 지적할 수 있지만, 즉시 위기에서는 그의 현장 정보와 조작 능력을 활용할 수 있다.

# 6. 적대적 검토

## 위험 A — 카시안이 사고만 치는 민폐 캐릭터가 됨

대응:

- 사고가 기초 주문의 실제 오판에서 발생한다.
- 즉시 사실을 숨기지 않고 책임을 인정한다.
- 네 개 이상의 해결 패턴에서 수동 조작으로 기여한다.
- 이후 수업과 관계에서 재발 방지 학습을 남긴다.

## 위험 B — 믿음직한 선배가 있는데 왜 해결하지 않는가

대응:

- 마렌은 인접 온실 확산 차단이라는 별도 필수 임무를 맡는다.
- 원격 정보와 도면 해석만 제공한다.
- 내부 핵심 목표를 대신 해결하면 교육 원칙과 플레이어 역할이 무너지므로 금지한다.

## 위험 C — 인물이 줄어 정보가 부족해짐

대응:

- 시설 표식·도면·압력계·주문 잔향 등 환경 단서를 강화한다.
- 필수 생존 정보는 교수 모니터와 카시안 통신으로 중복한다.
- 기본 관찰만으로 봉쇄·철수 루트를 선택할 수 있게 한다.

## 위험 D — 모든 사건이 동급생 실수로 시작함

대응:

- 이번 대표 사건에만 사용하는 발단이다.
- 이후 사건은 시설 노후, 외부 마력 생태, 교수 과제, 플레이어 선택 등 다른 원인을 사용한다.

---

# 7. 검토 대상

1. 인간 핵심 인물을 교수·동급생·선배 카메오 3명으로 줄이는가.
2. 카시안이 사고 촉발자이자 협력자인 구성이 자연스러운가.
3. 마렌은 상시 파티원이 아니라 가끔 등장하는 믿음직한 선배인가.
4. 1학년 과정에서 일상 관계는 동급생 중심으로 유지되는가.
5. 인물을 줄여도 다섯 해결 루트와 20개 대표 패턴을 지원할 수 있는가.
