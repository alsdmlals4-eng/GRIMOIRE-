## 2. 수정 결론

기존 상급생 조언자 `마렌 브리어`를 이번 사건에서 완전히 제거한다. 동급생 `카시안 렌`이 성급한 주문 응용으로 사고를 촉발하고 안전 격벽 안에 고립된다. 카시안은 사고 원인이면서도 밸브·격벽을 조작하는 협력자다.

에일린 교수는 온실 밖으로 번지는 냉기만 고급 외곽 회로로 차단한다. 플레이어는 그 회로의 일부에서 자신이 배운 `흐름`과 `분산`의 형태를 알아보고 다음 원리를 추론할 수 있다.

```text
냉기는 사라지지 않는다
→ 다른 경로로 옮겨진다
→ 좁은 한 점이 아니라 외곽 여러 구간으로 나뉜다
→ 닫힌 고리 안에서 되돌아 순환한다
```

교수는 회로의 이름, 정확한 조합, 플레이어가 사용할 목표를 설명하지 않는다. 회로 관찰은 방향성 힌트이지 정답 공개가 아니다.

최종 등장 구조:

1. 에일린 로스베르 — 교수, 안전선과 관찰 가능한 고급 회로
2. 카시안 렌 — 같은 1학년, 사고 촉발자이자 내부 협력자
3. 모트 — 플레이어의 메인 동반 정령, 정령·마력 감각

# 3. 주요 등장인물

## 3.1 현장 지도 교수 — 에일린 로스베르

```yaml
role: 현장 대응·마력운용학 교수
speech: 짧은 평서문과 판단 질문
core_value: 책임 있는 자립
bias: 근거 없는 자기희생과 책임 전가를 가장 낮게 평가
visible_spell: OUTER_COLD_RETURN_CONTAINMENT_CIRCUIT
```

### 사건 중 행동

사고 직후 교수는 온실 외벽을 따라 고급 회로를 펼친다.

- 네 방향에 `흐름`과 유사한 이동 글자가 반복된다.
- 연결부마다 플레이어가 배운 `분산`과 닮은 가지 구조가 나타난다.
- 화살표는 외부로 향하지 않고 온실 둘레를 따라 닫힌 고리를 만든다.
- 고리의 네 모서리에는 아직 배우지 않은 고정·안전 계열 글자가 존재한다.
- 냉기는 회로 안에서 사라지지 않고 외곽을 따라 이동한 뒤 빈 완충 지대로 되돌아간다.

플레이어가 이해할 수 있는 부분:

```yaml
recognized:
  - FLOW_REDIRECTS_EXISTING_COLD
  - DISPERSE_REDUCES_LOCAL_PRESSURE
  - CLOSED_PATH_PREVENTS_EXTERNAL_SPREAD
not_yet_understood:
  - ADVANCED_ANCHOR_GLYPHS
  - AUTOMATIC_PRESSURE_FEEDBACK
  - FACULTY_SCALE_MANA_CONTROL
```

교수는 다음을 수행하지 않는다.

- 회로 이름과 전체 문법 설명
- 플레이어가 사용할 정확한 출발점·목표 제시
- 내부 핵·배관·정령 문제 해결
- 자신의 회로를 그대로 복사하라고 지시

대표 화법:

- “내 회로가 무엇을 없앴다고 생각하지 마라. 무엇이 어디로 움직였는지 보아라.”
- “알아볼 수 있는 글자만 읽어라. 모르는 부분을 억지로 흉내 내지 마라.”
- “외부 확산은 막았다. 내부 압력과 카시안의 상태는 그대로다.”

## 3.2 동급생 — 카시안 렌

```yaml
role: 플레이어와 같은 1학년 학생
speech: 빠르고 직설적이며 실수 뒤에는 관찰 사실을 숨기지 않음
core_value: 지연보다 행동
bias: 집중과 빠른 결과를 과대평가
incident_role: ACCIDENT_TRIGGER_AND_COOPERATOR
```

### 사고 원인

카시안은 보조 배관의 냉기 마력을 빨리 회수하려고, 출구 상태를 확인하지 않은 채 `흐름+집중`을 사용한다.

```text
냉기 마력 집중 이동
→ 닫힌 회수 밸브에서 역압 발생
→ 중심 핵 안전 정지
→ 서리 정령 과부하
→ 자동 격벽 폐쇄
→ 카시안이 온실 안쪽에 고립
```

카시안의 행동은 악의나 장난이 아니다. 배운 주문을 빠르게 응용하려 했지만 `집중은 흐름의 출구가 확보됐을 때만 안전하다`는 조건을 놓친 실수다.

사건 중 역할:

- 자신의 실수를 즉시 인정한다.
- 안쪽 압력계·균열음·밸브 상태를 전달한다.
- 플레이어가 흐름을 보내면 수동 밸브와 격벽을 조작한다.
- 교수의 외곽 회로를 안쪽에서 관찰한 정보를 공유한다.
- 구조 대상이면서도 해결에 기여한다.

대표 화법:

- “내가 보조관으로 냉기를 몰았어. 끝이 닫혀 있는 줄 몰랐다.”
- “교수님 회로도 냉기를 없앤 게 아니야. 밖으로 나가려던 흐름이 벽을 따라 돌아가고 있어.”
- “네가 흐름을 보내면 내가 출구를 연다. 이번에는 끝을 확인하고 움직이자.”

## 3.3 메인 동반 정령 — 모트

```yaml
role: 플레이어의 지속형 메인 동반 정령
form: 작은 잉크빛 구체와 얇은 날개
speech: 짧고 감각적인 비유
core_value: 살아 있는 마력의 감정과 리듬
bias: 기계 구조와 인간의 장기 계획을 이해하지 못함
```

- 정령이 공격자가 아니라 과부하 피해자일 가능성을 알려준다.
- 교수 회로 안에서 냉기가 흐르는 방향을 감각적으로 전달한다.
- 배관 구조·정확한 수치·정답 조합은 알지 못한다.

대표 화법:

- “저 아이들은 화난 게 아니야. 너무 많이 삼켜서 떨고 있어.”
- “교수의 빛은 차가운 것을 죽이지 않아. 길을 접어서 되돌려 보내고 있어.”
- “길은 느껴져. 어느 길을 열지는 네가 정해.”

# 4. 교수 회로 관찰 UX

사고 직후 플레이어는 별도 행동 횟수를 소비하지 않고 교수의 회로를 짧게 관찰한다.

```yaml
observation_card:
  visible_known_glyphs: [흐름, 분산]
  visible_unknown_elements: [고정_계열, 자동압력조절_계열]
  inferred_effects:
    - 냉기 외부 확산 차단
    - 국부 압력 분산
    - 닫힌 고리 순환
  explicitly_not_solved:
    - 중심 핵 정지
    - 내부 배관 과압
    - 카시안 고립
    - 정령 과부하
```

플레이어에게 표시하는 문구:

```text
알아볼 수 있는 글자
- 흐름: 냉기의 이동 방향을 바꾼다.
- 분산: 한 지점에 몰린 흐름을 여러 구간으로 나눈다.

추론 가능한 경향
- 이 회로는 냉기를 제거하지 않는다.
- 외부로 나가던 냉기를 온실 둘레의 닫힌 경로로 돌린다.
- 내부 문제는 그대로 남아 있다.

알 수 없는 부분
- 모서리의 고급 고정 글자
- 압력을 자동 조절하는 연결 구조
```

`따라 그리기` 버튼은 제공하지 않는다. 플레이어는 자신이 이해한 원리만 현재 주문 설계에 응용한다.

# 5. 정보 전달 구조

| 정보 | 기본 경로 | 보조 경로 |
|---|---|---|
| 주 배관 과압 | 압력계 | 카시안 통신 |
| 저압 회수관 | 온실 도면 | 배관 표식 |
| 냉기 경로 변경 가능 | 교수 회로 관찰 | 모트 감각 |
| 분산이 국부 압력을 낮춤 | 교수 회로의 가지 구조 | 예상 효과 카드 |
| 카시안 생명 상태 | 교수 생체 모니터 | 카시안 대사 |
| 정령 과부하 | 행동 관찰 | 모트 감각 |
| 사고 원인 | 카시안 고백 | 주문 잔향 조사 |
| 철수 가능 | 교수 브리핑 | 비상 규정판 |

한 인물과 대화하지 않아도 최소 하나의 안전한 해결과 철수 판단이 가능해야 한다.

# 6. 적대적 검토

## 위험 A — 교수 회로가 사실상 정답 시연이 됨

대응:

- 교수는 외부 확산만 막고 내부 목표는 해결하지 않는다.
- 회로에는 플레이어가 배우지 않은 고급 글자가 포함된다.
- 플레이어는 `흐름·분산·닫힌 경로`라는 원리만 이해한다.
- 출발점·목표·대가·우선순위는 여전히 플레이어가 선택한다.
- 회로 복사 기능과 정확한 조합 표시는 금지한다.

## 위험 B — 교수가 설명하지 않으면 힌트가 너무 모호함

대응:

- 알려진 글자에는 시각적 하이라이트를 제공한다.
- 회로에 실제 냉기 입자가 이동하는 연출을 보여준다.
- 관찰 카드에서 `무엇이 움직였는가`와 `무엇이 해결되지 않았는가`를 표시한다.
- 교수는 답이 아니라 관찰 범위를 좁히는 한 문장만 말한다.

## 위험 C — 카시안이 사고만 치는 민폐 캐릭터가 됨

대응:

- 즉시 사고를 인정하고 사실을 숨기지 않는다.
- 수동 조작과 내부 관찰로 여러 해결 패턴에 기여한다.
- 결말 뒤 재발 방지 학습을 남긴다.

## 위험 D — 인물이 줄어 정보가 부족해짐

대응:

- 교수 회로, 시설 표식, 도면, 압력계, 주문 잔향을 정보원으로 사용한다.
- 필수 정보는 최소 두 경로로 제공한다.

---

# 7. 검토 대상

1. 이번 사건의 지속 등장 인물을 교수·동급생·동반 정령로 제한하는가.
2. 상급생을 이번 사건에서 완전히 제거하는가.
3. 교수의 외곽 회로를 관찰해 `흐름·분산·순환` 원리를 추론하게 하는가.
4. 교수 회로가 정답 공개가 아니라 방향성 힌트로 남는가.
5. 내부 사건 해결과 주문 설계는 전적으로 플레이어에게 남는가.
