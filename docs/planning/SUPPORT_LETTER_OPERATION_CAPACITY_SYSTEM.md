## 1. 핵심 목적

1학년 초반부터 메인 글자에 보조 글자 두 개를 결합해, 단순 발현이 아니라 **의미 있는 주문 조합의 재미**를 제공한다.

```text
메인 글자 1
+
보조 글자 최대 2
=
1학년부터 운용 가능한 기본 조합 주문
```

예시:

```text
불꽃 메인
+ 투사체 형상
+ 발사 전달
→ 화염탄
```

메인 글자 하나만으로도 주문은 성립하지만, 1학년부터 보조 글자 두 개를 안정적으로 연결할 수 있어야 주문 제작의 핵심 재미를 초반에 체험할 수 있다.

## 2. 학년별 표준 안전 운용량

학년별 기본 보조 글자 운용량은 다음을 `PLANNING_DEFAULT`로 사용한다.

| 학년 | 표준 안전 운용량 | 기본 주문 구조 |
|---:|---:|---|
| 1학년 | 보조 2개 | 메인 1 + 보조 0~2 |
| 2학년 | 보조 4개 | 메인 1 + 보조 0~4 |
| 3학년 | 보조 6개 | 메인 1 + 보조 0~6 |

```text
1학년 2개
→ 2학년 4개
→ 3학년 6개
```

- 학년이 오를 때마다 표준 안전 운용량이 2개씩 증가한다.
- 학년 기본치는 해당 학년의 공통 문법·안전 교육을 정상적으로 이수한 학생에게 보장한다.
- 기본치는 모든 주문에 붙여야 하는 권장 개수가 아니라, 큰 불안정 없이 다룰 수 있는 최대 기준이다.
- 보조 글자를 적게 사용하는 짧고 빠른 주문도 계속 유효해야 한다.

## 3. 절대 슬롯이 아닌 인증된 안전 범위

학년별 수치는 절대적인 하드 슬롯보다 **학교가 인증한 표준 안전 운용 범위**로 취급한다.

```text
표준 범위 이내
→ 안정적인 직접 작성·등록·실습 가능

표준 범위 초과
→ 추가 성적·연구·실기 인증 필요
```

기본 설계에서는 인증되지 않은 조합을 단순히 UI에서 완전히 금지하기보다 다음과 같은 위험 후보를 둘 수 있다.

- 마나 부담 증가
- 작성 오차 허용 범위 감소
- 발동 지연 또는 불안정
- 실습 평가 감점
- 학교 감독 실습에서 사용 제한

정확한 과부하 패널티와 실전 허용 여부는 후속 전투·데이터 설계에서 확정한다.

## 4. 우수 성적 보너스

성적과 연구 성과가 좋은 학생은 현재 학년의 표준치보다 더 많은 보조 글자를 안정적으로 운용할 수 있다.

### 기본 예시

```text
1학년 표준
→ 보조 2개

해당 계열·회로 문법 우수 인증
→ 보조 3개

특별 연구·실기 성과
→ 보조 4개 이상도 후보
```

- 우수 성적 보너스는 단순 전체 평균 점수보다 `회로 문법`, `해당 메인 글자 계열`, `응용 실기`의 성과와 연결한다.
- 모든 메인 글자에 일괄 적용되는 전역 보너스보다, 성과를 증명한 메인 계열에서 추가 운용량을 얻는 방향을 우선한다.
- 예를 들어 불꽃 계열 실기 성적이 우수하면 불꽃 메인을 사용할 때 보조 글자 1개를 추가로 안정 운용할 수 있다.
- 매우 우수한 학생은 한 학년 앞선 조합 규모를 부분적으로 체험할 수 있다.
- 우수 성적이 필수 메인 진행 조건이 되지는 않는다.

## 5. 메인 글자 레벨과의 관계

학년, 성적, 메인 글자 레벨은 서로 다른 역할을 가진다.

| 요소 | 담당 역할 |
|---|---|
| 학년 | 모든 학생에게 제공되는 공통 안전 운용 기반 |
| 성적·인증 | 특정 계열에서 표준치보다 앞선 추가 운용 허가 |
| 메인 글자 레벨 | 해당 현상의 안정성·효율·보조 수용력·전문화 품질 |

- 학년만 올랐다고 메인 글자 자체의 레벨이 자동 상승하지 않는다.
- 메인 글자 레벨만 높다고 배우지 않은 보조 글자를 사용할 수 있는 것은 아니다.
- 추가 운용량은 연결 가능한 보조 글자 수를 늘릴 뿐, 보조 글자의 기능을 자동 습득시키지 않는다.
- 메인 글자 레벨과 성적이 모두 높을수록 상위 조합을 더 안정적으로 다룰 수 있다.
- 정확한 계산식은 후속 데이터 설계에서 정하며, 현재는 역할 경계만 확정한다.

## 6. 학년별 플레이 감각

### 1학년 — 기본 주문 제작의 재미

```text
메인 1 + 보조 2
```

- 기본 발현
- 투사체+발사
- 장벽+고정
- 범위+지속
- 감지+표시

두 보조 글자만으로도 주문의 목적이 명확하게 달라진다.

### 2학년 — 복합 기능 주문

```text
메인 1 + 보조 4
```

- 형상·전달에 출력·지속·행동을 추가
- 서로 다른 수업의 보조 글자를 교차 활용
- 전투와 구조 목적을 함께 만족하는 주문 설계
- 조건·순서 문법의 본격적인 도입

### 3학년 — 고위 주문과 독립 설계

```text
메인 1 + 보조 6
```

- 다단계 행동과 조건 연결
- 장시간 유지되는 영역 주문
- 졸업 실습용 복합 주문
- 메인 글자 전문 분기에 맞는 개인 설계

## 7. DDD 적용 원칙

DDD를 위해 초반 조합 가능성을 과도하게 제한하지 않는다.

```text
메인 글자 습득
→ 같은 학기 안에 보조 글자 두 개 조합
→ 즉시 다른 주문 결과 체험
→ 현장실습에서 활용
→ 결과와 성장 보상
```

- 1학년을 메인 글자 단독 주문만 사용하는 긴 튜토리얼로 만들지 않는다.
- 초반부터 최소 하나의 완성형 조합 주문을 플레이어가 직접 만들 수 있게 한다.
- 수업에서 보조 글자 두 개를 배우는 시점을 지나치게 늦추지 않는다.
- 새로운 보조 글자를 배울 때마다 즉시 기존 메인 글자와 조합해 결과를 확인할 수 있게 한다.
- 복잡도 증가는 학년 전체에 걸쳐 단계적으로 제공하되, 주문 제작의 핵심 재미는 초반부터 노출한다.

## 8. 스톡·준비 용량과의 관계

보조 글자 운용량과 스톡 준비 용량은 별개의 개념이다.

```text
보조 글자 운용량
→ 한 주문에 안정적으로 연결할 수 있는 보조 글자 수

스톡 준비 용량
→ 완성 주문 또는 하위 글자를 몇 개 준비할 수 있는가
```

- 보조 글자 하나는 기존과 동일하게 기능 글자 1개로 계산한다.
- 메인 1 + 보조 2 주문은 기능 글자 3개이며, 완성 주문 스톡 준비 용량도 3을 사용한다.
- 성적이 좋아 보조 글자를 더 운용할 수 있어도 각 글자의 스톡 비용이 할인되지는 않는다.
- 학년별 운용량 증가는 전체 스톡 준비 용량을 자동 증가시키는 규칙이 아니다.
- 완성 주문 스톡에 학년·성적 운용 인증을 어떻게 적용할지는 후속 결정으로 남긴다.

## 9. 성적 보상의 방향

성적 보상은 단순 스탯 증가보다 실제 주문 설계 자유도를 앞당기는 데 사용한다.

보상 후보:

- 특정 메인 계열의 보조 글자 안전 운용량 +1
- 한 단계 높은 응용 실습 조기 참가
- 교수의 고급 보조 글자 연구 과제
- 추가 현장실습 후보
- 전문 연구실 사전 체험
- 시험에서 복합 주문 사용 허가

가드레일:

- 좋은 성적이 없으면 메인 스토리를 진행할 수 없는 구조를 만들지 않는다.
- 모든 과목에서 최고 성적을 받아야 최적 빌드가 되는 구조를 피한다.
- 성적 보너스로 기본 학년 성장의 의미를 완전히 무너뜨리지 않는다.
- 한 학년 학생이 모든 계열에서 다음 학년 표준치 이상을 얻기 어렵게 한다.
- 성적 보너스는 노력과 전문화를 보상하지만 필수 전투력 격차로 확대하지 않는다.

## 10. 현재 확정·보류

### 확정 방향

- 1학년부터 보조 글자 2개 안정 운용
- 학년별 표준 운용량 `2 → 4 → 6`
- 우수 성적·연구 성과로 현재 학년 표준보다 1개 이상 추가 가능
- 추가 운용 보너스는 관련 계열·회로 문법 성과와 연결
- 표준치는 절대 하드 슬롯보다 학교 인증 안전 범위
- 메인 글자 레벨·보조 글자 습득·학년 운용량은 별도 성장축
- 보조 운용량과 스톡 준비 용량은 별개

### 추후 결정

- 성적 등급별 정확한 추가 운용량
- 추가 운용 보너스가 계열별인지 일부 전역인지
- 인증 범위를 넘긴 과부하 주문의 실전 허용 여부
- 과부하의 마나·정확도·불안정 패널티
- 메인 글자 레벨과 안전 운용량의 계산식
- 완성 주문 스톡이 운용 인증을 확인하는 시점
- 각 학년에서 배우는 필수 보조 글자의 실제 목록
