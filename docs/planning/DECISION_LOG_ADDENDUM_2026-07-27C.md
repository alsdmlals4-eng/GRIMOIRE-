## GM-CIRCUIT-07 — Lv.4~Lv.5 메인 글자 전문화

### 채택안

`B — Lv.1~Lv.3 공통 성장, Lv.4~Lv.5 전문 활용 분기`

### 확정 방향

```text
Lv.1 입문
→ Lv.2 숙련
→ Lv.3 응용
→ Lv.4 전문 분야 선택
→ Lv.5 선택 분야 심화·개인 연구
```

- Lv.1~Lv.3은 해당 메인 글자의 공통 원리·안전·기본 활용을 학습한다.
- Lv.4부터 계열별 전문 활용 분야를 선택한다.
- Lv.5는 선택한 분야를 졸업 연구와 개인적인 주문 설계로 심화한다.
- 전문화는 전투·생활·구조·연구의 활용 방식과 관련 실습·교수·진로를 변화시킨다.
- 전문 분기는 새로운 보조 글자를 자동 지급하지 않는다.
- 모든 계열에 공격·방어·지원 분기를 동일하게 복사하지 않고 현상 특성에 맞게 설계한다.
- 실제 분기 수·명칭·변경 가능 여부는 후속 설계로 남긴다.

상태: `DIRECTION_CONFIRMED`

책임 원본: `docs/planning/MAIN_LETTER_SPECIALIZATION_SYSTEM.md`

## GM-CIRCUIT-08 — 학년별 보조 글자 운용량

### 채택안

`1학년부터 보조 2개, 학년마다 기본 운용량 +2, 우수 성적이면 추가 운용`

### 기획 기본값

| 학년 | 표준 안전 운용량 |
|---:|---:|
| 1학년 | 보조 2개 |
| 2학년 | 보조 4개 |
| 3학년 | 보조 6개 |

### 확정 방향

- 1학년부터 `메인 1 + 보조 2` 조합을 운용할 수 있게 한다.
- 1학년을 메인 글자 단독 주문만 사용하는 긴 튜토리얼로 만들지 않는다.
- 학년이 오를 때마다 표준 안전 운용량이 2개씩 증가한다.
- 학년 기본치는 해당 학년의 공통 문법·안전 교육을 이수한 학생에게 보장한다.
- 우수 성적·연구·실기 인증을 받은 학생은 현재 학년의 표준치보다 보조 글자 1개 이상을 추가로 안정 운용할 수 있다.
- 1학년 우수 학생은 보조 3개, 특별한 연구·실기 성과가 있으면 그 이상도 후보로 둔다.
- 추가 운용 보너스는 전체 평균 점수보다 관련 메인 계열·회로 문법·응용 실기 성과와 연결하는 방향을 우선한다.
- 학년별 수치는 절대 하드 슬롯보다 학교가 인증한 안전 운용 범위로 취급한다.
- 인증 범위를 넘는 과부하 주문의 허용 여부와 패널티는 후속 설계로 남긴다.
- 보조 글자 운용량은 한 주문의 조합 복잡도이고, 스톡 준비 용량은 전투 전 준비량이므로 서로 별개다.
- 보조 글자 하나는 여전히 기능 글자 1개로 계산한다.
- 성적이 좋아 더 많은 보조 글자를 사용할 수 있어도 스톡 비용이 할인되지는 않는다.

### DDD 적용

```text
1학년 초반
→ 메인 글자 습득
→ 보조 글자 두 개 습득
→ 메인+보조2의 의미 있는 주문 제작
→ 현장실습에서 즉시 활용
```

주문 제작의 핵심 재미를 초반부터 제공하고, 이후 학년은 단순 기능 해금이 아니라 더 복잡하고 정교한 조합으로 확장한다.

상태: `DIRECTION_CONFIRMED_WITH_PLANNING_DEFAULT`

책임 원본: `docs/planning/SUPPORT_LETTER_OPERATION_CAPACITY_SYSTEM.md`

## 후속 미해결 결정

1. Lv.4 전문 분기를 나중에 변경할 수 있는가.
2. 각 메인 글자의 실제 전문 분기 수와 명칭은 무엇인가.
3. 성적 등급별 추가 보조 글자 운용량은 얼마인가.
4. 추가 운용 인증은 계열별인가, 일부 전역 인증도 존재하는가.
5. 표준 운용량을 넘긴 과부하 주문을 실전에서 허용하는가.
6. 과부하의 마나·정확도·발동 안정성 패널티는 무엇인가.
7. 완성 주문 스톡은 어느 시점의 메인 레벨·운용 인증을 적용하는가.
8. 보조 글자에도 독립 레벨을 둘 것인가, 숙련 등급만 둘 것인가.
