사용자는 전투 화면을 다음 방향으로 승인했다.

> 전투 화면의 전장에는 적만 보이게 하고, 아군은 좌측 하단 얼굴 초상으로 표시하며, 우측에는 마법진·마법 글자를 직접 그릴 수 있는 영역을 둔다.

## 2. 보호되는 기존 결정

이 결정은 다음을 변경하지 않는다.

- 필드와 분리된 별도 고정 3/4 전술 전투장.
- 필드 사건과 전투장의 장소·색·환경 인과.
- 직접 글자 작성과 `메인 글자 1 + 보조 글자 0개 이상` 문법.
- 결과 후 원래 장면 복귀.
- 메인 동반 정령과 수호형 보조 소환수의 역할 분리.
- PC 우선·Mobile 후속.

## 3. 승인된 레이아웃 계약

### 3.1 전장 영역

- 상단·중앙의 가장 큰 영역은 적과 환경 목표에 사용한다.
- 주인공·아군·수호 소환수의 몸체를 전장에 상시 배치하지 않는다.
- 적의 실루엣, 행동 예고, 대상 상태, 환경 위험이 가장 먼저 읽혀야 한다.
- 적 수·위치·전신 또는 반신 표현 방식은 조우별로 조정 가능하지만 아군 몸체가 전장 집중도를 침해하면 안 된다.

### 3.2 아군 상태 영역

- 좌측 하단에 아군 얼굴 초상을 배치한다.
- 초상은 최소한 다음 상태를 구분할 수 있어야 한다.
  - 현재 행동 가능 여부.
  - HP·마나 또는 해당 캐릭터의 핵심 자원.
  - 상태 이상·보호 상태.
  - 선택·대상 여부.
- 실제 파티 인원과 초상 수는 이 이미지나 결정만으로 확정하지 않는다.
- 아군의 공격·보호·피격은 초상 반응, 화면 방향성 FX, 짧은 Cut-in 또는 임시 실루엣으로 표현할 수 있다.

### 3.3 수호 소환수

- 수호 소환수는 전장에 상시 서 있는 아군 몸체로 취급하지 않는다.
- 좌측 하단 초상·배지·보호 게이지 등으로 준비·활성·소진 상태를 표시한다.
- 발동 순간에는 짧은 실루엣·Cut-in·보호 FX로 등장할 수 있으나 적과 작성 영역을 지속적으로 가리지 않는다.

### 3.4 우측 마법 작성 영역

- 우측에 직접 글자·마법진을 그리는 전용 영역을 둔다.
- 일반 전투 상태에서는 축소된 작성 진입 영역으로 둘 수 있다.
- 작성 시작 시 우측 약 30~40% 범위로 확장하는 안을 우선 검토한다.
- 작성 중에도 적의 대상·행동 예고·위험 범위가 완전히 사라지면 안 된다.
- 작성 획, 인식 후보, 메인·보조 글자, 비용·위험, 취소·확정만 우선 표시한다.

## 4. 전투 화면 상태

```text
BATTLE_OVERVIEW
→ ALLY_OR_ACTION_SELECT
→ SPELL_WRITE_OPEN
→ SPELL_RECOGNITION
→ SPELL_COMBINATION_REVIEW
→ CAST_COMMIT
→ BATTLE_RESOLVE
→ BATTLE_OVERVIEW 또는 RESULT
```

### BATTLE_OVERVIEW

- 적과 위험 예고 중심.
- 아군 초상은 좌측 하단.
- 우측 작성 영역은 축소 또는 진입 버튼 상태.

### SPELL_WRITE_OPEN

- 우측 작성 영역 확장.
- 적 화면은 유지하되 보조적으로 암전.
- 좌측 하단 아군 초상과 현재 자원 유지.
- 화면 전환 없이 동일 전투 상태 위에서 작성한다.

### BATTLE_RESOLVE

- 작성 패널을 축소하거나 입력 잠금.
- 적·환경 변화와 원인 피드백을 중심으로 보여 준다.
- 아군은 초상 반응과 상태 갱신으로 결과를 전달한다.

## 5. 금지 사항

- 아군 SD 여러 명과 적을 같은 전장에 상시 나열.
- 수호 소환수가 적보다 큰 면적을 장시간 점유.
- 작성 패널이 적의 위험 예고·타깃·환경 목표를 전부 가림.
- 좌측 하단에 카드 손패·장비·긴 설명을 한꺼번에 배치.
- 참고 이미지의 캐릭터·카드 UI·색·수치를 복제.
- 모바일 Touch UI를 PC판 전투 화면에 상시 표시.

## 6. 후행 결정

다음은 아직 확정하지 않는다.

- 우측 작성 영역의 정확한 폭.
- 작성 패널의 상시 노출 또는 버튼 확장 최종안.
- 동시 표시 아군 수와 파티 구조.
- HP·마나 외 초상 표시 항목.
- 적의 전신·반신·SD 표현 규칙.
- 수호 소환수 Cut-in 길이와 형태.
- 행동 순서 UI의 정확한 위치.

이 항목은 `BATTLE-UX-01`과 `ASSET-SPEC-01`에서 검토한다.
