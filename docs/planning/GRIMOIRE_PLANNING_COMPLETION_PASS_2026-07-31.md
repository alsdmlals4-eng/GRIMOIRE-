## 2. 보호 결정

다음은 유지한다.

- 의미를 가진 마법 글자
- `메인 글자 1개 + 보조 글자 0개 이상`
- 신규·미숙·중요 글자의 직접 작성
- 입력 실패와 주문 설계 실패 분리
- 즉각적이고 설명 가능한 세계 변화
- 수업 → 시험 → 축제 → 현장실습 → 귀환·기록 순환
- 세 번의 자유일정 `휴식 / 준비 / 교류`
- 별도 고정 3/4 전술 전투장
- 메인 동반 정령 초기 형상 1개
- 수호 또는 견제형 보조 소환수 1체
- 첫 완주 목표 45~50분, 허용 상한 60분
- Codex와 Godot 구현은 기획 완료·독립 검수·사용자 승인 뒤 마지막 단계

## 3. 감사 결과

### P0 — 기획 완료 차단

1. PC 우선 플랫폼과 모바일 터치 중심 계약이 충돌한다.
2. 기존 구간별 권장 상한 합계가 전체 60분 상한을 초과할 수 있다.
3. 메인 글자 1개와 보조 글자 2개의 실제 의미·규칙·조합 결과가 없다.
4. 다섯 Situation Challenge의 실제 문제와 복수 해법 표가 없다.
5. 교수와 핵심 동급생이 최소 콘텐츠 범위에는 있지만 주요 인물 정본에 없다.
6. 주인공은 역할만 있고 출발 조건·결핍·개인 목표·Slice 감정 변화가 없다.
7. 자유일정은 이름만 있고 선택별 동등한 효용과 후속 반영이 없다.
8. 학교와 현장실습은 기능 설명은 있으나 사회적 의미와 갈등이 부족하다.
9. 귀환·마도서 기록의 기억 가능한 보상이 추상적이다.
10. Art Style보다 먼저 확정해야 할 콘텐츠 대상이 남아 있다.

### P1 — 보완 필요

- 완성 주문 스톡과 소환수 충전이 장기 참고인지 현재 코어인지 문서마다 다르게 읽힌다.
- PC 마우스·펜 작성의 손맛, 피로, 오류 복구 계약이 없다.
- Gamepad 지원 여부가 미정이며 직접 작성 코어와 충돌 가능성이 있다.
- 전투의 승리 조건과 환경 문제의 결과 차이가 구체화되지 않았다.
- 학교 문화, 장학생의 위치, 정석과 현장의 차이가 인물 갈등에 연결되지 않았다.
- 제작량을 제한하는 장면·캐릭터·변형·대사 예산이 없다.

## 4. 대표 글자 접근법 비교

| 접근 | 메인 | 보조 | 장점 | 위험 | 판정 |
|---|---|---|---|---|---|
| A | 흐름 | 집중 / 분산 | 전투·환경·축제에 모두 적용, 동일 원리의 재해석이 선명함 | 추상적으로 보일 수 있어 시각 피드백이 중요 | **권장** |
| B | 열 | 집중 / 분산 | 즉시 이해되고 연출이 강함 | 불·공격 중심 게임으로 오해될 수 있음 | 대안 |
| C | 결속 | 고정 / 해방 | 세계 규칙을 바꾸는 지적 판타지가 강함 | 첫 5분 학습 난도가 높고 결과가 덜 직관적 | 후행 후보 |

### 권장 이유

`흐름`은 물, 공기, 빛, 마력, 압력처럼 이미 존재하는 움직임을 다룬다. 물질이나 에너지를 무에서 생성하지 않으므로 제한 조건과 실패 원인을 설명하기 쉽다. `집중`과 `분산`은 서로 반대되는 성향이라 같은 메인 글자에 붙였을 때 결과 차이가 즉시 보인다.

이 선택은 `RECOMMENDED_CANDIDATE`이며 사용자 검토 전 최종 룬·시각 문양·세계관 고유명으로 확정하지 않는다.

## 5. 권장 글자 문법

### 5.1 메인 글자: 흐름

```text
의미
= 이미 존재하는 물질·에너지·힘의 이동 방향을 바꾼다.

가능
= 우회, 전달, 순환, 끌어오기, 밀어내기, 경로 변경

불가능
= 무에서 물질·에너지 생성, 대상의 본질 변경, 영구 고정
```

### 5.2 보조 글자: 집중

```text
의미
= 흐름의 범위를 좁히고 힘·정밀도·도달 거리를 높인다.

대가
= 높은 불안정성, 국소 손상 위험, 더 높은 집중 부담
```

### 5.3 보조 글자: 분산

```text
의미
= 흐름을 넓게 나누어 최대 힘을 낮추고 범위·안정성을 높인다.

대가
= 낮은 순간 출력, 느린 해결, 넓은 자원 소모
```

### 5.4 조합 결과

| 조합 | 기본 결과 | 플레이 감정 | 대표 위험 |
|---|---|---|---|
| 흐름 | 방향을 바꾸고 연결한다 | 원리를 이해했다 | 힘이 부족하거나 경로가 불안정 |
| 흐름 + 집중 | 좁고 강한 흐름을 만든다 | 정밀하고 대담하다 | 과압·과열·대상 손상 |
| 흐름 + 분산 | 넓고 완만한 흐름을 만든다 | 안정적이고 배려한다 | 출력 부족·시간 지연 |

### 5.5 실패 분류

| 실패 | 원인 | 피드백 |
|---|---|---|
| 입력 불일치 | 의도한 글자와 인식 후보가 다름 | 획·후보·수정 위치만 표시, 주문 결과 판정 금지 |
| 문법 불완전 | 메인 없이 보조만 사용 | 필요한 역할을 설명하되 정답 조합은 제시하지 않음 |
| 대상 부적합 | 움직일 흐름이 없거나 대상이 고정됨 | 관찰한 세계 상태와 부족한 조건을 설명 |
| 과집중 | 국소 힘이 안전 한계를 초과 | 손상 위치·원인·감소 방법을 표시 |
| 과분산 | 목표 달성에 필요한 최소 출력 미달 | 범위는 충분하지만 힘이 부족했음을 표시 |
| 자원 부족 | 현재 집중력·마나·허용 횟수 부족 | 비용과 현재 보유량을 분리 표시 |

## 6. 주인공과 핵심 인물

### 6.1 주인공 — 일반 가정 출신 장학생 신입생

```text
외적 목표
= 첫 학기 평가와 현장실습을 통과해 장학생 자격을 증명한다.

내적 결핍
= 마법에는 하나의 정답이 있으며 틀리면 자격이 없다고 생각한다.

강점
= 관찰, 원리 이해, 서로 다른 상황의 공통점 발견

약점
= 평가 압박에서 정석을 과도하게 복제하고 실패를 자기 재능 부족으로 해석

Slice 변화
= 정답을 외우는 학생에서, 결과의 책임을 지고 의미를 설계하는 마법사로 이동
```

### 6.2 지도 교수

- 역할: 글자의 형태보다 의미·조건·책임을 가르친다.
- 가치: 안전성과 설명 가능성을 중시하지만 창의성을 억압하지 않는다.
- 갈등: 주인공이 정답을 요구할수록 결과의 원인을 스스로 말하게 한다.
- 기능: 튜토리얼, 시험 평가, 귀환 기록의 성장 비교.
- 금지: 정답 조합을 직접 알려주거나 실패를 단순 재능 문제로 규정.
- 이름: `WORKING_NAME_REQUIRED`, Art/Narrative 검토 전 확정하지 않는다.

### 6.3 핵심 동급생

- 출발: 마법사 가문 출신이며 정석 글자를 빠르고 정확하게 재현한다.
- 가치: 속도, 평가 기준, 검증된 방식.
- 주인공과의 관계: 적대자가 아니라 서로 다른 학습 방식의 경쟁자이자 협력자.
- 시험: 정석 해법을 먼저 보여 주어 주인공의 압박을 높인다.
- 축제: 효율보다 표현이 중요하다는 사실을 함께 경험한다.
- 현장: 주인공의 비정형 재설계가 실제 위험을 줄이는 것을 목격한다.
- 귀환: 성적이 아니라 서로의 해결 방식에 대한 존중으로 관계가 한 단계 변한다.
- 이름: `WORKING_NAME_REQUIRED`.

### 6.4 메인 동반 정령

- 초기 형태: 작은 늑대형 원소 정령수 방향 유지.
- 역할: 플레이어의 학습·감정·기록을 연결하는 동반자.
- 표현: 말로 정답을 제공하기보다 긴장, 신뢰, 망설임, 기쁨을 반응으로 보여 준다.
- 관찰 도움: 위험 강도나 흐름의 불안정을 감지할 수 있지만 해결 조합은 제시하지 않는다.
- Slice 관계 단계: 낯섦 → 신뢰 시도 → 공동 발견.

### 6.5 전투 보조 소환수

- 역할 후보: `수호` 우선 권장.
- 이유: 직접 작성 시간을 확보하는 기능이 명확하며 주문 설계를 대체하지 않는다.
- 행동: 짧은 보호막 또는 공격 차단 구간을 제공.
- 금지: 자동 공격으로 전투 해결, 글자 선택, 자동 시전, 상시 무적.

## 7. 학교와 세계의 최소 설정

### 학교의 교육 철학

마법 글자는 단어가 아니라 세계에 가하는 명령이다. 학교는 강한 주문보다 결과를 설명하고 책임질 수 있는 주문을 우선 평가한다.

### 장학생의 위치

- 일반 가정 출신 학생에게 학교는 계층 이동의 기회다.
- 장학 평가가 있어 주인공에게 현실적 압박을 준다.
- 가문 출신 학생은 사전 교육과 정석 자료에 익숙하다.
- 갈등은 혈통 우열이 아니라 접근 가능한 교육 자원과 실패 허용 폭의 차이로 표현한다.

### 현장실습의 이유

교내 장치는 조건이 통제되지만 실제 세계의 마력 흐름은 낡은 구조물, 생명, 날씨, 사람의 생활과 얽혀 있다. 현장실습은 정답 암기가 아니라 관찰·책임·부분 성공을 배우는 과정이다.

### 마도서의 사회적 의미

마도서는 완성 주문 목록이 아니라 `상황-설계-결과-부작용-발견`을 기록하는 학습 증거다. 기록은 다음 수업과 평가의 근거이며, 플레이어가 어떤 마법사로 성장하는지 보여 준다.

## 8. Vertical Slice 장면 설계

### 8.1 프롤로그·첫 수업·교내 연습

**상황:** 입학 첫날, 실습실의 소형 마력 수로가 불안정해 연습 장치로 공급되는 흐름이 새고 있다.

```text
학교 도착과 장학 평가 압박
→ 메인 동반 정령과 첫 반응
→ 교수의 흐름 시범
→ 플레이어가 흐름 글자 직접 작성
→ 새는 마력의 경로를 되돌림
→ 집중·분산 학습
→ 같은 흐름을 좁고 강하게 / 넓고 안정적으로 바꾸는 비교
→ 동급생의 빠른 정석 시전
→ 교수의 "결과 원인을 설명하라" 피드백
```

학습 증거:

- 첫 직접 작성이 시작 후 5분 이내.
- 흐름·집중·분산의 차이를 결과 화면에서 비교.
- 입력 불일치 1회와 설계 부족 1회를 안전하게 경험할 수 있음.

### 8.2 첫 실기시험 — 취약한 부유 수정구 이송

**목표:** 교차 기류가 있는 시험장에서 깨지기 쉬운 수정구를 안전선 안으로 이동한다.

**제한:** 허용 시전 2회, 수정구 충격 한계, 정해진 마나.

유효 해법:

1. `흐름 + 집중`: 짧고 정밀한 경로로 빠르게 이동. 효율 점수가 높지만 과집중 시 손상 위험.
2. `흐름 + 분산`: 넓은 완충 흐름으로 안정적으로 이동. 안전 점수가 높지만 시간·마나 소모가 큼.

금지되는 단순 반복:

- 흐름 단독을 반복하면 교차 기류를 이기지 못하고 경로가 흔들린다.
- 동급생의 정석 경로를 그대로 복제해도 플레이어의 현재 자원과 시작 위치가 달라 동일 결과가 나지 않는다.

평가 축:

- 상황 적합성
- 주문 설계
- 실행 안정성

### 8.3 학교축제 — 빛실 장막 복구

**상황:** 기존 학교 장면 세트에 설치된 빛실 장막의 마력 흐름이 끊겨 공연 직전 연출이 무너진다.

유효 결과:

| 설계 | 결과 태그 | 표현 |
|---|---|---|
| 흐름 | PRACTICAL | 끊긴 경로를 단순 복구해 안정적으로 점등 |
| 흐름 + 집중 | SPECTACULAR | 빛을 좁고 강하게 모아 선명한 상징과 순간 연출 생성 |
| 흐름 + 분산 | ELEGANT | 빛을 넓게 퍼뜨려 공간 전체를 부드럽게 감싸는 장막 생성 |

세 결과는 모두 성공 가능하다. 축제는 최적해가 아니라 플레이어의 표현 성향과 관계 반응을 기록한다.

### 8.4 첫 현장실습 — 외곽 생태 온실의 마력 관개 수로

**사건:** 오래된 관개 수로의 마력 압력이 비정상적으로 쌓여 온실 수호 정령이 폭주한다. 전투와 환경 문제는 같은 원인에서 발생한다.

#### 전투 문제

목표: 폭주 정령을 파괴하는 대신 압력 근원을 끊고 진정시킨다.

유효 해법:

1. `흐름 + 집중`: 압력을 정령의 고정점에 정밀하게 되돌려 핵을 노출. 빠르지만 반격 위험이 높다.
2. `흐름 + 분산`: 압력파를 넓게 흩어 공격 강도를 낮추고 안전하게 접근. 느리지만 피해가 적다.

보조 소환수:

- 수호형 소환수가 짧은 작성 안전 시간을 제공.
- 소환수 사용 시 작성 중 피격과 취소 횟수가 줄어드는지 검증.
- 소환수 없이도 더 어려운 방식으로 완료 가능하되 자동 정답은 제공하지 않음.

#### 환경 문제

전투 후 금이 간 관개관에서 마력수가 새어 희귀 묘목과 구조물 모두가 위험하다.

유효 해법:

1. `흐름 + 집중`: 누출을 임시 우회관으로 모아 희귀 묘목을 즉시 구함. 낡은 관의 추가 부담이 남음.
2. `흐름 + 분산`: 전체 압력을 측면 배수로에 나누어 구조물을 보호. 일부 마력수와 수확량을 포기.

결과는 성공/실패만이 아니라 `SEEDLINGS_PRIORITIZED` 또는 `STRUCTURE_PRIORITIZED`로 기록한다.

### 8.5 귀환·마도서 기록

```text
시험의 설계 성향
→ 축제 표현 태그
→ 현장 우선순위 태그
→ 입력 실패와 설계 실패 복기
→ 플레이어가 발견한 첫 주문 활용에 이름 붙이기
→ 교수의 성장 비교
→ 동급생의 관점 변화
→ 메인 동반 정령의 관계 반응
→ 다음 학기의 새 의미군 예고
```

기억 가능한 보상:

- 첫 발견 항목을 플레이어가 직접 명명.
- `정밀 / 안정 / 표현 / 책임` 중 드러난 성향을 문장으로 요약.
- 필드와 마도서에 결과 흔적을 남김.
- 다음 학기에서 배우게 될 다른 메인 의미의 실루엣만 예고.

## 9. Problem Differentiation Matrix

| 세션 | 읽어야 할 정보 | 핵심 판단 | 복수 해법 | 반복 해법 방지 | 다음 학습 |
|---|---|---|---|---|---|
| 수업 | 흐름 방향·강도 | 메인과 보조의 역할 | 집중 / 분산 비교 | 실패 비용이 낮아 직접 비교 | 결과 원인을 말할 수 있음 |
| 시험 | 교차 기류·충격 한계·자원 | 효율과 안정성 균형 | 정밀 이송 / 완충 이송 | 흐름 단독 반복은 기류에 밀림 | 제한 조건 아래 설계 |

| 현장 전투 | 압력원·정령 공격·작성 안전 시간 | 빠른 노출과 안전한 진정 | 집중 돌파 / 분산 완화 | 공격 반복으로 정령 파괴 시 낮은 책임 평가 | 위험 속 우선순위 |
| 현장 환경 | 누출·묘목·구조물 상태 | 무엇을 먼저 보호할지 | 묘목 우선 / 구조 우선 | 모두 완전 보존하는 무비용 해법 없음 | 부분 성공과 책임 |

## 10. 자유일정 설계

공통 결과 태그:

- `CALM`: 입력 복구와 집중 안정
- `PREPARED`: 조건 관찰과 결과 예측 강화
- `CONNECTED`: 관계 반응과 다른 관점 강화

어떤 태그도 필수 정보나 유일한 해법을 독점하지 않는다.

### 자유일정 A — 시험 전

| 선택 | 짧은 장면 | 시험 영향 |
|---|---|---|
| 휴식 | 동반 정령과 조용한 휴식 | 첫 입력 불일치 1회에 평가 페널티 없음 |
| 준비 | 연습 장치로 보조 의미 비교 | 예상 결과에 안정성 또는 비용 축 하나 추가 표시 |
| 교류 | 동급생과 정석·응용 관점 대화 | 시험 후 관계 반응과 해법 해석 대사 변화 |

### 자유일정 B — 축제 전

| 선택 | 짧은 장면 | 축제 영향 |
|---|---|---|
| 휴식 | 소음에서 벗어나 정령과 호흡 조율 | 작성 제한 시간이 완화되거나 재작성 1회 추가 |
| 준비 | 빛실 재료의 반응을 미리 확인 | 재료 한 종류의 반응 경향 사전 공개 |
| 교류 | 동급생과 공동 연출 아이디어 교환 | 축제 결과에 공동 모티프와 관계 반응 추가 |

### 자유일정 C — 현장 전

| 선택 | 짧은 장면 | 현장 영향 |
|---|---|---|
| 휴식 | 장거리 이동 전 회복 | 현장 시작 집중 버퍼 증가 |
| 준비 | 현장 보고서와 수로 도면 확인 | 위험 원인 하나를 전투 전 관찰 가능 |
| 교류 | 보조 소환수와 수호 타이밍 조율 | 첫 수호 지속 또는 경고 피드백 강화 |

## 11. PC 우선 입력 계약

### 11.1 기본 입력

| 행동 | 기본 입력 | 대체·보조 |
|---|---|---|
| 획 작성 | 마우스 왼쪽 버튼 드래그 | 펜 태블릿·스타일러스 |
| 현재 획 취소 | 마우스 오른쪽 버튼 또는 `Esc` | 화면 버튼 |
| 이전 획 되돌리기 | `Ctrl+Z` | Undo 버튼 |
| 글자 전체 지우기 | `R` 길게 누르기 | Clear 버튼과 확인 |
| 후보 이동 | 마우스 클릭·휠 | 방향키·Tab |
| 후보 확정 | 클릭 또는 `Enter` | 확인 버튼 |
| 이전 단계 | `Esc` | 뒤로 버튼 |
| UI 포커스 이동 | `Tab / Shift+Tab` | 마우스 |

게임패드는 직접 작성 코어를 대체할 안전한 방식이 확정되기 전까지 `DEFERRED / NOT_PROMISED`로 둔다.

### 11.2 공통 입력 흐름

```text
획 작성
→ 인식 후보와 확신 상태
→ 사용자 확인 또는 부분 수정
→ 의미 조합
→ 상황 결과 경향 확인
→ 명시적 시전
→ 세계 변화와 원인 설명
```

### 11.3 PC 접근성 후보

- 획 허용 범위 조절
- 선택적 선 보정과 떨림 완화
- 커서 크기와 대비 조절
- 고대비 획 잔상
- 색 외 형태·아이콘·텍스트 피드백
- 반복 클릭 대신 키보드 확정
- 모션 감소와 화면 흔들림 제한
- 자동 시전 완전 금지

이 항목은 구현 수치가 아니라 Art/UX 검증 전 계약 후보다.

### 11.4 후속 모바일 원칙

모바일은 PC판 규칙과 콘텐츠를 바꾸지 않는다. 포인터 입력을 터치로 치환하고 가림·피로·배터리·백그라운드 복귀를 별도 검증한다. 기존 Android 연구는 모바일 전환 참고 자료로 보존하되 PC 런타임 증거로 사용하지 않는다.

- 53분을 넘으면 대사를 축약하기 전에 반복 입력, 이동, 중복 설명을 먼저 감량.
