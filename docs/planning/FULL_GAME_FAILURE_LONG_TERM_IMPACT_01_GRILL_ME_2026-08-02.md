## 2. 승인된 결론

사용자는 권장 A안을 승인하고 다음 평가 규칙을 추가했다.

```text
사건·활동 결과 발생
→ 지킨 것·잃은 것·부작용·발견은 즉시 세계와 마도서에 기록
→ 성적 점수·감점·장학 상태는 즉시 표시하지 않음
→ 부분 성공·실패는 내부 학기 평가에 작은 감점만 누적
→ 이후 수업·교류·연구·제작·현장에서 새 긍정 증거를 쌓을 수 있음
→ 학기 종료 시 전체 포트폴리오와 함께 종합 평가
```

## 3. 즉시 보이는 것과 숨기는 것

### 즉시 보이는 것

- 현장에서 실제로 보존하거나 잃은 대상.
- 제작물의 품질·부작용·변질·대체 활용.
- 인물과 정령의 자연스러운 대사·행동 반응.
- 장소 상태와 후속 문제·발견.
- 마도서의 사건 기록과 플레이어가 설명한 판단.

### 학기 중 숨기는 것

- 내부 평가 점수.
- 사건별 감점량.
- 현재 예상 학기 등급.
- 장학 유지 임계값과 남은 여유치.

숨김 점수는 UI 게이지·팝업·경고 문구·교수의 암시적 숫자 대사로 노출하지 않는다.

## 4. 평가 규칙

- 부분 성공·실패의 감점은 **작고 상한이 있는 보정치**다.
- 한 번의 실패가 학기 전체 평가·장학 유지·전문화를 지배하지 못한다.
- 같은 실수를 반복하면 별도 무한 감점 대신 반복 패턴으로 학기말 서술 평가에 반영한다.
- 성공·발견·복기·다른 맥락의 응용은 별도 포트폴리오 증거로 누적된다.
- 회복 활동은 숨은 감점을 직접 삭제하는 벌점 제거 퀘스트가 아니다. 새로운 긍정 증거·관계·발견·대체 해법을 만든다.
- 학기 중 관계 단절·수강 폐쇄·메인 진행 차단·즉시 장학 경고는 발생하지 않는다.
- 중대한 서사 결과는 세계 상태로 남을 수 있지만 성적 처벌과 동일시하지 않는다.

정확한 사건별 감점, 학기 총감점 상한, 평가 가중치, 등급 경계는 `TEST_VALUE`다.

## 5. 학기말 평가

학기 종료 시 다음 증거를 함께 평가한다.

1. 기초 학습과 문자 이해.
2. 일상·축제의 비전투 응용.
3. 현장 전투·환경 해결.
4. 제작·연구·미니게임 활용.
5. 부분 성공·실패 이후의 복기와 후속 행동.
6. 마도서에 남긴 판단·책임·발견.

플레이어에게는 최종 평가 결과와 근거가 된 대표 사건을 문장으로 설명한다. 내부 원점수와 사건별 숨은 감점표를 그대로 공개하지 않는다. 학기말 표시 형식은 등급·평가 문장·교수 코멘트 후보이며 정확한 UI는 후속 UX Gate에서 결정한다.

## 6. 적대적 보호 규칙

- 숨김 점수가 플레이어를 기만하는 무작위 판정이 되지 않도록 모든 반영은 승인된 평가 축과 실제 사건 로그에서만 계산한다.
- 학기말 평가 문장은 어떤 행동과 판단이 영향을 줬는지 설명한다.
- 재료·미니게임 반복으로 숨은 점수를 무한 상쇄하지 못한다.
- 저장 불러오기를 하지 않아도 정상 진행·장학 유지·본편 완주가 가능해야 한다.
- 낮은 평가가 콘텐츠 대량 폐쇄나 메인 진행 실패로 직결되지 않는다.
- 장학 상태의 실제 변화가 필요하다면 학기말 종합 평가에서만 처리하고, 보완 학습·다음 학기 회복 경로를 함께 제공한다.

## 7. 거부된 구조

- 사건 직후 점수 증감 팝업.
- 실시간 장학 게이지와 예상 등급 표시.
- 한 번의 실패로 장학 박탈·관계 단절·수강 폐쇄.
- 제작·반복 파밍으로 감점을 직접 구매해 제거.
- 원인을 설명하지 않는 학기말 블랙박스 판정.
