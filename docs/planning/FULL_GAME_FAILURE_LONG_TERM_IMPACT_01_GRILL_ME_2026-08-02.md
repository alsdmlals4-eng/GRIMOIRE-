## 2. 결정 질문

부분 성공·실패·부작용·포기한 대상이 장학 평가·관계·다음 일정과 추가 콘텐츠에 어떻게 남아야, 선택의 책임은 느껴지면서도 저장 불러오기와 영구 진행 차단을 강요하지 않을 것인가?

## 3. A안 — 결과 태그 + 회복 기회 나선 / 권장

```text
사건 결과
→ 보존·피해·부작용·책임 태그 기록
→ 교수·동료·정령·장소 반응 변화
→ 다음 Chapter의 준비 조건·추가 콘텐츠·회복 기회 개방
→ 후속 행동으로 일부 피해 복구 또는 새로운 해법 발견
→ 결과와 회복 과정 모두 마도서에 남김
```

장기 상태 예시:

- `TRUST_GAINED / TRUST_STRAINED`.
- `SITE_STABLE / SITE_DAMAGED`.
- `RESEARCH_LEAD / UNRESOLVED_RISK`.
- `SCHOLARSHIP_STABLE / SCHOLARSHIP_WARNING`.
- `MATERIAL_SAVED / MATERIAL_LOST / ALTERED_MATERIAL_DISCOVERED`.

핵심 규칙:

- 실패는 즉시 Game Over나 메인 진행 봉쇄보다 세계·관계·준비 조건을 바꾼다.
- 장학 상태는 한 번의 실수로 즉시 박탈되지 않고 경고·보완·회복 단계가 있다.
- 회복 기회는 단순 벌점 제거 퀘스트가 아니라 수업·연구·교류·제작 미니게임·현장 재방문으로 구성한다.
- 모든 손실을 완전히 되돌릴 수는 없지만 다른 가치·발견·관계가 생길 수 있다.
- 부분 성공은 성공과 동일한 보상을 받는 것이 아니라 지킨 것·잃은 것·새로 배운 것을 분리한다.
- 저장 불러오기를 하지 않아도 게임을 계속할 수 있다.

장점:

- 책임 선택이 세계에 남는다.
- 실패가 추가 콘텐츠·연구·제작·관계 장면으로 이어진다.
- 재료·제작 C 계층이 복구와 새로운 발견에 의미 있게 쓰인다.
- 단일 숫자 평판보다 원인과 결과를 설명하기 쉽다.

위험:

- 결과 태그 조합이 늘어나면 콘텐츠 제작·QA가 증가한다.
- 모든 실패에 회복 콘텐츠를 만들면 분기량이 폭증한다.

보정:

- 결과를 `사람 / 장소 / 연구 / 장학` 네 축의 제한된 상태로 표준화한다.
- 고유 회복 콘텐츠는 주요 Chapter에 집중하고, 나머지는 공통 장면·미니게임·대화 변주를 재사용한다.

## 4. B안 — 장학 점수·평판 수치형

```text
성공·실패에 따라 장학 점수와 인물 평판 증감
→ 기준치에 따라 보상·경고·콘텐츠 개방
```

장점:

- 상태를 이해하기 쉽고 구현이 단순하다.
- 밸런스와 조건 분기가 명확하다.

위험:

- 플레이어가 결과보다 점수 최적화와 저장 불러오기에 집중한다.
- 책임·부작용·관계 맥락이 숫자 하나로 축소된다.
- 미니게임과 재료가 점수 파밍 수단으로 변질될 수 있다.

## 5. C안 — 강한 영구 분기·손실형

```text
실패·포기한 대상에 따라 장소·인물·수강·결말이 영구 폐쇄
→ 다음 플레이에서 다른 경로 탐색
```

장점:

- 선택의 무게와 재플레이 가치가 강하다.
- 세계가 실제로 변한다는 감각이 크다.

위험:

- 초기 실수로 콘텐츠가 사라지고 학습 RPG가 처벌적으로 변한다.
- Solo 제작에서 분기 콘텐츠의 미소비율이 너무 커진다.
- 사용자가 원하는 다계열·미니게임·추가 콘텐츠를 한 회차에서 경험하기 어렵다.

## 6. 권장 판정

```text
→ 완전 복구 또는 새로운 방향 수용

```

- 제작 미니게임과 추가 콘텐츠가 회복·재해석 경로에 포함된다.
- 모든 결과를 완전 복구할 수는 없지만 대체 가치와 발견을 제공한다.
