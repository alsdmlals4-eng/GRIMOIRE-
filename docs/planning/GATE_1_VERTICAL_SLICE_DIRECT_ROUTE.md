## 3. 확정된 Vertical Slice 형태

### 축약 학기형

```text
프롤로그·학교 도착
→ 세션 1: 첫 수업·교내 연습
→ 자유일정 A 1회
→ 세션 2: 첫 실기시험
→ 자유일정 B 1회
→ 세션 3: 학교축제 준비·학교축제
→ 자유일정 C 1회
→ 세션 4: 첫 현장실습
→ 귀환·마도서 기록·다음 학기 예고
```

### 세션 역할

```text
수업·연습 = 배움
시험 = 이해의 증명
학교축제 = 표현·관계·비전투 활용
현장실습 = 실제 위험 속 응용·발견
자유일정 = 휴식·준비·관계·연구의 완충
귀환·기록 = 결과 해석과 다음 학습 연결
```

### 자유일정 원칙

- 수업 후·시험 후·축제 후에 총 3회 배치한다.
- 한 슬롯에서 행동 1개만 선택한다.
- `휴식`을 유효한 전략 선택지로 제공한다.
- 복습·관계·축제 준비·현장 조사·보조 소환수 훈련 등을 상황에 따라 제공한다.
- 어떤 선택도 다음 중요 일정 참가를 차단하지 않는다.
- 특정 선택에 필수 정보나 정답을 독점시키지 않는다.
- 선택은 작은 보정·관계·정보·준비 차이를 만든다.

## 4. Validation-First 원칙

Vertical Slice는 콘텐츠와 연출부터 늘리는 단계가 아니다.

```text
핵심 인과를 실제 플레이로 연결
→ Slice 내부 검증 빌드
→ 실패 가설 수정
→ 최종 방향에 가까운 UI·아트·사운드 통합
→ 외부 플레이 가능한 축약 학기형 Slice
```

비타협 검증 인과:

```text
상황 관찰
→ 메인·보조 글자 선택
→ 직접 작성
→ 설명 가능한 적·환경·생활 문제 변화
→ 성공 또는 실패 원인 확인
→ 주문 재설계
→ 시험·축제·현장에서 다른 활용
→ 새 활용 기록
```

이 인과가 증명되기 전에는 학기·지역·관계·소환수·주문 콘텐츠를 확대하지 않는다.

## 5. 반드시 포함할 검증

### 핵심 마법

- 첫 5분 안의 직접 작성과 즉각적 발현
- 메인 글자 1개와 보조 글자 2개의 역할 차이
- 입력 실패와 설계 실패의 분리
- 최소 두 가지 유효 해결법
- 실패 원인 이해와 재설계
- 같은 마법 문법의 시험·축제·현장실습 재사용

### 학교생활

- 수업·시험·학교축제·현장실습의 역할 차이
- 중요 일정 사이 자유일정 1회씩
- 휴식이 유효한 선택인지 확인
- 자유일정 결과가 다음 일정에 작은 차이를 만드는지 확인
- 고정 핵심 사건과 자유 일정의 혼합 구조 이해

### 소환수

- 메인 동반 소환수의 학습·관계·기록 연결
- 전투 보조 소환수의 수호 또는 견제
- 보조 소환수 유무에 따른 작성 시간·피격·완주율 비교
- 두 계층의 역할 구분
- 주문 설계와 글자 작성 대행 금지

### 모바일·제품

- 완전 정지·감속·실시간 작성 방식 비교
- 손가락 가림·피로·인지 부하
- Android 실제 기기와 주요 화면비
- 각 핵심 세션·자유일정 사이 저장·중단·복귀
- 두 번째 유사 콘텐츠 제작 가능성

## 8. 통과 금지 조건

- 직접 작성이 반복 피로나 인식 오류로 핵심 재미를 방해
- 시험·축제·현장실습이 같은 문제의 외형 변경처럼 느껴짐
- 자유일정이 최적 보상 메뉴 또는 불필요한 대화로만 느껴짐
- 휴식이 명백한 손해 선택으로 작동
- 메인 동반자가 정답을 대신 제시
- 보조 소환수 조작이 주문 설계보다 복잡
- 전체 Slice가 학교 1학기 전체 제작으로 팽창
- 세션별 콘텐츠가 일회성 하드코딩에 의존
- 저장·복귀 후 현재 목표와 선택 결과를 이해하기 어려움

수정 우선순위:

```text
입력 판정·시간 처리·피드백
→ 세션별 문제 역할 구분
→ 자유일정 선택 수와 결과 규모
→ 전투 압박·보조 소환수 조작량
→ 축제·관계 연출 분량
→ 전체 세션 길이
```
