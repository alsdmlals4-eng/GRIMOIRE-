## GM-NARRATIVE-02 — 상황별 혼합형 핵심 스토리 표현

### 채택안

`C — 상황별 혼합형`, 일반 사건은 B안에 가까운 `짧은 대사 + 목표 카드`를 기본값으로 사용한다.

### 확정 구조

```text
일반 사건·수업·학교 의뢰
→ NPC 한두 문장
→ 목표·위험·보상 카드
→ 즉시 조작

긴급 임무·전투 돌입
→ 경고 또는 한 줄 보고
→ 긴급 목표·위험 카드
→ 즉시 행동

중요한 감정·관계·학년 전환
→ 일반 대화창
→ 감정적 핵심 전달
→ 조작권 반환

선택형 상세 이야기
→ NPC 재대화·질문 목록·장소 조사·기록
```

### 정보 역할 분리

- 진행 정보는 목표 카드와 HUD에서 명확하게 전달한다.
- 인물의 감정과 관계는 필요한 장면에서 일반 대화창으로 전달한다.
- 세계관·학교 역사·사건의 세부 맥락은 선택형 대화와 기록으로 확장한다.
- 중요한 장면에서도 이미 전달한 임무 정보를 반복하지 않는다.
- 일반 사건에 장문 대화창을 기본값으로 사용하지 않는다.

### 상황별 적용

| 상황 | 기본 표현 | 목적 |
|---|---|---|
| 일반 수업·의뢰 | 짧은 대사 + 목표 카드 | 빠른 이해와 즉시 행동 |
| 긴급 임무·전투 돌입 | 경고 + 긴급 목표 카드 | 위험 정보 우선 전달 |
| 감정·관계·승급 장면 | 일반 대화창 | 감정적 핵심 보존 |
| 선택형 상세 이야기 | 재대화·질문 목록 | 원하는 깊이만 감상 |
| 완료 보고 | 짧은 결과 카드 + 선택 상세 보고 | 보상 확인 후 선택 확장 |

### DDD 연결

```text
짧은 사건 제시
→ 목표 카드
→ 즉시 플레이
→ 결과·보상 카드
→ 선택형 상세 대화
→ 다음 행동
```

이 결정은 서사를 축소하는 것이 아니라, 진행 정보·감정·세계관 상세의 전달 채널을 분리해 행동과 보상의 리듬을 유지한다.

### 가드레일

- 모든 장면을 목표 카드로만 처리해 인물 감정을 제거하지 않는다.
- 모든 장면을 대화창으로 처리해 플레이 흐름을 끊지 않는다.
- 중요한 장면이라는 이유로 긴 컷신을 반복하지 않는다.
- 목표 카드와 대화창에서 같은 내용을 그대로 반복하지 않는다.
- 선택형 상세 대화에 필수 진행 정보와 필수 대응법을 숨기지 않는다.
