## Dialogue Contract

```text
환경 사실
→ 인물별 해석과 편향
→ 플레이어 우선순위
→ 주문 초안과 예상 효과
→ 실제 결과
→ 관계 반응과 복기
```

- 누구도 정확한 주문 조합·성공률·최종 결말을 말하지 않는다.
- 필수 생존 정보는 최소 두 경로로 제공한다.
- 교수는 L1 방향 질문, L2 안전 경고, L3 생명 구조 원칙을 따른다.
- 네아는 구조 대상이면서 밸브·격벽·이동으로 해결에 참여한다.
- 마렌과 카시안의 관점은 상황에 따라 실제 최적 판단이 될 수 있다.
- 모트는 감각 힌트를 제공하지만 기계 구조와 수치를 설명하지 못한다.
