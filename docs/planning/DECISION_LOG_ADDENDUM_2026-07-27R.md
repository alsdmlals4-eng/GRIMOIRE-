## 확정된 원칙

- 학교·시험·축제·현장실습은 같은 화면 체계를 사용한다.
- 자유 이동형 대형 학교 대신 장면 단위 이동을 사용한다.
- 카메라는 고정 구도를 기본으로 하고 제한된 연출 이동만 허용한다.
- 기준 구도는 16:9 가로형이며 18:9~20:9는 좌우 월드 확장으로 대응한다.
- 대화는 장소 배경을 유지하고 캐릭터 초상을 레이어로 표시한다.
- 마법 작성 시 장소·대상·위험·소환수 지원 상태를 잃지 않는다.
- 감속형 작성 표현을 기본 후보로 삼되 실제 시간 규칙은 M0 비교 후 확정한다.
- 학교 배경은 기본·시험·축제·자유일정 상태로 재사용한다.
- 현장 배경은 전투·환경·복구 상태를 같은 장소에서 처리한다.
- 시각적 화려함보다 글자 궤적·대상·위험·결과 인과의 가독성을 우선한다.
