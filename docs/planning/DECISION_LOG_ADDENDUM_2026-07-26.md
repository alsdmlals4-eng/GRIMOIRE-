## GM-00-15 — 스톡 귀속 방식

- 스톡은 공용 충전량이 아니라 미리 준비해 둔 주문 또는 회로별 사용량이다.
- 플레이어는 충전할 스톡 대상을 지정할 수 있다.
- 충전량은 지정 대상의 현재 스톡을 채운다.
- 특정 주문 또는 회로를 우선 충전할 수 있어 전략적 운용과 편의성을 제공한다.
- 동일 주문 직접 시전만 강제하는 과거 후보는 채택하지 않는다.

상태: `CONFIRMED`

## GM-00-16 — 스톡 최대 마나 예약

### 이전 구조

- 완성 주문 스톡 한 칸을 준비할 때 해당 주문의 기존 마나 비용 중 50%를 최대 마나에서 예약한다.
- 준비한 완성 주문 스톡 수가 많을수록 실전에서 사용할 수 있는 최대 마나가 감소한다.
- 빈 스톡도 예약량을 유지한다.

상태: `SUPERSEDED_BY_GM-00-21`

## GM-00-14 최신 수정 — 자동 충전 허용

### 이전 규칙

- 전투 중에는 시간 경과만으로 스톡이 충전되지 않는다.
- 능동 행동으로만 제한적으로 재충전한다.

상태: `SUPERSEDED`

### 최신 규칙

- 전투 중 플레이어가 지정한 스톡 대상 1종의 빈 스톡만 자동으로 충전된다.
- 자동 충전 속도는 플레이어 능력치와 소환수의 생산 능력치에 비례한다.
- 직접 시전, 정확 입력, 방어·반격, 주문 연계와 소환수 지원은 충전 속도를 추가로 높인다.
- 자동 충전은 능동 충전 기여를 대체하지 않고 함께 사용한다.
- 다른 준비 주문과 회로는 동시에 자동 충전되지 않는다.

상태: `LATEST_OVERRIDE`

## GM-00-17 — 조건부 자동스펠 폐기와 스톡 통합

### 이전 구조

- 원터치 자동스펠과 조건부 자동발동을 함께 사용한다.
- 체력, 피격, 적 수 등의 조건을 만족하면 저장된 주문이 자동으로 발동한다.

상태: `SUPERSEDED`

### 최신 구조

- 조건부 자동발동은 사용하지 않는다.
- 자동스펠 기능은 완성 주문 스톡으로 대체한다.
- 완성 주문 스톡은 플레이어가 한 번 터치했을 때 저장된 주문을 기동한다.
- 주문 사용 시점과 대상은 플레이어가 결정한다.
- 성장할수록 일정 이하 단계의 기존 주문을 스톡으로 준비할 수 있다.

상태: `LATEST_OVERRIDE`

## GM-00-18 — 하위 회로 스톡

- 성장 기준보다 낮은 단계이며 이미 학습·숙련한 하위 회로를 스톡화할 수 있다.
- 하위 회로 스톡을 한 번 터치하면 현재 작성 중인 주문에 해당 회로가 자동 배치·연결된다.
- 회로 스톡은 반복 입력을 줄이지만 상위 회로, 신규 회로, 연결 판단과 최종 기동은 플레이어가 담당한다.
- 자동화 가능 단계는 플레이어 성장에 따라 상승한다.

상태: `CONFIRMED_DIRECTION`

## GM-00-19-A — 소환수 회로 작성 폐기와 스톡 생산 통합

### 이전 구조

- 소환수가 숙련한 보조 회로나 미완성 회로 구간을 직접 작성한다.
- 플레이어와 소환수가 서로 다른 회로 구간을 동시에 작성한다.
- 회로 지원·협동 스탠스로 직접 회로 작성 우선순위를 조절한다.

상태: `SUPERSEDED`

### 최신 구조

- 소환수는 회로를 직접 작성하지 않는다.
- 반복 회로 자동완성은 하위 회로 스톡이 전담한다.
- 소환수는 지정한 완성 주문 또는 하위 회로 스톡의 생산량·자동 충전 속도를 높인다.
- 소환수의 생산·동조·지속 관련 능력치가 충전 효율에 영향을 줄 수 있다.
- 소환수는 전투·수호 역할을 유지하며 플레이어가 회로를 그리는 시간을 확보한다.
- 회로 선택, 삽입 위치, 연결 방식과 최종 기동은 플레이어가 담당한다.

상태: `LATEST_OVERRIDE`

## GM-00-20 — 회로 개수 기반 공용 스톡 준비 용량

- 완성 주문 스톡과 하위 회로 스톡은 하나의 공용 준비 용량을 공유한다.
- 준비 용량의 기준 단위는 설계도에 포함된 기능 회로 개수다.
- 하위 회로 스톡 1개는 기능 회로 하나를 저장하므로 준비 용량 1을 사용한다.
- 완성 주문 스톡 1개는 해당 주문 설계도를 구성하는 기능 회로 수만큼 준비 용량을 사용한다.
- 고위 주문은 회로 수가 많으므로 별도 등급 가중치 없이 자연스럽게 더 많은 준비 용량을 소비한다.
- 회로 개수는 선 길이, 획수, 시각 장식이 아니라 메인·형상·전달·보조·조건·기동 등의 기능 회로 블록을 기준으로 계산한다.
- 연결·분기·합류가 독립 기능 회로인지 여부는 연결 문법 확정 때 결정한다.

상태: `CONFIRMED`

최신 책임 원본: `docs/planning/STOCK_CAPACITY_SYSTEM.md`

## GM-00-21 — 스톡 제약을 공용 준비 용량으로 단일화

### 사용자 근거

- 하위 회로는 사용자가 직접 터치해 상위 주문에 조합해야 하는 조작 부담이 남아 있다.
- 완성 주문은 구성 회로가 많을수록 공용 준비 용량을 더 많이 소비한다.
- 스톡 슬롯 제한 자체로 충분한 편성 제약이 생긴다.

### 최신 규칙

- 완성 주문 스톡과 하위 회로 스톡 모두 최대 마나를 예약하지 않는다.
- 스톡 준비 시 현재 마나를 선불로 소비하지 않는다.
- 스톡 발동·적용·자동 충전에 추가 마나 비용을 적용하지 않는다.
- 스톡 제약은 회로 개수 기반 공용 준비 용량만 사용한다.
- 직접 회로 시전만 기존 마나 소비·회복·절감 시스템을 사용한다.
- 기존의 완성 주문 비용 50% 최대 마나 예약 규칙은 폐기한다.

상태: `LATEST_OVERRIDE_CONFIRMED`

```text
전투 전 전체 준비 용량 안에서 완성 주문·하위 회로 스톡 배정
→ 완성 주문은 구성 회로 수만큼 준비 용량 사용
→ 하위 회로는 1개당 준비 용량 1 사용
→ 최대 마나는 감소하지 않음
→ 기본 소환수 1체 전개
→ 하위 회로 스톡 터치로 반복 회로 자동완성
→ 직접 입력으로 상위 회로·연결·조건 구성
→ 완성 주문 스톡 터치로 저장 주문 기동
→ 지정한 스톡 대상 1종 자동 충전
→ 직접 시전·정확 입력과 소환수 생산 지원으로 충전 가속
```

## 후속 미해결 결정

1. 충전 대상은 전투 중 언제 변경할 수 있는가.
2. 완성 주문과 하위 회로의 충전 시간을 같은 공식으로 계산하는가.
3. 소환수 생산 능력치가 충전 속도, 단위 시간당 생산량, 둘 모두에 영향을 주는가.
4. 완성 주문 스톡과 하위 회로 스톡에 대한 소환수 적성을 분리하는가.
5. 연결·분기·합류를 준비 용량 계산에서 독립 회로로 취급하는가.
6. 전체 준비 용량의 초기값과 성장 증가량은 얼마인가.
7. 주문·회로별 개별 최대 보유량을 추가로 둘 것인가, 공용 용량만 사용할 것인가.
