# Spell 결정 원장 추가 기록 — 2026-07-26

## 문서 역할

이 문서는 `docs/planning/DECISION_LOG.md` 이후 확정된 자동스펠 스톡 결정을 누락 없이 추가 기록한다. 이전 결정과 충돌할 경우 이 문서의 최신 결정이 우선한다.

## GM-00-15 — 스톡 귀속 방식

- 스톡은 공용 충전량이 아니라 미리 준비해 둔 자동스펠 주문별 사용량이다.
- 플레이어는 충전할 자동스펠을 지정할 수 있다.
- 충전량은 지정 주문의 현재 스톡을 채운다.
- 특정 주문을 우선 충전할 수 있어 전략적 운용과 편의성을 제공한다.
- 동일 주문 직접 시전만 강제하는 과거 후보는 채택하지 않는다.

상태: `CONFIRMED`

## GM-00-16 — 스톡 마나 비용

- 스톡 한 칸을 준비할 때 해당 주문의 기존 마나 비용 중 50%를 최대 마나에서 예약한다.
- 준비한 스톡 수가 많을수록 실전에서 사용할 수 있는 최대 마나가 감소한다.
- 스톡 편성 중 예약량은 유지되며, 빈 스톡은 예약된 용량을 기반으로 재충전한다.
- 현행 설계에서는 자동스펠 발동 시 같은 주문 비용을 다시 전액 지불하는 이중 비용을 적용하지 않는다.
- 스톡 편성을 해제하면 예약 마나는 최대 마나로 복귀한다.

상태: `CONFIRMED_DIRECTION`

## GM-00-14 최신 수정 — 자동 충전 허용

이 결정은 기존 GM-00-14의 일부를 수정한다.

### 이전 규칙

- 전투 중에는 시간 경과만으로 스톡이 충전되지 않는다.
- 능동 행동으로만 제한적으로 재충전한다.

상태: `SUPERSEDED`

### 최신 규칙

- 전투 중 지정한 주문의 빈 스톡은 자동으로 충전된다.
- 자동 충전 속도는 플레이어 능력치와 소환수 능력치에 비례한다.
- 직접 시전, 정확 입력, 방어·반격, 주문 연계, 소환수 지원은 충전 속도를 추가로 높인다.
- 자동 충전은 능동 충전 기여를 대체하지 않고 함께 사용한다.
- 조건부 자동발동과 자동 충전이 무한 순환하지 않도록 속도, 기동 간격, 충전 대상 수를 제한한다.

상태: `LATEST_OVERRIDE`

## 최신 스톡 전투 순환

```text
전투 전 자동스펠별 스톡 배정
→ 주문 비용 50% 기준으로 최대 마나 예약
→ 전투 시작 시 준비 스톡 사용
→ 지정 주문 자동 충전
→ 직접 시전·정확 입력·소환수 지원으로 충전 가속
→ 지정 주문의 스톡 회복
```

## 후속 미해결 결정

1. 자동 충전은 지정한 주문 1종만 동시에 진행되는가.
2. 여러 준비 주문이 동시에 각자 충전되는가.
3. 충전 대상은 전투 중 언제 변경할 수 있는가.
4. 마나 절감 보조가 50% 예약 비용에 적용되는가.
5. 주문별 최대 스톡과 전체 스톡 한도를 어떻게 나누는가.
