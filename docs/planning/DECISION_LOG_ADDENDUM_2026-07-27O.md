6. 저장은 핵심 세션 경계와 현장 문제 전환 지점 중심의 최소 상태로 제한한다.

## 승인된 공통 Situation Challenge

```text
상황 목표
→ 관찰 가능한 상태
→ 사용 가능한 메인·보조 글자
→ 제한 조건
→ 방향성 결과 미리보기
→ 주문 작성
→ 세계 상태 변화
```
