## GM-CIRCUIT-09 — 보조 글자 3단계 숙련

### 채택안

```text
미숙
→ 숙련
→ 달인
```

### 확정 방향

- 보조 글자는 메인 글자처럼 Lv.0~Lv.5를 사용하지 않는다.
- `미숙`은 직접 작성으로 기능을 학습하는 단계다.
- `숙련`부터 하위 글자 스톡과 소환수 보조 묶음의 등록 후보가 된다.
- `달인`은 복합 연결 안정성·작성 효율·상위 연구에 기여한다.
- 숙련도가 높아져도 기능 글자 수와 스톡 준비 용량은 할인되지 않는다.
- 단순 반복 버튼으로 최고 등급에 도달하지 않고 수업·직접 작성·현장 활용·시험·연구를 사용한다.
- 1학년부터 핵심 기초 보조 글자 일부를 `숙련`까지 올려 자동화 성장을 체험한다.

상태: `DIRECTION_CONFIRMED`

책임 원본: `docs/planning/SUPPORT_LETTER_MASTERY_SYSTEM.md`

## GM-SUMMON-01 — 준비형 보조 묶음 원터치 호출

### 채택안

`B — 전투 전에 소환수에게 보조 글자 또는 보조 묶음을 장착하고, 전투 중 플레이어가 호출해 자동 연결`

### 확정 방향

```text
전투 전
→ 소환수에게 숙련 보조 묶음 설정

전투 중
→ 플레이어가 메인 글자·주문 골격 작성
→ 소환수 보조 호출
→ 준비된 보조 묶음 자동 배치·연결
→ 플레이어가 추가 변형·대상·기동 결정
```

- 소환수 AI가 상황에 따라 임의의 보조 글자를 선택하지 않는다.
- 고정 보조가 모든 주문에 강제 적용되지 않는다.
- 사용 여부와 시점은 플레이어가 결정한다.
- 소환수는 플레이어가 배우지 않았거나 아직 미숙한 글자를 우회 제공하지 않는다.
- 소환수 보조 묶음은 재사용형 지원 행동으로 취급한다.
- 하위 글자 스톡과 완성 주문 스톡은 소비·충전형 준비 자원으로 유지한다.
- 소환수 보조 묶음은 공용 스톡 준비 용량을 소비하지 않는다.
- 재사용 대기·지원 자원·묶음 수와 글자 수는 플레이테스트 조정 대상으로 남긴다.

### 이전 결정 대체

기존 `GM-00-19-A`의 “소환수는 회로·글자를 직접 지원하지 않고 스톡 생산만 지원” 범위를 부분 대체한다.

- 폐기 상태 유지: 소환수가 플레이어 허가 없이 주문을 판단·완성하는 협동 시전
- 최신 허용 범위: 플레이어가 미리 준비한 숙련 보조 묶음을 호출 시 자동 배치·연결

상태: `LATEST_OVERRIDE_CONFIRMED`

## GM-COMBAT-01 — 1학년부터 소환수·스톡으로 간결화한 전투

### 확정 방향

```text
전투 시작
→ 기본 소환수 1체 전개

일반 직접 시전
→ 메인 글자·핵심 판단은 플레이어
→ 반복 보조는 소환수 보조 묶음
→ 상황 대응 글자는 하위 글자 스톡

긴급·반복 대응
→ 완성 주문 스톡
```

- 완성 주문 스톡과 하위 글자 스톡은 1학년부터 사용할 수 있다.
- 첫 학기 안에 직접 작성·소환수 보조·스톡의 세 전투 축을 경험하게 한다.
- 사용자가 한 주문의 모든 보조 글자를 매번 직접 넣지 않게 한다.
- 신규 글자·상위 조합·핵심 변형은 직접 작성 영역으로 유지한다.
- 고학년의 보조 6개는 최대 설계 복잡도이며 필수 직접 입력량이 아니다.
- 소환수 보조가 없어도 직접 시전과 스톡으로 전투를 계속할 수 있다.
- 스톡이 없어도 직접 시전은 가능하다.

상태: `DIRECTION_CONFIRMED`

책임 원본: `docs/planning/COMBAT_CORE_SYSTEM.md`

## 프로젝트 코어에 미치는 영향

기존 코어 문장 중 “플레이어와 동료가 여러 회로 구간을 동시에 직접 작성한다”는 표현을 다음으로 대체한다.

> 플레이어는 메인 글자와 핵심 변형을 직접 작성하고, 숙련된 반복 보조는 소환수 보조 묶음과 스톡으로 호출하여 더 복잡한 주문을 빠르게 완성한다.

## DDD 적용

```text
메인 글자 작성
→ 소환수 보조가 즉시 전개
→ 필요 글자를 스톡으로 추가
→ 주문 결과 변화 확인
→ 전투 피드백
→ 숙련·충전·성장 보상
```

- DDD는 전투를 자동화하는 것이 아니라 핵심 판단과 결과 사이의 반복 입력을 줄이는 데 사용한다.
- 자동화가 늘어날수록 플레이어는 새로운 글자·즉석 변형·대상·발동 시점에 집중한다.
