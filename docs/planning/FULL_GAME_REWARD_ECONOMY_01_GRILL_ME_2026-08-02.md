## 2. 결정 질문

별도 시험·범용 경험치 없이 수업·축제/일상·교류·현장실습 모두를 의미 있게 보상하면서, 전투 반복 파밍과 화폐 인플레이션을 막으려면 어떤 경제 구조를 사용할 것인가?

## 3. A안 — 평가·접근·준비·발견 분리형 / 권장

보상을 하나의 숫자로 합치지 않고 네 층으로 나눈다.

| 층 | 예시 | 사용 방식 |
|---|---|---|
| 누적 평가 | 교수 평가 문장·계열 포트폴리오 | 심화 수강·현장 허가·전문화 후보 판단; 소비 불가 |
| 접근 권한 | 수강 허가·연구실 초대·현장 배치·동료 협력 | 새 선택지·콘텐츠 접근; 화폐처럼 지불하지 않음 |
| Chapter 준비 자원 | 도구·촉매·정보·지원 요청·보호 장치 | 다음 사건의 준비 선택에 소비; Chapter 경계에서 정리/전환 |
| 발견 기록 | 새 해법·부작용·상황 지식·플레이어 명명 주문 | 마도서 비교·대화·연구 선택 개방; 원시 공격력 구매 아님 |

핵심 규칙:

- 성적·평가를 소비 화폐로 사용하지 않는다.
- 전투·축제·일상·교류·휴식은 서로 다른 준비 자원과 접근 기회를 제공한다.
- 현장실습 반복은 첫 완료·새 조건·새 해법 이후 핵심 보상이 크게 줄어든다.
- 영구 성장은 활동 포트폴리오와 명시적 수강/전문화 결정에서 발생한다.
- Chapter 준비 자원은 영구 축적을 제한해 최적 루트의 눈덩이 효과를 막는다.
- 돈·재료가 필요하면 생활 소모품용의 작은 보조 경제로만 사용하고 전문화를 구매하지 못하게 한다.
- 정확한 자원 수·보유 상한·전환율은 `TEST_VALUE`다.

장점:

- 평가와 소비 자원을 분리해 성적을 구매하거나 소모하는 모순을 막는다.
- 비전투 활동도 독립된 보상 가치를 가진다.
- Chapter 준비 선택과 현장 책임이 연결된다.
- 현장실습 반복 파밍의 영구 누적을 제한한다.

위험:

- 보상 층이 많아 보이면 UI가 복잡해질 수 있다.
- 준비 자원이 Chapter마다 초기화되면 보상이 사라진다고 느낄 수 있다.

보정:

- 실제 UI에서는 `평가 / 허가 / 이번 Chapter 준비 / 마도서 발견` 네 의미만 명확히 보여준다.
- 사용하지 않은 준비 자원은 완전 소멸보다 소량의 기록·관계 반응·다음 Chapter 선택지로 전환하는 후보를 둔다.

## 4. B안 — 단일 학교 학점·공헌도 화폐형

```text
수업·축제·현장실습에서 공통 학점 획득
→ 수강·연구·전문화·도구에 자유 소비
```

장점:

- 이해와 UI가 단순하다.
- 모든 활동의 보상을 한 화면에서 비교하기 쉽다.
- 구현과 밸런스가 상대적으로 단순하다.

위험:

- 가장 효율적인 활동 반복이 최적 파밍이 된다.
- 전투로 번 학점으로 비전투 전문화와 관계 기회를 구매할 수 있다.
- 평가와 화폐가 섞여 성적을 소비하는 이상한 구조가 된다.
- 활동의 맥락 차이가 하나의 숫자로 사라진다.

## 5. C안 — 재료 수집·제작 경제형

```text
수업·탐사·전투에서 재료 획득
→ 촉매·도구·주문 보조품 제작
→ 더 어려운 현장과 전문화 준비
```

장점:

- 마법학교와 현장 탐사의 물질적 손맛이 강하다.
- 준비 행동과 전투 결과를 구체적인 아이템으로 표현한다.
- 수집·제작을 통한 장기 목표를 만들기 쉽다.

위험:

- 인벤토리·레시피·채집·제작 UI가 별도 대형 시스템이 된다.
- 현장 전투·탐사 파밍이 학교생활을 압도할 수 있다.
- 문자의 의미·상황 설계보다 장비 수치가 해법을 결정할 위험이 있다.
- Solo·Mobile 제작 범위를 크게 늘린다.

## 6. 권장 판정

`A — 평가·접근·준비·발견 분리형`을 권장한다.

```text
활동 수행
→ 평가 기록과 발견 축적
→ 관계·수강·현장 접근 변화
→ 이번 Chapter 준비 자원 선택·소비
→ 책임 있는 결과와 마도서 복기
```

평가는 성장 자격을 설명하고, 접근 권한은 새로운 경험을 열며, 준비 자원은 단기 선택을 만들고, 발견 기록은 플레이어의 마법 정체성을 남긴다.

## 7. 승인 후 확정되는 것

A안 승인 시:

- 평가와 소비 화폐를 분리한다.
- 영구 진행은 포트폴리오·접근 권한·발견 기록 중심이다.
- Chapter 준비 자원은 단기 선택과 소모처를 담당한다.
- 현장실습 반복은 핵심 영구 보상을 무한 제공하지 않는다.
- 범용 경험치·학점으로 모든 계열을 구매하지 않는다.
- Grill Me counter는 `5/10`.
- 다음 설계는 `부분 성공·실패·장학/관계의 장기 영향`이다.

## 8. 미확정 경계

- 준비 자원의 실제 종류·개수·보유 상한.
- 접근 권한의 세부 단계.
- 사용하지 않은 준비 자원의 전환 규칙.
- 생활 화폐·재료의 포함 여부와 범위.
- Mobile UI 표현.
