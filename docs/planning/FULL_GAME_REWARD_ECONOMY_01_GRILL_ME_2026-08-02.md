## 3. 미니게임·추가 콘텐츠 제작 승인

미니게임과 추가 콘텐츠는 더 이상 금지 범위가 아니다. 본편 제작 범위에 명시적으로 포함한다.

승인된 대표 유형:

1. **문자 획·마력 보정** — 수업에서 글자의 의미와 안정 구간을 익힌다.
2. **재료 식별·분류** — 특징·위험·계열 친화성을 관찰한다.
3. **촉매 배합·안정화** — 순서·양·열·마력 흐름을 조절한다.
4. **축제·일상 응용** — 장식 복구·공연 연출·생활 문제 해결에 글자와 제작물을 사용한다.
5. **현장 채집·안전 회수** — 전투·환경 위험 속에서 재료를 보존하거나 포기할 대상을 선택한다.
6. **연구실 실험·공동 제작** — 교수·동료와 가설을 세우고 결과를 기록한다.

각 미니게임은 독립 장르 복제가 아니라 다음 중 하나 이상을 검증해야 한다.

- 문자의 의미 이해.
- 상황 관찰과 조건 판단.
- 위험·부작용·보존 우선순위.
- 재료의 성질과 계열 상호작용.
- 플레이어가 선택한 해법의 표현.

- 평가·성적·전문화를 재료나 화폐로 구매할 수 없다.
