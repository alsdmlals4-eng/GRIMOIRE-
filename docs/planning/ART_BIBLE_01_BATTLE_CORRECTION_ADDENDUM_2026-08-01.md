## 1. 전투 배우 구성 교정

초안의 다음 방향은 더 이상 사용하지 않는다.

```text
주인공·적·수호 소환수·환경 목표가 전장에 동시에 상시 표시된다.
필드와 전투에서 같은 아군 SD 골격을 상시 전장 배우로 재사용한다.
```

현재 권위:

```text
전장 상단·중앙 = 강한 적 1개체와 필요한 환경 목표
좌측 하단 = 아군 얼굴 초상·HP·마나·상태·수호 배지
우측 = 축소형→확장형 직접 글자·마법진 작성 영역
```

- 아군과 수호 소환수 몸체는 전장에 상시 배치하지 않는다.
- 아군 행동·피격·보호는 초상 반응, 방향성 FX, 짧은 Cut-in 또는 임시 실루엣으로 표현한다.
- 필드 SD와 전투 표현의 일관성은 몸체 상시 재사용이 아니라 얼굴·머리·의상·대표색·FX Design Key로 유지한다.

## 2. 단일 강적 시각 규칙

- Vertical Slice 일반 전투는 강한 적 1개체에 집중한다.
- 잡몹·웨이브·상시 소형 적 자산은 기본 제작 범위에서 제외한다.
- 적은 화면의 중심 실루엣과 공격 예고를 독점한다.
- 전술 깊이는 적 수가 아니라 공격 예고, 상태·환경 변화, 주문 결과 차이에서 만든다.
- 일반 적에게 다중 페이즈용 별도 외형 세트를 제작하지 않는다.
- 보스만 페이즈별 외형·공격 표현을 추가할 수 있다.

## 3. 전투 작성 화면 교정

초안의 `완전 정지·감속 비율은 미정` 문장은 다음으로 교체한다.

```text
기본 작성 중 = 적 공격 타이머 1.0× 진행
선택형 작성 보조 = 초기 프로토타입 목표 0.5×
마법 시전·적 공격·보스 전환 해결 중 = 0× 정지
```

- 작성 중에도 다음 공격과 남은 시간, 대상, 위험을 유지한다.
- 현재 시간 배율을 숫자·아이콘·문구로 표시한다.
- 시스템 처리 시간이 적 공격 위험으로 전환되지 않는다.
- 감속 옵션 사용으로 보상·콘텐츠·기록을 제한하지 않는다.

## 4. 전투 FX 규칙

- 적 공격 예고는 색뿐 아니라 실루엣·아이콘·게이지·문구로 표시한다.
- `[구현]` 승인 후 마법 해결 중에는 공격 타이머를 정지하고 결과 인과를 보여준다.
- 적 공격이 먼저 확정되면 작성 내용을 초기화하지 않는다.
- 아군·수호 Cut-in이 적과 우측 작성 영역을 장시간 가리면 실패다.
- 일반 전투의 장기 페이즈 전환 연출은 제작하지 않는다.

## 5. Slice 자산 상한 교정

| 자산 | 현재 Slice 상한 |
|---|---|
| 일반 전투 적 | 강한 적 1개체용 기본·공격·피격·해결 상태 |
| 일반 적 페이즈 변형 | 없음 |
| 아군 전장 몸체 | 상시 표시 없음 |
| 아군 초상 | 실제 파티 구조 결정 후 최소 세트 |
| 수호 소환수 | 상태 배지 + 짧은 보호 Cut-in/FX 1세트 |
| 우측 작성 패널 | 축소·확장·유효·마나부족·해결잠금 상태 |
| 시간 상태 UI | `1.0× / 감속 / 정지` 표시 |
| 보스 변형 | `BOSS-PHASE-01` 승인 전 제작하지 않음 |

## 6. Art Bible 최종 검수에 추가할 질문

1. 적의 공격 예고가 첫 3초 안에 읽히는가.
2. 좌측 초상과 우측 작성 영역이 적 실루엣을 침해하지 않는가.
3. 아군이 전장에 없어도 공격·피격·보호 결과를 이해할 수 있는가.
4. `1.0× / 감속 / 정지` 상태를 색 없이 구분할 수 있는가.
5. 일반 적 한 개체가 단순 HP 스펀지가 아니라 상황형 위협으로 보이는가.
6. 전투 결과가 원래 필드 환경 변화와 같은 사건으로 느껴지는가.
