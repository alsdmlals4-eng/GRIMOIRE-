# Spell 상태이상–스톡 충전 연동 시스템 — 책임 원본

## 문서 상태

- 상태: `PLANNING_IN_PROGRESS`
- 결정 상태: `CONFIRMED_DIRECTION`
- 기준 날짜: 2026-07-26
- 관련 결정: `GM-00-30`, `GM-00-31`, `GM-00-32`
- 상위 스톡 시스템: `docs/planning/STOCK_SYSTEM.md`
- 직접 피해 정지 시스템: `docs/planning/STOCK_HIT_PAUSE_SYSTEM.md`

이 문서는 지속 피해와 별개로 상태이상이 스톡 충전과 사용에 직접 영향을 주는 구조를 정의한다.

## 1. 핵심 결정

상태이상의 스톡 방해 역할을 두 종류로 제한한다.

```text
마력 교란
→ 스톡 충전 속도 감소

주문 봉인
→ 준비된 스톡 사용 불가
```

`회로 혼선`과 충전 대상 전환 방해 상태는 사용하지 않는다.

- 지속 피해는 체력만 감소시키고 스톡에 영향을 주지 않는다.
- 마력 교란과 주문 봉인은 서로 다른 기능을 담당한다.
- 하나의 상태이상이 두 기능을 동시에 갖는 것은 예외적인 복합 상태로만 검토한다.
- 상태이상으로 충전 진행도나 보유 스톡을 삭제하지 않는다.

## 2. 책임 분리

| 효과 유형 | 역할 | 스톡 영향 |
|---|---|---|
| 직접 피해 | 순간 체력 압박 | 실제 손실 비율에 따른 짧은 정지 |
| 지속 피해 | 시간에 따른 체력 압박 | 없음 |
| 마력 교란 | 스톡 재생산 방해 | 충전 속도 감소 |
| 주문 봉인 | 준비된 자원의 사용 차단 | 보유 스톡 사용 불가 |

## 3. 마력 교란

```text
마력 교란 적용
→ 현재 충전 진행도 유지
→ 스톡 충전 속도 30% 감소
→ 실제 충전 속도 70%
→ 해제 후 정상 속도로 복귀
```

### 기획 기준값

- 기본 충전 속도 감소: `30%`
- 상태 적용 중 충전 속도: `70%`
- 동일 상태 중첩: 없음
- 재적용: 중첩 수를 늘리지 않고 남은 지속시간 갱신
- 지속시간: 적·스킬 데이터 단계에서 결정

상태: `PLANNING_DEFAULT`

위 수치는 시스템 구조를 설명하기 위한 기본 설계값이다. 실제 감속률과 지속시간은 전투 PoC와 난이도 테스트에서 조정할 수 있다.

### 확정 운용 원칙

- 자동 충전은 계속 진행한다.
- 충전 대상은 유지한다.
- 충전 진행도는 감소하거나 초기화하지 않는다.
- 이미 완성된 스톡은 정상적으로 사용할 수 있다.
- 재적용으로 감속률이 누적되지 않는다.
- 재적용은 상태 지속시간만 처음 기준으로 갱신한다.
- 해제 후 정상 충전 속도로 즉시 복귀한다.

### 설계 역할

- 미래의 스톡 공급을 눈에 띄게 늦춘다.
- 이미 준비된 스톡 대응 능력은 빼앗지 않는다.
- 플레이어가 직접 시전이나 보유 스톡으로 위기를 넘길 여지를 남긴다.
- 중첩 계산을 제거해 모바일 UI와 전투 판독성을 유지한다.

## 4. 주문 봉인

```text
주문 봉인 적용
→ 준비된 완성 주문 스톡 사용 불가
→ 하위 회로 스톡 사용 불가
→ 자동 충전은 계속
→ 충전 진행도와 보유량 유지
→ 해제 후 즉시 다시 사용 가능
```

- 봉인은 스톡의 `사용`을 차단한다.
- 자동 충전과 생산 기여는 계속 적용한다.
- 충전 대상 전환도 정상적으로 허용한다.
- 보유 스톡을 소비하거나 삭제하지 않는다.
- 봉인 중 완성된 스톡은 한도까지 정상 저장된다.
- 봉인 해제 후 별도 복구 입력 없이 스톡 버튼이 다시 활성화된다.
- 직접 회로 시전까지 봉인하는지는 별도 주문·회로 상태이상 설계에서 결정한다.

### 설계 역할

- 미리 비축한 즉시 대응 수단을 잠시 차단한다.
- 봉인 시간 동안에도 충전은 계속되어 해제 후 반격 가능성을 만든다.
- 충전 봉인과 사용 봉인을 동시에 적용하는 과도한 이중 차단을 피한다.

## 5. 삭제한 회로 혼선

다음 상태는 사용하지 않는다.

```text
회로 혼선
→ 충전 대상 전환 지연 증가 또는 전환 제한
```

상태: `REMOVED_BY_GM-00-31`

삭제 이유:

- 충전 대상 전환 자체에 이미 전환 지연이 존재한다.
- 별도 상태이상까지 전환을 방해하면 UI와 예외 규칙이 복잡해진다.
- 마력 교란과 주문 봉인만으로 생산 방해와 사용 방해를 충분히 구분할 수 있다.

## 6. 지속 피해와 복합 상태

```text
화상
→ 지속 체력 피해
→ 스톡 영향 없음
```

```text
마력 교란
→ 지속 피해 없음
→ 충전 속도 30% 감소
```

```text
봉인 화상
→ 화상 피해: 스톡 영향 없음
→ 주문 봉인: 스톡 사용 불가
```

복합 상태에서도 피해 틱 자체는 직접 피해 정지를 발생시키지 않는다.

## 7. 상태 중첩 방향

- 마력 교란은 동일 상태끼리 중첩하지 않는다.
- 마력 교란 재적용은 감속률이 아니라 지속시간을 갱신한다.
- 주문 봉인도 중첩 수보다 남은 지속시간 갱신을 기본 후보로 둔다.
- 마력 교란과 주문 봉인이 동시에 적용되면 각각 독립적으로 동작한다.
- 두 상태가 동시에 있어도 진행도·보유량을 삭제하지 않는다.
- 다른 종류의 충전 속도 수정치가 추가될 경우 전체 최소 충전 속도 하한은 별도 밸런스 단계에서 정한다.

## 8. UI 필수 정보

### 마력 교란

- 상태 아이콘과 남은 시간
- 충전 속도 `-30%` 표시
- 충전은 계속된다는 표시
- 재적용 시 중첩 숫자 대신 지속시간 갱신 표시

### 주문 봉인

- 스톡 버튼 비활성화 표시
- 봉인 아이콘과 남은 시간
- 충전 진행도는 계속 움직이는 표시
- 보유 스톡 수량이 유지되는 표시
- 해제 후 자동으로 사용 가능해지는 피드백

## 9. 가드레일

- 지속 피해 틱에 스톡 방해를 부여하지 않는다.
- 마력 교란으로 충전을 완전히 정지시키지 않는다.
- 마력 교란을 동일 상태끼리 중첩하지 않는다.
- 주문 봉인으로 충전 진행도나 보유 스톡을 삭제하지 않는다.
- 주문 봉인 중에도 자동 충전을 중단하지 않는다.
- 회로 혼선이나 전환 방해 상태를 다시 추가하지 않는다.
- 상태 하나가 충전 감속과 사용 봉인을 동시에 기본 적용하지 않게 한다.
- 해제 수단 없는 장시간 주문 봉인을 사용하지 않는다.
- 상태이상 저항이 필수 능력치가 되지 않게 한다.

## 10. 추후 데이터 조정 사항

다음 항목은 시스템 방향이 아니라 밸런스 데이터 단계에서 조정한다.

1. 마력 교란의 실제 지속시간
2. 테스트 후 30% 감속률의 미세 조정
3. 여러 종류의 충전 감속이 함께 적용될 때 최소 충전 속도
4. 주문 봉인의 실제 지속시간
5. 주문 봉인의 재적용 시 지속시간 갱신 방식
6. 적 등급과 스킬별 상태이상 적용 확률

## 11. 기획 단계 미해결 사항

1. 주문 봉인이 직접 회로 시전까지 차단하는 별도 상위 상태가 필요한가.
2. 소환수의 수호·동조 능력치가 마력 교란·주문 봉인을 저항하거나 해제할 수 있는가.
