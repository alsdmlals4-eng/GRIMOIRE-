# Spell 상태이상–스톡 충전 연동 시스템 — 책임 원본

## 문서 상태

- 상태: `PLANNING_IN_PROGRESS`
- 결정 상태: `DIRECTION_CONFIRMED_DETAILS_DEFERRED`
- 기준 날짜: 2026-07-26
- 관련 결정: `GM-00-30`, `GM-00-31`, `GM-00-32`, `GM-00-33`
- 상위 스톡 시스템: `docs/planning/STOCK_SYSTEM.md`
- 직접 피해 정지 시스템: `docs/planning/STOCK_HIT_PAUSE_SYSTEM.md`

이 문서는 지속 피해와 별개로 상태이상이 스톡 충전과 사용에 직접 영향을 주는 구조를 정의한다. 상태이상 목록, 지속시간, 적용 확률과 세부 밸런스는 추후 상태이상 설계 단계로 연기한다.

## 1. 핵심 결정

상태이상의 스톡 방해 역할은 다음 구조로 제한한다.

```text
마력 교란
→ 스톡 충전 속도 감소

주문 봉인
→ 준비된 스톡 사용 불가
→ 직접 회로 시전 가능

마력 봉쇄
→ 준비된 스톡 사용 불가
→ 직접 회로 작성·시전 불가
→ 희귀·보스급 상위 상태
```

`회로 혼선`과 충전 대상 전환 방해 상태는 사용하지 않는다.

- 지속 피해는 체력만 감소시키고 스톡에 영향을 주지 않는다.
- 마력 교란, 주문 봉인과 마력 봉쇄는 서로 다른 강도와 기능을 담당한다.
- 상태이상으로 충전 진행도나 보유 스톡을 삭제하지 않는다.
- 일반 전투에서 플레이어의 핵심 조작을 장시간 완전히 봉쇄하지 않는다.

## 2. 책임 분리

| 효과 유형 | 역할 | 스톡·시전 영향 |
|---|---|---|
| 직접 피해 | 순간 체력 압박 | 실제 손실 비율에 따른 짧은 충전 정지 |
| 지속 피해 | 시간에 따른 체력 압박 | 스톡 영향 없음 |
| 마력 교란 | 스톡 재생산 방해 | 충전 속도 감소 |
| 주문 봉인 | 비축 자원의 사용 차단 | 두 종류 스톡 사용 불가, 직접 시전 가능 |
| 마력 봉쇄 | 상위 마법 행동 차단 | 두 종류 스톡과 직접 회로 시전 불가 |

## 3. 마력 교란

```text
마력 교란 적용
→ 현재 충전 진행도 유지
→ 스톡 충전 속도 30% 감소
→ 실제 충전 속도 70%
→ 해제 후 정상 속도로 복귀
```

### 기획 기준값

- 기본 충전 속도 감소: `30%`
- 상태 적용 중 충전 속도: `70%`
- 동일 상태 중첩: 없음
- 재적용: 중첩 수를 늘리지 않고 남은 지속시간 갱신
- 지속시간: 적·스킬 데이터 단계에서 결정

상태: `PLANNING_DEFAULT`

위 수치는 시스템 구조를 설명하기 위한 기본 설계값이다. 실제 감속률과 지속시간은 전투 PoC와 난이도 테스트에서 조정할 수 있다.

### 확정 운용 원칙

- 자동 충전은 계속 진행한다.
- 충전 대상과 진행도를 유지한다.
- 이미 완성된 스톡은 정상적으로 사용할 수 있다.
- 재적용으로 감속률이 누적되지 않는다.
- 해제 후 정상 충전 속도로 즉시 복귀한다.

## 4. 주문 봉인

```text
주문 봉인 적용
→ 준비된 완성 주문 스톡 사용 불가
→ 하위 회로 스톡 사용 불가
→ 직접 회로 작성·시전 가능
→ 자동 충전은 계속
→ 충전 진행도와 보유량 유지
→ 해제 후 즉시 스톡 사용 가능
```

- 주문 봉인은 스톡의 `사용`만 차단한다.
- 직접 회로 작성과 마나를 사용하는 직접 시전은 허용한다.
- 자동 충전과 플레이어·소환수 생산 기여는 계속 적용한다.
- 충전 대상 전환도 정상적으로 허용한다.
- 보유 스톡을 소비하거나 삭제하지 않는다.
- 봉인 중 완성된 스톡은 한도까지 정상 저장된다.
- 해제 후 별도 복구 입력 없이 스톡 버튼이 다시 활성화된다.

### 설계 역할

- 미리 비축한 즉시 대응 수단을 잠시 차단한다.
- 직접 회로 시전을 대응 수단으로 남겨 핵심 조작의 완전한 무력화를 피한다.
- 봉인 시간에도 충전은 계속되어 해제 후 반격 가능성을 만든다.

## 5. 상위 상태 — 마력 봉쇄

```text
마력 봉쇄 적용
→ 완성 주문 스톡 사용 불가
→ 하위 회로 스톡 사용 불가
→ 직접 회로 작성·시전 불가
→ 충전 진행도와 보유량은 유지
```

### 확정 기획 원칙

- 일반 주문 봉인과 별개의 상위 상태로 분리한다.
- 희귀 적, 엘리트 기믹 또는 보스급 패턴에만 제한한다.
- 적용 전에 명확한 사전 경고를 제공한다.
- 회피, 차단, 해제, 패턴 파훼 중 적어도 하나의 대응 수단을 제공한다.
- 장시간 연속 적용하거나 높은 빈도로 반복하지 않는다.
- 상태가 끝난 뒤 스톡과 직접 시전 기능을 별도 복구 입력 없이 즉시 되돌린다.
- 충전 진행도와 보유 스톡을 삭제하지 않는다.

### 보류 범위

다음 세부사항은 상태이상 설계 단계에서 결정한다.

- 마력 봉쇄 중 자동 충전 지속 여부
- 회로 작성 UI를 완전히 잠글지, 작성은 가능하되 기동만 막을지
- 보스 패턴별 지속시간과 해제 방식
- 무적·저항·소환수 수호와의 상호작용

## 6. 삭제한 회로 혼선

다음 상태는 사용하지 않는다.

```text
회로 혼선
→ 충전 대상 전환 지연 증가 또는 전환 제한
```

상태: `REMOVED_BY_GM-00-31`

- 충전 대상 전환 자체에 이미 전환 지연이 존재한다.
- 별도 상태이상까지 전환을 방해하면 UI와 예외 규칙이 복잡해진다.
- 생산 방해, 스톡 사용 방해와 상위 마법 행동 차단만으로 역할을 구분한다.

## 7. 지속 피해와 복합 상태

```text
화상
→ 지속 체력 피해
→ 스톡 영향 없음
```

```text
마력 교란
→ 충전 속도 감소
```

```text
봉인 화상
→ 화상 피해: 스톡 영향 없음
→ 주문 봉인: 스톡 사용 불가
→ 직접 회로 시전 가능
```

복합 상태에서도 지속 피해 틱 자체는 직접 피해 정지를 발생시키지 않는다.

## 8. 상태 중첩 방향

- 마력 교란은 동일 상태끼리 중첩하지 않는다.
- 마력 교란 재적용은 감속률이 아니라 지속시간을 갱신한다.
- 주문 봉인은 중첩 수보다 남은 지속시간 갱신을 기본 방향으로 둔다.
- 마력 교란과 주문 봉인이 동시에 적용되면 각각 독립적으로 동작한다.
- 두 상태가 동시에 있어도 진행도·보유량을 삭제하지 않는다.
- 마력 봉쇄의 중첩과 갱신 규칙은 추후 상태이상 설계로 연기한다.

## 9. UI 필수 정보

### 마력 교란

- 상태 아이콘과 남은 시간
- 충전 속도 `-30%` 표시
- 충전은 계속된다는 표시

### 주문 봉인

- 스톡 버튼 비활성화 표시
- 직접 회로 시전은 가능하다는 구분
- 봉인 아이콘과 남은 시간
- 충전 진행도와 보유량 유지 표시

### 마력 봉쇄

- 적용 전 명확한 위험 예고
- 스톡과 직접 시전이 모두 차단되었다는 표시
- 남은 시간 또는 해제 조건
- 회피·차단·해제·패턴 파훼 수단의 피드백

## 10. 가드레일

- 지속 피해 틱에 스톡 방해를 부여하지 않는다.
- 마력 교란으로 충전을 완전히 정지시키지 않는다.
- 마력 교란을 동일 상태끼리 중첩하지 않는다.
- 주문 봉인으로 직접 회로 시전을 차단하지 않는다.
- 주문 봉인 중 자동 충전을 정지하거나 스톡을 삭제하지 않는다.
- 마력 봉쇄를 일반 적의 상시 상태이상으로 사용하지 않는다.
- 마력 봉쇄를 사전 경고나 대응 수단 없이 적용하지 않는다.
- 마력 봉쇄로 충전 진행도나 보유 스톡을 삭제하지 않는다.
- 회로 혼선이나 전환 방해 상태를 다시 추가하지 않는다.
- 상태이상 저항이 필수 능력치가 되지 않게 한다.

## 11. 추후 데이터 조정 사항

- 마력 교란의 실제 지속시간과 30% 감속률 미세 조정
- 주문 봉인의 실제 지속시간과 재적용 방식
- 마력 봉쇄의 지속시간, 적용 빈도와 보스 패턴 데이터
- 상태이상 적용 확률
- 여러 종류의 충전 감속 효과가 함께 있을 때 최소 충전 속도

## 12. 설계 보류 선언

상태이상의 핵심 역할 구분만 확정하고 세부 상태이상 목록, 속성별 상태, 중첩식, 저항·해제 능력치와 수치는 추후 별도 상태이상 설계 단계로 연기한다.
