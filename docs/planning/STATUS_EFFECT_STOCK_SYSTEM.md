# Spell 상태이상–스톡 충전 연동 시스템 — 책임 원본

## 문서 상태

- 상태: `PLANNING_IN_PROGRESS`
- 결정 상태: `DIRECTION_CONFIRMED`
- 기준 날짜: 2026-07-26
- 관련 결정: `GM-00-30`
- 상위 스톡 시스템: `docs/planning/STOCK_SYSTEM.md`
- 직접 피해 정지 시스템: `docs/planning/STOCK_HIT_PAUSE_SYSTEM.md`

이 문서는 지속 피해와 별개로, 상태이상이 스톡 충전과 충전 대상 전환에 직접 영향을 주는 구조를 정의한다.

## 1. 핵심 결정

화상·독·출혈 등의 지속 피해는 스톡 충전이나 대상 전환을 정지시키지 않는다. 대신 스톡 방해를 의도한 별도의 상태이상이 충전 시스템에 직접 영향을 준다.

```text
지속 피해
→ 체력 감소
→ 스톡 충전·전환에는 영향 없음

스톡 방해 상태이상
→ 충전 속도·충전 가능 여부·대상 전환 등에 직접 영향
```

- 피해를 입었다는 사실만으로 지속 피해에 스톡 방해를 부여하지 않는다.
- 상태이상의 스톡 영향은 툴팁과 UI에서 명시한다.
- 하나의 상태이상이 지속 피해와 스톡 방해를 함께 가질 수는 있지만, 두 효과는 독립적으로 계산한다.

## 2. 책임 분리

| 효과 유형 | 주된 역할 | 스톡 영향 |
|---|---|---|
| 직접 피해 | 순간 체력 압박 | 실제 손실 비율에 따른 짧은 정지 |
| 지속 피해 | 시간에 따른 체력 압박 | 기본적으로 없음 |
| 스톡 방해 상태이상 | 생산·충전 운용 방해 | 명시된 충전·전환 수정치 적용 |
| 수호·해제 상태이상 | 방해 완화·복구 | 명시된 저항·해제 효과 적용 가능 |

## 3. 상태이상이 조정할 수 있는 축 — 후보

아래는 아직 개별 상태이상에 배정하지 않은 기능 후보다.

### 3.1 충전 속도 감소

```text
정상 충전 속도 100%
→ 방해 상태 적용
→ 일정 시간 70% 등으로 감소
```

- 진행도는 감소하지 않는다.
- 상태 해제 후 정상 속도로 복귀한다.

### 3.2 충전 봉인

```text
충전 봉인 상태
→ 자동 충전 정지
→ 현재 진행도 보존
→ 해제 후 자동 재개
```

- 강한 상태이상에만 제한적으로 사용한다.
- 이미 완성된 스톡 사용 가능 여부는 별도 결정이다.

### 3.3 충전 대상 전환 방해

후보 효과:

- 전환 지연 증가
- 전환 일시 금지
- 전환 중 재변경 제한 강화

현재 전환 진행도를 삭제하는 효과는 사용하지 않는다.

### 3.4 능동 충전 기여 억제

```text
직접 시전·정확 입력·방어·연계 보너스
→ 상태이상 동안 일부 또는 전부 억제
```

기본 자동 충전은 유지하면서 능동 보너스만 막는 중간 강도의 방해로 사용할 수 있다.

### 3.5 생산 지원 억제

후보 효과:

- 플레이어 생산 능력치 감소
- 소환수 생산 기여 감소
- 플레이어와 소환수 중 한쪽만 억제

## 4. 지속 피해와 복합 상태

예시 구조:

```text
화상
→ 지속 체력 피해
→ 스톡 충전 영향 없음
```

```text
마력 과부하
→ 지속 피해 없음
→ 스톡 충전 속도 감소
```

```text
저주받은 화상
→ 화상 피해: 스톡 영향 없음
→ 별도 마력 교란 효과: 스톡 충전 속도 감소
```

복합 상태에서도 피해 틱 자체를 피격 정지로 계산하지 않는다.

## 5. 중첩 원칙 — 방향

- 동일 상태이상의 중첩 방식은 상태별로 명시한다.
- 여러 스톡 방해 효과가 동시에 적용될 때 무제한 곱연산을 피한다.
- 충전 속도는 최소 하한을 둔다.
- 봉인과 속도 감소가 동시에 있으면 봉인이 우선한다.
- 해제 후 저장 진행도부터 자동으로 재개한다.
- 상태이상으로 충전 진행도를 삭제하지 않는다.

정확한 중첩식과 최소 충전 속도는 미확정이다.

## 6. UI 필수 정보

- 상태이상 이름과 아이콘
- 남은 지속시간
- 스톡에 영향을 주는 축
- 충전 속도 변화량 또는 봉인 여부
- 충전 대상 전환 영향
- 중첩 수와 중첩 효과
- 해제 후 자동 재개 여부

지속 피해 상태이상에는 스톡 방해가 없다는 사실도 툴팁에서 구분할 수 있어야 한다.

## 7. 가드레일

- 지속 피해 틱을 피격 정지로 다시 계산하지 않는다.
- 모든 상태이상에 스톡 방해를 붙이지 않는다.
- 상태이상 하나가 충전 속도·봉인·전환·능동 기여를 동시에 과도하게 억제하지 않게 한다.
- 상태이상으로 충전 진행도나 완성 스톡을 삭제하지 않는다.
- 스톡 방해 상태가 전투 내내 사실상 영구 유지되지 않게 한다.
- 해제 수단 없는 장시간 충전 봉인은 사용하지 않는다.
- 상태이상 저항이 필수 능력치가 되지 않게 한다.

## 8. 미해결 사항

1. 상태이상별로 어떤 스톡 영향 축을 배정할 것인가.
2. 충전 봉인 중 완성 스톡 사용을 허용할 것인가.
3. 충전 속도 감소의 최소 하한은 얼마인가.
4. 여러 상태이상 중첩을 합산·최댓값·감쇠 중 어떤 방식으로 처리할 것인가.
5. 소환수의 수호·동조 능력치가 스톡 방해 상태에 저항하거나 해제할 수 있는가.
