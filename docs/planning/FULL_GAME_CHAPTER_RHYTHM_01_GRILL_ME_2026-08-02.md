## 2. 결정 질문

학습 나선 Chapter가 반복 공식으로 느껴지지 않으면서도 플레이어가 매 Chapter의 진행 구조를 이해하게 하려면 어떤 리듬을 사용할 것인가?

## 3. A안 — 기능 고정·순서 가변형 / 권장

각 Chapter는 다음 다섯 기능을 갖지만 순서·개수·표현은 달라진다.

```text
발견·학습
선택·준비
통제된 응용
실전·책임 선택
복기·다음 질문
```

규칙:

- Chapter마다 `발견·학습`, `실전·책임 선택`, `복기`는 최소 1회 존재한다.
- 자유일정 창은 Chapter 맥락에 따라 1~3회 후보이며 정확한 개수는 `TEST_VALUE`다.
- 자유일정에서 휴식·준비·교류·현장실습을 선택할 수 있지만, 모든 창에서 네 선택을 전부 제공할 필요는 없다.
- 선택형 현장실습은 학교 허가·공간·서사 상태가 맞을 때 열린다.
- 시험·축제·대회·공동연구·구조작업·탐사 등은 `통제된 응용` 기능을 서로 다른 형태로 수행한다.
- 메인 현장 사건이 Chapter 중간에 발생하고 이후 학교에서 원인을 배우는 역순 Chapter도 허용한다.

예시 변주:

```text
Chapter A: 수업→자유일정→시험→현장→복기
Chapter B: 현장 이상 징후→학교 조사→교류/실습→공동 해결→복기
Chapter C: 축제 준비→사고→현장 대응→사후 수업→마도서 재해석
Chapter D: 실습 전투→실패 원인 분석→새 글자 학습→재도전→평가
```

장점:

- 플레이어는 학습 나선의 기능을 이해하면서도 사건 순서를 예측하기 어렵다.
- 기존 Vertical Slice를 첫 표준형 Chapter로 보존할 수 있다.
- 자유일정 현장실습을 Chapter별 필요에 맞게 배치할 수 있다.
- 콘텐츠 템플릿은 유지하면서 수업·시험·축제 복제를 피한다.

위험:

- 변주가 과하면 Chapter 정체성이 흐려질 수 있다.
- 작가·기획자가 기능 누락을 눈치채지 못할 수 있다.

보정:

- 각 Chapter 기획표에 다섯 기능의 담당 장면을 명시한다.
- 동일 콘텐츠 형식이 연속 두 Chapter의 같은 위치에 반복되지 않도록 검사한다.

## 4. B안 — 고정 주차·달력형

```text
1주 학습
→ 2주 자유일정
→ 3주 시험·행사
→ 4주 현장
→ 월말 평가
```

장점:

- 이해가 쉽고 일정 계획의 전략성이 강하다.
- Chapter 제작 템플릿과 UI 구조가 단순하다.

위험:

- 공식 반복이 빠르게 드러난다.
- 자유일정이 Activity Point 최적화로 변질될 수 있다.
- 서사 사건이 달력 틀에 끌려간다.

## 5. C안 — 사건 우선·학교 회귀형

```text
사건 발생
→ 현장 대응
→ 학교에서 원인·원리 학습
→ 자유일정·추가 실습
→ 사건 재해결 또는 후속 사건
→ 기록
```

장점:

- 시작이 빠르고 전투·현장 비중이 높다.
- 플레이어가 필요성을 느낀 뒤 마법을 배운다.
- 자유일정 현장실습을 자연스럽게 연결하기 쉽다.

위험:

- 학교생활과 축제·관계 콘텐츠가 사후 정비로 약화될 수 있다.
- 매 Chapter가 두 번의 현장 방문을 요구해 공간·전투 제작량이 늘어난다.
- 기존 첫 Vertical Slice와 대표 구조가 달라진다.

## 6. 권장 판정

`A — 기능 고정·순서 가변형`을 권장한다.

A안은 다음 균형을 만든다.

- 게임 정체성은 `학습 나선 기능`으로 고정.
- 서사와 콘텐츠 신선도는 `순서·형태·비중`으로 변주.
- 자유일정 현장실습은 선택 가능한 실전 학습으로 통합.
- Solo 제작은 기존 장소·적·상황 규칙 재사용으로 통제.
