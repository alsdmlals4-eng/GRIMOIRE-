> 마법학교 학생이 되어 글자의 의미를 배우고, 수업과 현장실습에서 주문을 직접 설계해 내가 생각한 해결법으로 세계를 바꾸는 모바일 마법 RPG.

### 설계 필터

새 시스템은 다음 중 하나 이상을 강화해야 한다.

```text
배움
→ 글자와 문제의 원리를 이해한다.

설계
→ 상황에 맞는 주문 구조를 선택·작성한다.

세계 변화
→ 설계 결과가 적·환경·사건을 실제로 바꾼다.
```

- 직접 작성은 주체성을 증명하고 반복 노동이 되지 않아야 한다.
- 스톡과 소환수는 설계 판단을 대체하지 않고 숙련 반복과 시간 압박을 보조한다.
- 학교 콘텐츠는 완성 주문 지급 메뉴가 아니라 새로운 문법과 문제를 학습시키는 프레임이다.
- 단순 수치 성장·자동 전투·장문 서사가 플레이어 약속보다 전면에 나오지 않는다.

이 승인은 Gate 1 전체 승인, `CORE_CONFIRMED`, CORE_POC 통과 또는 구현 승인이 아니다.

## 6. 확정된 게임플레이 Loop — GM-LOOP-01

사용자 제안:

- 수업에서 주문을 배우고 설계·사용을 연습한다.
- 현장실습 전투에서 실전을 통해 배운다.
- 일상에서 관계가 진행된다.

사용자 승인: 2026-07-27, `권장안대로 진행`

상태: `LOOP_STRUCTURE_CONFIRMED_FOR_GATE_1`

책임 원본: `docs/planning/GATE_1_GAMEPLAY_LOOP_SYSTEM.md`

```text
수업
→ 마법 글자·원리·설계법 학습

교내 연습
→ 안전한 환경에서 직접 작성·조합·사용

일상
→ 관계·정보·동행·실습 관점 누적

현장실습
→ 실전 문제와 전투에서 응용·변형·발견

복귀·정리
→ 주문·활용법·실패 원인·관계 결과 기록

다음 수업·연구
→ 실전에서 드러난 부족함과 관심 분야 재학습
```

핵심 문장:

> 수업에서 알고, 연습에서 할 수 있게 되고, 실전에서 다르게 써 보며, 일상에서 그 경험의 관계와 의미가 누적된다.

### 일정 방식

`고정 핵심 사건 + 자유 일정` 혼합형을 채택한다.

- 고정 축: 학기 시작, 필수 기초 수업, 중간 현장실습, 학기 핵심 실습, 시험·평가
- 자유 일정: 선택 수업, 교내 연습, 연구, 실습 준비·조사, 일상·관계, 소환수 교감, 휴식·정비

### Loop 층

- `Micro Loop`: 관찰→메인·보조 선택→직접 작성·스톡→결과 확인→재설계
- `Combat Loop`: 현장 파악→첫 주문→반응 확인→변형·교체→핵심 위협 해결→기록
- `Session Loop`: 수업·연습·현장실습·일상 중 하나를 중심으로 약 10~15분에 완결
- `Semester Loop`: 고정 수업·실습·평가와 자유 일정이 교차하여 다음 학습·관계·문제를 변화

### 보호 원칙

- 수업은 완성 주문 상점이 아니다.
- 현장실습은 배운 주문을 그대로 재생하는 시험이 아니다.
- 일상은 전투와 무관한 호감도 메뉴가 아니다.
- 자유 일정은 필수 진행을 영구 차단하지 않는다.
- 모든 세션에 수업·전투·일상을 억지로 동시에 넣지 않는다.
- 직접 작성·조합 판단을 스톡·소환수·자동화가 제거하지 않는다.

### 수치·범위 상태

- 시간 목표: `PLAYTEST_TUNING_REQUIRED`
- 학기 `자유 일정 10회 + 고정 사건 4회`: `REFERENCE_CANDIDATE`
- 3년·6학기: `NEUTRAL_SCOPE_RISK`
- 전투 중 완전 상태 복원 범위: `NOT_AUTHORED`

## 7. WHY → HOW → WHAT

### WHY

플레이어가 정답 스킬을 고르는 것이 아니라 마법의 의미를 이해하고 스스로 해결책을 만들었다는 감각을 제공한다.

### HOW

- 수업에서 글자와 문제의 원리를 배운다.
- 교내 연습에서 직접 작성·조합하여 원인과 결과를 익힌다.
- 현장실습에서 상황과 위험을 관찰한다.
- 메인 글자로 핵심 현상을 선택한다.
- 보조 글자로 형상·전달·출력·조건 등을 변형한다.
- 중요하거나 새로운 구성은 직접 작성한다.
- 이미 숙련한 반복 구성은 스톡으로 줄인다.
- 결과를 즉시 관찰하고 원인과 결과를 학습한다.
- 일상 관계와 정보가 이후 실습의 동행·관점·대화를 바꾼다.
- 필수 이야기는 짧게, 선택한 이야기는 깊게 제공한다.

### WHAT

- 터치 기반 마법 글자 작성
- `메인 글자 1개 + 보조 글자 0개 이상` 문법
- 직접 작성·하위 글자 스톡·완성 주문 스톡
- 전투·수호·스톡 충전을 보조하는 소환수
- 10~15분 수업·연습·현장실습 중심 세션
- 고정 핵심 사건과 자유 일정이 결합된 학기 구조
- 수업·연구·현장실습을 통한 장기 성장
- 관계가 다음 학습·실습에 반영되는 일상 구조
- 필수 핵심층과 선택형 상세층의 서사 UX

## 8. 뾰족한 재미 초안

```text
상황과 위험을 읽는다
→ 필요한 현상과 변형을 선택한다
→ 핵심 글자를 직접 작성하고 숙련 반복은 스톡으로 삽입한다
```

- 직접 작성할 가치가 있는가, 준비한 스톡을 사용할 것인가?
- 짧고 안전한 주문과 복잡하고 강한 주문 중 무엇을 선택할 것인가?

## 10. 보호할 기존 결정

- 주문은 `메인 글자 1개 + 보조 글자 0개 이상`
- 메인 글자 하나로 기본 주문 성립
- 복수 메인 글자 결합 금지
- 신규·미숙 글자는 직접 작성
- 숙련 보조만 하위 글자 스톡 후보
- 소환수는 회로·글자를 직접 작성·연결하지 않음
- 소환수 주문 보조는 전투·수호·스톡 생산·충전 범위
- 스톡 없이 직접 시전 가능
- 조건부 완전 자동 발동 재도입 금지
- 필수 정보는 선택형 상세 대화에만 숨기지 않음
- 수업은 완성 주문 상점이 아님
- 현장실습은 정답 주문 재생 시험이 아님
