### 주 경험

> 마법 글자의 의미를 이해하고 상황에 맞는 주문을 설계해 발견하는 지적 마법 판타지.

### 보조 경험

- 직접 작성은 마법을 내가 실제로 다룬다는 손맛과 주체성을 증명한다.
- 숙련과 스톡은 이미 이해한 반복을 줄이고 새로운 조합 판단에 집중시키는 성장 보상이다.
- 소환수는 작성 시간을 확보하고 준비·충전 우선순위를 만드는 보조자다.
- 마법학교는 새로운 글자, 활용 문제, 관계와 전문화를 공급하는 장기 프레임이다.

### 우선순위

```text
1. 조합하고 발견하는 지적 재미
2. 직접 쓰는 마법의 손맛
3. 숙련하고 자동화하는 성장감
```

2번과 3번은 1번을 약화시키지 않는 범위에서만 확대한다.

## 3. WHY → HOW → WHAT

### WHY

플레이어가 정답 스킬을 선택하는 것이 아니라 마법의 의미를 이해하고 스스로 해결책을 만들었다는 감각을 제공한다.

### HOW

- 상황과 위험을 관찰한다.
- 메인 글자로 핵심 현상을 선택한다.
- 보조 글자로 형상·전달·출력·조건 등을 변형한다.
- 중요하거나 새로운 구성은 직접 작성한다.
- 이미 숙련한 반복 구성은 스톡으로 줄인다.
- 결과를 즉시 관찰하고 원인과 결과를 학습한다.

### WHAT

- 터치 기반 마법 글자 작성
- `메인 글자 1개 + 보조 글자 0개 이상` 문법
- 직접 작성·하위 글자 스톡·완성 주문 스톡
- 전투·수호·스톡 충전을 보조하는 소환수
- 수업·연구·현장실습을 통한 장기 성장

## 5. 뾰족한 재미 초안

```text
상황과 위험을 읽는다
→ 필요한 현상과 변형을 선택한다
→ 핵심 글자를 직접 작성하고 숙련 반복은 스톡으로 삽입한다
→ 주문 결과가 적·환경·문제를 어떻게 바꾸는지 즉시 확인한다
→ 새 활용을 발견하거나 실패 원인을 이해한다
→ 다음 주문을 더 영리하게 설계한다
```

- 지금 필요한 핵심 현상은 무엇인가?

- 직접 작성할 가치가 있는가, 준비한 스톡을 사용할 것인가?
- 짧고 안전한 주문과 복잡하고 강한 주문 중 무엇을 선택할 것인가?

## 7. 보호할 기존 결정

다음은 이번 승인으로 폐기하지 않는다. 다만 Gate 1 전체 승인 전 `PROJECT_CORE_CONFIRMED`로 승격하지 않는다.

- 주문은 `메인 글자 1개 + 보조 글자 0개 이상`
- 메인 글자 하나로 기본 주문 성립
- 복수 메인 글자 결합 금지
- 신규·미숙 글자는 직접 작성
- 숙련 보조만 하위 글자 스톡 후보
- 소환수는 회로·글자를 직접 작성·연결하지 않음
- 소환수 주문 보조는 전투·수호·스톡 생산·충전 범위
- 스톡 없이 직접 시전 가능
- 사용자 승인 전 `CORE_CONFIRMED` 사용 금지

## 8. 확인된 위험

### P1

- 현재 전투는 작성·마나·적·스톡·충전·소환수·대상을 동시에 판단하게 될 위험이 있다.

- 직접 작성이 주체성을 주기 전에 반복 피로와 화면 가림을 만들 수 있다.
- 완성 주문 스톡 비중이 높아지면 최상위 경험이 버튼 전투로 퇴행할 수 있다.
