# Spell 스톡 준비 용량 시스템 — 최신 책임 원본

## 문서 상태

- 상태: `PLANNING_IN_PROGRESS`
- 결정 상태: `CONFIRMED`
- 기준 날짜: 2026-07-26
- 관련 결정: `GM-00-20`
- 상위 스톡 시스템: `docs/planning/STOCK_SYSTEM.md`

이 문서는 완성 주문 스톡과 하위 회로 스톡이 사용하는 공용 준비 한도와 계산 단위를 정의한다. 스톡 한도와 관련해 기존 문서의 미해결 항목과 충돌할 경우 이 문서가 우선한다.

## 1. 공용 준비 용량

완성 주문 스톡과 하위 회로 스톡은 별도 슬롯이 아니라 하나의 `스톡 준비 용량`을 공유한다.

```text
전체 스톡 준비 용량
= 준비 가능한 기능 회로의 총개수
```

플레이어 성장에 따라 전체 준비 용량이 증가한다.

## 2. 하위 회로 스톡 비용

하위 회로 스톡 1개는 기능 회로 하나를 저장하므로 준비 용량 1을 사용한다.

```text
하위 회로 스톡 1개
= 준비 용량 1
```

같은 회로를 여러 번 준비하면 준비한 수만큼 각각 계산한다.

## 3. 완성 주문 스톡 비용

완성 주문 스톡 1개의 준비 용량은 해당 설계도를 구성하는 기능 회로 수와 같다.

```text
완성 주문 스톡 1개 비용
= 주문 설계도에 포함된 기능 회로 수
```

예시:

```text
공격 메인 + 투사체 형상
= 2회로 주문
= 주문 스톡 1개당 준비 용량 2

공격 메인 + 투사체 형상 + 분열 보조 + 지연 조건
= 4회로 주문
= 주문 스톡 1개당 준비 용량 4
```

따라서 고위 주문은 더 많은 회로로 구성되므로 별도의 등급 가중치 없이도 자연스럽게 더 많은 준비 용량을 사용한다.

## 4. 회로 개수 판정 단위

준비 용량은 입력 획수나 선 길이가 아니라 설계도에 등록된 `기능 회로 블록`을 기준으로 계산한다.

계산에 포함:

- 메인 회로
- 형상·전달 회로
- 보조 회로
- 조건·기동 회로
- 이후 독립 계층으로 확정되는 기능 회로

기본적으로 계산하지 않음:

- 단순 연결선 길이
- 손가락으로 그린 획수
- 시각 장식
- 동일 기능 회로 내부의 세부 노드

연결·분기·합류가 독립적인 기능 회로로 정의될 경우에만 별도 1회로로 계산한다. 이 부분은 연결 문법 확정 시 결정한다.

## 5. 편성 예시

```text
전체 준비 용량 8

2회로 화염탄 스톡 2개
→ 용량 4

결계 메인 회로 스톡 1개
→ 용량 1

범위 형상 회로 스톡 2개
→ 용량 2

지연 조건 회로 스톡 1개
→ 용량 1

총 사용량 8/8
```

## 6. 설계 효과

- 완성 주문과 하위 회로가 같은 자원을 사용해 편성 선택이 생긴다.
- 고위 주문은 구성 회로가 많아 자연스럽게 무거워진다.
- 하위 회로를 여러 개 준비해 즉석 조합 중심으로 운용할 수 있다.
- 단순 저위 주문을 여러 번 준비하는 반복 시전 빌드도 가능하다.
- 별도의 주문 등급별 임의 가중치 표가 필요하지 않다.

## 7. 가드레일

- 회로 하나에 여러 독립 효과를 과도하게 압축해 용량을 우회하지 않게 한다.
- 같은 효과를 명칭만 바꿔 회로 수를 부풀리지 않는다.
- 연결선 길이나 터치 난이도로 준비 비용을 계산하지 않는다.
- 완성 주문 스톡 하나의 비용은 저장된 설계도가 변경되면 다시 계산한다.
- 성장으로 전체 준비 용량과 소환수 생산 속도가 동시에 과도하게 증가하지 않게 한다.

## 8. UI 필수 정보

- 전체 준비 용량과 현재 사용량
- 각 회로 스톡의 용량 비용 1
- 각 완성 주문 스톡의 구성 회로 수와 총 용량 비용
- 설계도 변경 전후의 용량 차이
- 용량 초과 시 어떤 스톡을 줄여야 하는지 표시

## 9. 미해결 사항

1. 하위 회로 스톡에도 최대 마나 예약 비용을 적용하는가.
2. 완성 주문 스톡의 50% 최대 마나 예약과 회로 개수 기반 준비 용량을 동시에 어떻게 표시하는가.
3. 연결·분기·합류 문법을 독립 회로로 계산하는가.
4. 전체 준비 용량의 초기값과 성장 증가량은 얼마인가.
