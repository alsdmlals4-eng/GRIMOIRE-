# Spell 스톡 준비 용량 시스템 — 최신 책임 원본

## 문서 상태

- 상태: `PLANNING_IN_PROGRESS`
- 결정 상태: `CONFIRMED_WITH_MAGIC_LETTER_REINTERPRETATION`
- 기준 날짜: 2026-07-27
- 관련 결정: `GM-00-20`, `GM-00-21`, `GM-CIRCUIT-01`
- 상위 스톡 시스템: `docs/planning/STOCK_SYSTEM.md`
- 마법 글자 문법: `docs/planning/MAGIC_LETTER_CIRCUIT_SYSTEM.md`
- 충전시간 시스템: `docs/planning/STOCK_CHARGE_TIME_SYSTEM.md`

이 문서는 완성 주문 스톡과 하위 회로 스톡이 사용하는 공용 준비 한도와 계산 단위를 정의한다. 기존의 `기능 회로 수`는 최신 문법에서 **기능 마법 글자 수**로 해석한다.

## 1. 단일 제약 원칙

스톡의 준비·보유·사용을 제한하는 자원은 `스톡 준비 용량` 하나만 사용한다.

```text
스톡 제약
= 공용 스톡 준비 용량
```

적용하지 않는 제약:

- 최대 마나 예약
- 현재 마나 선불 소모
- 스톡 발동 시 추가 마나 소모
- 주문별·글자별 별도 최대 보유량
- 완성 주문과 하위 글자에 서로 다른 보조 자원 제한

직접 회로 시전은 마나를 사용하지만 준비된 스톡은 마나와 독립적으로 운용한다.

## 2. 공용 준비 용량

완성 주문 스톡과 하위 글자 스톡은 하나의 준비 용량을 공유한다.

```text
전체 스톡 준비 용량
= 준비 가능한 기능 마법 글자의 총개수
```

- 플레이어 성장에 따라 전체 준비 용량이 증가한다.
- 동일한 주문이나 글자를 여러 번 편성할 수 있다.
- 총 사용량이 전체 준비 용량을 넘지 않는 한 개별 보유 상한은 두지 않는다.

## 3. 하위 글자 스톡 비용

숙련된 마법 글자 하나를 저장한 하위 회로 스톡은 준비 용량 1을 사용한다.

```text
하위 글자 스톡 1개
= 기능 마법 글자 1개
= 준비 용량 1
```

메인 글자, 형상 글자, 전달 글자, 일반 보조 글자, 조건 글자 등 역할과 관계없이 독립 기능 글자 하나라면 동일하게 계산한다.

## 4. 완성 주문 스톡 비용

완성 주문 스톡 1개의 비용은 설계도에 포함된 기능 마법 글자 수와 같다.

```text
완성 주문 스톡 1개 비용
= 메인 글자 수 + 보조 글자 수
```

주문에는 메인 글자가 정확히 하나 있으므로 다음처럼 계산한다.

```text
메인 글자만 사용한 기본 주문
= 1글자 주문
= 준비 용량 1

불꽃 메인 + 투사체 형상 + 발사 전달
= 3글자 주문
= 준비 용량 3

불꽃 메인 + 투사체 + 발사 + 확대 + 분열 + 추적
= 6글자 주문
= 준비 용량 6
```

기존 `메인 + 형상·전달이 최소 2회로`라는 예시는 폐기한다. 메인 글자 하나만으로도 완성 주문 스톡을 구성할 수 있다.

## 5. 계산 단위

준비 용량은 입력 획수나 선 길이가 아니라 설계도에 등록된 `기능 마법 글자`를 기준으로 계산한다.

계산에 포함:

- 메인 글자
- 형상 보조 글자
- 전달 보조 글자
- 출력·규모·시간·행동·효율·안정 보조 글자
- 조건·순서 보조 글자
- 이후 독립 기능 글자로 확정되는 항목

기본적으로 계산하지 않음:

- 단순 연결선 길이
- 손가락으로 그린 획수
- 시각 장식
- 동일 기능 글자 내부의 세부 노드

연결·분기·합류가 독립적인 기능 글자로 정의될 경우에만 별도 비용으로 계산한다. 이 부분은 후속 문법 설계에서 결정한다.

## 6. 편성 예시

```text
전체 준비 용량 8

3글자 화염탄 스톡 1개
→ 용량 3

불꽃 메인 글자 스톡 1개
→ 용량 1

확대 보조 글자 스톡 2개
→ 용량 2

안정화 보조 글자 스톡 1개
→ 용량 1

지연 조건 글자 스톡 1개
→ 용량 1

총 사용량 8/8
최대 마나 변화 없음
```

메인 글자만 사용하는 1글자 기본 주문을 여러 개 준비해 빠른 순환형 편성을 만드는 것도 허용한다.

## 7. 설계 효과

- 기본 주문은 용량 1로 가볍게 여러 번 준비할 수 있다.
- 다수 보조 글자를 포함한 고위 주문은 자연스럽게 더 많은 준비 용량을 사용한다.
- 완성 주문과 개별 글자가 같은 자원을 사용해 편성 선택이 생긴다.
- 하위 글자를 여러 개 준비해 현장 즉석 조합 중심으로 운용할 수 있다.
- 특정 고위 주문에 용량을 집중하는 특화 편성도 가능하다.
- 스톡 준비 때문에 직접 시전용 최대 마나가 감소하지 않는다.

## 8. 가드레일

- 메인 글자 하나에 여러 독립 기능을 압축해 용량을 우회하지 않는다.
- 같은 기능을 명칭만 바꿔 글자 수를 부풀리지 않는다.
- 연결선 길이·입력 난이도로 준비 비용을 계산하지 않는다.
- 완성 주문 설계도가 변경되면 비용을 다시 계산한다.
- 보조 글자를 많이 붙인 주문이 용량 비용 없이 강해지지 않게 한다.
- 성장으로 전체 용량과 생산 속도가 동시에 과도하게 증가하지 않게 한다.
- 스톡에 마나 비용·예약·개별 보유 상한을 재도입하려면 기존 결정 변경으로 명시한다.

## 9. UI 필수 정보

- 전체 준비 용량과 현재 사용량
- 각 하위 글자 스톡의 비용 1
- 각 완성 주문의 메인·보조 글자 수와 총비용
- 동일 항목의 편성 수량
- 주문 설계도 변경 전후의 용량 차이
- 용량 초과 시 줄여야 할 항목
- 스톡이 최대 마나를 감소시키지 않는다는 안내

## 10. 미해결 사항

1. 연결·분기·합류 문법을 독립 기능 글자로 계산하는가.
2. 전체 준비 용량의 초기값과 성장 증가량은 얼마인가.
3. 같은 보조 글자를 한 주문에 반복 사용할 수 있는가.
