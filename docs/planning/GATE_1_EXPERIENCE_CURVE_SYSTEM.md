# 스펠 Gate 1 경험 곡선

## 문서 상태

- 프로젝트: `스펠` (임시)
- 제품 단계: `CONCEPT_APPROVAL`
- 실행 프로필: `PLANNING_ONLY_PROFILE`
- Work Mode: `PLAN`
- 결정 ID: `GM-CURVE-01`
- 상태: `EXPERIENCE_CURVE_CONFIRMED_FOR_GATE_1`
- 사용자 승인: 2026-07-27, `권장안대로 진행`
- 상위 플레이어 약속: `GM-PROMISE-01`
- 상위 Loop: `GM-LOOP-01`
- 구현 상태: `NOT_STARTED`
- 정확한 시간·숙련 요구량: `PLAYTEST_TUNING_REQUIRED`

이 문서는 첫 실행부터 첫 수업, 첫 독립 설계, 첫 현장실습, 첫 발견과 첫 숙련 자동화까지의 경험 순서와 감정 곡선을 책임진다.

## 1. 채택 방향

초반 경험은 긴 입학 설명이나 캐릭터 소개보다 **짧은 수업에서 즉시 마법을 사용하고 설계하게 하는 방향**을 채택한다.

```text
학교 도착·현재 목표 소개
→ 교수의 짧은 시범
→ 첫 메인 글자 직접 작성
→ 세계가 변하는 결과 확인
→ 보조 글자 하나로 작은 설계 선택
→ 짧은 일상·관계 장면
→ 첫 모의 현장실습에서 응용
→ 새 활용 발견·마도서 기록
→ 반복 숙련 후 첫 하위 글자 스톡 해금
```

핵심 문장:

> 먼저 마법이 작동하는 기쁨을 주고, 곧바로 내가 설계했다는 감각을 주며, 실전에서 응용한 뒤 숙련된 반복만 자동화한다.

## 2. 경험 곡선의 핵심 원리

```text
작동시킨다
→ 원리를 이해한다
→ 직접 선택한다
→ 실전에서 변형한다
→ 결과를 발견·기록한다
→ 익힌 반복을 줄인다
→ 더 복잡한 설계에 집중한다
```

- 첫 재미는 설정 설명이 아니라 직접 작성과 즉각적인 현상 변화에서 발생한다.
- 첫 성취는 정답을 따라 그린 성공보다, 작은 선택이 다른 결과를 만든 경험에서 발생한다.
- 첫 실전은 수업 내용을 그대로 재생하는 시험이 아니라 익숙한 규칙 하나와 새로운 변수 하나를 결합한다.
- 첫 자동화는 편의 기능 선지급이 아니라 직접 익힌 반복이 줄어드는 성장 보상이어야 한다.

## 3. 첫 5분 목표

정확한 초 단위는 플레이테스트 항목이며, 아래는 경험 순서 목표다.

### 3.1 학교와 목표 제시

- 주인공이 마법학교 학생이라는 사실을 즉시 이해시킨다.
- 현재 수업의 목표를 한두 문장으로 제시한다.
- 학교 역사·세계관·인물 관계의 장문 설명은 선택형 상세 대화로 미룬다.

목표 감정: `호기심`

### 3.2 첫 메인 글자 작성

- 교수가 짧게 시범을 보인다.
- 플레이어가 안내선을 따라 첫 메인 글자를 직접 작성한다.
- 입력 판정은 성공 중심으로 널럴하게 제공한다.
- 작성 직후 불꽃·바람·빛·보호막 등 눈에 보이는 현상 변화가 발생한다.

목표 감정: `내 손으로 마법이 작동했다`

### 3.3 첫 독립 설계 선택

- 메인 글자 하나만으로 기본 발현을 경험한 뒤 보조 글자 하나를 소개한다.
- 두 가지 이상 유효한 선택 또는 결과 차이를 제공한다.
- 예: 불꽃을 크게 만들 것인가, 좁게 집중할 것인가.
- 선택 결과를 적·환경·목표 변화로 즉시 비교할 수 있어야 한다.

목표 감정: `내가 주문의 성질을 정했다`

### 첫 5분 종료 기준

플레이어가 다음 세 가지를 말할 수 있어야 한다.

1. 메인 글자는 핵심 현상을 만든다.
2. 보조 글자는 그 현상의 작동 방식을 바꾼다.
3. 내가 직접 작성하고 선택한 결과가 세계를 변화시킨다.

## 4. 첫 10~15분 온보딩 세션

첫 온보딩은 여러 정규 Session Loop를 압축해 맛보게 하는 예외적 통합 구간이다. 이후 모든 세션에 수업·일상·실습을 강제로 동시에 넣지 않는다.

```text
짧은 수업
→ 첫 메인 글자와 보조 글자 학습

작은 설계 과제
→ 두 개 이상의 유효한 해결법 비교

짧은 관계 장면
→ 교수·동급생·라이벌 중 한 명의 관점 확인

모의 현장실습
→ 수업과 같은 글자를 다른 조건에서 응용

복귀·기록
→ 사용한 조합과 결과를 마도서에 저장
```

### 온보딩 관계 장면의 역할

- 인물 소개를 길게 하지 않는다.
- 다른 학생이나 교수가 같은 문제를 보는 다른 관점을 보여준다.
- 기본 대화는 짧게 끝나며, 선택형 상세 대화로 관계·배경·원리를 확장한다.
- 관계 선택이 첫 실습의 대사·힌트·동행 반응 중 하나를 바꾸게 한다.

목표 감정: `이 학교에서 다른 사람들과 함께 배우고 있다`

## 5. 첫 모의 현장실습

첫 실습은 학교 감독 아래 진행되는 낮은 위험의 모의 또는 지정 실습으로 둔다.

### 구성 원칙

- 수업에서 배운 익숙한 규칙 하나
- 현장에서 새로 발생하는 변수 하나
- 최소 두 개의 유효한 해결법
- 실패해도 즉시 게임오버가 아니라 피드백과 재설계 기회 제공
- 실습 종료 후 어떤 선택이 왜 작동했는지 기록

예시 구조:

```text
수업: 불꽃은 열을 만든다
→ 연습: 불꽃의 크기·집중을 바꾼다
→ 실습: 얼어붙은 장치를 해동하되 주변 재료는 태우지 않는다
→ 선택: 약한 지속 열 / 좁은 집중 열 / 다른 보조 조합
```

목표 감정: `배운 마법을 실제 문제에 맞게 바꿨다`

## 6. 첫 발견

첫 발견은 정해진 레시피를 외운 보상이 아니라, 플레이어가 선택한 조합이 새로운 상황에서 유효하게 작동한 순간으로 정의한다.

### 발견 조건 방향

- 이미 배운 메인·보조 글자를 사용한다.
- 플레이어가 결과 차이를 관찰하고 의도적으로 조합한다.
- 한 가지 정답 주문만 강제하지 않는다.
- 성공한 활용은 마도서에 주문 또는 활용 기록으로 남는다.
- 교수·동료의 반응은 발견을 인정하되 플레이어 대신 이름과 의미를 모두 결정하지 않는다.

목표 감정: `내가 알아낸 주문이다`

## 7. 첫 숙련 자동화

첫 자동화는 **하위 글자 스톡**으로 시작한다. 완성 주문 스톡은 직접 작성·조합·발견을 충분히 이해한 이후 단계로 미룬다.

### 해금 순서

```text
글자 직접 작성
→ 서로 다른 상황에서 반복 사용
→ 결과와 역할 이해
→ 안정적인 재현
→ 숙련 인정
→ 해당 보조 글자의 하위 글자 스톡 후보 해금
```

### 보호 원칙

- 첫 5분에 스톡을 지급하지 않는다.
- 수동 작성 경험 없이 자동화를 먼저 보여주지 않는다.
- 단순 사용 횟수만으로 해금하지 않고 이해·재현·활용 기록을 함께 본다.
- 정확한 요구 횟수와 시간은 `PLAYTEST_TUNING_REQUIRED`다.
- 스톡은 주문 전체를 자동 결정하지 않고 숙련된 반복 보조 하나만 줄인다.
- 스톡 해금 전후를 직접 비교해 성장 체감을 보여준다.

목표 감정: `내가 익힌 부분은 빨라졌고, 더 중요한 설계에 집중할 수 있다`

## 8. 시스템 공개 순서

초반 모바일 인지 부하를 줄이기 위해 기능을 다음 순서로 공개한다.

```text
1. 메인 글자 직접 작성
2. 보조 글자 하나와 결과 차이
3. 마나·작성 시간의 기본 의미
4. 현장 목표와 환경 반응
5. 여러 보조 조합과 재설계
6. 하위 글자 스톡
7. 소환수의 전투·수호 지원
8. 소환수의 지정 스톡 충전
9. 완성 주문 스톡과 고급 준비 전술
```

- 소환수 충전과 완성 주문 스톡은 첫 5분에 동시에 공개하지 않는다.
- 시스템 공개 순서는 방향 확정이며 정확한 세션 번호는 `PLAYTEST_TUNING_REQUIRED`다.

| 단계 | 플레이어 경험 | 목표 감정 |

## 10. 온보딩 가드레일

- 첫 마법 사용 전 장문 세계관 설명을 강제하지 않는다.
- 첫 수업을 획 따라 그리기만 하는 긴 튜토리얼로 만들지 않는다.
- 첫 설계에 실패 정답 하나만 두지 않는다.
- 첫 실습에서 모든 전투·스톡·소환수 시스템을 동시에 공개하지 않는다.
- 첫 자동화가 직접 작성의 존재 이유를 제거하지 않게 한다.
- 관계 장면을 호감도 숫자 설명으로 시작하지 않는다.
- UI 메뉴와 성장 수치를 한꺼번에 공개하지 않는다.
- 실패 시 무반응·즉사보다 원인 피드백과 즉시 재시도를 우선한다.

## 11. 경험 곡선 검증 항목

### CORE_POC·플레이테스트 지표 후보

- 첫 마법 발현까지 걸린 시간
- 첫 독립 설계 선택까지 걸린 시간
- 플레이어가 메인·보조 글자 역할을 설명할 수 있는지
- 서로 다른 결과의 원인을 이해하는지
- 첫 실습에서 수업 조합을 그대로 반복하는지, 변형하는지
- 첫 발견을 자기 선택의 결과로 인식하는지
- 첫 스톡 해금이 성장 보상으로 느껴지는지
- 스톡 이후에도 직접 작성과 조합 판단이 유지되는지
- 첫 15분의 설명·대화·플레이 비율
- 모바일 화면 혼잡과 손가림 정도

### 미검증

- 첫 발현·첫 설계·첫 실습의 정확한 시간
- 첫 숙련과 스톡 해금까지 필요한 세션 수
- 온보딩에서 사용할 실제 메인·보조 글자
- 첫 모의 실습의 적·환경·목표
- 소환수 공개 시점
- 완성 주문 스톡 공개 시점
- 관계 선택이 실습에 주는 정확한 효과
