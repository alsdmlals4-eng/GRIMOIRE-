## 제작 범위 변경

사용자 결정에 따라 다음 기존 제한은 폐기 또는 대체한다.

- `세션별 독립 미니게임·전용 프레임워크를 만들지 않는다`는 전면 금지 규칙을 폐기한다.
- `자유일정별 독립 대형 미니게임 금지`는 **Chapter 질문과 연결되지 않은 반복형 대형 콘텐츠 금지**로 좁힌다.
- `별도 미니게임 프레임워크 금지`는 폐기한다.
- `추가 콘텐츠는 기존 슬롯 재분류만으로 해결` 규칙은 폐기한다.

유지되는 제한:

- 시험 전용 Chapter·시험장·시험 전용 미니게임은 만들지 않는다.
- 문자 의미·상황 설계와 무관한 장식성 반복 미니게임은 만들지 않는다.
- 모든 미니게임을 한 Vertical Slice에 넣지 않는다.
