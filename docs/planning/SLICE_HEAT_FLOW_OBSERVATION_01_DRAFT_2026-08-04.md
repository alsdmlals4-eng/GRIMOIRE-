사용자는 교수가 해결법을 말로 설명하지 않고, 이미 배운 `열 + 흐름` 회로를 안전조치에 사용하는 장면을 보여주도록 지시했다. 키워드 확인은 자동 판독 UI가 아니라 **텍스트 노벨 조사 선택**으로 진행하고, 플레이어에게 표시되는 관찰 결과는 감각과 실제 변화만 전달한다.

이 Draft는 기존 Slice 문서의 `흐름을 대표 메인 글자로 사용`한 부분과 충돌하므로 승인 시 별도 정본 보정이 필요하다. 승인 전에는 기존 확정 결정을 조용히 덮어쓰지 않는다.

---

## 1. 권장 문법 정리

```yaml
main_glyph: 열
known_connection_grammar: 흐름
optional_support_glyphs:
  - 집중
  - 분산
representative_known_circuit: 열 + 흐름
```

- `열`: 세계에 열 현상을 발생시키는 메인 글자다.
- `흐름`: 발생한 열을 대상과 경로를 따라 이동·순환시키는 연결 문법이다.
- `집중`: 열을 좁은 지점·경로에 모은다.
- `분산`: 열을 여러 대상·넓은 구역에 나눈다.
- `흐름`은 두 번째 메인 글자가 아니다.

---

## 2. 카시안의 사고

카시안은 결빙된 보조 배관을 빨리 해빙하려고 `열 + 흐름`을 사용한다.

```text
열 발생
→ 닫힌 보조 배관 안으로 전달
→ 출구가 없는 상태에서 온도·압력 급상승
→ 배관 균열
→ 냉기 마력 누출
→ 중심 핵 안전 정지
→ 서리 정령 과부하
→ 자동 격벽 폐쇄와 카시안 고립
```

판정:

```yaml
input: VALID
circuit_grammar: VALID
situation_fit: INVALID
failure_type: SITUATION_DESIGN_FAILURE
missed_conditions:
  - 출구가 열려 있는가
  - 배관 내부 압력이 안전한가
  - 열이 도착한 뒤 빠져나갈 경로가 있는가
```

## 3. 교수의 외곽 안전 회로

에일린 교수는 온실 내부 사건을 해결하지 않는다. 학교 회랑으로 번지기 시작한 냉기만 외곽 안전 회로로 막는다.

```yaml
recognizable_parts:
  - 열
  - 흐름 경로
unknown_advanced_parts:
  - 경로 고정
  - 자동 온도 보정
  - 외곽 안전막 결합
objective: STOP_EXTERNAL_SPREAD_ONLY
```

교수는 온실 외벽의 한 지점에 열을 발생시키고, 그 열을 유리벽 전체를 따라 닫힌 고리로 흐르게 한다.

### 장면에서 보이는 변화

```text
호박색 빛이 외벽을 따라 이동
→ 공기가 따뜻해짐
→ 지나간 유리의 서리가 녹음
→ 밖으로 뻗던 냉기 안개의 방향이 바뀜
→ 학교 회랑으로의 확산만 억제
```

해결되지 않는 것:

- 중심 핵 정지
- 내부 배관 과압과 균열
- 카시안 고립
- 서리 정령 과부하
- 희귀 묘목 동결

## 4. 키워드 확인은 텍스트 노벨 조사로 처리

교수 회로가 펼쳐질 때 자동으로 `[인식: 열]`, `[인식: 흐름]`을 띄우지 않는다. 플레이어가 회로를 조사해야 배운 키워드를 확인한다.

### 조사 선택

```text
1. 빛이 시작된 문양을 살핀다.
2. 빛이 이동한 선을 따라간다.
3. 회로의 모서리를 살핀다.
4. 조사하지 않고 온실 내부를 본다.
```

### 조사 결과

#### 시작 문양 조사

```text
수업에서 여러 번 그렸던 모양이다.
빛의 중심에서 따뜻한 기운이 번진다.

[확인한 키워드: 열]
```

#### 이동 경로 조사

```text
빛은 한곳에 머물지 않는다.
수업에서 익힌 연결선과 같은 방향으로 유리벽을 따라 이어진다.

[확인한 키워드: 흐름]
```

#### 모서리 조사

```text
익숙한 선 사이에 아직 배우지 않은 복잡한 문양이 섞여 있다.
형태를 따라 그릴 수는 있어도 작동 원리는 알 수 없다.
```

이 조사는 행동 횟수와 실시간 시간을 소모하지 않는다.

---

## 5. 플레이어에게 보여주는 관찰 결과

관찰 결과 UI는 회로를 해설하거나 추론을 대신하지 않는다. 감각과 발생한 변화만 짧게 표시한다.

### 권장 표시

```text
따뜻한 기운이 느껴진다.
회로가 지나간 유리의 서리가 녹는다.
밖으로 나가려던 냉기가 방향을 바꿨다.
온실 안쪽의 붉은 압력계는 그대로다.
```

상황에 따라 2~4줄만 사용한다.

### 금지 표시

```text
열이 흐름 경로를 따라 이동했습니다.
열+흐름 회로를 확인했습니다.
열을 배관에 사용하면 해결할 수 있습니다.
열을 열린 순환 경로에 보내십시오.
```

키워드 확인은 조사 장면에서만 이루어지고, 관찰 결과는 결과 자체만 보여준다.

## 6. 교수의 발화 경계

허용:

- `외부 확산은 막았다.`
- `내부 문제는 그대로다.`
- L2·L3 안전 경고

금지:

- `열과 흐름을 사용해라.`
- `내 회로를 따라 그려라.`
- 정확한 출발점·목표·경로·보조 글자 지시
- 플레이어 대신 회로 효과 해설

---

## 7. 사건 플레이에 주는 방향

플레이어는 조사와 관찰을 조합해 다음을 스스로 추론할 수 있다.

- 교수 회로에 `열`과 `흐름`이 사용됐다.
- 따뜻한 기운이 회로를 따라 외벽 전체에 전달됐다.
- 냉기는 사라진 것이 아니라 진행 방향이 달라졌다.
- 교수의 회로는 외부 확산만 막았고 내부 압력은 해결하지 않았다.
- 같은 키워드도 출구·경로·대상에 따라 다른 결과를 만든다.

그러나 시스템은 다음을 알려주지 않는다.

- 무엇을 먼저 구할지
- 어느 열원을 사용할지
- 어느 경로가 안전한지
- 집중·분산을 쓸지
- 시설·묘목·정령 중 무엇을 포기할지

## 8. 적대적 검토

### 위험 A — 자동 판독이 사실상 정답 공개가 됨

대응:

- 키워드는 선택형 텍스트 노벨 조사로 확인한다.
- 조사하지 않으면 키워드 확인 없이도 사건 진행은 가능하다.
- 조사 결과는 이미 배운 글자의 재인식이며 새 글자 해금이 아니다.

### 위험 B — 관찰 결과가 해설문으로 변함

대응:

- 감각과 상태 변화만 표시한다.
- `왜`, `어떻게 써야 하는가`는 말하지 않는다.
- 추천 주문·성공률·결말을 표시하지 않는다.

### 위험 C — 교수의 시연이 정답이 됨

대응:

- 교수는 외부 확산만 막는다.
- 내부에서 무엇을 먼저 해결할지는 플레이어가 정한다.
- 고급 고정·자동 보정 부분은 복제할 수 없다.

### 위험 D — 열이 만능 정답이 됨

대응:

- 열은 냉기를 삭제하지 않는다.
- 과도한 열은 배관 파열·묘목 손상·정령 적대를 만든다.
- 닫힌 출구에 열을 보내면 카시안의 사고가 반복된다.
