## 2. 결정 질문

## 3. A안 — 학기형 학습 나선 / 권장

```text
새 마법 원리 학습
→ 자유일정으로 준비·관계 선택
→ 시험·학교 행사에서 통제된 응용
→ 현장 사건에서 복합 적용
→ 마도서 복기·발견·평가
→ 다음 원리와 더 어려운 상황 개방
```

### 장점

- 기존 Vertical Slice가 본편의 첫 Chapter이자 전체 구조의 축소판이 된다.
- 학교생활·마법 학습·현장 사건·관계·마도서가 한 방향으로 순환한다.
- Chapter마다 새 글자와 상황 조건을 제한해 조합·QA 폭증을 통제할 수 있다.
- 장학생 신입생의 `정답 복제→책임 설계` 성장을 구조적으로 반복·심화할 수 있다.

### 위험

- 매 Chapter가 수업→시험→현장의 똑같은 공식으로 보일 수 있다.
- 자유일정이 다음 도전의 단순 버프 메뉴로 축소될 수 있다.

### 보정 원칙

- 모든 Chapter에 수업·시험·축제를 의무 배치하지 않는다.
- `학습 / 준비 / 통제된 응용 / 현장 적용 / 복기` 기능은 유지하되 순서·형태는 변주한다.
- 자유일정은 수치 상승보다 정보·관점·복구·관계 반응을 우선한다.

## 4. B안 — 학교 허브 + 사건 의뢰형

```text
학교에서 학습·준비
→ 여러 사건 중 하나 선택
→ 현장 해결
→ 보상·기록·관계 변화
→ 새로운 사건 개방
```

### 장점

- 플레이어 선택권과 독립 에피소드 확장이 강하다.
- 사건별 재플레이와 추가 콘텐츠 구성이 쉽다.

### 위험

- 학교가 메뉴 허브로 약해질 수 있다.
- 장학생 평가·학기 성장선이 느슨해진다.
- 유리한 사건만 선택하는 최적 루트가 생길 수 있다.

## 5. C안 — 반복 학기·Roguelite형

```text
학기 시작 성장 방향 선택
→ 제한 일정·변동 사건
→ 시험·현장
→ 성공·실패 결산
→ 발견 일부를 유지하고 새 학기 반복
```

### 장점

- 조합 실험과 반복성이 높다.
- 부분 성공·실패를 장기 구조로 흡수하기 쉽다.

### 위험

- 연속 서사·인물 관계·마도서 책임 기록과 충돌한다.
- 직접 작성 피로와 반복 콘텐츠 요구량이 증가한다.
- 무작위 사건·메타 성장·밸런스·Save 범위가 Solo 제작 한계를 넘기 쉽다.

## 6. 권장안

`A — 학기형 학습 나선`을 권장한다.

다만 전형적인 달력 생활 시뮬레이션이나 매주 같은 학교 작업을 복제하지 않는다. 본편은 여러 **학습 나선 Chapter**로 구성하고, 각 Chapter는 새 원리 하나와 상황 질문 하나를 중심으로 한다.

예시:

```text
Chapter 1: 흐름 — 방향을 바꾸는 것과 책임
Chapter 2: 결속 — 연결하는 것과 얽매는 것
Chapter 3: 분리 — 구하는 것과 포기하는 것
Chapter 4: 변환 — 바꾸는 것과 정체성을 잃는 것
```

위 글자와 Chapter 명칭은 구조 설명용 예시이며 승인된 본편 콘텐츠가 아니다.

## 7. 승인 후 즉시 확정되는 것

A안 승인 시:

- 전체 게임의 기본 반복 단위는 `학습 나선 Chapter`.
- 기존 Vertical Slice는 첫 Chapter의 검증판으로 유지.
- 다음 Grill Me는 `Chapter 내부 리듬과 변주 규칙`.
- 이후 마법 커리큘럼·성장축·관계 환류·보상 경제를 순서대로 설계.
- Grill Me Batch counter는 `1/10`.

B·C 승인 시 해당 구조를 기준으로 기존 Slice와 Mobile/Asset 범위의 충돌을 재감사한다.
