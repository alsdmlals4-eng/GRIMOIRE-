## 2. 사용자 승인

사용자는 `A — 학기형 학습 나선` 권장안을 승인했다.

추가 승인:

> 자유일정에서도 현장실습을 선택해 숲·훈련장·전투 공간에서 전투를 진행할 수 있다.

따라서 전체 게임 Macro Loop는 다음과 같이 확정됐다.

```text
새 마법 원리·상황 질문 학습
→ 자유일정에서 휴식·준비·교류·현장실습 중 선택
→ 시험·행사·훈련에서 통제된 응용
→ 메인 현장 사건에서 복합 적용
→ 마도서 복기·발견·평가
→ 다음 원리와 더 어려운 상황 개방
```

세부 권위와 적대적 보호 규칙은 다음 문서가 담당한다.

`docs/planning/FULL_GAME_MACRO_LOOP_01_APPROVAL_2026-08-02.md`

## 3. 승인된 A안의 핵심

- 전체 게임의 기본 반복 단위는 `학습 나선 Chapter`.
- 기존 Vertical Slice는 첫 Chapter 검증판.
- Chapter마다 새 글자·상황 질문을 제한적으로 추가한다.
- `학습 / 선택 / 통제된 응용 / 현장 적용 / 복기` 기능은 유지하되 순서·형태를 변주한다.
- 자유일정은 `휴식 / 준비 / 교류 / 현장실습` 네 축이다.
- 선택형 현장실습은 상황 해결형 전투를 사용하되 메인 사건·필수정보·무한 파밍을 대체하지 않는다.
- Grill Me Batch counter는 `1/10`.

## 4. 거부한 대안

### B — 학교 허브 + 사건 의뢰형

사건 선택권은 강하지만 학교가 기능 메뉴로 약화되고 학기 성장선이 느슨해질 위험 때문에 전체 구조로 채택하지 않았다.

### C — 반복 학기·Roguelite형

반복성은 강하지만 연속 서사·관계·마도서 책임 기록과 충돌하고 Solo 제작 범위가 증가하므로 채택하지 않았다.

## 5. 새로 열린 위험

- 자유일정 전투가 가장 효율적인 선택으로 고착될 위험.
- 선택형 전투가 메인 현장 사건보다 보상 효율이 높아질 위험.
- 숲·전투 공간·적 변형 요구로 Asset 제작량이 증가할 위험.
- 직접 작성 전투가 자유일정마다 반복되어 피로를 높일 위험.

보호 규칙:

- 자유일정 슬롯 1개 소비.
- 고유 첫 완료·새 조건 발견 보상 우선.
- 필수 정보·핵심 글자·유일 해법 독점 금지.
- 기존 공간·강한 적 1개체 규칙 재사용 우선.
- 정확한 보상량·반복 감쇠·전투 길이는 후속 `TEST_VALUE`.
