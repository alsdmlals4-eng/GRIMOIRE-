## 핵심 결정 상세

### 회로 입력과 자동화

- 초반에는 `메인 + 형상·전달`을 직접 그린다.
- 한 주문에는 메인 회로를 정확히 하나만 사용한다.
- 보조 회로는 이후 단계적으로 해금하고 중반에는 조건·기동 회로를 추가한다.
- 미발견·미숙련 회로와 현재 성장 단계의 신규 회로는 자동화하지 않는다.
- 성장 기준 이하의 학습·숙련 회로는 하위 회로 스톡으로 준비한다.
- 완성 주문 스톡은 저장된 주문 전체를 한 번의 터치로 기동한다.
- 하위 회로 스톡은 현재 주문에 회로 한 구간을 자동 배치·연결한다.
- 조건부 자동발동은 사용하지 않는다.

### 소환수 최신 역할

#### 폐기

- 회로 구간 직접 작성
- 플레이어와 동시 회로 작성
- 보조 회로 자동작성
- 회로 지원·협동 작성 스탠스

상태: `SUPERSEDED`

#### 유지·전환

- 전투와 적 방해
- 플레이어 수호와 회로 작성 시간 확보
- 지정 스톡의 생산량·자동 충전 속도 증가
- 직접 시전·정확 입력 등 능동 충전 보너스 강화
- 능력치·적성·스탠스에 따른 효율 차이

### 회로 정확도와 보상

- 모바일 입력을 고려해 성공 기준을 널럴하게 설정한다.
- 합리적인 부정확 입력은 정상 또는 거의 정상으로 발동한다.
- 부정확 패널티는 낮게 유지한다.
- 정확 입력에는 연출, 손맛, 효율 중심의 추가 보상을 제공한다.
- 정확 보상은 기본 성공을 무가치하게 만들 정도로 강하지 않게 한다.

### 마나와 스톡

- 마나는 기본 자동 회복과 플레이 행동 보너스를 함께 사용한다.
- 마나 회복 메인과 마나 절감 보조를 추가한다.
- 마나는 직접 회로 시전에만 적용한다.
- 스톡 준비·발동·적용·충전에는 마나를 사용하지 않는다.
- 완성 주문 스톡과 하위 회로 스톡은 회로 수 기반 공용 준비 용량만 사용한다.
- 지정 스톡 대상 1종만 자동 충전한다.
- 플레이어 능력치와 소환수 생산 능력치가 충전 효율에 기여한다.
- 직접 시전, 정확 입력, 방어·반격, 주문 연계는 충전을 추가 가속한다.
- 회복·절감·스톡 생산으로 무한 자원 순환이 발생하지 않게 한다.

### 충전시간과 대상 전환

- 스톡 1회분 기준 충전시간은 `1.0 + 0.5 × (회로 수 - 1)`이다.
- 충전 대상은 전투 중 변경할 수 있다.
- 대상별 다음 스톡 1회분 충전 진행도를 보존한다.
- 대상 변경 시 짧은 전환 지연 동안 모든 충전을 정지한다.
- 전환 완료 후 새 대상의 저장 진행도부터 자동 재개한다.
- 최대치 도달 시 다른 대상으로 자동 전환하지 않는다.

### 체력 피해 시 처리

- 충전 중 플레이어 체력이 실제 감소하면 진행도를 전부 보존한다.
- 충전 대상 전환 중 체력이 실제 감소하면 전환 게이지를 전부 보존한다.
- 체력 피해 후 고정된 짧은 시간 동안 정지하고 별도 입력 없이 자동 재개한다.
- 피격 정지 중 생산 기여와 능동 충전 보너스를 적용하지 않는다.
- 연속 피해는 정지 시간을 단순 합산하지 않고 하나의 타이머만 갱신 또는 제한적으로 연장한다.
- 소환수·보호막·회피·무적·상쇄로 최종 체력 피해가 0이면 충전·전환을 정지하지 않는다.
- 방어 후 체력이 1 이상 감소하면 피격 정지를 적용한다.
- 피해량, 공격 등급, 최대 체력 대비 피해 비율과 관계없이 동일한 정지시간을 적용한다.
- 큰 피해의 위협은 체력 손실과 공격 자체의 경직·넉백·연출로 표현하고 스톡 정지시간은 늘리지 않는다.

## 운영 규칙

1. 사용자의 최신 지시가 이전 결정에 우선한다.
2. 변경된 결정은 삭제하지 않고 `SUPERSEDED`, `LATEST_OVERRIDE`, `TRANSFERRED` 상태로 기록한다.
3. 핵심 결정이 추가되거나 기존 결정이 변경되면 책임 원본과 Active Context를 함께 갱신한다.
4. 방향 확정과 세부 목록·수치 확정을 구분한다.
5. 테스트 전 수치를 확정하지 않는다.
6. 구현 파일은 현재 기획 브랜치에 포함하지 않는다.
7. 사용자가 프로젝트 코어를 승인하기 전 `CORE_CONFIRMED`를 사용하지 않는다.
8. 현재 단계에서는 Codex를 실행하지 않는다.
9. 외부 작품은 구조를 참고하되 용어·데이터·고유 분류를 직접 복제하지 않는다.
