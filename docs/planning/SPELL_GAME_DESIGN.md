## 유지되는 코어

- 마법학교 학생이 의미 있는 글자를 배우고 응용한다.
- 메인 글자는 주문의 중심 현상이며 한 주문에 하나다.
- 소환수는 조사·전투·수호·Stock 충전을 지원하지만 주문 판단을 대신하지 않는다.
- 주문 발견과 마도서 복기가 성장으로 이어진다.

## 대체된 핵심

- 주문마다 모든 글자를 직접 그리는 구조 → `3×3 노드 조합 + typed glyph Stock`.
- 완성 주문 Stock → 폐기.
- 하위 글자 자동 삽입·연결 → 글자 노드 배치만 대체, 연결은 플레이어 판단.
- 직접 작성 정확도 위력 보상 → 폐기.
- 과거 자유 회로 → 인접 셀 방향 연결 3×3 회로.
- Stock 주문 무마나 시전 → 폐기; 모든 주문 Commit은 마나 사용.
