## 2. 기본 용어

```text
마법 글자
→ 마법적 의미를 가진 최소 기능 단위

회로
→ 마법 글자의 위치·연결·적용 순서를 구성한 문법

주문
→ 메인 글자 1개와 보조 글자 0개 이상으로 완성한 마법 문장
```

- 세계관 교육에서는 `마법 글자`라는 개념을 중심으로 설명한다.
- 시스템·데이터에서는 기존 용어인 `메인 회로`, `보조 회로`를 병기할 수 있다.
- 마법 글자 하나는 스톡 준비 용량과 충전시간에서 하나의 기능 단위로 계산한다.

## 3. 주문 성립 규칙

### 3.1 메인 글자는 정확히 하나

```text
메인 글자 1개
= 기본 주문 성립
```

- 메인 글자 하나만 정확히 작성해도 주문이 정상 발동한다.
- 메인 글자는 해당 현상의 가장 단순하고 안전한 `기본 발현`을 포함한다.
- 형상·전달 글자는 주문 성립의 필수 조건이 아니다.
- 한 주문에 복수 메인 글자를 넣지 않는다.
- 복잡성은 메인 결합이 아니라 보조 글자와 연결 문법으로 만든다.

### 3.2 보조 글자는 선택적이다

```text
메인 글자 1개
+
보조 글자 0개 이상
=
완성 주문
```

- 보조 글자가 없으면 빠르고 단순한 기본 주문이 된다.
- 보조 글자가 추가되면 출력·형상·전달·규모·시간·행동·효율·안정·조건을 확장할 수 있다.
- 다수의 보조 글자가 포함된 주문은 더 강력하고 복합적이지만 작성 시간·마나·준비 용량·충전시간도 증가한다.

## 4. 메인 글자

메인 글자는 주문이 **무엇을 발생시키거나 변화시키는가**를 결정한다.

각 메인 글자는 다음 정보를 가진다.

1. 중심 현상·개념
2. 기본 발현
3. 기본 대상·범위
4. 주요 위험과 안전 규칙
5. 잘 결합하는 보조 글자
6. 관련 수업 계열과 교수
7. 생활·연구·현장 활용 후보

메인 글자의 최종 계열은 아직 확정하지 않는다.

후보 예시:

- 열·불꽃
- 물·유동
- 바람·압력
- 빛
- 생명·회복
- 힘·충격
- 보호·차단
- 이동·공간
- 감지
- 소환
- 변환

## 5. 보조 글자

기존 형상·전달·일반 보조·조건·기동 회로는 보조 글자의 하위 역할로 통합한다.

| 보조 역할 | 기능 | 후보 예시 |
|---|---|---|
| 형상 | 발현 모양·범위 | 투사체, 장벽, 원형, 선형, 오라 |
| 전달 | 대상에 도달하는 방식 | 접촉, 발사, 광선, 지정, 추적 |
| 출력 | 힘의 크기·집중 | 증폭, 집중, 분산 |
| 규모 | 범위·수량·대상 수 | 확대, 다중화, 분열 |
| 시간 | 발동·지속 시점 | 가속, 지속, 지연 |
| 행동 | 발현 후 움직임 | 관통, 연쇄, 귀환, 추적 |
| 효율 | 마나·부산물 처리 | 절감, 회수, 재활용 |
| 안정 | 정밀도·안전성 | 안정화, 보정, 고정 |
| 조건 | 내부 효과 반응 조건 | 적중 시, 피격 시, 일정 시간 후 |
| 순서 | 적용 순서와 반복 | 선행, 후행, 반복, 분기 |

- 공통 보조 글자는 여러 메인 계열에서 재사용할 수 있다.
- 일부 보조 글자는 특정 계열과 높은 친화성 또는 전용 상호작용을 가질 수 있다.
- 계열 전용과 공통 보조의 비율은 후속 설계에서 결정한다.

## 6. 주문 복잡도와 강함

```text
메인만 사용
→ 기본 주문
→ 빠른 작성·낮은 부담·단순한 효과

메인 + 소수 보조
→ 실전 주문
→ 명확한 목적과 활용

메인 + 다수 보조
→ 고위 주문
→ 높은 출력·넓은 기능·복합 행동
```

`강력함`은 피해량만 의미하지 않는다.

- 출력과 범위
- 지속시간과 대상 수
- 추적·연쇄·관통 등 행동
- 마나 효율과 안정성
- 조건 반응과 실행 순서
- 구조·봉인·복구·탐색 성능

보조 글자가 많을수록 무조건 효율적인 것은 아니다.

- 직접 작성 시간이 길어진다.
- 마나 부담이 커진다.
- 연결 판단이 복잡해진다.
- 완성 주문 스톡의 준비 용량이 증가한다.
- 완성 주문 스톡의 기준 충전시간이 증가한다.

상황에 맞는 짧은 주문과 다수 글자를 투자한 고위 주문이 서로 다른 역할을 갖는다.

## 7. 연결·흐름 문법

마법 글자가 단어라면 회로는 문장 구조다.

```text
직접 연결
→ 메인에 보조 효과 적용

분기
→ 효과를 여러 대상·경로로 나눔

합류
→ 여러 보조 효과를 하나의 결과에 집중

방향·순서
→ 보조 효과의 실행 순서 결정
```

- 연결선 길이와 획수는 독립 기능 글자로 계산하지 않는다.
- 연결·분기·합류가 별도 기능 글자로 계산되는지는 후속 결정으로 남긴다.
- 조건·순서 글자는 폐기된 조건부 자동스펠과 다르다.
- 완성 주문 스톡은 플레이어가 터치할 때만 기동한다.

## 8. 예시

### 기본 주문

```text
불꽃 메인
→ 기본 불꽃 발생
```

### 실전 주문

```text
불꽃 메인
+ 투사체 형상
+ 발사 전달
→ 화염탄
```

### 고위 주문

```text
불꽃 메인
+ 투사체 형상
+ 확대
+ 분열
+ 추적
+ 지속
→ 다수 대상을 추적하며 지속되는 복합 화염 주문
```

### 비전투 활용

```text
불꽃 메인
+ 집중
+ 안정화
+ 지속
→ 해빙·온도 유지·재료 가공
```

예시는 문법 설명용이며 최종 주문 데이터가 아니다.

## 9. 학습과 수업

수업은 메인 글자 계열을 중심으로 구성한다.

```text
계열 원리 학습
→ 메인 글자 습득
→ 메인만으로 기본 주문 성공
→ 관련 보조 글자 습득
→ 응용 조합 과제
→ 현장실습 검증
→ 마도서 등록
→ 숙련·스톡화
```

- 공통 문법 과목은 연결·안전·형상·전달·안정화 같은 보편 글자를 가르친다.
- 메인 계열 과목은 해당 메인 글자와 계열 친화 보조 글자를 함께 가르친다.
- 응용 실습에서는 다른 과목에서 배운 보조 글자를 가져와 조합할 수 있다.
- 수업 수강만으로 완성 주문이 자동 등록되지 않는다.
- 최종 활용 발견은 현장에서 플레이어가 직접 성공시킨다.

## 10. 단계별 성장

### 1학년

- 여러 기초 메인 계열을 경험한다.
- 메인 글자 단독 발동을 익힌다.
- 소수의 형상·전달·안정 보조 글자를 배운다.
- 특정 계열에 너무 빨리 영구 고정하지 않는다.

### 2학년

- 선택 계열을 심화한다.
- 출력·행동·조건·순서 보조 글자를 확장한다.
- 다른 계열 수업에서 배운 보조 글자를 교차 활용한다.
- 스톡 편성과 복합 주문을 본격적으로 사용한다.

### 3학년

- 다수 보조 글자의 복합 설계를 수행한다.
- 독립 연구와 고위 주문을 설계한다.
- 현장 목표와 안전 기준에 맞는 글자 조합을 제안한다.
- 졸업 연구·발표·종합 실습에서 활용 결과를 검증한다.

## 11. 하위 회로 스톡

숙련된 마법 글자는 하위 회로 스톡으로 준비할 수 있다.

```text
상위 주문 작성 시작
→ 하위 글자 스톡 선택
→ 한 번 터치
→ 저장된 글자 자동 배치·연결
→ 플레이어가 나머지 글자와 문법을 계속 작성
```

- 미발견·미숙련 글자는 스톡화하지 않는다.
- 현재 성장 단계의 신규 글자는 직접 그린다.
- 스톡은 삽입 위치와 예상 연결 결과를 미리 표시한다.
- 스톡은 최종 주문 설계와 기동 판단을 대신하지 않는다.

## 12. 소환수와 책임 경계

```text
하위 회로 스톡
→ 숙련 글자의 자동 배치·연결

소환수
→ 지정 스톡의 생산·충전 지원
→ 전투·수호 지원
```

- 소환수는 마법 글자를 직접 작성하지 않는다.
- 소환수 성장으로 신규 글자 학습을 건너뛰지 않는다.
- 글자 선택·삽입 위치·연결·최종 기동은 플레이어가 담당한다.

## 13. 스톡 계산 기준

기존 `기능 회로 수`는 `기능 마법 글자 수`로 재해석한다.

```text
메인 글자만 사용
→ n=1
→ 준비 용량 1
→ 기준 충전시간 1.0단위

메인 1 + 보조 3
→ n=4
→ 준비 용량 4
→ 기준 충전시간 2.5단위
```

기존 공식은 유지한다.

```text
기준 충전시간(n)
= 1.0 + 0.5 × (n - 1)
```

## 14. 가드레일

- 주문 성립에 보조 글자를 강제로 요구하지 않는다.
- 복수 메인 글자 결합을 허용하지 않는다.
- 메인 글자 하나에 여러 독립 현상을 과도하게 압축하지 않는다.
- 보조 글자를 많이 붙이는 방식만 정답이 되지 않게 한다.
- 초반부터 모든 보조 문법을 노출하지 않는다.
- 처음 배우는 글자를 스톡으로 건너뛰지 않는다.
- 수업을 완성 주문 구매 목록으로 만들지 않는다.
- 소환수가 글자를 직접 작성하지 않는다.

## 15. 미해결 사항

1. 메인 글자 계열의 최종 분류
2. 각 메인 글자의 기본 발현
3. 공통 보조와 계열 전용 보조의 비율
4. 같은 보조 글자의 반복·중복·상충·감쇠 규칙
5. 마나 비용의 글자 수·종류별 계산
6. 연결·분기·합류를 독립 기능 글자로 계산하는지 여부
7. 소환수 생산 적성을 메인 글자 계열별로 구분하는지 여부
