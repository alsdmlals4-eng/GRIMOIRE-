## 3. Loop A — 결정 기억·정본 공격

### 공격

> 이미 승인된 내용을 새 질문처럼 다시 제시하게 만드는 구조라면 프로젝트 운영 체계가 실패한 것이다.

### 확인된 증거

- GitHub의 다음 차단 결정은 여전히 `GM-CHARACTER-PRESENTATION-01`이었다.
- 실제 대화에서는 필드 SD·대화 반신·별도 전투 화면을 이미 승인했다.
- 메인 소환수 성장·형상 선택·탑승 방향이 GitHub에 없었다.
- Gate 1 소환수 문서는 `CONCEPT_APPROVAL`, `CORE_CANDIDATE`, 오래된 다음 결정을 유지했다.
- 생성 이미지와 시스템 확정의 상태가 분리되지 않아, 후보 이미지가 승인된 규칙처럼 취급될 위험이 있었다.

### 판정

`P0 / MUST_FIX`

### 수정

- `CURRENT_CONFIRMED_DECISIONS.md`를 단일 복원 지점으로 신설
- 질문 전 정본 조회 순서와 허용 질문 상태 정의
- 최신 캐릭터·전투·소환수 결정을 책임 원본으로 승격
- 다음 차단 결정을 `ART-STYLE-01`로 이동
- 이미지 상태를 콘셉트·참조 승인·Art Bible·런타임 승인으로 분리

### 회귀 확인

- Gate 1 코어와 Slice 범위는 변경하지 않음
- 구현·Codex·프로필 전환은 계속 차단
- 미확정 사항을 임의 확정하지 않음

## 4. Loop B — 화면·전투 연속성 공격

### 공격

> 필드와 전투 화면을 분리하면 주문이 세계를 변화시킨다는 코어가 끊기고, 일반 RPG의 별도 전투 인스턴스처럼 느껴질 수 있다.

### 비판 검증

비판은 사실이다. 기존 정본은 같은 장면에서 전투하도록 설계되어 있었지만 사용자가 별도 전투 화면을 선택했다. 화면 분리는 승인된 최신 결정이므로 폐기할 수 없으며, 대신 인과 연속성을 보존해야 한다.

### 판정

`P0 / MUST_FIX`

### 수정안

```text
필드에서 위험·대상 확인
→ 짧은 전투 전환
→ 같은 장소 정체성을 가진 고정 3/4 전술 전투장
→ 주문 결과로 적·환경 상태 변화
→ 전투 결과를 반영한 원래 필드 장면으로 복귀
```

보호 규칙:

- 전투 전후 장소·목표·대상의 정체성 유지
- 배경 색·건축·핵심 오브젝트를 전투장에 계승
- 전투 후 손상·복구·구조 결과를 필드에 반영
- 전투장 전용 서사·탐색 시스템 추가 금지
- 작은 고정 전투장과 제한된 이동만 허용

### 회귀 확인

- `상황 관찰→주문 설계→세계 변화` 코어 유지
- 별도 전투 화면은 표현 외피 변경이며 프로젝트 코어 변경 아님

## 5. Loop C — 캐릭터 자산 폭증 공격

### 공격

> 필드 SD, 대화 반신, 별도 전투 자산을 모두 만들면 캐릭터 하나에 세 벌의 아트 파이프라인이 필요해 1인 개발 범위를 초과한다.

### 비판 검증

부분적으로 사실이다. 전투 비율까지 별도로 바꾸면 확실히 초과하지만, 필드와 전투에 같은 3.5~4등신 SD 비율을 사용하면 재사용 가능하다.

### 판정

`P1 / SHOULD_FIX`

### 확정 처리

```text
필드·학교생활
= 3.5~4등신 SD

대화
= 반신 일러스트

전투
= 같은 SD 비율과 기본 골격 재사용
= 전투용 최소 상태만 추가
```

초기 Slice 상태 예산 후보:

- 필드: 대기·짧은 이동·상호작용
- 전투: 대기·이동 또는 회피·주문 반응·피격
- 대화: 기본·긍정·부정 중심의 소수 표정

정확한 프레임과 표정 수는 `ASSET-SPEC-01`에서 확정한다.

### 회귀 확인

- 캐릭터 매력과 학교생활 표현 유지
- 전투 전용 5~6등신·고프레임 애니메이션은 추가하지 않음

## 6. Loop D — 메인 소환수 성장·형상 공격

### 공격 1

> 4단계 성장과 모든 이전 형상 선택은 소환수 한 체에 필드·전투·대화·탑승 자산을 네 배 이상 요구한다.

### 비판 검증

사실이다. 장기 제품 방향으로는 가치가 있지만 Vertical Slice에 전 단계 런타임 제작을 넣으면 직접 작성 검증보다 비용이 커진다.

### 판정

`P0 SCOPE / MUST_DEFER_FROM_SLICE`

### 처리

- 4단계 성장 프레임은 장기 제품 방향으로 유지
- Vertical Slice 런타임은 초기 형상 1개만 필수
- 이후 단계는 콘셉트 실루엣 또는 로드맵으로만 보존 가능
- 성장 단계와 표시 형상을 분리

```text
actual_growth_stage
= 능력·관계·기억 해금

display_form_stage
= 해금된 현재 단계 이하에서 플레이어 선택
```

### 공격 2

> 하위 형상 표시 중 상위 능력을 사용하면 외형과 힘의 불일치가 발생한다.

### 비판 검증

발생 가능하지만, 외형 선택이 순수 코스메틱임을 UI로 명시하고 발동 시 상위 원소 문양·오라를 잠시 표시하면 해결 가능하다.

### 판정

`P1 / ART_BIBLE_AND_FX_RULE_REQUIRED`

### 처리

- 기본 능력은 실제 성장 단계 기준
- 표시 형상은 코스메틱 선택
- 상위 능력 발동 시 현재 형상 위에 성장 단계의 문양·오라를 표시할 수 있음
- 플레이어가 형상 선택으로 전투 성능을 오해하지 않게 UI 분리

## 7. Loop E — 탑승 기능 공격

### 공격

> 탑승은 자유 이동형 넓은 맵을 요구하며, 장면 기반 학교·작은 현장 구조와 충돌한다.

### 비판 검증

완전 자유 탑승이라면 사실이다. 그러나 연출형·특정 구간형·월드 이동형으로 제한하면 장기 보상으로 유지할 수 있다.

### 판정

`P1 / LONG_TERM_CONFIRMED, SLICE_EXCLUDED`

### 처리

- 탑승은 장기 성장 보상
- 초기 구현 우선순위: 연출형 → 특정 구간형
- 자유 탐색 상시 탑승은 후행 검토
- 하위 표시 형상 사용 중 탑승하면 탑승 가능 형상으로 자동 전환 가능
- 학교 실내·대화·시험·모든 전투에 탑승 상태를 강제 대응하지 않음

## 8. Loop F — 전투 보조 소환수 과잉 확정 공격

### 공격

> 이미지 제작을 요청했다는 이유만으로 공격·견제·수호·보조 4역할 체계와 성장·탑승을 모두 확정하면 초기 Slice가 소환수 수집 RPG로 변한다.

### 비판 검증

사실이다. 사용자가 확정한 것은 메인 동반자와 같은 세계관의 정령 계열 느낌과 전투 소환수도 유사한 방향이라는 점이다. 4역할 전체 이미지는 비교 시도였으며 최종 시스템 승인은 없었다.

### 판정

`P0 / MUST_NOT_OVERSTATE`

### 처리

확정:

- 원소·정령 중심 시각 언어
- 역할 우선 실루엣
- 전투에서 호출
- 초기 Slice는 수호 또는 견제 1체

미확정:

- 4역할 전체 체계
- 성장 단계와 이전 형상 선택
- 탑승
- 획득·계약·편성 경제

### 회귀 확인

- 2계층 소환수 책임 분리 유지
- 초기 Slice 콘텐츠 수 증가 없음

---

## 9. Loop G — 이미지 작업 운영 공격

### 공격

> 이미지 생성 실패 때마다 사용자에게 같은 요청을 다시 입력하게 하면 작업 기억과 책임이 사용자에게 전가된다.

### 비판 검증

사실이다. 생성 도구의 상세 오류 로그를 확인할 수 없는 경우가 있지만, 동일 브리프를 보존하고 내부적으로 복잡도를 낮추는 것은 가능하다.

### 판정

`P1 / OPERATING_RULE_REQUIRED`

### 처리

- 동일 요청 재입력을 기본 해결책으로 사용하지 않음
- 기존 브리프·승인 이미지를 유지
- 한글 장문·복합 UI·다수 인물을 줄여 단계적으로 재시도
- 실패 시 도구 한계를 명시하고 성공하지 않은 산출물을 완료로 주장하지 않음
- 이미지 관련 결정은 가능한 경우 이미지로 제시
- 이미지 생성 결과는 자동 확정이 아니라 상태 태그로 관리

## 10. 최종 확정 사항

### 캐릭터

- 필드·전투: 3.5~4등신 SD
- 대화: 반신 일러스트
- 필드와 전투는 동일 비율·기본 골격 공유

### 전투

- 별도 고정 3/4 전술 전투장
- 작성 시 전투장 감속·암전 오버레이
- 전투 종료 후 필드 복귀 및 환경 결과 반영

### 메인 동반 소환수

- 원소·정령 우선, 동물 형상은 선택 가능
- 신비한 정령수 계열 대표 방향
- 장기 4단계 성장
- 실제 성장 단계와 표시 형상 분리
- 해금된 이전 형상 선택 가능
- 장기 탑승 기능, 초기 Slice 제외

### 전투 보조 소환수

- 같은 세계관의 원소·정령 시각 언어
- 초기 Slice에서 수호 또는 견제 1체
- 4역할 전체·성장·형상 선택·탑승은 미확정
