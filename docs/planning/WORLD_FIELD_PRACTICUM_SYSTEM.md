## 1. 채택 구조

현장실습은 **학년이 오를수록 학교 배정에서 학생 제안으로 자율성이 증가하는 혼합형**으로 운영한다.

```text
1학년
→ 학교 지정 중심

2학년
→ 필수 지정 실습 + 선택 실습

3학년
→ 학생 제안 중심 + 학교 위험 승인
```

학년 상승은 단순히 더 어려운 적을 만나는 것이 아니라, 학생이 임무·팀·접근법을 결정할 권한과 책임을 얻는 과정이다.

## 2. 1학년 — 배정과 보호

학교가 다음을 대부분 지정한다.

- 실습 지역
- 핵심 목표
- 담당 교수 또는 감독자
- 기본 팀 구성
- 허용 위험 등급
- 필수 안전 회로

플레이어가 선택하는 영역:

- 준비할 마도서와 스톡
- 배운 메인 글자·보조 글자의 활용 방식
- 현장 내 세부 경로와 해결법
- 팀 내 역할과 대화 선택
- 추가 조사 여부

1학년 실습은 학교가 문제를 정해 주되, 해답까지 지정하지 않는다.

## 3. 2학년 — 지정과 선택의 병행

한 학기에는 학교가 정한 핵심 실습과 플레이어가 선택하는 실습 후보가 함께 존재한다.

```text
필수 핵심 실습
→ 학기 주요 사건·공통 평가 담당

선택형 실습
→ 수강 계열·관계·연구 성향에 따라 후보 변화
```

선택 가능 영역:

- 여러 임무 후보 중 하나 선택
- 동행 학생 또는 역할 선택
- 사전 조사 방식
- 전문 계열에 맞는 준비
- 전투·구조·봉인·복구·조사 중 해결 방향

학교는 위험 등급과 기본 안전 조건만 관리하고, 접근법은 학생에게 더 많이 맡긴다.

## 4. 3학년 — 제안과 책임

3학년은 학생이 실습 계획을 제안하는 구조가 중심이다.

플레이어 제안 항목 후보:

- 연구·실습 주제
- 대상 지역
- 해결하려는 문제
- 사용할 메인 글자 계열
- 필요한 보조 글자와 장비
- 동행 인물 또는 팀
- 예상 위험과 대응 계획

학교의 역할:

- 위험 등급 심사
- 민간인·시설 안전 기준 확인
- 감독자 또는 비상 지원 지정
- 과도한 위험 계획의 수정 요구
- 졸업 기준과 연결

3학년 자유는 무제한 임무 생성이 아니라, 준비된 후보와 플레이어의 성장 데이터를 조합해 자신의 계획으로 보이게 하는 방식이 적합하다.

## 5. 수업과 실습의 연결

수강한 메인 글자 계열과 보조 글자는 현장실습 후보와 해결 방법에 영향을 준다.

```text
열 계열 수업 반복
→ 마력 난방 시설·동결 지역·재료 가공 실습 후보 증가

보호 계열 수업 반복
→ 구조·시설 보호·봉쇄 임무 후보 증가

감지 계열 수업 반복
→ 탐색·추적·유적 조사 선택지 증가
```

수업 선택은 임무를 자동 해결하지 않는다. 관련 정보를 이해하고 사용할 수 있는 글자와 접근법을 늘린다.

## 6. 메인 스토리와 자유도

- 각 학기 핵심 사건과 승급 평가에 필요한 공통 실습은 유지한다.
- 선택형 실습을 하지 않아도 메인 진행이 영구 차단되지 않는다.
- 선택형 실습은 전문성·관계·주문 발견·진로 차이를 만든다.
- 3학년 제안형 실습도 메인 스토리 핵심 목표와 연결할 수 있다.
- 플레이어가 선택하지 않은 실습은 다른 학생의 활동이나 후속 사건으로 일부 반영할 수 있다.

## 7. 실패 처리

- 1학년 실패는 감독자의 개입, 보충 수업, 재실습으로 이어진다.
- 2학년 실패는 선택한 준비와 팀 관계에 따라 다른 후속 사건을 만든다.
- 3학년 실패는 계획의 문제점, 책임 범위, 졸업 평가에 반영하되 즉시 게임오버로 처리하지 않는다.
- 민간인·시설 피해가 큰 경우 복구 임무와 관계 변화가 발생할 수 있다.
- 한 번의 실패로 계열 수업이나 핵심 회로를 영구 박탈하지 않는다.

## 8. 제작 범위 가드레일

- 3학년 제안형을 완전한 자유 텍스트 임무 생성 시스템으로 만들지 않는다.
- 학년마다 모든 실습 지역을 새로 만들지 않는다.
- 같은 지역도 수업 계열, 사건 상태, 계절, 팀과 목표에 따라 재활용한다.
- 모든 실습을 전투 임무로 만들지 않는다.
- 학교가 지정한 임무에서도 플레이어의 회로 조합과 해결 선택을 남긴다.
- 자유 선택이 메인 스토리의 난이도와 인과관계를 붕괴시키지 않게 한다.

## 9. 확정·보류 구분

### 확정 방향

- 1학년은 학교 지정 실습 중심
- 2학년은 필수 지정 실습과 선택 실습 병행
- 3학년은 학생 제안형 실습 중심
- 학년 상승에 따라 임무·팀·접근법 선택 권한 확대
- 학교는 위험 승인과 안전 기준을 유지
- 수업 계열과 관계가 실습 후보·해결 선택지에 영향

### 추후 세부 설계

- 학기별 필수·선택 실습의 정확한 개수
- 실습 후보가 갱신되는 방식
- 팀원 선택과 역할 분담
- 3학년 제안 UI와 승인 단계
- 실패·평가·보상의 세부 공식
- 같은 지역을 재사용하는 사건 변형 규칙
