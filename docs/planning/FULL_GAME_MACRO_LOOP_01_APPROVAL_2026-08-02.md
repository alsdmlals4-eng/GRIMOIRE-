## 2. 승인된 전체 게임 반복 구조

전체 게임의 기본 콘텐츠 단위는 `학습 나선 Chapter`다.

```text
새 마법 원리·상황 질문 학습
→ 수업에서 문자 의미와 가벼운 작성 연습
→ 자유일정에서 휴식·준비·교류·현장실습 중 선택
→ 일상 이벤트·축제·훈련에서 비전투 또는 통제된 응용
→ 메인 현장 사건·현장실습에서 전투·환경 해결과 책임 선택
→ 마도서 복기·교수 누적 평가
→ 다음 원리와 심화·전문화 후보 개방
```

별도 시험 Chapter나 시험 전용 미니게임은 두지 않는다. 기존 Vertical Slice는 이 구조의 첫 검증판이며 모든 Chapter가 같은 순서를 복제하지 않는다.

## 3. 자유일정의 네 선택축

| 선택 | 주된 플레이 가치 | 금지되는 축소 |
|---|---|---|
| 휴식 | 상태 회복·작성 피로 완화·복구 | 단순 HP 회복 버튼 |
| 준비 | 상황 관찰·조건 파악·도구·전략 준비 | 정답 미리보기·유일 해법 제공 |
| 교류 | 다른 관점·관계 반응·공동 행동 | 호감도 숫자 파밍 |
| 현장실습 | 선택형 전투·실전 응용·현장 기록 | 무한 파밍·메인 사건 대체 |

한 자유일정 슬롯에서는 중심 행동 하나만 선택한다. 어느 선택도 필수 정보·유일 해법·영구적으로 우월한 최적 루트를 독점하지 않는다.

## 4. 선택형 현장실습·전투 계약

### 공간

- 학교 모의전투장·실습장.
- 숲·생태 구역·야외 훈련지.
- 이미 개방된 사건 지역의 안전 구획.
- 별도 승인된 전투 공간.

기존 Chapter 공간과 전투장 변형을 우선 재사용한다.

### 플레이 흐름

```text
실습 목적·환경 조건 확인
→ 출전·동반자·수호 수단 확인
→ 강한 적 또는 훈련 표적 1개체 중심 전투
→ 마법 작성·상황 대응
→ 결과·부작용·관찰 기록
→ 자유일정 종료
```

단순 HP 처치 반복이 아니라 적·환경의 불안정 원인을 읽고 진정·통제·보호 목표를 수행한다.

### 일정 비용과 보상

- 현장실습은 자유일정 슬롯 1개를 소비한다.
- 같은 활동의 안전 Anchor 재시도는 추가 슬롯을 자동 소비하지 않는다.
- 고유 첫 완료와 새로운 조건·해법 발견을 우선 보상한다.
- 반복 전투만으로 관계·글자·장학 평가·핵심 성장 자원을 무한 축적할 수 없다.
- 보상량·반복 감쇠·전투 길이는 `TEST_VALUE`다.

보상 후보:

1. 마도서 현장 기록.
2. 환경·적 행동에 대한 이해.
3. 동반 정령·동급생·교수의 반응.
4. 다음 핵심 세션의 제한적 준비 상태.
5. 새 해법·부작용 발견 기록.

랜덤 장비 파밍과 현장실습 독점 영구 스탯은 승인하지 않는다.

## 5. 누적 평가 계약

평가는 별도 시험 점수가 아니라 다음 포트폴리오를 합친다.

```text
수업 학습·작성 기록
+
축제·일상 이벤트의 비전투 응용
+
현장실습·메인 현장의 전투/환경 수행
+
마도서 복기와 책임 설명
→ 계열 성장·심화·전문화 후보
```

- 수업은 안전한 학습·연습 구간이며 성적 경쟁 콘텐츠가 아니다.
- 현장실습의 처치 속도·피해량만으로 평가를 독점하지 않는다.
- 축제·일상 이벤트의 생활·표현·구조·관계 해결도 성장 증거가 된다.
- 부분 성공·실패도 원인과 책임을 설명하면 학습 기록이 될 수 있다.
- 정확한 활동별 가중치는 `TEST_VALUE`다.

## 6. 메인 현장 사건과의 경계

| 선택형 현장실습 | 메인 현장 사건 |
|---|---|
| 자유일정에서 선택 가능 | Chapter 핵심 진행 |
| 낮거나 통제된 위험 | 실제 인물·생태·시설에 대한 책임과 대가 |
| 실전 연습·관찰·준비 | 세계 상태 변화·서사 결과·장기 평가 |
| 안전 Anchor 재시도 | 부분 성공·손실·포기한 대상 기록 가능 |
| 필수 정보 독점 금지 | 핵심 갈등과 다음 Chapter 개방 담당 |

실습 반복으로 메인 사건을 자동 해결하거나 위험을 제거할 수 없다.

## 7. Vertical Slice 영향

기존 45~50분 대표 경로와 53분 콘텐츠 상한은 자동 변경하지 않는다.

- 기존 `취약한 부유 수정구 이송`은 별도 실기시험이 아니라 `교내 일상 응용` 또는 수업 후 실습으로 재분류한다.
- 기존 7분 목표·8분 상한 슬롯은 동일하게 유지해 제작량을 늘리지 않는다.
- 본편 자유일정의 네 번째 축으로 현장실습을 유지한다.
- Slice 자유일정 A/B/C에 선택형 전투를 몇 회 노출할지는 대표성 재검증에서 정한다.
- 새 전투 공간·새 적·장시간 전투를 단순 추가해 53분 상한을 넘길 수 없다.

## 8. 적대적 보호 규칙

- 전투가 자유일정의 지배적 선택이 되지 않도록 독점 영구 성장과 무한 파밍을 금지한다.
- 학교생활은 수업·일상 응용·축제·관계·누적 평가의 독립 기능을 유지한다.
- 계열별 새 맵·적·VFX를 병렬 제작하지 않고 공통 상황을 재해석한다.
- 현장실습을 선택하지 않아도 메인 진행·필수 정보·계열 성장이 봉쇄되지 않는다.
- 별도 시험 제거가 교수 피드백과 학교 평가 기능의 삭제를 의미하지 않는다.

## 9. 거부한 대안

- 학교 허브+사건 의뢰형을 전체 Macro Loop로 사용하지 않는다.
- 반복 학기 Roguelite형을 사용하지 않는다.
- 자유일정 전투를 무제한 파밍 던전으로 만들지 않는다.
- 수업→시험→축제→현장을 매 Chapter 반복하지 않는다.
- 별도 시험 Chapter·시험장·시험 전용 미니게임을 만들지 않는다.
