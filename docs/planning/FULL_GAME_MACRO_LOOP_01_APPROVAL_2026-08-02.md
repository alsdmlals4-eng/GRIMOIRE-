## 2. 승인된 전체 게임 반복 구조

전체 게임의 기본 콘텐츠 단위는 `학습 나선 Chapter`다.

```text
새 마법 원리·상황 질문 학습
→ 자유일정에서 회복·준비·관계·현장실습 중 선택
→ 학교 시험·행사·훈련에서 통제된 응용
→ 메인 현장 사건에서 복합 적용과 책임 선택
→ 마도서 복기·발견·평가
→ 다음 원리와 더 어려운 상황 개방
```

기존 Vertical Slice는 이 구조의 첫 검증판으로 유지한다. 단, 모든 Chapter가 같은 순서와 같은 콘텐츠 종류를 복제하지는 않는다. `학습 / 선택 / 응용 / 현장 / 복기` 기능은 보존하되 배치·강도·형태를 변주한다.

## 3. 자유일정의 네 선택축

본편 자유일정은 다음 네 축 중 하나를 선택한다.

| 선택 | 주된 플레이 가치 | 금지되는 축소 |
|---|---|---|
| 휴식 | 상태 회복·작성 피로 완화·복구 | 단순 HP 회복 버튼 |
| 준비 | 상황 관찰·조건 파악·도구·전략 준비 | 정답 미리보기·유일 해법 제공 |
| 교류 | 다른 관점·관계 반응·공동 행동 | 호감도 숫자 파밍 |
| 현장실습 | 선택형 전투·실전 응용·현장 기록 | 무한 파밍·메인 사건 대체 |

한 자유일정 슬롯에서는 중심 행동 하나만 선택한다. 네 선택 모두 다음 핵심 콘텐츠에 의미 있는 도움을 주되, 어느 하나도 필수 정보·유일 해법·영구적으로 우월한 최적 루트를 독점하지 않는다.

## 4. 선택형 현장실습·전투 계약

### 4.1 공간 유형

현장실습은 Chapter와 학교 권한에 따라 다음 공간을 사용한다.

- 학교 모의전투장·실습장.
- 숲·생태 구역·야외 훈련지.
- 이미 개방된 사건 지역의 안전 구획.
- 별도 승인된 전투 공간.

공간은 새 Asset을 매번 요구하지 않고, 메인 Chapter 공간과 전투장 변형을 우선 재사용한다.

### 4.2 플레이 기능

```text
실습 목적·환경 조건 확인
→ 출전·동반자·수호 수단 확인
→ 강한 적 또는 훈련 표적 1개체 중심 전투
→ 마법 작성·상황 대응
→ 결과·부작용·관찰 기록
→ 자유일정 종료
```

현장실습은 현재 승인된 상황 해결형 전투를 사용한다. 단순 HP 처치 반복이 아니라 적·환경의 불안정 원인을 읽고 진정·통제·보호 목표를 수행한다.

### 4.3 일정 비용과 보상

- 현장실습 진입은 자유일정 슬롯 1개를 소비한다.
- 전투 재시도는 같은 활동의 안전 진입 Anchor에서 수행하며 추가 자유일정 슬롯을 자동 소비하지 않는다.
- 동일 실습의 진행 보상은 고유 첫 완료와 새로운 조건·해법 발견을 우선한다.
- 반복 전투만으로 관계·글자·장학 평가·핵심 성장 자원을 무한 축적할 수 없다.
- 정확한 보상량·반복 감쇠·전투 길이는 후속 성장·경제·Chapter 리듬 결정에서 `TEST_VALUE`로 정의한다.

보상 후보의 우선순위:

1. 실전 관찰·마도서 현장 기록.
2. 특정 환경 또는 적 행동에 대한 이해.
3. 동반 정령·동급생·교수의 짧은 반응.
4. 다음 핵심 세션을 보조하는 제한적 준비 상태.
5. 새 해법·부작용을 발견했다는 기록.

현장실습만의 독점 영구 스탯이나 랜덤 장비 파밍은 현재 승인하지 않는다.

### 4.4 메인 현장 사건과의 경계

선택형 현장실습은 메인 현장 사건과 다음처럼 구분한다.

| 선택형 현장실습 | 메인 현장 사건 |
|---|---|
| 자유일정에서 선택 가능 | Chapter 핵심 진행 |
| 낮거나 통제된 위험 | 실제 인물·생태·시설에 대한 책임과 대가 |
| 실전 연습·관찰·준비 | 세계 상태 변화·서사 결과·장기 평가 |
| 실패해도 안전 Anchor 재시도 | 부분 성공·손실·포기한 대상이 기록될 수 있음 |
| 메인 필수정보 독점 금지 | 핵심 갈등과 다음 Chapter 개방을 담당 |

선택형 실습을 반복해 메인 사건을 자동 해결하거나 위험을 제거할 수 없다.

## 5. Vertical Slice 영향

기존 45~50분 대표 경로와 53분 콘텐츠 상한은 자동 변경하지 않는다.

- 본편 자유일정의 네 번째 선택축으로 현장실습을 승인한다.
- 현재 Vertical Slice A/B/C 슬롯에 실제 선택형 전투를 몇 회 노출할지는 `Vertical Slice 대표성 재검증`에서 정한다.
- Slice에 포함할 경우 기존 전투장·숲/온실 공간을 재사용하고 다른 자유일정 장면과 동등한 시간 예산으로 재조정해야 한다.
- 새 전투 공간·새 적·추가 장시간 전투를 단순 추가하여 53분 상한을 넘기는 것은 승인되지 않았다.

## 6. 적대적 검토와 보호 규칙

### 공격 1 — 전투가 가장 효율적인 선택이 되는가

보정:
- 현장실습은 독점 영구 성장·반복 파밍을 제공하지 않는다.
- 휴식·준비·교류도 각각 다른 상황에서 동등한 규모의 효용을 갖는다.

### 공격 2 — 학교생활이 전투 대기실로 축소되는가

보정:
- Chapter 개방·평가·관계·마법 학습은 학교의 독립 기능으로 유지한다.
- 현장실습도 학교의 교육·허가·안전·책임 문맥 안에서 제공한다.

### 공격 3 — 선택형 전투가 제작량을 폭증시키는가

보정:
- 강한 적 1개체 중심 규칙과 기존 공간 변형을 우선 재사용한다.
- 매 자유일정마다 새 적·맵·보스를 제작하지 않는다.
- 고유 상황 질문이 없는 단순 반복 전투는 콘텐츠로 추가하지 않는다.

### 공격 4 — 전투를 고르지 않으면 손해인가

보정:
- 핵심 글자·메인 사건 접근·필수 정보는 현장실습에 묶지 않는다.
- 선택하지 않은 플레이어도 다른 축을 통해 동등한 규모의 준비·관계·회복 이점을 얻는다.

## 7. 거부한 대안

- B 학교 허브+사건 의뢰형을 전체 Macro Loop로 사용하지 않는다.
- C 반복 학기·Roguelite형을 사용하지 않는다.
- 자유일정 전투를 무제한 반복 가능한 파밍 던전으로 만들지 않는다.
- 모든 Chapter에 같은 수업→시험→축제→현장 순서를 의무화하지 않는다.
