# Spell 세계관 컨셉 — 마법학교·현장실습·회로 활용 모험

## 문서 상태

- 상태: `PLANNING_IN_PROGRESS`
- 세계관 코어 상태: `WORLD_CORE_CANDIDATE`
- 결정 상태: `DIRECTION_CONFIRMED`
- 기준 날짜: 2026-07-26
- 관련 결정: `GM-WORLD-01`, `GM-WORLD-02`
- 상위 게임 기획: `docs/planning/SPELL_GAME_DESIGN.md`
- 현재 작업 맥락: `docs/ACTIVE_CONTEXT.md`

이 문서는 Spell의 세계관·서사·성장 배경에 관한 최신 책임 원본이다. 기존 시스템 문서는 전투 규칙을 담당하고, 이 문서는 그 규칙이 세계 안에서 어떤 의미를 갖는지 정의한다.

## 1. 한 문장 세계관

> 회로 마법이 학문과 기술로 발전한 세계에서, 마법학교 학생이 수업으로 기초 원리를 배우고 현장실습에서 회로를 자유롭게 활용해 새로운 주문과 해결법을 발견하며 성장하는 모험.

## 2. 채택한 기본 컨셉

```text
마법학교 생활과 성장
+
학교 밖 현장실습과 지역 모험
+
배운 회로의 자유로운 활용과 주문 발견
```

- 학교는 학습·교류·준비·성장의 중심 허브다.
- 실제 모험과 주문 발견은 현장실습에서 주로 발생한다.
- 플레이어는 정해진 스킬 목록만 배우는 학생이 아니라, 회로의 원리를 이해하고 상황에 맞게 활용하는 실습생이다.
- 학년·등급·자격 상승은 새로운 회로 계층과 더 어려운 현장에 접근하는 성장 장치로 사용한다.

## 3. 비밀학과 중심 서사 제외

비밀학과, 삭제된 학과, 금지된 학생 조직을 세계관의 필수 중심축으로 사용하지 않는다.

상태: `REMOVED_FROM_CORE_DIRECTION`

- 학교가 숨긴 거대한 음모를 반드시 추적하는 구조로 만들지 않는다.
- 플레이어가 특별히 선택된 비밀학과 학생이어야 할 필요가 없다.
- 학교의 일상, 경쟁, 수업과 현장 모험을 자연스럽게 유지한다.
- 지역 사건이나 과거 유적에 비밀이 존재할 수는 있지만, 모든 이야기가 학교의 음모로 수렴하지 않는다.
- 금지된 주문이나 위험한 연구는 개별 사건·고난도 콘텐츠로 사용할 수 있으나 세계관 코어는 아니다.

## 4. 회로의 `활용`

Spell에서 새로운 콘텐츠를 추가하는 핵심 개념은 숨겨진 회로 계통이 아니라 **이미 배운 회로의 새로운 활용**이다.

```text
기초 회로 학습
→ 기능과 연결 원리 이해
→ 현장의 문제와 환경 관찰
→ 회로를 다른 형상·전달·보조·조건과 조합
→ 새로운 활용 발견
→ 유효한 주문 설계도로 등록
```

### 활용의 의미

- 같은 회로라도 목적, 대상, 환경과 연결 방식에 따라 다른 결과를 낼 수 있다.
- 회로는 단순한 스킬 조각이 아니라 마법 현상을 만드는 문법이다.
- 콘텐츠 확장은 새로운 메인 회로를 계속 추가하는 방식에만 의존하지 않는다.
- 기존 회로에 새로운 형상, 전달, 조건, 보조 또는 현장 상황을 결합해 활용 범위를 늘릴 수 있다.

### 활용 예시

```text
열 회로
+ 투사체 전달
→ 화염탄

열 회로
+ 범위 형상
→ 주변 난방·빙결 지역 해제

열 회로
+ 지속 보조
→ 온실 유지·부화 지원
```

```text
방벽 회로
+ 전방 형상
→ 공격 차단

방벽 회로
+ 고정 조건
→ 지역 봉쇄

방벽 회로
+ 보존 보조
→ 유물·재료 보호
```

이 예시는 방향 설명용이며 실제 회로 목록과 주문 데이터는 별도 설계에서 확정한다.

## 5. 학교의 역할

학교는 전투 전에 메뉴를 여는 장소가 아니라, 플레이어의 지식·관계·성장과 다음 모험의 이유를 제공하는 생활 허브다.

### 수업

- 기초 회로 원리 학습
- 형상·전달·보조·조건 회로 소개
- 직접 입력 훈련
- 소환수 계약과 운용 학습
- 스톡 준비와 안전 규칙 학습

### 실습 시설

- 회로 훈련장
- 마도서와 설계도 등록소
- 소환수 훈련·교감 공간
- 모의 전투실
- 재료 분석실 또는 응용 연구실

### 학생 생활

- 동급생·선배·교수와의 관계
- 조별 과제와 경쟁
- 시험, 발표, 대회, 축제
- 선택 과목 또는 연구 주제 선택

학교 운영이나 건설을 핵심 경영 게임으로 만들지는 않는다. 학교는 플레이어 성장과 이야기의 허브 역할에 집중한다.

## 6. 현장실습의 역할

현장실습은 Spell의 전투·탐험·주문 발견을 세계관 안에서 정당화한다.

```text
학교에서 실습 의뢰 수령
→ 대상 지역과 위험 정보 확인
→ 스톡·소환수·마도서 준비
→ 현장 이동
→ 마법 생물·재해·환경 문제 조사
→ 회로를 직접 활용해 해결
→ 발견한 활용과 기록 회수
→ 학교 귀환 후 보고·등록·평가
```

현장실습 후보:

- 마법 생태 지역 조사
- 불안정한 마력 현상 안정화
- 유적과 오래된 회로 장치 해석
- 마을·시설의 마법 사고 해결
- 마법 생물 구조·진정·제압
- 다른 학교 또는 기관과의 공동 실습
- 정기 시험과 현장 자격 평가

처치만을 유일한 해결 방식으로 두지 않는다. 방어, 구조, 봉인, 복구, 운반, 추적, 환경 조작도 회로 활용의 목표가 될 수 있다.

## 7. 성장 루프와 세계관 연결

```text
수업
→ 기초 회로와 원리 학습

현장실습
→ 직접 회로 작성과 상황별 활용

발견
→ 새로운 주문·응용 방식 발견

보고와 등록
→ 마도서 설계도에 기록

숙련
→ 반복 회로를 하위 회로 스톡으로 자동화

자격 상승
→ 상위 회로·새 지역·고난도 실습 해금
```

### 시스템 의미

| 게임 시스템 | 세계관 의미 |
|---|---|
| 직접 회로 작성 | 학생이 원리를 이해하고 현장에서 즉석 해결 |
| 주문 발견 | 새로운 회로 활용을 실제로 증명 |
| 마도서 등록 | 발견한 활용을 공식 설계도로 기록 |
| 숙련과 스톡화 | 반복 가능성과 안전성을 인증받은 표준화 |
| 준비 용량 | 전투 전 안정적으로 유지할 수 있는 준비 한계 |
| 소환수 | 실습을 보조하는 계약형 마법 존재 |
| 현장실습 | 지식을 실제 문제 해결 능력으로 바꾸는 과정 |

## 8. 서사 구조 방향

### 기본 톤

- 성장과 모험을 중심으로 한다.
- 학교의 밝은 일상과 외부 지역의 위험을 대비시킨다.
- 학생의 실패, 경쟁, 우정과 발견을 중요하게 다룬다.
- 세계 규모의 위기는 초반부터 전면에 내세우지 않고 현장 사건을 통해 점진적으로 확장한다.

### 장기 이야기 후보

다음은 방향 후보이며 아직 확정하지 않는다.

1. 회로 마법의 급속한 보급으로 발생하는 새로운 마법 재해
2. 지역마다 다르게 진화한 회로 활용과 학교 간 경쟁
3. 마법 생태계와 인간의 회로 기술 사이의 충돌
4. 오래된 자연 마법과 표준화된 학교 회로의 차이
5. 플레이어가 발견한 새로운 활용이 사회와 학교의 규칙을 변화시키는 과정

학교 내부 비밀학과를 장기 서사의 필수 전제로 두지 않는다.

## 9. 콘텐츠 확장 방식

새로운 지역이나 업데이트는 다음 단위로 확장할 수 있다.

```text
새 현장 지역
+
기존 회로의 새로운 활용 조건
+
새 형상·전달·보조 회로 일부
+
지역 소환수와 사건
+
학교 내 새로운 수업·인물 반응
```

- 신규 콘텐츠마다 완전히 새로운 마법 체계를 만들 필요가 없다.
- 기존 회로가 새로운 환경에서 다르게 작동하도록 설계할 수 있다.
- 학교는 새 활용이 공식 교육과 사회에 반영되는 변화를 보여준다.
- 지역 에피소드를 독립적으로 추가하면서도 플레이어의 마도서와 숙련은 누적된다.

## 10. 가드레일

- 비밀학과·학교 음모를 세계관의 필수 중심축으로 만들지 않는다.
- 학교를 튜토리얼 이후 버려지는 장소로 만들지 않는다.
- 현장실습을 단순 전투 스테이지 선택 메뉴로만 축소하지 않는다.
- 모든 문제의 해결법을 적 처치로 고정하지 않는다.
- 회로 활용이 정답 하나를 맞히는 퍼즐로만 굳어지지 않게 한다.
- 신규 콘텐츠가 기존 회로를 무가치하게 만드는 상위 호환 회로 추가에만 의존하지 않게 한다.
- 학생 성장보다 국가·세계 정치 설정이 앞서지 않게 한다.
- 학교 경영·건설 시스템을 현재 코어에 추가하지 않는다.

## 11. 현재 미해결 사항

1. 학교는 단일 명문학교인가, 마법학교 도시인가, 여러 학교 중 하나인가.
2. 주인공은 신입생·편입생·견습 연구생 중 무엇인가.
3. 학교의 교육 기간을 학년제로 표현할 것인가, 자격 등급제로 표현할 것인가.
4. 현장실습 의뢰를 학교가 직접 배정하는가, 학생이 선택하는가.
5. 세계의 주요 장기 갈등은 마법 재해·생태 충돌·학교 경쟁 중 무엇인가.
6. 전투 외 회로 활용을 어느 범위까지 실제 플레이로 구현할 것인가.
