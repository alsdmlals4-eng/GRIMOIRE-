# Spell 세계관 컨셉 — 마법학교·현장실습·회로 활용 모험

- 상태: `PLANNING_IN_PROGRESS`
- 세계관 코어 상태: `WORLD_CORE_CANDIDATE`
- 결정 상태: `DIRECTION_CONFIRMED`
- 기준 날짜: 2026-07-26
- 관련 결정: `GM-WORLD-01`~`GM-WORLD-06`
- 상위 게임 기획: `docs/planning/SPELL_GAME_DESIGN.md`

- 현재 작업 맥락: `docs/ACTIVE_CONTEXT.md`

이 문서는 Spell의 세계관·서사·성장 배경에 관한 최신 책임 원본이다. 전투 시스템 문서는 규칙을 담당하고, 이 문서는 그 규칙이 세계 안에서 어떤 의미를 갖는지 정의한다.

## 1. 한 문장 세계관

> 회로 마법이 학문과 기술로 발전한 세계에서, 단일 명문 마법학교의 학생이 수업과 학기 활동으로 성장하고 학교 밖 현장실습에서 회로를 자유롭게 활용해 새로운 주문과 해결법을 발견하는 모험.

## 2. 채택한 기본 컨셉

```text
하나의 중심 마법학교 생활과 학년 성장
+
학교 밖 현장실습과 지역 모험
+
배운 회로의 자유로운 활용과 주문 발견
+
학기별 일정 선택 육성
```

- 학교는 학습·교류·준비·육성·성장의 중심 허브다.
- 실제 모험과 주문 발견은 현장실습에서 주로 발생한다.
- 플레이어는 정해진 스킬 목록만 배우는 학생이 아니라 회로의 원리를 이해하고 상황에 맞게 활용하는 실습생이다.
- 학년 승급은 새로운 회로 문법, 시설, 인물, 지역과 현장 책임을 여는 큰 성장 단계다.
- 학기 일정 선택은 플레이어의 능력, 관계, 활용 성향을 만드는 중간 성장 단계다.

## 3. 학교 규모와 세계 안의 위치

채택 구조: `단일 명문 마법학교 + 인근 생활권 + 점진적으로 확장되는 현장실습 지역`

```text
중심 명문학교
→ 인근 마을·도시
→ 숲·유적·마법 생태 지역
→ 고위험 마법 재해 지역
→ 다른 학교·기관과의 교류 지역
```

- 플레이어가 반복적으로 돌아오고 관계를 쌓을 중심 학교는 하나다.
- 학교 주변의 마을과 도시가 학생 생활과 초급 현장실습을 담당한다.
- 학년이 오르면 더 먼 지역과 고난도 실습이 개방된다.
- 다른 학교는 교류전, 축제, 대회, 공동 실습, 라이벌과 교수를 통해 등장한다.
- 여러 학교를 매 학년 순회하거나 학교 도시 전체를 관리하는 구조는 현재 코어에서 제외한다.

### 제작상 의미

- 학교 인물과 장소를 반복 활용해 애착을 만든다.
- 외부 지역은 에피소드 단위로 독립 추가할 수 있다.
- 하나의 허브를 깊게 만들고 지역 콘텐츠를 점진적으로 확장한다.
- 학교 경영·건설·교직원 배치는 핵심 시스템에 포함하지 않는다.

## 4. 비밀학과 중심 서사 제외

비밀학과, 삭제된 학과, 금지된 학생 조직을 세계관의 필수 중심축으로 사용하지 않는다.

상태: `REMOVED_FROM_CORE_DIRECTION`

- 학교가 숨긴 거대한 음모를 반드시 추적하는 구조로 만들지 않는다.
- 플레이어가 특별히 선택된 비밀학과 학생일 필요가 없다.
- 학교의 일상, 경쟁, 수업과 현장 모험을 자연스럽게 유지한다.
- 지역 사건이나 과거 유적에 비밀이 존재할 수는 있지만 모든 이야기가 학교 음모로 수렴하지 않는다.
- 금지 주문이나 위험한 연구는 개별 사건·고난도 콘텐츠로 사용할 수 있으나 세계관 코어는 아니다.

## 5. 회로의 `활용`

Spell에서 새로운 콘텐츠를 추가하는 핵심 개념은 숨겨진 회로 계통이 아니라 **이미 배운 회로의 새로운 활용**이다.

```text
기초 회로 학습
→ 기능과 연결 원리 이해
→ 현장의 문제와 환경 관찰
→ 형상·전달·보조·조건 회로와 조합
→ 새로운 활용 발견
→ 유효한 주문 설계도로 등록
```

### 활용의 의미

- 같은 회로라도 목적, 대상, 환경과 연결 방식에 따라 다른 결과를 낸다.
- 회로는 단순 스킬 조각이 아니라 마법 현상을 만드는 문법이다.
- 콘텐츠 확장은 새로운 메인 회로를 계속 추가하는 방식에만 의존하지 않는다.
- 기존 회로에 새로운 형상, 전달, 조건, 보조와 현장 상황을 결합해 활용 범위를 늘린다.

### 활용 예시

```text
열 회로 + 투사체 전달
→ 화염탄

열 회로 + 범위 형상
→ 주변 난방·빙결 지역 해제

열 회로 + 지속 보조
→ 온실 유지·마법 생물 부화 지원
```

```text
방벽 회로 + 전방 형상
→ 공격 차단

방벽 회로 + 고정 조건
→ 위험 지역 봉쇄

방벽 회로 + 보존 보조
→ 유물·재료 보호
```

예시는 방향 설명용이며 실제 회로 목록과 주문 데이터는 별도 설계에서 확정한다.

## 6. 학교의 역할

학교는 전투 전에 메뉴를 여는 장소가 아니라 플레이어의 지식·관계·육성과 다음 모험의 이유를 제공하는 생활 허브다.

### 수업

- 기초 회로 원리
- 형상·전달·보조·조건 회로
- 직접 입력 훈련
- 소환수 계약과 운용
- 스톡 준비와 마법 안전
- 현장 대응과 마법 사고 처리

### 실습 시설

- 회로 훈련장
- 마도서·설계도 등록소
- 소환수 훈련·교감 공간
- 모의 전투실
- 재료 분석실·응용 연구실

### 학생 생활

- 동급생·선배·교수와의 관계
- 조별 과제와 경쟁
- 시험, 발표, 대회, 축제
- 선택 과목과 연구 주제
- 동아리·자율활동·휴식

## 7. 학년 승급과 육성

학년은 플레이어가 다룰 수 있는 마법 범위와 현장 책임을 나타내는 큰 성장 단계다.

```text
학기별 수업·활동 선택
→ 현장실습에서 결과 검증
→ 시험·발표·실기 평가
→ 학년말 승급
→ 상위 회로·실습 지역·시설·사건 해금
```

### 프린세스 메이커식 육성의 변형

- 일정 선택이 장기간 누적되어 능력, 관계와 성장 성향을 바꾸는 구조를 참고한다.
- 매일 단위의 세밀한 생활 관리는 사용하지 않는다.
- 학기 단위로 의미 있는 수업·자율활동·현장실습을 선택한다.
- 교육·훈련·일 경험은 회로 수업, 모의 전투, 연구 보조, 동아리, 학교·마을 의뢰로 변형한다.
- 활동 결과는 능력치뿐 아니라 활용 힌트, 현장 선택지, 인물 관계와 사건에 반영한다.
- 육성만으로 주문을 자동 획득하지 않는다. 최종 발견은 현장에서 플레이어가 직접 성공해야 한다.

### 학기 루프

```text
학기 시작
→ 필수 수업 확인
→ 선택 수업·자율활동 선택
→ 현장실습 준비
→ 현장실습 수행
→ 시험·발표·평가
→ 능력·관계·활용 성향 누적
```

### 승급 원칙

- 특정 빌드나 선택 과목 때문에 메인 진행이 영구 차단되지 않게 한다.
- 부족한 항목은 보충 수업이나 재시험으로 회복 가능하게 한다.
- 승급 실패는 즉시 게임오버보다 보충 기간, 추가 사건과 관계 변화로 처리한다.
- 우수한 성적은 추가 선택지와 보상을 주되 기본 승급을 과도하게 어렵게 만들지 않는다.

세부 활동과 성장축은 `WORLD_SCHOOL_GROWTH_SYSTEM.md`에서 관리한다.

## 8. 현장실습의 역할

현장실습은 수업과 육성 결과를 실제 플레이에서 검증하고 Spell의 전투·탐험·주문 발견을 세계관 안에서 정당화한다.

```text
학교에서 실습 의뢰 확인
→ 대상 지역과 위험 정보 조사
→ 스톡·소환수·마도서 준비
→ 현장 이동
→ 마법 생물·재해·환경 문제 조사
→ 회로를 직접 활용해 해결
→ 활용 기록과 재료 회수
→ 학교 귀환 후 보고·등록·평가
```

현장실습 후보:

- 마법 생태 지역 조사
- 불안정한 마력 현상 안정화
- 유적과 오래된 회로 장치 해석
- 마을·시설의 마법 사고 해결
- 마법 생물 구조·진정·제압
- 다른 학교·기관과의 공동 실습
- 정기 시험과 현장 자격 평가

처치만을 유일한 해결 방식으로 두지 않는다. 방어, 구조, 봉인, 복구, 운반, 추적, 환경 조작도 회로 활용 목표가 될 수 있다.

## 9. 성장 루프와 시스템 의미

```text
수업·육성
→ 회로 원리·활용 힌트·관계 성장

현장실습
→ 직접 회로 작성과 상황별 활용

발견
→ 새로운 주문·응용 방식 증명

보고와 등록
→ 마도서 설계도로 기록

숙련
→ 반복 회로를 하위 회로 스톡으로 자동화

학년 승급
→ 상위 회로·새 지역·고난도 실습 해금
```

| 게임 시스템 | 세계관 의미 |
|---|---|
| 직접 회로 작성 | 학생이 원리를 이해하고 현장에서 즉석 해결 |
| 주문 발견 | 새로운 회로 활용을 실제로 증명 |
| 마도서 등록 | 발견한 활용을 공식 설계도로 기록 |
| 숙련과 스톡화 | 반복 가능성과 안전성을 인증받은 표준화 |
| 준비 용량 | 전투 전 안정적으로 유지할 수 있는 준비 한계 |
| 소환수 | 실습을 보조하는 계약형 마법 존재 |
| 학기 육성 | 학생의 전문 성향과 관계를 형성 |
| 학년 승급 | 마법 책임과 콘텐츠 범위를 확장 |
| 현장실습 | 지식을 실제 문제 해결 능력으로 전환 |

## 10. 서사 구조 방향

### 기본 톤

- 성장과 모험을 중심으로 한다.
- 학교의 밝은 일상과 외부 지역의 위험을 대비시킨다.
- 학생의 실패, 경쟁, 우정과 발견을 중요하게 다룬다.
- 세계 규모 위기는 초반부터 전면에 내세우지 않고 현장 사건을 통해 점진적으로 확장한다.

### 장기 이야기 후보

1. 회로 마법의 급속한 보급으로 발생하는 새로운 마법 재해
2. 지역마다 다르게 진화한 회로 활용과 학교 간 경쟁
3. 마법 생태계와 인간의 회로 기술 사이의 충돌
4. 오래된 자연 마법과 표준화된 학교 회로의 차이
5. 플레이어가 발견한 새로운 활용이 사회와 학교 규칙을 변화시키는 과정

학교 내부 비밀학과를 장기 서사의 필수 전제로 두지 않는다.

## 11. 콘텐츠 확장 방식

```text
새 현장 지역
+
기존 회로의 새로운 활용 조건
+
새 형상·전달·보조 회로 일부
+
지역 소환수와 사건
+
새 수업·활동·인물 반응
```

- 신규 콘텐츠마다 완전히 새로운 마법 체계를 만들 필요가 없다.
- 기존 회로가 새로운 환경에서 다르게 작동하도록 설계한다.
- 학교는 새 활용이 공식 교육과 사회에 반영되는 변화를 보여준다.
- 지역 에피소드를 독립 추가하면서도 마도서, 관계와 학년 성장은 누적된다.

## 12. 가드레일

- 비밀학과·학교 음모를 세계관의 필수 중심축으로 만들지 않는다.
- 학교를 튜토리얼 이후 버려지는 장소로 만들지 않는다.
- 현장실습을 단순 전투 스테이지 선택 메뉴로 축소하지 않는다.
- 모든 문제의 해결법을 적 처치로 고정하지 않는다.
- 회로 활용이 정답 하나를 맞히는 퍼즐로만 굳어지지 않게 한다.
- 신규 콘텐츠가 상위 호환 회로 추가에만 의존하지 않게 한다.
- 학생 성장보다 국가·세계 정치 설정이 앞서지 않게 한다.
- 학교 경영·건설 시스템을 현재 코어에 추가하지 않는다.
- 매일 단위 복잡한 일정과 수십 개 생활 능력치를 초기 코어에 넣지 않는다.
- 육성 메뉴가 회로 전투와 현장실습보다 플레이 시간을 압도하지 않게 한다.
- 연애·결혼 중심 육성 시뮬레이션을 현재 코어에 추가하지 않는다.

## 13. 현재 미해결 사항

1. 주인공은 신입생·편입생·견습 연구생 중 무엇인가.
2. 교육 기간은 총 몇 학년인가.
3. 학기당 선택 가능한 활동 수는 몇 개인가.
4. 필수 수업과 선택 수업의 비율은 어떻게 구성하는가.
5. 현장실습 의뢰를 학교가 배정하는가, 학생이 선택하는가.
6. 컨디션을 단일 피로도로 둘 것인가, 집중·스트레스로 나눌 것인가.
7. 세계의 주요 장기 갈등은 마법 재해·생태 충돌·학교 경쟁 중 무엇인가.
8. 전투 외 회로 활용을 어느 범위까지 실제 플레이로 구현할 것인가.
9. 졸업과 진로를 다중 엔딩으로 운영할 것인가.
