## GM-00-31 — 스톡 방해 상태이상 역할 단순화

### 채택안

`B 변형 — 마력 교란과 주문 봉인만 사용하고 회로 혼선 삭제`

### 최종 구조

```text
마력 교란
→ 스톡 충전 속도 감소

주문 봉인
→ 준비된 스톡 사용 불가

회로 혼선
→ 사용하지 않음
```

### 마력 교란

- 자동 충전은 계속 진행한다.
- 현재 충전 진행도와 충전 대상은 유지한다.
- 충전 속도만 감소한다.
- 이미 완성된 스톡은 정상적으로 사용할 수 있다.
- 해제 후 정상 충전 속도로 복귀한다.

### 주문 봉인

- 완성 주문 스톡과 하위 회로 스톡 모두 사용할 수 없다.
- 자동 충전은 계속 진행한다.
- 플레이어와 소환수의 생산 기여도 계속 적용한다.
- 충전 대상 전환도 정상적으로 허용한다.
- 보유 스톡 수량과 충전 진행도는 유지한다.
- 봉인 중 충전이 완료된 스톡도 정상 저장된다.
- 해제 후 별도 복구 입력 없이 즉시 사용 가능해진다.

### 회로 혼선 삭제

- 충전 대상 전환 지연 증가 상태는 사용하지 않는다.
- 충전 대상 전환 자체에 이미 전환 지연이 있으므로 별도 방해 상태는 중복 복잡도를 만든다.
- 상태이상 역할은 `생산 방해`와 `사용 방해` 두 축으로 유지한다.

### 설계 의도

- 마력 교란은 미래의 스톡 공급을 늦춘다.
- 주문 봉인은 현재 비축한 즉시 대응 수단을 잠시 차단한다.
- 하나의 상태가 생산과 사용을 동시에 기본 봉쇄하지 않게 한다.
- 상태 해제 후 반격할 수 있도록 진행도와 보유량을 보존한다.

## 후속 미해결 결정

1. 마력 교란의 기본 충전 속도 감소율과 지속시간은 얼마인가.
2. 마력 교란의 중첩 방식과 최소 충전 속도는 무엇인가.
3. 주문 봉인의 기본 지속시간과 중첩·갱신 방식은 무엇인가.
4. 주문 봉인이 직접 회로 시전까지 차단하는 별도 상위 효과가 필요한가.
5. 소환수 수호·동조가 두 상태를 저항하거나 해제할 수 있는가.
