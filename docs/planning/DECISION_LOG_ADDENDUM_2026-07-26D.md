## GM-00-31 — 스톡 방해 상태이상 역할 단순화

### 채택안

`B 변형 — 마력 교란과 주문 봉인만 사용하고 회로 혼선 삭제`

### 최종 구조

```text
마력 교란
→ 스톡 충전 속도 감소

주문 봉인
→ 준비된 스톡 사용 불가

회로 혼선
→ 사용하지 않음
```

### 마력 교란

- 자동 충전은 계속 진행한다.
- 현재 충전 진행도와 충전 대상은 유지한다.
- 충전 속도만 감소한다.
- 이미 완성된 스톡은 정상적으로 사용할 수 있다.
- 해제 후 정상 충전 속도로 복귀한다.

### 주문 봉인

- 완성 주문 스톡과 하위 회로 스톡 모두 사용할 수 없다.
- 자동 충전은 계속 진행한다.
- 플레이어와 소환수의 생산 기여도 계속 적용한다.
- 충전 대상 전환도 정상적으로 허용한다.
- 보유 스톡 수량과 충전 진행도는 유지한다.
- 봉인 중 충전이 완료된 스톡도 정상 저장된다.
- 해제 후 별도 복구 입력 없이 즉시 사용 가능해진다.

### 회로 혼선 삭제

- 충전 대상 전환 지연 증가 상태는 사용하지 않는다.
- 충전 대상 전환 자체에 이미 전환 지연이 있으므로 별도 방해 상태는 중복 복잡도를 만든다.
- 상태이상 역할은 `생산 방해`와 `사용 방해` 두 축으로 유지한다.

상태: `CONFIRMED`

최신 책임 원본: `docs/planning/STATUS_EFFECT_STOCK_SYSTEM.md`

## GM-00-32 — 마력 교란 기획 기본값

### 채택안

`권장안 — 충전 속도 30% 감소, 동일 상태 중첩 없음, 재적용 시 지속시간 갱신`

### 기획 기준값

```text
정상 충전 속도 100%
→ 마력 교란 적용
→ 충전 속도 70%
```

- 기본 충전 속도 감소율은 30%로 둔다.
- 동일한 마력 교란은 중첩하지 않는다.
- 재적용 시 감속률을 높이지 않고 남은 지속시간만 갱신한다.
- 현재 충전 진행도와 충전 대상은 유지한다.
- 완성된 스톡 사용은 허용한다.
- 해제 후 정상 충전 속도로 즉시 복귀한다.

### 수치 상태

- 시스템 운용 원칙: `CONFIRMED`
- 충전 속도 30% 감소: `PLANNING_DEFAULT`
- 실제 지속시간: `BALANCE_LATER`
- 다른 감속 효과와의 전체 하한: `BALANCE_LATER`

상태: `CONFIRMED_DIRECTION_WITH_PLANNING_DEFAULT`

최신 책임 원본: `docs/planning/STATUS_EFFECT_STOCK_SYSTEM.md`

## GM-00-33 — 일반 주문 봉인과 상위 마력 봉쇄 분리

### 채택안

`권장안 — 일반 주문 봉인은 스톡만 차단하고, 상위 마력 봉쇄는 스톡과 직접 회로 시전을 모두 차단`

### 일반 주문 봉인

```text
주문 봉인
→ 완성 주문 스톡 사용 불가
→ 하위 회로 스톡 사용 불가
→ 직접 회로 작성·시전 가능
```

- 일반 주문 봉인은 비축한 스톡의 사용만 차단한다.
- 직접 회로 작성과 마나를 사용하는 직접 시전은 대응 수단으로 남긴다.
- 자동 충전, 생산 기여, 충전 대상 전환과 스톡 저장은 계속 진행한다.
- 진행도와 보유량은 유지한다.

### 상위 마력 봉쇄

```text
마력 봉쇄
→ 완성 주문 스톡 사용 불가
→ 하위 회로 스톡 사용 불가
→ 직접 회로 작성·시전 불가
```

- 일반 주문 봉인과 별개의 상위 상태로 분리한다.
- 희귀 적, 엘리트 기믹 또는 보스급 패턴에만 제한한다.
- 적용 전에 명확한 사전 경고를 제공한다.
- 회피, 차단, 해제 또는 패턴 파훼 중 적어도 하나의 대응 수단을 제공한다.
- 장시간·고빈도 적용을 금지한다.
- 충전 진행도와 보유 스톡은 삭제하지 않는다.
- 종료 후 별도 복구 입력 없이 기능을 즉시 복원한다.

### 설계 의도

- 일반 상태에서는 직접 회로 시전이라는 핵심 조작과 대응 수단을 보존한다.
- 모든 마법 행동 차단은 보스급 전투 기믹으로만 사용한다.
- 일반 봉인과 상위 봉쇄의 위협도를 명확하게 구분한다.

상태: `CONFIRMED_DIRECTION`

최신 책임 원본: `docs/planning/STATUS_EFFECT_STOCK_SYSTEM.md`
