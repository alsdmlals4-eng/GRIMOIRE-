## GM-00-31 — 스톡 방해 상태이상 역할 단순화

### 채택안

`B 변형 — 마력 교란과 주문 봉인만 사용하고 회로 혼선 삭제`

### 최종 구조

```text
마력 교란
→ 스톡 충전 속도 감소

주문 봉인
→ 준비된 스톡 사용 불가

회로 혼선
→ 사용하지 않음
```

### 마력 교란

- 자동 충전은 계속 진행한다.
- 현재 충전 진행도와 충전 대상은 유지한다.
- 충전 속도만 감소한다.
- 이미 완성된 스톡은 정상적으로 사용할 수 있다.
- 해제 후 정상 충전 속도로 복귀한다.

### 주문 봉인

- 완성 주문 스톡과 하위 회로 스톡 모두 사용할 수 없다.
- 자동 충전은 계속 진행한다.
- 플레이어와 소환수의 생산 기여도 계속 적용한다.
- 충전 대상 전환도 정상적으로 허용한다.
- 보유 스톡 수량과 충전 진행도는 유지한다.
- 봉인 중 충전이 완료된 스톡도 정상 저장된다.
- 해제 후 별도 복구 입력 없이 즉시 사용 가능해진다.

### 회로 혼선 삭제

- 충전 대상 전환 지연 증가 상태는 사용하지 않는다.
- 충전 대상 전환 자체에 이미 전환 지연이 있으므로 별도 방해 상태는 중복 복잡도를 만든다.
- 상태이상 역할은 `생산 방해`와 `사용 방해` 두 축으로 유지한다.

### 설계 의도

- 마력 교란은 미래의 스톡 공급을 늦춘다.
- 주문 봉인은 현재 비축한 즉시 대응 수단을 잠시 차단한다.
- 하나의 상태가 생산과 사용을 동시에 기본 봉쇄하지 않게 한다.
- 상태 해제 후 반격할 수 있도록 진행도와 보유량을 보존한다.

상태: `CONFIRMED`

최신 책임 원본: `docs/planning/STATUS_EFFECT_STOCK_SYSTEM.md`

## GM-00-32 — 마력 교란 기획 기본값

### 채택안

`권장안 — 충전 속도 30% 감소, 동일 상태 중첩 없음, 재적용 시 지속시간 갱신`

### 기획 기준값

```text
정상 충전 속도 100%
→ 마력 교란 적용
→ 충전 속도 70%
```

- 기본 충전 속도 감소율은 30%로 둔다.
- 동일한 마력 교란은 중첩하지 않는다.
- 재적용 시 감속률을 높이지 않고 남은 지속시간만 갱신한다.
- 현재 충전 진행도와 충전 대상은 유지한다.
- 완성된 스톡 사용은 허용한다.
- 해제 후 정상 충전 속도로 즉시 복귀한다.

### 수치 상태

- 시스템 운용 원칙: `CONFIRMED`
- 충전 속도 30% 감소: `PLANNING_DEFAULT`
- 실제 지속시간: `BALANCE_LATER`
- 다른 감속 효과와의 전체 하한: `BALANCE_LATER`

### 설계 의도

- 현재 단계에서는 세부 수치보다 상태이상의 전술적 역할을 확정한다.
- 중첩 계산을 제거해 모바일 UI와 전투 판독성을 유지한다.
- 향후 PoC에서 감속률과 지속시간을 조정하더라도 `충전은 계속`, `진행도 보존`, `중첩 없음`이라는 구조는 유지한다.

상태: `CONFIRMED_DIRECTION_WITH_PLANNING_DEFAULT`

최신 책임 원본: `docs/planning/STATUS_EFFECT_STOCK_SYSTEM.md`
