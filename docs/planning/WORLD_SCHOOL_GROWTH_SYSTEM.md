# Spell 마법학교 학년·육성 시스템 — 책임 원본

## 문서 상태

- 상태: `PLANNING_IN_PROGRESS`
- 결정 상태: `DIRECTION_CONFIRMED`
- 세계관 코어 상태: `WORLD_CORE_CANDIDATE`
- 기준 날짜: 2026-07-26
- 관련 결정: `GM-WORLD-04`~`GM-WORLD-10`
- 상위 세계관: `docs/planning/WORLD_SETTING_CONCEPT.md`
- 학년 구조: `docs/planning/WORLD_ACADEMIC_YEAR_STRUCTURE.md`

이 문서는 단일 명문 마법학교, 3년제·6학기 학년 승급, 프린세스 메이커식 일정 선택 육성을 Spell의 회로·현장실습 구조에 맞게 변형한 성장 방향을 정의한다.

## 1. 핵심 방향

```text
하나의 중심 마법학교
→ 학기별 수업·활동·현장실습 선택
→ 능력·관계·회로 활용 성향 성장
→ 학년말 평가
→ 다음 학년 승급
→ 상위 회로·시설·지역·실습 해금
```

- 학교는 하나의 중심 명문학교를 깊게 사용한다.
- 인근 마을·도시·숲·유적·마법 재해 지역을 현장실습지로 확장한다.
- 다른 학교는 교류전, 축제, 공동 실습, 경쟁 인물로 점진적으로 등장시킨다.
- 학년 승급은 플레이어 성장과 콘텐츠 해금을 설명하는 주요 세계관 장치다.
- 프린세스 메이커식 육성은 일정 선택과 성장 결과의 누적 구조를 참고하되, 복잡한 생활 관리 전체를 그대로 복제하지 않는다.

## 2. 교육 기간과 학년 역할

채택 구조는 **3년제, 학년당 2학기, 총 6학기**다.

```text
1학년 2학기
→ 적응·기초 회로·인근 실습

2학년 2학기
→ 전문화·보조/조건 회로·중급 실습

3학년 2학기
→ 독립 판단·고난도 실습·졸업 진로
```

### 1학년 — 적응과 기초

- 학교 규칙과 생활 적응
- 기본 회로 문법과 안전 규칙
- 직접 회로 작성 훈련
- 기본 소환수 계약·교감
- 인근 학교 시설·마을·숲 중심 초급 현장실습
- 동급생·교수·라이벌 관계의 시작

1학년은 긴 튜토리얼이 아니라, 학교생활과 기초 회로 활용의 재미가 완결되는 첫 성장 단계다.

### 2학년 — 전문화와 확장

- 선택 수업과 연구 분야 확대
- 보조 회로·조건 회로·복합 연결 도입
- 스톡 편성과 소환수 운용 심화
- 도시·유적·마법 생태 지역의 중급 현장실습
- 공동 실습·대회·다른 학교와의 교류
- 성장 성향과 전문 분야의 구체화

2학년부터 같은 문제를 수업·관계·회로 활용에 따라 다르게 해결하는 차이를 본격적으로 보여준다.

### 3학년 — 독립 판단과 졸업

- 상위 회로 조합과 독립 설계
- 고위험·장기·독립 현장실습
- 교수의 정답 없이 판단하는 문제 해결
- 후배·동급생·민간인·지역에 대한 책임 확대
- 졸업 연구·발표·실기·종합 현장실습
- 전문 분야와 졸업 후 진로 결정

3학년의 성장은 단순 화력보다 자율성·책임·문제 복잡도 증가로 표현한다.

## 3. 학기의 역할

학기는 플레이어가 성장 방향을 선택하는 반복 단위다.

```text
학기 시작
→ 필수 수업 확인
→ 선택 수업·자율활동·관계 활동 선택
→ 학교 내 소규모 사건
→ 현장실습 준비와 수행
→ 시험·발표·평가
→ 성장 결과와 사건 반영
```

- 매일을 세밀하게 관리하지 않는다.
- 한 학기 안에서 의미 있는 몇 개의 활동을 선택하는 경량 구조를 우선한다.
- 일정 선택은 능력치 상승뿐 아니라 회로 활용, 인간관계, 사건, 실습 선택지에 영향을 준다.
- 1·2학년 2학기 종료 시 승급 평가를 진행한다.
- 3학년 2학기 종료 시 졸업 종합 평가와 진로 결정을 진행한다.
- 한 학기당 정확한 활동 선택 수는 `GM-WORLD-10`에서 확정한다.

## 4. 프린세스 메이커식 육성의 변형

| 육성 시뮬레이션 요소 | Spell식 변형 |
|---|---|
| 교육 | 회로 이론·형상·전달·보조·조건 수업 |
| 훈련 | 직접 회로 입력·모의 전투·소환수 교감 |
| 일·사회 경험 | 학교 의뢰·연구 보조·마을 지원·동아리 활동 |
| 모험 | 학교 밖 현장실습 |
| 상태 관리 | 피로·집중·자신감 등 최소한의 컨디션 후보 |
| 관계 | 동급생·선배·교수·소환수와의 신뢰·이벤트 |
| 진로·엔딩 | 회로 활용 성향, 전문 분야, 졸업 후 진로 후보 |

## 5. 활동 축

### 5.1 필수 수업

- 기본 회로 문법
- 마법 안전과 봉인
- 직접 입력 훈련
- 소환수 운용
- 현장 대응 기초

필수 수업은 전체 플레이어가 공통 기반을 배우는 장치다. 핵심 회로 문법을 선택하지 않아 영구적으로 놓치는 구조는 피한다.

### 5.2 선택 수업

후보:

- 회로 해석과 응용
- 방어·구조 마법
- 전투 마법
- 마법 생태와 소환수
- 유적·고대 회로
- 마도구·스톡 운용
- 조건·기동 회로 연구

선택 수업은 단순 공격력 증가보다 다음에 영향을 주는 편이 적합하다.

- 특정 활용 힌트와 실험 범위
- 현장 상호작용 선택지
- 주문 설계도 발견 가능성
- 교수·동급생 이벤트
- 실습 평가 방식
- 장기 전문 분야와 진로 성향

### 5.3 자율활동

후보:

- 회로 자율 연구
- 모의 전투
- 소환수 교감
- 휴식과 회복
- 동아리·친구 활동
- 교수 연구 보조
- 마을·시설 지원 활동

자율활동은 능력, 관계와 컨디션 사이의 선택을 만든다.

### 5.4 현장실습

현장실습은 육성 결과를 실제 플레이에서 검증하는 핵심 활동이다.

```text
수업과 활동으로 준비
→ 현장 문제 선택
→ 직접 회로 활용
→ 전투·구조·봉인·복구·조사 수행
→ 평가와 새로운 주문 발견
```

육성만으로 주문을 자동 획득하지 않는다. 학습은 힌트와 가능성을 열고, 최종 활용 발견은 현장에서 플레이어가 직접 증명한다.

## 6. 성장 축 — 최소화 원칙

초기 기획에서는 성장 수치를 과도하게 늘리지 않는다.

권장 상위 축 후보:

1. `회로 이해` — 활용 힌트, 상위 문법, 분석
2. `시전 숙련` — 직접 입력 안정성, 마나 운용
3. `현장 대응` — 방어, 위험 대처, 실습 평가
4. `소환 동조` — 소환수 전투·수호·생산 지원
5. `관계·평판` — 인물 사건, 공동 실습, 지원
6. `컨디션` — 피로·집중을 대표하는 단일 또는 소수 자원

이 목록은 방향 후보이며 명칭과 최종 개수는 별도 데이터 설계에서 확정한다.

### 수치 성장보다 중요한 결과

- 어떤 활용 힌트를 얻는가
- 어떤 수업·교수·학생 이벤트를 여는가
- 어떤 현장실습을 선택할 수 있는가
- 같은 문제를 어떤 방식으로 해결할 수 있는가
- 어떤 회로 활용 성향과 진로를 형성하는가

## 7. 학년 승급과 졸업

학년 승급은 단순 경험치 레벨업이 아니라 한 기간의 성장과 현장 성과를 정리하는 사건이다.

평가 후보:

- 필수 과목 이수
- 최소 현장실습 완료
- 회로 활용 보고서 또는 실기 시험
- 직접 회로 시전과 안전성 평가
- 소환수 운용 평가

권장 원칙:

- 특정 빌드나 선택 과목 때문에 메인 진행이 영구 차단되지 않게 한다.
- 부족한 평가 항목은 보충 수업이나 재시험으로 회복 가능하게 한다.
- 승급 실패는 게임오버보다 추가 사건·보충 기간·관계 변화로 처리한다.
- 우수한 성적은 추가 보상과 선택지를 주되, 기본 승급을 지나치게 어렵게 만들지 않는다.
- 3학년 졸업 평가는 회로 활용·현장 판단·관계·소환수 운용을 종합 검증한다.

## 8. 일정 선택의 결과

```text
전투 수업 집중
→ 직접 전투 대응과 공격 주문 활용 강화
→ 방어·관계·연구 기회 일부 포기

응용 연구 집중
→ 기존 회로의 새로운 활용 힌트 증가
→ 실전 숙련과 컨디션 관리 필요

소환수 교감 집중
→ 소환수 수호·생산 지원과 관련 사건 강화
→ 회로 학습 속도 일부 희생
```

결과는 하나의 정답 빌드보다 서로 다른 성장 경험을 만들어야 한다.

## 9. 관계와 생활 이벤트

학교 육성은 숫자만 올리는 메뉴가 아니라 인물과 사건을 만드는 장치다.

- 같은 수업을 반복 선택하면 담당 교수와 연구 관계 발전
- 동급생과 같은 실습을 선택하면 협력·경쟁 이벤트 발생
- 휴식 없이 훈련을 반복하면 컨디션과 대사 변화
- 특정 활용 분야에 집중하면 학교 내 평판과 진로 인식 변화
- 축제·대회·발표회에서 육성 결과를 비전투 방식으로 확인
- 학년이 오르면 동급생 관계가 협력자·경쟁자·전문 분야 동료로 변화
- 3학년에는 후배와 진로 관계가 추가될 수 있음

연애·결혼 시뮬레이션은 현재 코어에 포함하지 않는다. 관계는 우정, 경쟁, 신뢰, 사제 관계와 팀워크를 우선한다.

## 10. 전투·회로 시스템과 연결

| 육성 선택 | 시스템 연결 |
|---|---|
| 회로 이론 수업 | 새로운 조합 힌트·상위 회로 해금 조건 |
| 직접 시전 훈련 | 입력 안정성·마나 운용 관련 성장 |
| 모의 전투 | 위험 대응·현장 평가 준비 |
| 소환수 교감 | 수호·전투·스톡 생산 지원 성장 |
| 마도구·스톡 수업 | 준비 용량·스톡 운용 관련 성장 기회 |
| 현장실습 | 주문 활용 발견·마도서 등록·재료·관계 사건 |

정확한 능력치 공식과 학년별 해금 시점은 시스템 데이터 단계에서 결정한다.

## 11. 방학과 학기 사이

방학은 별도의 대규모 자유생활 시뮬레이션으로 만들지 않는다.

후보:

- 짧은 귀향·학교 잔류 선택
- 보충 수업과 개인 연구
- 특정 인물 관계 사건
- 다음 학기 준비와 스톡·소환수 정비
- 선택형 특별 현장실습
- 이전 학기 결과 요약

방학 콘텐츠의 분량과 필수 여부는 후속 설계에서 정한다.

## 12. 제작 범위 가드레일

- 매일 단위의 복잡한 일정표를 필수로 만들지 않는다.
- 수십 개의 생활 능력치와 직업 데이터를 초기 코어에 추가하지 않는다.
- 육성 메뉴가 실제 회로 전투보다 플레이 시간을 압도하지 않게 한다.
- 학교 경영·건설·교직원 배치 게임으로 확장하지 않는다.
- 선택 수업 하나로 핵심 회로를 영구히 놓치게 하지 않는다.
- 단순 반복 클릭으로 능력치만 올리는 활동을 최소화한다.
- 육성 결과를 현장실습의 선택지와 플레이 방식으로 체감하게 한다.
- 1학년을 긴 튜토리얼로만 소비하지 않는다.
- 3학년에서 학교생활을 버리고 전투만 진행하지 않는다.
- 각 학기마다 학교 맵 전체와 관계 콘텐츠를 새로 제작하지 않는다.
- 6학기 모두에 세계 멸망급 사건을 배치하지 않는다.

## 13. 현재 미해결 사항

1. 한 학기의 일정 선택 단위는 몇 개인가.
2. 필수 수업과 선택 수업의 비율은 어떻게 구성하는가.
3. 현장실습은 학교 배정·학생 선택·혼합형 중 무엇인가.
4. 컨디션을 단일 피로도로 둘 것인가, 집중·스트레스로 나눌 것인가.
5. 학년 승급 평가에서 성적·실습·관계 중 어떤 비중을 사용하는가.
6. 졸업과 진로를 다중 엔딩으로 운영할 것인가, 메인 스토리 이후 평가로 운영할 것인가.
7. 방학의 길이와 선택 콘텐츠 범위는 어느 정도인가.
