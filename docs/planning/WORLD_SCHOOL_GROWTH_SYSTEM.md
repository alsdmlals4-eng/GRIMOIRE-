## 1. 핵심 성장 루프

```text
학교 수업
→ 메인 글자·보조 글자 학습
→ 자유 일정에서 연구·훈련·관계 누적
→ 현장실습에서 회로 활용
→ 주문 발견·마도서 등록
→ 숙련·스톡화
→ 시험·평가·승급
```

- 학교는 수업·교류·준비·연구·육성의 생활 허브다.
- 현장실습은 배운 글자와 육성 결과를 실제 문제에 적용하는 핵심 콘텐츠다.
- 학년 상승은 글자 문법, 선택 권한, 책임과 현장 범위를 함께 확장한다.
- 육성만으로 완성 주문을 자동 획득하지 않는다.
- 학교생활을 3~4회의 메뉴 선택처럼 압축하지 않는다.
- 매일 단위 복잡한 일정표와 수십 개 생활 능력치는 사용하지 않는다.

## 2. 교육 기간과 학년 역할

정규 교육 기간은 **3년제, 학년당 2학기, 총 6학기**다.

### 1학년 — 적응·기초 글자·배정 실습

- 학교 규칙과 생활 적응
- 마법 글자의 획·연결·안전 문법
- 여러 기초 메인 글자 계열 경험
- 메인 글자 하나로 기본 주문 발동
- 소수의 형상·전달·안정 보조 글자
- 기본 소환수 계약·교감
- 학교가 지역·목표·감독자를 지정하는 초급 실습
- 동급생·교수·라이벌 관계 형성

1학년은 긴 튜토리얼이 아니라 기초 글자 조합과 학교생활이 완결되는 첫 성장 단계다. 학교가 임무를 지정하지만 해결법은 플레이어가 선택한다.

### 2학년 — 계열 선택·복합 글자·혼합 실습

- 관심 메인 글자 계열의 중급 수업 선택
- 계열 대표 보조 글자와 교차 응용
- 출력·행동·조건·순서 보조 글자 확장
- 스톡 편성과 소환수 운용 심화
- 필수 지정 실습과 선택형 실습 병행
- 도시·유적·마법 생태 지역의 중급 실습
- 공동 연구·교류전·다른 학교와의 협력
- 성장 성향과 전문 분야 구체화

2학년부터 같은 문제를 수강 계열, 관계, 글자 조합과 준비 방식에 따라 다르게 해결하는 차이를 본격화한다.

### 3학년 — 독립 설계·제안형 실습·졸업

- 다수 보조 글자를 활용한 고위 주문 설계
- 독립 연구와 졸업 주제
- 후배 지도와 공동 프로젝트
- 학생이 주제·지역·팀·접근법을 제안하는 현장실습
- 학교는 위험 등급·안전 기준·감독만 승인
- 고위험·장기·독립 임무
- 졸업 연구·발표·실기·종합 평가
- 전문 분야와 졸업 후 진로 결정

3학년의 성장은 화력보다 자율성·책임·문제 복잡도와 설계 능력의 증가로 표현한다.

## 3. 한 학기의 장기 일정

한 학기는 **자유 일정 10회 + 고정 사건 4회**, 총 14구간이다.

```text
자유 일정 3회
→ 학기 초 학교 사건
→ 자유 일정 2회
→ 중간 현장실습
→ 자유 일정 3회
→ 학기 핵심 사건
→ 자유 일정 2회
→ 시험·발표·평가
```

- 6학기 전체 자유 일정은 총 60회다.
- 학기 초 사건은 새 계열 수업·교수·학생·갈등을 소개한다.
- 중간 실습은 초반 수업과 준비의 결과를 처음 검증한다.
- 핵심 사건은 학교생활·관계·지역 문제를 연결한다.
- 시험·평가는 글자 이해·회로 활용·현장 판단·관계·소환수 운용을 확인한다.

## 4. 템포 원칙

### 미시 템포 — 빠르게

- 개별 대화·수업 설명은 짧고 명확하게 진행한다.
- 활동 선택 뒤 성장·관계·환경 변화 중 하나를 빠르게 보여준다.
- 회로 실습과 전투는 행동과 보상의 거리를 줄인다.

### 거시 템포 — 길게

- 같은 수업·교수·학생·활동이 학기 안에서 반복 등장한다.
- 메인·보조 글자의 숙련과 관계가 단계적으로 누적된다.
- 현장실습 전 준비와 실습 후 결과가 이후 일정에 영향을 준다.
- 학년과 학교생활이 지나치게 빠르게 지나가지 않게 한다.

DDD는 학기를 짧게 만드는 원칙이 아니라 각 행동의 결과와 보상을 빠르게 제공하는 원칙이다.

## 5. 마법 수업 체계

수업은 **메인 글자 계열**을 기준으로 나눈다.

### 5.1 공통 문법 과목

- 마법 글자 판독과 직접 작성
- 연결·방향·안전 규칙
- 기본 마력 운용
- 보편 형상·전달 글자
- 안정화와 보정
- 마도서 등록·스톡화 기초

### 5.2 메인 글자 계열 과목

각 계열 과목은 다음을 함께 가르친다.

1. 계열 현상과 위험
2. 메인 글자
3. 메인 글자의 기본 발현
4. 계열과 잘 맞는 보조 글자
5. 생활·전투·구조·연구 활용
6. 담당 교수와 과제
7. 관련 현장실습

```text
메인 글자 계열 수업
→ 메인 글자 습득
→ 메인 단독 기본 주문 성공
→ 관련 보조 글자 습득
→ 조합 과제
→ 현장 활용
```

### 5.3 응용·융합 실습

- 한 계열의 메인 글자와 다른 과목에서 배운 보조 글자를 조합한다.
- 목표와 제한 조건만 제공하고 정답 주문은 하나로 고정하지 않는다.
- 수업에서 배운 글자만으로 해결 가능한 기본 경로를 제공한다.
- 자유 연구와 관계를 통해 추가 해결 관점을 열 수 있다.

수업은 완성 주문 구매 메뉴가 아니다. 완성 주문은 현장에서 플레이어가 조합을 성공시켜 발견한다.

## 6. 글자 습득 단계

```text
관찰
→ 모사
→ 메인 단독 발동
→ 보조 글자 조합
→ 현장 활용
→ 마도서 등록
→ 숙련
→ 스톡화
```

| 단계 | 의미 |
|---|---|
| 관찰 | 교수 시범과 원리 이해 |
| 모사 | 안내를 따라 직접 작성 |
| 기본 발동 | 메인 글자만으로 주문 성공 |
| 조합 | 관련 보조 글자 결합 |
| 활용 | 현장 문제에 맞게 변형 |
| 등록 | 성공한 주문을 마도서에 기록 |
| 숙련 | 반복 사용으로 안정화 |
| 스톡화 | 성장 기준 이하의 숙련 글자·주문 준비 |

## 7. 자유 일정 활동

### 수업·연구

- 메인 글자 계열 선택 수업
- 공통 보조 글자 문법
- 회로 자율 연구
- 교수 연구 보조
- 마도서·스톡 정비

### 훈련·현장 준비

- 직접 시전·모의 전투
- 소환수 교감
- 현장실습 사전 조사
- 학교·마을 의뢰

### 관계·생활

- 동아리·친구·라이벌 활동
- 휴식과 컨디션 회복
- 학교 행사와 발표 준비

짧은 NPC 대화, 선택형 상세 대화, 학교 탐색, 기록 열람과 목표 확인은 자유 일정 횟수를 소비하지 않는다.

## 8. 반복 활동의 누적 변화

동일 수업과 활동을 반복해도 같은 결과만 반복하지 않는다.

```text
계열 수업 1회
→ 메인 글자와 기초 원리

계열 수업 3회
→ 대표 보조 글자와 교수 과제

계열 수업 5회
→ 개인 연구 주제·특화 활용

관련 현장실습 성공
→ 실제 주문 발견·마도서 등록
```

누적 변화 후보:

- 글자 숙련 단계
- 교수·학생 관계
- 새로운 수업 변형
- 현장실습 후보와 사전 정보
- 해결 선택지
- 조건부 학교 사건
- 전문 분야·평판·진로 성향
- 컨디션과 대사 변화

정확한 필요 횟수와 수치는 후속 데이터 설계에서 정한다.

## 9. 현장실습 자율성

```text
1학년
→ 학교 지정 중심

2학년
→ 필수 지정 + 선택형

3학년
→ 학생 제안 + 학교 승인
```

### 1학년

학교가 지역·목표·감독자·기본 팀을 지정한다. 플레이어는 글자 조합, 현장 경로, 역할, 추가 조사와 해결 방식을 선택한다.

### 2학년

학기 핵심 실습은 공통으로 유지하고, 수강 계열·관계·연구에 따라 선택 실습 후보가 달라진다. 팀과 준비 방식의 선택권도 확대한다.

### 3학년

플레이어가 연구 주제, 지역, 문제, 팀과 접근법을 제안한다. 학교는 위험 등급과 안전 기준을 심사한다. 완전 자유 생성이 아니라 준비된 후보와 성장 데이터를 조합한다.

## 10. 수업과 현장실습의 연결

```text
특정 메인 계열 수강
→ 관련 글자·원리·위험 지식 획득
→ 관련 실습 후보·사전 조사·해결 선택지 증가
→ 현장 조합 성공
→ 주문 발견·평가·관계 변화
```

- 수업 선택은 임무를 자동 해결하지 않는다.
- 핵심 진행에 필요한 기본 글자와 해결법은 필수 교육으로 보장한다.
- 선택 수업은 더 효율적이거나 다른 결과를 만드는 경로를 제공한다.
- 선택형 실습을 하지 않아도 메인 진행은 영구 차단되지 않는다.

## 11. 성장 축 — 최소화 원칙

후보:

1. `글자 이해` — 메인·보조 원리, 활용 힌트, 분석
2. `시전 숙련` — 직접 입력 안정성, 마나 운용
3. `현장 대응` — 위험 대처, 구조·봉인·전투 판단
4. `소환 동조` — 전투·수호·스톡 생산 지원
5. `관계·평판` — 공동 실습, 교수 연구, 진로
6. `컨디션` — 피로·집중을 대표하는 단일 또는 소수 자원

명칭과 최종 개수는 후속 데이터 설계에서 확정한다.

수치보다 중요한 결과:

- 어떤 메인·보조 글자를 배웠는가
- 어떤 계열 교수·학생과 연결되는가
- 어떤 현장실습을 선택·제안할 수 있는가
- 같은 문제를 어떤 주문 문장으로 해결하는가
- 어떤 전문 분야와 진로를 형성하는가

## 12. 관계와 생활 이벤트

- 같은 계열 수업을 반복하면 담당 교수와 연구 관계가 발전한다.
- 동급생과 같은 계열·실습을 선택하면 협력·경쟁 이벤트가 발생한다.
- 다른 계열 학생과 협력하면 보조 글자 교차 활용을 배울 수 있다.
- 과도한 훈련은 컨디션과 대사를 변화시킨다.
- 특정 계열과 활용에 집중하면 학교 내 평판과 진로 인식이 변한다.
- 3학년에는 후배 지도와 졸업 진로 관계가 추가된다.

연애·결혼은 현재 코어가 아니다. 우정·경쟁·신뢰·사제 관계·팀워크를 우선한다.

## 13. 승급과 졸업

평가 후보:

- 필수 글자·안전 과목 이수
- 최소 현장실습 완료
- 메인 단독 주문과 보조 조합 실기
- 회로 활용 보고서·발표
- 현장 판단과 안전성
- 소환수 운용

원칙:

- 특정 계열을 고르지 않았다는 이유로 메인 진행이 막히지 않는다.
- 부족한 항목은 보충 수업·재시험·추가 실습으로 회복할 수 있다.
- 승급 실패는 게임오버보다 보충 기간·관계·후속 사건으로 처리한다.
- 3학년 졸업 평가는 독립 주문 설계와 제안형 실습을 종합 검증한다.

## 14. 제작 범위 가드레일

- 학기를 3~4회의 선택으로 압축하지 않는다.
- 자유 일정 60회를 모두 고유 컷신으로 제작하지 않는다.
- 활동 템플릿에 학년·글자 숙련·관계·실습 결과를 결합해 변주한다.
- 수업을 완성 주문 구매 메뉴로 만들지 않는다.
- 모든 보조 글자를 계열 전용으로 중복 생산하지 않는다.
- 1학년 초반에 전문 계열을 영구 고정하지 않는다.
- 수업 수강만으로 주문 발견·등록·숙련을 자동 완료하지 않는다.
- 3학년 제안형 실습을 무제한 자유 텍스트 생성으로 만들지 않는다.
- 모든 실습을 전투 임무로 만들지 않는다.
- 휴식을 실패 선택으로 만들지 않는다.
- 학교를 튜토리얼 이후 버려지는 로비로 만들지 않는다.
