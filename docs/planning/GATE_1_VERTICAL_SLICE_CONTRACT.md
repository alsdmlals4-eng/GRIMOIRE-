> **첫 Vertical Slice는 마법학교의 축약된 한 학기를 네 개의 핵심 세션과 세 번의 자유일정으로 체험하며, 배우고·시험받고·표현하고·실전에 응용해 자신의 주문 활용을 발견하는 45~50분 목표의 완결형 데모다.**

## 2. 전체 구조

```text
프롤로그·학교 도착
→ 세션 1: 첫 수업·교내 연습
→ 자유일정 A 1회
→ 세션 2: 첫 실기시험
→ 자유일정 B 1회
→ 세션 3: 학교축제 준비·학교축제
→ 자유일정 C 1회
→ 세션 4: 첫 현장실습
→ 귀환·마도서 기록·다음 학기 예고
```

### 구조 원칙

- 중요 일정 직후 다음 중요 일정으로 바로 넘어가지 않는다.
- 수업 후·시험 후·축제 후에 자유일정 슬롯을 정확히 1회 제공한다.
- 한 자유일정에서는 중심 행동 하나만 선택한다.
- `휴식`은 정식 전략이며 손해 전용 선택이 아니다.
- 어떤 자유일정 선택도 시험·축제·현장실습 참가를 차단하지 않는다.
- 필수 정보와 유일한 정답을 특정 자유일정에 독점시키지 않는다.
- 각 핵심 세션과 자유일정은 저장·중단·복귀 경계를 가진다.
- 수업·시험·축제·현장실습은 서로 다른 게임이 아니라 같은 마법 문법과 문제 계약을 공유한다.

## 3. 공통 Situation Challenge 계약

수업·시험·학교축제·현장실습의 모든 플레이 문제는 다음 공통 데이터·플레이 계약을 사용한다.

```text
상황 목표
→ 관찰 가능한 상태
→ 사용 가능한 메인·보조 글자
→ 제한 조건
→ 방향성 결과 미리보기
→ 주문 작성
→ 세계 상태 변화
→ 성공·부분 성공·실패 원인
→ 기록·후속 반응
```

### 세션 차이를 만드는 데이터 필드

- 위험 수준
- 시간 압박
- 허용 자원
- 평가 방식
- 결과의 성격
- 소환수 허용 여부
- 실패 후 복구 방식
- 관계·기록 후속 반응

### 제작 가드레일

- 시험·축제·현장 문제를 같은 데이터 계약으로 정의한다.
- 두 번째 문제를 새 전용 Scene과 전용 시스템 코드 없이 추가할 수 있어야 한다.
- 세션별 독립 미니게임 프레임워크를 만들지 않는다.
- 모든 문제는 `메인 글자 1개 + 보조 글자 0개 이상` 문법을 공유한다.
- 방향성 미리보기는 정답을 공개하지 않고 영향 대상·범위·위험·소모 경향만 보여준다.

## 4. 세션 차별화 계약

| 세션 | 핵심 판단 | 압박 | 결과 구조 | 실패 처리 |
|---|---|---|---|---|
| 수업·연습 | 원리 이해·결과 비교 | 없음 또는 매우 낮음 | 즉각적 인과 설명 | 실패보다 수정 유도 |
| 실기시험 | 제한 조건 안의 선택·효율 | 횟수·시간·마나 중 하나 | 항목별 평가 | 진행 차단 없이 평가 하락 |
| 학교축제 | 표현·개성·관계 | 전투 압박 없음 | 복수의 긍정적 표현 결과 | 다른 분위기·완성도 |
| 현장실습 | 위험 속 우선순위·재설계 | 적·환경·시간 압박 | 성공·부분 성공·피해 | 안전 지점 재시도·원인 기록 |

플레이테스트 후 플레이어가 다음을 자기 말로 구분할 수 있어야 한다.

```text
수업은 이해하는 곳
시험은 증명하는 곳
축제는 표현하는 곳
현장은 응용하는 곳
```

## 5. 프롤로그·학교 도착

목적:

- 플레이어가 마법학교 학생이라는 역할 이해
- 메인 동반 소환수와 첫 관계 제시
- 이번 축약 학기의 주요 일정 예고
- 장문 세계관 설명 없이 첫 수업으로 연결

완료 기준:

- 현재 목표와 다음 행동을 이해한다.
- 첫 직접 작성이 시작 후 5분을 넘지 않는다.

## 6. 세션 1 — 첫 수업·교내 연습

핵심 질문:

> 이 글자는 무엇을 만들고, 보조 글자에 따라 어떻게 달라지는가?

```text
교수의 짧은 시범
→ 메인 글자 1개 직접 작성
→ 즉각적인 세계 변화 확인
→ 보조 글자 2개 학습
→ 같은 메인 글자에 서로 다른 보조 적용
→ 안내형 비교 문제 해결
→ 메인 동반 소환수와 결과 정리
```

필수 증거:

- 첫 5분 안에 직접 작성과 발현
- 메인·보조 글자의 역할 차이
- 같은 메인 글자가 보조에 따라 달라지는 결과
- 입력 실패와 설계 실패의 다른 피드백
- 15분 안에 메인·보조 차이 이해

## 7. 자유일정 시스템

### 7.1 슬롯 수

1. 수업·연습 후, 시험 전
2. 시험 후, 학교축제 전
3. 학교축제 후, 현장실습 전

### 7.2 공통 행동 원형

모든 슬롯은 다음 세 원형을 재사용한다.

```text
휴식
= 컨디션·집중 회복과 안전 보정

준비
= 다음 일정에 맞는 복습·축제 준비·현장 조사·보조 소환수 조율

교류
= 메인 동반자 또는 핵심 인물과 관계·관점·짧은 정보 획득
```

슬롯별 준비 문맥:

- 자유일정 A: 시험 복습
- 자유일정 B: 축제 준비
- 자유일정 C: 현장 조사 또는 보조 소환수 조율 중 하나

### 7.3 기본 흐름

```text
현재 상태와 다음 중요 일정 확인
→ 휴식 / 준비 / 교류 제시
→ 행동 1개 선택
→ 짧은 플레이·대화·정리
→ 결과 태그 저장
→ 다음 중요 일정으로 이동
```

### 7.4 허용 결과

- 컨디션·집중 회복
- 작은 안전·판정 보정
- 추가 관찰 정보
- 관계 반응
- 보조 소환수 준비
- 선택형 상세 대화
- 마도서 메모

### 7.5 금지

- 필수 일정 영구 차단
- 특정 선택만 가능한 유일 정답
- 선택하지 않은 관계 때문에 필수 정보 누락
- 자유일정마다 독립 대형 미니게임 제작
- 선택 하나당 신규 지역·전투·장문 분기 제작
- `휴식 / 준비 / 교류` 중 절대 우위 고정
- 보조 소환수 훈련을 모든 슬롯의 별도 네 번째 선택으로 반복

## 8. 세션 2 — 첫 실기시험

핵심 질문:

> 나는 배운 원리를 제한 조건 안에서 정확히 이해하고 적용할 수 있는가?

```text
시험 규칙 확인
→ 제한 조건과 평가 목표 제시
→ 문제 관찰
→ 주문 설계·직접 작성
→ 결과 판정
→ 실패 원인 확인·재설계
→ 교수의 항목별 피드백
```

플레이어 표시 평가 축은 세 개로 제한한다.

1. 상황 적합성
2. 주문 설계
3. 실행 안정성

원칙:

- 정답 하나만 강요하지 않는다.
- 최소 두 가지 유효 해결법을 허용한다.
- 입력 실수와 잘못된 설계를 별도 평가한다.
- 전투 보조 소환수는 사용 금지 또는 제한 상태로 둔다.
- 낮은 성적은 진행 실패가 아니라 피드백과 다음 준비의 차이다.

## 9. 세션 3 — 학교축제

핵심 질문:

> 마법을 전투나 시험이 아닌 놀이·표현·생활·관계에 어떻게 사용할 수 있는가?

```text
축제 활동 선택
→ 짧은 준비·관계 장면
→ 비전투 마법 활동
→ 작은 문제 발생
→ 자유로운 주문 활용
→ 표현 성향·관계·기록 변화
```

### 범위

- 대표 비전투 문제 하나만 제작한다.
- 별도 축제 맵을 만들지 않는다.
- 학교 장면 세트에 장식 오버레이·NPC 배치·음악 상태를 적용한다.
- 후보: 공연 효과 조정, 장식·장치 복구, 제한 재료 주문 경연, 방문객 지원 중 하나.

### 결과

축제 결과는 대규모 분기보다 표현 성향 태그로 기록한다.

- `ELEGANT`
- `PRACTICAL`
- `SPECTACULAR`

성공·실패보다 플레이어가 어떤 마법 표현을 선택했는지 기록한다.

## 10. 세션 4 — 첫 현장실습

핵심 질문:

> 배운 원리를 실제 위험과 복합 상황에서 응용하고 새 활용을 발견할 수 있는가?

```text
현장 브리핑
→ 메인 동반 소환수와 상황 관찰
→ 전투 보조 소환수 호출
→ 전투 문제 1개
→ 환경·구조 문제 1개
→ 같은 메인 글자의 다른 목적 활용
→ 실패 원인 확인·주문 재설계
→ 새로운 활용 발견
→ 귀환
```

필수 증거:

- 전투 문제와 환경·구조 문제 모두 포함
- 같은 메인 글자를 다른 목적으로 재사용
- 최소 두 가지 유효 해결법
- 보조 소환수의 수호 또는 견제로 작성 시간 확보
- 보조 소환수 유무에 따른 작성 시간·피격·완주율 비교
- 소환수가 주문 설계와 글자 작성을 대행하지 않음

보조 소환수는 Slice에서 `수호` 또는 `견제` 중 하나만 구현한다. 공격·충전·다중 편성·진화는 제외한다.

## 11. 귀환·마도서 기록

```text
시험·축제·현장 결과 요약
→ 발견한 주문 활용 기록
→ 실패 원인과 다음 연구 목표 기록
→ 메인 동반 소환수의 관계 반응
→ 다음 수업·학기·전문화 가능성 예고
```

완료 감정:

- 학교에서 한 기간을 보냈다는 감각
- 같은 원리가 시험·축제·현장에서 다르게 쓰였다는 이해
- 자신의 주문 활용을 발견했다는 성취
- 다음 학기를 계속하고 싶은 기대

메인 동반자 관계 단계는 Slice에서 최대 3단계로 제한한다.

| 구간 | 권장 상한 |
|---|---:|
| 프롤로그·수업·연습 | 10~12분 |

제품 계약:

- 목표 중앙값: `45~50분`
- 허용 상한: `60분`
- 연속 플레이 강제: 없음
- 60분을 넘는 신규 콘텐츠를 기본 범위에 추가하지 않음
- 현장실습 도달 전 필수 대화·이동 누적 15분 초과 금지
- 정확한 세부 시간: `PLAYTEST_TUNING_REQUIRED`

```text
current_step

festival_result_tag
free_schedule_C_choice
field_result_tag
companion_relation_band
```

## 15. 최소 콘텐츠 범위

### 포함

## 16. Vertical Slice 내부 구현 체크포인트

```text
M0 입력·피드백

→ 관찰·작성·세계 변화·실패 피드백

M2 학교 세션
→ 수업·시험·축제를 공통 계약으로 연결

M3 현장실습

M4 저장·복귀·최종 연출
```

M0~M4는 Vertical Slice 내부 체크포인트이며 별도 CORE_POC가 아니다.

- M0에서 입력 실패와 설계 실패를 구분한다.
- M1이 확인되기 전 축제 전용 연출·장문 대화·다수 자산을 확대하지 않는다.
- M2까지 학교 장면 세트를 재사용한다.
- 구현 순서를 역전하지 않는다.

## 17. 통과 기준

### 핵심 마법

- 첫 5분 안에 `내가 마법을 썼다`고 인식한다.
- 15분 안에 메인·보조 글자 역할을 설명한다.
- 같은 문법을 시험·축제·현장에서 다르게 사용한다.
- 최소 두 가지 유효 해결법 중 하나를 의도적으로 선택한다.
- 입력 실패와 설계 실패를 구분하고 재설계한다.

### 학교생활

- 수업·시험·축제·현장의 역할을 자기 말로 구분한다.
- 단순 현장 데모가 아니라 축약된 학교 기간을 경험했다고 인식한다.
- 자유일정이 휴식과 준비로 기능한다.
- 휴식이 실제로 유효한 선택이다.
- 자유일정 선택이 작은 차이를 만들지만 진행을 차단하지 않는다.

### 소환수

- 메인 동반자가 학습·관계·기록을 연결한다.
- 전투 보조 소환수가 작성 시간을 확보한다.
- 두 소환수 계층을 구분한다.
- 어느 소환수도 주문 설계·글자 작성을 대행하지 않는다.

### 모바일 UX·기술

- 손가락 가림과 반복 피로가 핵심 행동을 방해하지 않는다.
- 완전 정지·감속·실시간을 비교한다.
- 세션·자유일정 사이 저장·복귀가 안정적이다.
- 목표 Android 기기와 주요 화면비에서 플레이 가능하다.
- 작성 화면 정보 예산을 지킨다.

### 제작성

- 모든 문제가 공통 Situation Challenge를 사용한다.
- 자유일정이 공통 이벤트 구조와 결과 태그를 사용한다.
- 대표 장면이 일회성 하드코딩에만 의존하지 않는다.
- 두 번째 유사 문제를 기존 구조로 추가할 수 있다.
- 첫 완주가 60분 이내를 목표로 한다.

## 18. 실패 기준과 감량 순서

콘텐츠 확대 금지 조건:

- 직접 작성이 반복 피로나 인식 오류로 핵심 재미를 방해
- 시험·축제·현장실습이 같은 문제의 외형 변경처럼 느껴짐
- 세션별 전용 시스템이 생겨 공통 계약이 깨짐
- 자유일정이 보상 최적화 메뉴나 불필요한 대화로만 느껴짐
- 휴식이 명백한 손해 선택
- 메인 동반자가 정답을 대신 제시
- 보조 소환수 운용이 주문 설계보다 복잡
- 첫 완주가 60분을 구조적으로 초과
- 저장·복귀 후 목표와 선택 결과를 이해하기 어려움
- 두 번째 콘텐츠 제작에 전용 Scene·코드가 필요

수정 우선순위:

```text
입력 판정·시간 처리·피드백
→ 공통 Situation Challenge 계약
→ 세션별 역할 구분
→ 자유일정 선택 결과 규모
→ 전투 압박·보조 소환수 조작량
→ 축제·관계 연출 분량
→ 전체 세션 길이
```

우선 감량:

```text
완성 주문 스톡
→ 복잡한 소환수 충전·편성
→ 자유일정별 독립 미니게임
→ 다중 상태이상
→ 장문 관계 분기
→ 추가 축제 부스·시험 과목·현장 지역
```

비타협 유지:

- 의미 기반 글자
- 직접 작성
- 상황별 조합
- 설명 가능한 세계 변화
- 수업·시험·축제·현장실습의 역할 차이
- 중요 일정 사이 자유일정 1회
- 학습→증명→표현→응용→기록 순환
