## 2. 승인된 대표 글자 문법

### 메인 글자 — 흐름

이미 존재하는 물질·에너지·힘의 이동 방향을 바꾼다.

- 가능: 우회, 전달, 순환, 끌어오기, 밀어내기, 경로 변경
- 불가능: 무에서 생성, 대상 본질 변경, 영구 고정

### 보조 글자 — 집중

흐름의 범위를 좁히고 힘·정밀도·도달 거리를 높인다.

- 대가: 불안정성, 국소 손상, 반격·과압 위험

### 보조 글자 — 분산

흐름을 넓게 나누어 최대 힘을 낮추고 범위·안정성을 높인다.

- 대가: 낮은 순간 출력, 느린 해결, 넓은 자원 소모

### Slice 조합

| 조합 | 결과 | 대표 대가 |
|---|---|---|
| 흐름 | 방향·경로 변경 | 힘 부족·경로 불안정 |
| 흐름 + 집중 | 좁고 강한 정밀 흐름 | 과압·손상·반격 |
| 흐름 + 분산 | 넓고 완만한 안정 흐름 | 출력 부족·시간 지연 |

- 다중 보조 동시 사용: Slice 제외
- 순서 의존 문법: Slice 제외
- 완성 주문 자동 시전 스톡: Slice 제외

## 3. 승인된 인물·세계관 최소선

### 주인공

- 일반 가정 출신 장학생 신입생
- 외적 목표: 첫 학기 누적 평가와 현장실습을 통과해 장학생 자격을 증명
- 초기 결핍: 마법에는 하나의 정답이 있고 틀리면 자격이 없다고 믿음
- 강점: 관찰, 원리 이해, 상황 간 공통점 발견
- 변화: 정답을 복제하는 학생에서 결과를 설명하고 책임지는 설계자로 성장

### 지도 교수

- 글자의 형태보다 의미·조건·책임을 가르침
- 정답 조합을 직접 제시하지 않음
- 수업 관찰, 축제·일상 응용, 현장실습 결과, 귀환 기록을 함께 비교
- 별도 시험 점수 대신 활동 포트폴리오와 마도서 복기를 평가
- 최종 이름은 네이밍 패스에서 확정

### 핵심 동급생

- 마법사 가문 출신, 정석 글자를 빠르고 정확하게 재현
- 적대자가 아니라 정석·속도 중심 경쟁자이자 협력자
- 수업·일상 응용·축제·현장에서 주인공과 서로 다른 접근을 비교
- 갈등은 혈통 우열이 아니라 교육 자원·사전 훈련·실패 허용 폭의 차이로 표현
- 최종 이름은 네이밍 패스에서 확정

### 메인 동반 정령

- 작은 늑대형 원소 정령수 초기 형상
- 학습·감정·일상·현장·마도서 기록 연결
- 위험과 불안정은 감지할 수 있지만 해법·글자 조합을 제시하지 않음
- Slice 관계: 낯섦 → 신뢰 시도 → 공동 발견

### 전투 보조 소환수

- Slice 역할: 수호형 우선
- 짧은 보호·차단 구간으로 직접 작성 시간을 확보
- 자동 공격 해결, 글자 선택, 자동 시전, 상시 무적 금지

## 4. 승인된 Situation Challenge

### 수업 — 불안정한 마력 수로

- 목적: 흐름·집중·분산의 역할 비교
- 문자 의미와 기본 획을 배우고 가볍게 직접 작성
- 실패 비용이 낮은 안전한 입력·설계 복구
- 첫 직접 작성은 시작 후 5분 이내
- 수업 연습 자체는 성적 경쟁 콘텐츠가 아님

### 교내 일상 응용 — 취약한 부유 수정구 이송

기존 `실기시험`을 별도 시험이 아닌 교내 일상 응용 또는 수업 후 실습으로 재분류한다.

- 목표: 교차 기류 속 수정구를 안전선으로 이동
- 제한: 시전 횟수, 충격 한계, 마나
- 해법 A: 집중을 이용한 정밀·고효율 이송
- 해법 B: 분산을 이용한 안정·완충 이송
- 흐름 단독 반복과 동급생 경로 복제는 동일 결과를 보장하지 않음
- 결과는 비전투 응용 포트폴리오에 기록되며 독립 시험 점수는 없음

### 축제 — 빛실 장막 복구

| 설계 | 태그 | 표현 |
|---|---|---|
| 흐름 | PRACTICAL | 안정적인 단순 복구 |
| 흐름 + 집중 | SPECTACULAR | 선명한 상징·순간 연출 |
| 흐름 + 분산 | ELEGANT | 공간 전체의 부드러운 장막 |

- 세 결과 모두 성공 가능하며 단일 최적해를 두지 않는다.
- 축제 결과는 표현·상황 판단·비전투 응용의 누적 평가 기록이 된다.

### 현장 전투 — 생태 온실 관개 수로의 폭주 정령

- 목표: 정령을 파괴하지 않고 압력 근원을 끊어 진정
- 집중: 빠른 핵 노출, 높은 반격 위험
- 분산: 공격 강도 완화, 느리지만 낮은 피해
- 수호형 보조 소환수가 작성 안전 시간을 제공
- 처치 속도보다 환경 보존·부작용·남은 피해·해결 방법을 평가

### 현장 환경 — 관개관 누출

- 집중: 누출을 우회관에 모아 희귀 묘목 우선
- 분산: 전체 압력을 배수로로 나누어 구조물 우선
- 모든 대상을 무비용으로 완전 보존하는 해법은 없음
- 기록: `SEEDLINGS_PRIORITIZED / STRUCTURE_PRIORITIZED`

## 5. 자유일정

공통 태그:

- `CALM`: 입력 복구·집중 안정
- `PREPARED`: 조건 관찰·결과 예측
- `CONNECTED`: 관계 반응·다른 관점
- `FIELD_PRACTICE`: 선택형 전투·환경 실습·현장 기록

계약:

- Slice에는 자유일정 슬롯 3회를 유지
- 각 슬롯에서 휴식·준비·교류·개방된 현장실습 중 중심 행동 1개
- 모든 슬롯에서 네 선택을 전부 제공할 의무는 없음
- 현장실습은 학교 허가·안전·공간·서사 상태가 맞을 때만 개방
- 효과는 다음 핵심 세션을 주로 보조
- 장기 누적 최적 루트와 반복 파밍 금지
- 필수 정보·유일 해법 독점 금지
- 모든 선택에 짧은 장면과 동등 규모의 효용 제공

## 6. 직접 작성·입력

### 책임 흐름

```text
획 입력
→ 인식 후보

```

- 명시적 시전 전 마나·횟수 미소모
- Undo·취소·재작성 자원 미소모
- 낮은 확신 후보 자동 선택 금지
- 입력 실패·문법 실패·상황 실패 분리

### 작성 빈도

- 정상 완주 필수 성공 작성: 7회
- 안내형 복구 포함 목표 상한: 10회
- 같은 문제 안에서 확인한 동일 글자는 토큰으로 재선택 가능
- 신규·미숙·중요 결정은 직접 작성 또는 직접 작성한 글자의 명시적 조립 필수

정확한 허용 오차·선 보정·감속 비율은 `PLAYTEST_TUNING_REQUIRED`다.

## 7. 마도서 기록과 누적 평가

마도서는 다음을 저장한다.

```text
상황
→ 글자·조합
→ 플레이어 의도
→ 실제 결과
→ 부작용·포기한 것
→ 발견한 활용
→ 플레이어가 붙인 이름
```

누적 평가 증거:

| 증거 | Slice 대표 장면 |
|---|---|
| 기초 학습 | 수업·가벼운 작성 연습 |
| 비전투 응용 | 수정구 이송·축제 장막 복구 |
| 현장 수행 | 폭주 정령·관개관 누출 |
| 복기·설명 | 귀환·마도서 기록·교수 피드백 |

- 별도 시험 점수 없음
- 자동 최적 조합 추천 금지
- 기록 클릭으로 완성 주문 자동 시전 금지
- 재사용 시 현재 상황 검증 재실행
- 귀환 시 `정밀 / 안정 / 표현 / 책임` 성향을 문장으로 요약
- 실패·부분 성공도 원인과 책임을 설명하면 유효한 학습 기록이 될 수 있음
