# Spell 스톡 피격 일시정지 시스템 — 최신 책임 원본

## 문서 상태

- 상태: `PLANNING_IN_PROGRESS`
- 결정 상태: `CONFIRMED`
- 기준 날짜: 2026-07-26
- 관련 결정: `GM-00-24`, `GM-00-25`, `GM-00-26`, `GM-00-27`, `GM-00-28`, `GM-00-29`
- 상위 스톡 시스템: `docs/planning/STOCK_SYSTEM.md`
- 충전시간 시스템: `docs/planning/STOCK_CHARGE_TIME_SYSTEM.md`
- 대상 전환 시스템: `docs/planning/STOCK_TARGET_SWITCH_SYSTEM.md`

이 문서는 플레이어가 실제 체력 피해를 받았을 때 스톡 자동 충전과 충전 대상 전환을 얼마나 오래 정지할지 정의한다. 피격 정지시간에 관해서는 이 문서의 최신 결정이 우선한다.

## 1. 최신 핵심 결정

피격 정지시간을 타격 횟수나 공격 등급으로 정하지 않는다. **0.25초 피해 집계 구간 동안 실제로 감소한 체력의 합계가 최대 체력에서 차지하는 비율**에 따라 정한다.

```text
최종 체력 피해 발생
→ 0.25초 동안 실제 체력 손실 합산
→ 최대 체력 대비 손실 비율 계산
→ 손실 비율에 비례한 정지시간 산출
→ 진행도 전부 보존
→ 정지 종료 후 자동 재개
```

- 공격이 몇 번 맞았는지는 정지시간 계산에 직접 사용하지 않는다.
- 같은 총 체력 손실이라면 1회 강타와 여러 번의 다단 공격은 같은 정지시간을 목표로 한다.
- 충전 진행도와 전환 게이지는 감소하거나 초기화하지 않는다.
- 피격 정지 종료 후 별도 입력 없이 자동 재개한다.
- 피격 정지는 스톡 충전과 대상 전환의 시간 진행에만 적용한다.

## 2. 최신 오버라이드

### GM-00-26 폐기

```text
피해량과 관계없이 동일한 고정 정지시간
```

상태: `SUPERSEDED_BY_GM-00-28`

### GM-00-27 폐기

```text
타격 발생마다 0.5초 정지
→ 추가 타격 시 0.5초 갱신
→ 첫 타격부터 최대 1.0초
```

상태: `SUPERSEDED_BY_GM-00-28`

폐기 이유:

- 타격 수가 많은 공격이 같은 총 피해량의 단발 공격보다 과도하게 충전을 방해할 수 있다.
- 작은 연속 피해가 큰 한 번의 피해보다 더 강한 정지 효과를 만드는 역전이 발생할 수 있다.
- 최신 방향은 공격 횟수가 아니라 플레이어가 실제로 잃은 체력의 크기를 방해 강도로 사용한다.

## 3. 피해량 기준

정지 계산에는 방어·보호막·회피·무적·상쇄 이후 **최종적으로 플레이어 체력에서 감소한 값**만 사용한다.

```text
공격 원래 피해
→ 방어·수호·보호막·회피·무적·상쇄 적용
→ 실제 체력 감소량 확정
→ 정지시간 계산에 반영
```

피해 집계에서 제외:

- 소환수가 공격을 완전히 대신 맞음
- 보호막이 피해를 전부 흡수함
- 회피·무적·상쇄로 최종 체력 피해가 0이 됨
- 경직이나 피격 연출만 있고 체력 수치가 감소하지 않음

피해 집계에 포함:

- 방어 후 남은 실제 체력 피해
- 지속 피해의 실제 체력 감소
- 환경 피해의 실제 체력 감소
- 같은 피해 집계 구간 안에서 발생한 다단 피해의 총 체력 감소

## 4. 비율 기준

절대 체력값이 아니라 최대 체력 대비 손실 비율을 사용한다.

```text
체력 손실 비율 r
= 피해 집계 구간의 실제 체력 감소 합계 / 피해 집계 시작 시 최대 체력
```

이유:

- 최대 체력이 성장해도 정지 체감 기준을 일관되게 유지한다.
- 고체력 빌드가 절대 피해값 때문에 정지시간까지 과도하게 길어지는 것을 방지한다.
- 공격의 실질적 위협도를 플레이어 생존력 대비 비율로 비교할 수 있다.

## 5. 확정 계산식

```text
피격 정지시간(초)
= clamp(체력 손실 비율 × 3.0, 0.10, 0.80)
```

| 최대 체력 대비 실제 손실 | 정지시간 |
|---:|---:|
| 1% | 0.10초 — 최솟값 적용 |
| 5% | 0.15초 |
| 10% | 0.30초 |
| 20% | 0.60초 |
| 30% 이상 | 0.80초 — 최댓값 적용 |

설계 의도:

- 미세한 피해도 최소한의 방해 피드백은 남긴다.
- 중간 피해는 손실 비율에 따라 명확히 증가한다.
- 큰 피해도 0.80초 상한으로 충전이 지나치게 오래 멈추지 않게 한다.
- 정지시간은 피해 손실에 비례하지만 진행도 손실은 발생하지 않는다.

## 6. 피해 집계 구간

다단 공격을 타격당 계산하지 않기 위해 **0.25초 피해 집계 구간**을 사용한다.

```text
첫 실제 체력 피해
→ 0.25초 피해 집계 시작
→ 구간 안의 추가 실제 체력 피해를 합산
→ 누적 손실 비율로 정지시간 재계산
```

- 같은 0.25초 구간 안에서 발생한 다단 피해는 하나의 누적 체력 손실로 계산한다.
- 타격 수만큼 정지시간을 더하지 않는다.
- 추가 피해가 발생하면 누적 손실 비율에 따라 현재 정지 종료 시점을 재계산한다.
- 재계산은 해당 집계 구간의 누적 손실만 사용하며 타격 횟수 보너스를 주지 않는다.
- 집계 구간이 끝난 뒤 새 피해가 발생하면 새 피해 집계를 시작한다.

## 7. 자동 충전 중 처리

```text
화염탄 스톡 65% 충전
→ 0.25초 구간에 최대 체력 10% 손실
→ 진행도 65% 보존
→ 0.30초 정지
→ 65%부터 자동 충전 재개
```

피격 정지 중에는 다음 기여를 적용하지 않는다.

- 기본 자동 충전
- 플레이어 생산 능력치
- 소환수 생산 능력치
- 직접 시전·정확 입력·방어·연계의 능동 충전 보너스

피격 정지 중 발생한 충전 보너스는 나중에 소급 적립하지 않는다. 이미 완성된 스톡은 정상적으로 사용할 수 있다.

## 8. 충전 대상 전환 중 처리

```text
화염탄에서 결계로 전환 중
→ 전환 게이지 40%
→ 0.25초 구간에 최대 체력 20% 손실
→ 전환 게이지 40% 보존
→ 0.60초 정지
→ 40%부터 전환 재개
```

- 전환 대상은 바뀌지 않는다.
- 이전 대상과 새 대상의 저장 충전 진행도도 유지한다.
- 정지 중에는 전환 지연 게이지와 스톡 충전이 모두 진행되지 않는다.
- 정지 종료 후 기존 전환 요청을 자동으로 이어간다.

## 9. 소환수 수호와 보호막의 가치

```text
소환수·보호막이 최종 피해를 0으로 만듦
→ 체력 손실 비율 0%
→ 정지 없음
```

```text
공격 피해를 일부 감소
→ 남은 실제 체력 손실 비율로 정지시간 감소
```

고정 정지 구조와 달리 부분 방어도 정지시간 감소에 직접 기여한다. 따라서 수호와 보호막은 체력 보존뿐 아니라 스톡 충전 안정성도 비례적으로 개선한다.

## 10. UI 필수 정보

- 실제 체력 손실 비율에 따라 달라지는 피격 정지 게이지
- 진행도가 보존되었다는 표시
- 정지 종료 후 자동 재개된다는 안내
- 완전 차단 시 정지가 발생하지 않는 방어 성공 피드백
- 다단 공격이 하나의 누적 피해 집계로 처리된다는 일관된 표현
- 비활성 스톡의 저장 진행도 유지

진행도 바는 뒤로 이동하지 않는다. 피격 정지 게이지만 손실 비율에 맞는 길이로 표시한다.

## 11. 가드레일

- 타격 횟수를 정지시간에 직접 곱하지 않는다.
- 다단 공격의 각 타격마다 최소 정지시간을 반복 적용하지 않는다.
- 실제 체력 피해가 0이면 정지하지 않는다.
- 피격으로 충전·전환 진행도를 삭제하거나 감소시키지 않는다.
- 피해 집계 구간을 0.25초보다 임의로 늘려 서로 무관한 공격을 하나로 합치지 않는다.
- 비례 계수를 임의로 높여 큰 피해가 장시간 충전을 봉쇄하지 않게 한다.
- 최소 정지시간이 작은 지속 피해에 의해 반복 누적되지 않게 한다.
- 0.80초 상한을 적용해 보스 강타 후에도 전투 복귀가 지나치게 늦어지지 않게 한다.

## 13. 미해결 사항

1. 지속 피해는 매 틱을 별도 집계로 볼 것인가, 상태효과 주기 단위로 묶을 것인가.
2. 수호·동조 능력치가 계산된 정지시간을 추가 감소시킬 수 있는가.
