# Spell 스톡 피격 일시정지 시스템 — 최신 책임 원본

## 문서 상태

- 상태: `PLANNING_IN_PROGRESS`
- 결정 상태: `CONFIRMED`
- 기준 날짜: 2026-07-26
- 관련 결정: `GM-00-24`
- 상위 스톡 시스템: `docs/planning/STOCK_SYSTEM.md`
- 충전시간 시스템: `docs/planning/STOCK_CHARGE_TIME_SYSTEM.md`
- 대상 전환 시스템: `docs/planning/STOCK_TARGET_SWITCH_SYSTEM.md`

이 문서는 플레이어가 피격되었을 때 스톡 자동 충전과 충전 대상 전환 지연을 처리하는 방식을 정의한다. 피격으로 인한 충전·전환 처리와 관련해 기존 문서의 미해결 항목과 충돌할 경우 이 문서가 우선한다.

## 1. 핵심 결정

스톡 충전 또는 충전 대상 전환 중 플레이어가 피격되면 진행도를 잃지 않고 잠시 정지한 뒤 자동으로 재개한다.

```text
스톡 충전 또는 전환 진행
→ 플레이어 피격
→ 현재 진행도 전부 보존
→ 짧은 피격 정지
→ 정지 종료 후 자동 재개
```

- 충전 진행도를 감소시키거나 초기화하지 않는다.
- 충전 대상 전환 게이지도 동일하게 진행도를 보존한다.
- 피격 정지 종료 후 별도 입력 없이 자동으로 재개한다.
- 피격 정지는 스톡 시스템의 시간 진행에만 적용하며, 다른 전투 행동 제한은 별도 전투 규칙을 따른다.

## 2. 자동 충전 중 피격

```text
화염탄 다음 스톡 65% 충전
→ 플레이어 피격
→ 65% 보존
→ 짧은 정지
→ 65%부터 자동 충전 재개
```

피격 정지 중에는 다음 기여를 적용하지 않는다.

- 기본 자동 충전
- 플레이어 생산 능력치
- 소환수 생산 능력치
- 직접 시전·정확 입력·방어·연계로 발생하는 능동 충전 보너스

피격 정지 중 발생한 충전 보너스는 나중에 소급 적립하지 않는다. 이미 완성된 스톡은 정상적으로 사용할 수 있다.

## 3. 충전 대상 전환 중 피격

```text
화염탄에서 결계로 전환 중
→ 전환 게이지 40%
→ 플레이어 피격
→ 전환 게이지 40% 보존
→ 짧은 정지
→ 40%부터 전환 재개
```

- 전환 대상은 바뀌지 않는다.
- 이전 충전 대상과 새 충전 대상의 저장 진행도도 유지한다.
- 피격 정지 중에는 전환 지연 게이지와 스톡 충전이 모두 진행되지 않는다.
- 정지 종료 후 기존 전환 요청을 자동으로 이어간다.

## 4. 연속 피격 처리

연속 피격으로 정지 시간이 무한 누적되지 않게 한다.

```text
첫 피격
→ 단일 피격 정지 타이머 시작

정지 중 추가 피격
→ 별도 정지 시간을 더하지 않음
→ 현재 단일 타이머를 갱신하거나 제한 범위 안에서 연장
```

확정 원칙:

- 피격 횟수마다 정지 시간을 단순 합산하지 않는다.
- 동시에 여러 개의 정지 타이머를 생성하지 않는다.
- 진행도는 연속 피격 중에도 전부 보존한다.
- 정확한 갱신 방식과 최대 연장 한도는 PoC에서 결정한다.

## 5. 소환수 수호와의 연결

소환수의 수호 역할은 플레이어가 안전하게 회로를 그리고 스톡을 생산할 시간을 확보하는 데 기여한다.

현재 확정된 범위:

- 실제 피격이 발생하면 충전 또는 전환이 잠시 정지한다.
- 소환수가 공격을 막아 피격 자체를 방지하면 정지 발생을 줄일 수 있다.
- 소환수의 생산 능력치는 피격 정지 중에는 적용되지 않는다.

아직 확정하지 않은 범위:

- 소환수가 완전히 막은 공격도 피격 정지를 발생시키는가.
- 보호막이 피해만 흡수한 경우를 피격으로 계산하는가.
- 수호·동조 능력치가 피격 정지 시간을 줄이는가.

## 6. UI 필수 정보

- 충전 진행도 또는 전환 진행도가 보존되었다는 표시
- 피격 정지 상태 아이콘 또는 짧은 정지 게이지
- 정지 종료 후 자동 재개된다는 안내
- 비활성 스톡의 저장 진행도 유지
- 연속 피격 시 단일 정지 타이머만 동작한다는 일관된 표현

피격 시 진행도 바가 뒤로 이동하거나 사라지면 손실로 오해할 수 있으므로, 진행도는 그대로 유지하고 일시정지 상태만 명확하게 표시한다.

## 7. 가드레일

- 피격으로 충전·전환 진행도를 삭제하거나 감소시키지 않는다.
- 피격 정지 중 충전 보너스를 중복 적립하지 않는다.
- 연속 피격 횟수만큼 정지시간을 무제한 합산하지 않는다.
- 짧은 잡몹 공격만으로 스톡 생산이 사실상 영구 정지되지 않게 한다.
- 피격 정지가 지나치게 짧아 적 공격의 방해 의미가 사라지지 않게 한다.
- 피격 정지가 지나치게 길어 모바일 전투의 조작 스트레스를 높이지 않게 한다.
- 소환수 수호가 없으면 스톡 시스템을 사용할 수 없는 구조로 만들지 않는다.

## 8. PoC 검증 항목

| 가설 | 최소 검증물 | 통과 신호 |
|---|---|---|
| 진행도 보존이 손실 스트레스를 막는다 | 50% 이상 충전 중 피격 | 진행도가 유지됨을 즉시 이해 |
| 짧은 정지가 적 공격에 의미를 준다 | 피격 있음·없음 비교 | 위치 선정과 수호의 가치를 인식 |
| 자동 재개가 조작 부담을 줄인다 | 정지 후 별도 입력 없는 재개 | 충전 재시작을 반복 조작하지 않음 |
| 연속 피격이 영구 중단을 만들지 않는다 | 다단 히트·잡몹 연속 공격 | 단일 타이머 규칙으로 정상 복귀 |
| 소환수 수호가 보조적 가치를 가진다 | 수호 성공·실패 비교 | 필수는 아니지만 충전 안정성이 상승 |

## 9. 미해결 사항

1. 피격 정지의 실제 초 단위 값은 얼마인가.
2. 정지 중 추가 피격이 타이머를 초기화하는가, 일부 연장하는가.
3. 연속 피격 시 최대 정지 한도는 얼마인가.
4. 소환수·보호막이 완전히 막은 공격도 피격 정지를 발생시키는가.
5. 피해량이나 공격 강도에 따라 정지시간이 달라지는가.
6. 수호·동조 능력치가 피격 정지시간을 감소시키는가.
