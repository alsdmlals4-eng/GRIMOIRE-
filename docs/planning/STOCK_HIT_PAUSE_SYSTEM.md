# Spell 스톡 피격 일시정지 시스템 — 최신 책임 원본

## 문서 상태

- 상태: `PLANNING_IN_PROGRESS`
- 결정 상태: `CONFIRMED`
- 기준 날짜: 2026-07-26
- 관련 결정: `GM-00-24`, `GM-00-25`, `GM-00-26`
- 상위 스톡 시스템: `docs/planning/STOCK_SYSTEM.md`
- 충전시간 시스템: `docs/planning/STOCK_CHARGE_TIME_SYSTEM.md`
- 대상 전환 시스템: `docs/planning/STOCK_TARGET_SWITCH_SYSTEM.md`

이 문서는 플레이어가 실제 체력 피해를 받았을 때 스톡 자동 충전과 충전 대상 전환 지연을 처리하는 방식을 정의한다. 피격으로 인한 충전·전환 처리와 관련해 기존 문서의 미해결 항목과 충돌할 경우 이 문서가 우선한다.

## 1. 핵심 결정

스톡 충전 또는 충전 대상 전환 중 플레이어의 체력이 실제로 감소하면 진행도를 잃지 않고 잠시 정지한 뒤 자동으로 재개한다.

```text
스톡 충전 또는 전환 진행
→ 플레이어 체력 피해 발생
→ 현재 진행도 전부 보존
→ 고정된 짧은 피격 정지
→ 정지 종료 후 자동 재개
```

- 충전 진행도를 감소시키거나 초기화하지 않는다.
- 충전 대상 전환 게이지도 동일하게 진행도를 보존한다.
- 피격 정지 종료 후 별도 입력 없이 자동으로 재개한다.
- 피격 정지는 스톡 시스템의 시간 진행에만 적용하며, 다른 전투 행동 제한은 별도 전투 규칙을 따른다.
- 공격 접촉이나 피격 연출만 발생하고 체력이 감소하지 않았다면 피격 정지를 적용하지 않는다.
- 실제 체력 피해량과 관계없이 한 피해 사건당 동일한 정지시간을 적용한다.

## 2. 피격 정지 발생 기준

피격 정지는 **플레이어 체력의 실제 감소**를 기준으로 판정한다.

```text
소환수가 공격 완전 차단
또는
보호막이 피해 전부 흡수
→ 체력 감소 없음
→ 충전·전환 계속 진행
```

```text
공격이 방어를 일부 통과
→ 플레이어 체력 1 이상 감소
→ 피격 정지 발생
```

피격 정지를 발생시키지 않는 경우:

- 소환수가 공격을 완전히 대신 맞음
- 보호막이 최종 피해를 전부 흡수함
- 회피·무적·상쇄로 체력 피해가 0이 됨
- 경직이나 피격 연출만 있고 체력 수치가 감소하지 않음

피격 정지를 발생시키는 경우:

- 방어·보호막 적용 후에도 플레이어 체력이 감소함
- 지속 피해나 환경 피해로 플레이어 체력이 실제 감소함
- 한 번의 공격에서 여러 피해 판정이 발생하고 그중 하나 이상이 체력을 감소시킴

## 3. 피해량과 정지시간

피격 정지시간은 최종 체력 피해량이나 공격 강도에 비례하지 않는다.

```text
체력 피해 1
→ 고정된 짧은 정지

최대 체력의 큰 비율을 잃는 강타
→ 같은 고정 정지
```

- 작은 피해와 큰 피해 모두 동일한 피격 정지시간을 사용한다.
- 강타, 치명타, 보스 공격이라는 이유로 스톡 정지시간을 추가 증가시키지 않는다.
- 큰 피해의 위협은 체력 손실, 경직, 넉백과 연출 등 해당 공격 자체의 결과로 표현한다.
- 피해량에 따른 추가 정지를 적용하지 않아 체력 손실과 스톡 지연의 이중 처벌을 방지한다.
- 실제 고정 정지시간의 초 단위 값은 PoC에서 결정한다.

## 4. 자동 충전 중 체력 피해

```text
화염탄 다음 스톡 65% 충전
→ 플레이어 체력 피해 발생
→ 65% 보존
→ 고정된 짧은 정지
→ 65%부터 자동 충전 재개
```

피격 정지 중에는 다음 기여를 적용하지 않는다.

- 기본 자동 충전
- 플레이어 생산 능력치
- 소환수 생산 능력치
- 직접 시전·정확 입력·방어·연계로 발생하는 능동 충전 보너스

피격 정지 중 발생한 충전 보너스는 나중에 소급 적립하지 않는다. 이미 완성된 스톡은 정상적으로 사용할 수 있다.

## 5. 충전 대상 전환 중 체력 피해

```text
화염탄에서 결계로 전환 중
→ 전환 게이지 40%
→ 플레이어 체력 피해 발생
→ 전환 게이지 40% 보존
→ 고정된 짧은 정지
→ 40%부터 전환 재개
```

- 전환 대상은 바뀌지 않는다.
- 이전 충전 대상과 새 충전 대상의 저장 진행도도 유지한다.
- 피격 정지 중에는 전환 지연 게이지와 스톡 충전이 모두 진행되지 않는다.
- 정지 종료 후 기존 전환 요청을 자동으로 이어간다.

## 6. 연속 피해 처리

연속 피해로 정지 시간이 무한 누적되지 않게 한다.

```text
첫 체력 피해
→ 단일 피격 정지 타이머 시작

정지 중 추가 체력 피해
→ 별도 정지 시간을 더하지 않음
→ 현재 단일 타이머를 갱신하거나 제한 범위 안에서 연장
```

확정 원칙:

- 피해 횟수마다 정지 시간을 단순 합산하지 않는다.
- 동시에 여러 개의 정지 타이머를 생성하지 않는다.
- 진행도는 연속 피해 중에도 전부 보존한다.
- 각 피해의 크기는 타이머 갱신량에 영향을 주지 않는다.
- 정확한 갱신 방식과 최대 연장 한도는 PoC에서 결정한다.

## 7. 소환수 수호와 보호막의 가치

소환수 수호와 보호막은 피해량 감소뿐 아니라 스톡 충전 안정성을 높인다.

```text
소환수·보호막이 최종 피해를 0으로 만듦
→ 피격 정지 없음
→ 충전·전환 계속
```

```text
소환수·보호막이 피해를 줄였지만 체력 감소 발생
→ 고정된 피격 정지 적용
```

- 소환수가 공격을 완전히 막으면 충전 안정성 보상을 얻는다.
- 보호막의 남은 내구도가 공격 피해보다 충분하면 충전을 유지한다.
- 소환수의 생산 능력치는 실제 체력 피해로 정지한 동안에는 적용되지 않는다.
- 방어가 성공했더라도 플레이어 체력이 감소했다면 정지 판정을 피하지 못한다.
- 부분 방어 후 남은 피해량이 작더라도 정지시간은 다른 체력 피해와 동일하다.

## 8. UI 필수 정보

- 충전 진행도 또는 전환 진행도가 보존되었다는 표시
- 실제 체력 피해로 인한 피격 정지 상태 아이콘 또는 짧은 정지 게이지
- 정지 종료 후 자동 재개된다는 안내
- 완전 차단 시 충전이 유지되는 짧은 방어 성공 피드백
- 피해량과 관계없이 동일한 정지 규칙을 사용하는 일관된 표현
- 비활성 스톡의 저장 진행도 유지
- 연속 피해 시 단일 정지 타이머만 동작한다는 일관된 표현

체력 피해가 0인 방어 성공에서는 진행도 바를 정지시키지 않는다. 실제 체력 피해가 발생한 경우에도 진행도 바는 뒤로 이동하지 않고 동일한 일시정지 상태만 표시한다.

## 9. 가드레일

- 체력 피해가 없는 공격 접촉만으로 충전·전환을 정지하지 않는다.
- 피격으로 충전·전환 진행도를 삭제하거나 감소시키지 않는다.
- 피해량이나 공격 등급으로 피격 정지시간을 증가시키지 않는다.
- 피격 정지 중 충전 보너스를 중복 적립하지 않는다.
- 연속 피해 횟수만큼 정지시간을 무제한 합산하지 않는다.
- 짧은 잡몹 공격만으로 스톡 생산이 사실상 영구 정지되지 않게 한다.
- 보호막·소환수 수호가 충전 유지에 기여하되 필수 장비가 되지 않게 한다.
- 체력 피해 0 판정을 악용해 항상 충전이 유지되는 무한 방어 구조를 방지한다.
- 피격 정지가 지나치게 길어 모바일 전투의 조작 스트레스를 높이지 않게 한다.

| 체력 피해 기준이 명확하다 | 완전 차단·부분 차단 비교 | 피해 0이면 계속, 체력 감소면 정지를 예측 |
| 피해량 무관 고정 정지가 이해된다 | 경미한 피해·보스 강타 비교 | 두 공격의 정지시간이 같음을 자연스럽게 인식 |

| 연속 피해가 영구 중단을 만들지 않는다 | 다단 히트·지속 피해 | 단일 타이머 규칙으로 정상 복귀 |

## 11. 미해결 사항

1. 고정 피격 정지의 실제 초 단위 값은 얼마인가.
2. 정지 중 추가 체력 피해가 타이머를 초기화하는가, 일부 연장하는가.
3. 연속 피해 시 최대 정지 한도는 얼마인가.
4. 수호·동조 능력치가 피격 정지시간을 감소시키는가.
5. 지속 피해의 다단 판정을 단일 피해 사건으로 묶는 시간창은 얼마인가.
