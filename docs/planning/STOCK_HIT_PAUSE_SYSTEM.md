# Spell 스톡 피격 일시정지 시스템 — 최신 책임 원본

## 문서 상태

- 상태: `PLANNING_IN_PROGRESS`
- 결정 상태: `CONFIRMED`
- 기준 날짜: 2026-07-26
- 관련 결정: `GM-00-24`~`GM-00-30`
- 상위 스톡 시스템: `docs/planning/STOCK_SYSTEM.md`
- 상태이상 연동 시스템: `docs/planning/STATUS_EFFECT_STOCK_SYSTEM.md`

이 문서는 플레이어가 직접 피해를 받았을 때 스톡 자동 충전과 충전 대상 전환을 얼마나 오래 정지할지 정의한다. 지속 피해와 상태이상의 스톡 영향은 별도 규칙으로 분리한다.

## 1. 핵심 원칙

직접 공격·환경 충격 등 `직접 피해 사건`으로 실제 체력이 감소하면, 0.25초 동안의 실제 체력 손실 비율에 따라 스톡 충전과 전환을 잠시 정지한다.

```text
직접 피해로 실제 체력 감소
→ 0.25초 동안 직접 피해 손실 합산
→ 최대 체력 대비 손실 비율 계산
→ 비례 정지시간 산출
→ 충전·전환 진행도 전부 보존
→ 정지 종료 후 자동 재개
```

- 타격 횟수는 정지시간 계산에 직접 사용하지 않는다.
- 같은 총 직접 피해라면 단발 강타와 다단 공격은 같은 정지시간을 목표로 한다.
- 충전 진행도와 전환 게이지는 감소하거나 초기화하지 않는다.
- 정지 종료 후 별도 입력 없이 자동 재개한다.
- 이미 완성된 스톡은 정지 중에도 사용할 수 있다.

## 2. 피해 0 처리

방어·소환수 수호·보호막·회피·무적·상쇄 이후 플레이어 체력이 감소하지 않으면 피격 정지를 적용하지 않는다.

```text
최종 직접 피해 0
→ 충전·전환 계속
```

피격 정지를 발생시키지 않는 사례:

- 소환수가 공격을 완전히 대신 맞음
- 보호막이 피해를 전부 흡수함
- 회피·무적·상쇄로 최종 피해가 0이 됨
- 경직이나 피격 연출만 있고 체력 수치가 감소하지 않음

부분 방어 후 실제 체력이 감소하면 남은 직접 피해량만 계산한다.

## 3. 확정 계산식

```text
직접 피해 손실 비율 r
= 0.25초 집계 구간의 직접 피해 체력 감소 합계
  / 집계 시작 시 최대 체력

피격 정지시간(초)
= clamp(r × 3.0, 0.10, 0.80)
```

| 최대 체력 대비 직접 피해 손실 | 정지시간 |
|---:|---:|
| 1% | 0.10초 |
| 5% | 0.15초 |
| 10% | 0.30초 |
| 20% | 0.60초 |
| 30% 이상 | 0.80초 |

- 비례 계수 `3.0`, 최소 `0.10초`, 최대 `0.80초`는 확정값이다.
- 큰 피해에도 0.80초 상한을 적용해 충전이 장시간 봉쇄되지 않게 한다.
- 피해가 작아도 직접 피해 사건에는 최소 0.10초의 방해 피드백을 적용한다.

## 4. 다단 직접 공격

같은 0.25초 안의 다단 직접 피해는 하나의 피해 집계로 처리한다.

```text
첫 직접 피해
→ 0.25초 집계 시작
→ 구간 안의 추가 직접 피해 합산
→ 누적 손실 비율로 정지시간 재계산
```

- 타격 수만큼 정지시간을 더하지 않는다.
- 각 타격에 최소 0.10초를 반복 적용하지 않는다.
- 추가 직접 피해가 발생하면 해당 구간의 누적 손실로 현재 정지 종료 시점을 갱신한다.
- 집계 구간이 끝난 뒤 발생한 직접 피해는 새 집계로 처리한다.

## 5. 지속 피해 제외 — GM-00-30

화상·독·출혈처럼 상태효과가 주기적으로 발생시키는 지속 피해는 체력을 감소시키더라도 이 피격 정지 계산에 포함하지 않는다.

```text
지속 피해 틱
→ 체력 감소
→ 직접 피해 집계에 포함하지 않음
→ 스톡 충전·전환 정지 없음
```

제외 대상 후보:

- 화상 피해
- 독 피해
- 출혈 피해
- 저주·부식 등 상태효과 기반 주기 피해

핵심 판정은 피해의 수치나 출처 이름이 아니라 `직접 피해 사건`과 `지속 피해 틱`의 분류다.

### 설계 의도

- 작은 지속 피해가 반복적으로 충전을 끊는 문제를 방지한다.
- 지속 피해는 체력 압박과 회복 자원 소모에 집중한다.
- 스톡 방해는 별도의 상태이상 효과가 담당하게 해 역할을 명확히 분리한다.
- 화상처럼 피해와 별도 방해 상태가 함께 있는 경우, 피해 틱은 정지를 만들지 않고 별도 상태이상만 스톡에 영향을 줄 수 있다.

## 6. 상태이상과의 책임 분리

```text
지속 피해
→ 체력 압박
→ 스톡 정지 없음

스톡 방해 상태이상
→ 충전 속도·충전 가능 여부·전환 성능 등에 직접 영향
```

정확한 상태이상 종류와 효과축은 `STATUS_EFFECT_STOCK_SYSTEM.md`에서 관리한다. 상태이상 효과는 직접 피해 비례 정지시간에 몰래 더하지 않고 UI에 별도 효과로 표시한다.

## 7. 자동 충전 중 직접 피해

```text
화염탄 스톡 65% 충전
→ 0.25초 동안 최대 체력 10% 직접 피해
→ 진행도 65% 보존
→ 0.30초 정지
→ 65%부터 자동 재개
```

피격 정지 중에는 다음을 적용하지 않는다.

- 기본 자동 충전
- 플레이어 생산 능력치
- 소환수 생산 능력치
- 직접 시전·정확 입력·방어·연계의 능동 충전 보너스

정지 중 발생한 충전 보너스는 나중에 소급 적립하지 않는다.

## 8. 대상 전환 중 직접 피해

```text
화염탄에서 결계로 전환 중
→ 전환 게이지 40%
→ 최대 체력 20% 직접 피해
→ 전환 게이지 40% 보존
→ 0.60초 정지
→ 40%부터 전환 재개
```

- 전환 대상은 취소되지 않는다.
- 이전 대상과 새 대상의 저장 충전 진행도도 유지한다.
- 정지 중에는 전환 지연 게이지와 자동 충전이 모두 멈춘다.

## 9. UI 필수 정보

- 직접 피해 비율에 따라 달라지는 피격 정지 게이지
- 충전·전환 진행도가 보존되었다는 표시
- 정지 종료 후 자동 재개 안내
- 완전 차단 시 정지가 발생하지 않는 방어 성공 피드백
- 지속 피해에는 피격 정지 게이지가 발생하지 않는 일관된 표현
- 별도 스톡 방해 상태이상의 아이콘·남은 시간·효과량

진행도 바는 직접 피해를 받아도 뒤로 이동하지 않는다.

## 11. 가드레일

- 타격 횟수를 정지시간에 직접 곱하지 않는다.
- 다단 공격 각 타격에 최소 정지시간을 반복 적용하지 않는다.
- 최종 직접 피해가 0이면 피격 정지를 적용하지 않는다.
- 지속 피해 틱으로 충전·전환을 정지하지 않는다.
- 피격으로 충전·전환 진행도를 삭제하거나 감소시키지 않는다.
- 상태이상 효과를 직접 피해 정지시간에 은밀하게 중복 가산하지 않는다.
- 직접 피해 상한 0.80초를 초과하지 않는다.

## 13. 미해결 사항

1. 어떤 상태이상이 충전 속도·충전 봉인·대상 전환에 영향을 주는가.
2. 상태이상별 효과량과 중첩 규칙은 무엇인가.
3. 직접 피해와 지속 피해가 동시에 발생한 복합 공격의 데이터 분류 규칙은 무엇인가.
4. 수호·동조 능력치가 상태이상 기반 스톡 방해를 감소시킬 수 있는가.
