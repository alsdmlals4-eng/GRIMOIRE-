# Spell 선택형 상세 서사 시스템 — 책임 원본

## 문서 상태

- 상태: `PLANNING_IN_PROGRESS`
- 결정 상태: `DIRECTION_CONFIRMED`
- 세계관 코어 상태: `WORLD_CORE_CANDIDATE`
- 기준 날짜: 2026-07-26
- 관련 결정: `GM-NARRATIVE-01`, `GM-NARRATIVE-02`
- 상위 세계관: `docs/planning/WORLD_SETTING_CONCEPT.md`
- 학교 육성: `docs/planning/WORLD_SCHOOL_GROWTH_SYSTEM.md`

이 문서는 빠른 진행을 원하는 플레이어와 학교생활·인물·세계관을 자세히 보고 싶은 플레이어가 같은 콘텐츠를 각자 원하는 깊이로 경험하는 방식을 정의한다.

## 1. 핵심 방향

스토리는 **필수 핵심층**과 **선택형 상세층**으로 나눈다.

```text
사건 발생
→ 핵심 정보만 짧게 전달
→ 즉시 조작권과 목표 제공
→ 플레이 진행
→ 관심 있는 플레이어가 NPC와 대화·조사
→ 인물·세계관·사건의 상세 내용 확인
```

- 메인 진행은 짧고 명확하게 유지한다.
- 긴 설명을 듣지 않아도 다음 행동과 위험을 이해할 수 있어야 한다.
- 더 알고 싶은 플레이어는 관련 NPC에게 다시 말을 걸거나 장소·기록을 조사한다.
- 선택 대화는 서사의 밀도를 높이지만 메인 진행의 의무 대화량을 늘리지 않는다.
- 이 구조는 짧은 행동과 보상을 연속적으로 제공하는 DDD 방향을 지원한다.

## 2. 필수 핵심층

필수 핵심층은 게임 진행에 필요한 정보만 전달한다.

반드시 포함할 정보:

1. 지금 무슨 일이 발생했는가
2. 플레이어가 왜 행동해야 하는가
3. 현재 목표와 다음 행동은 무엇인가
4. 즉시 주의해야 할 위험·실패 조건은 무엇인가
5. 중요한 선택이 있다면 결과 차이가 무엇인가

예시:

```text
교수: 동쪽 온실의 온도 회로가 폭주했다.
교수: 생물들이 다치기 전에 안정화해라.

목표
→ 온실로 이동
→ 열 회로의 흐름 확인
→ 생물 피해 없이 안정화
```

필수층에서는 인물의 과거, 학교 역사, 사건의 장기적 배경을 모두 설명하지 않는다.

## 3. 선택형 상세층

핵심 안내가 끝나고 조작권이 돌아온 뒤, 관심 있는 플레이어가 직접 접근한다.

선택 접근 방식:

- 사건 관계자에게 다시 말 걸기
- 주변 동급생·교수와 대화
- 현장의 물건·회로 흔적 조사
- 학교 귀환 후 보고 내용 확장
- 마도서·학생 수첩·사건 기록 열람
- 관계가 깊어진 인물에게 개인적인 관점 묻기

선택형 상세 내용:

- 인물의 동기와 감정
- 교수와 수업의 배경
- 학교와 지역의 역사
- 사건 전후의 생활 변화
- 동급생의 서로 다른 해석
- 향후 관계·진로·소규모 사건의 복선
- 직접적인 정답이 아닌 회로 활용 관점과 부가 힌트

## 4. 상황별 혼합 표현 — GM-NARRATIVE-02

필수 핵심 스토리는 하나의 고정 UI로만 전달하지 않고 상황에 따라 표현 방식을 바꾼다.

### 4.1 일반 사건·수업·학교 의뢰

기본값은 `짧은 대사 + 목표 카드`다.

```text
NPC 한두 문장
→ 목표·위험·보상 카드
→ 즉시 조작 가능
```

- 대사는 사건의 인간적 맥락을 전달한다.
- 목표 카드는 다음 행동과 실패 조건을 정리한다.
- 일반 사건에서 장문의 대화창을 기본값으로 사용하지 않는다.

### 4.2 긴급 상황·현장 돌입

긴급 상황은 대화보다 목표·위험 정보를 먼저 보여준다.

```text
경고 연출 또는 한 줄 보고
→ 긴급 목표 카드
→ 즉시 이동·전투·회로 활용
```

카드 우선 정보:

- 즉시 목표
- 제한 시간 또는 피해 확산 조건
- 보호 대상
- 핵심 위험
- 성공 판단 기준

### 4.3 중요한 감정·관계·학년 전환 장면

중요 장면에서는 일반 대화창을 사용해 감정적 핵심을 충분히 전달한다.

적용 후보:

- 핵심 동급생·교수와의 관계 변화
- 학년말 평가와 승급
- 중대한 실패와 복구
- 소환수와의 중요한 교감
- 졸업·진로·장기 갈등의 전환점

다만 중요한 장면이라는 이유로 이미 설명한 정보를 반복하거나 과도하게 길게 만들지 않는다.

### 4.4 선택형 상세 대화

핵심 진행 후 NPC 재대화와 조사에서는 일반 대화창 또는 질문 목록을 사용한다.

```text
[사건의 배경]
[당신의 생각]
[회로 활용 원리]
[다른 학생 이야기]
[대화를 마친다]
```

- 상세 대화는 플레이어가 선택해 진입한다.
- 대화 종료 후 즉시 조작권을 돌려준다.
- 확인하지 않은 질문이 있어도 진행을 막지 않는다.

## 5. 화면 형식 선택 규칙

| 상황 | 기본 표현 | 목적 |
|---|---|---|
| 일반 수업·의뢰 | 짧은 대사 + 목표 카드 | 빠른 이해와 즉시 행동 |
| 긴급 임무·전투 돌입 | 경고 + 긴급 목표 카드 | 위험 정보 우선 전달 |
| 중요한 감정·관계 장면 | 일반 대화창 | 감정적 핵심 보존 |
| 선택형 상세 이야기 | 재대화·질문 목록 | 원하는 깊이만 감상 |
| 완료 보고 | 짧은 결과 카드 + 선택 상세 보고 | 보상 확인 후 선택 확장 |

### 우선순위

```text
게임 진행 정보
→ 목표 카드·HUD에서 명확하게

감정과 인물 관계
→ 필요한 장면에서 대화창으로

세계관과 세부 맥락
→ 선택형 대화·조사·기록으로
```

## 6. 대화 흐름

권장 기본 흐름:

```text
자동 또는 필수 대화
→ 핵심 요약
→ 목표 카드
→ 조작권 반환
→ 관련 NPC에 선택 대화 표시
→ 첫 선택 대화: 사건 맥락
→ 추가 질문: 인물·세계관·관계 상세
→ 대화 종료 후 즉시 플레이 복귀
```

### NPC 표시

- 새로운 상세 대화가 있으면 작고 일관된 대화 표시를 사용한다.
- 표시가 있어도 플레이어 이동과 다음 임무 진행을 막지 않는다.
- 이미 확인한 대화와 새 대화를 구분한다.
- 플레이어가 원하지 않으면 표시를 무시할 수 있다.

### 선택지 예시

```text
[무슨 일이 있었나요?]
→ 사건의 직접 배경

[왜 이 회로를 사용했나요?]
→ 활용 원리와 교수의 관점

[도움이 필요한가요?]
→ 관계·후속 활동

[바로 출발한다]
→ 대화 종료 후 진행
```

## 7. 핵심 정보 보호 규칙

선택 대화를 보지 않았다는 이유로 플레이어가 불합리한 손해를 입지 않게 한다.

선택층에만 숨기지 않는 정보:

- 임무 목표
- 제한 시간과 실패 조건
- 보스·위험 패턴의 필수 대응법
- 필수 조작법
- 메인 스토리의 인과관계
- 승급 조건
- 핵심 회로 해금 조건
- 되돌릴 수 없는 선택의 결과

부가 힌트가 선택 대화에 등장할 수는 있지만, 필수 해결법은 목표 UI·현장 표현·기본 대사 중 하나로도 확인 가능해야 한다.

## 8. 보상과 불이익

### 선택 대화의 보상 후보

- 인물 프로필과 사건 기록 추가
- 관계 대사와 소규모 생활 이벤트
- 회로 활용에 대한 부가 관점
- 다음 대화에서 달라지는 반응
- 장식·칭호·기록 완성도 같은 비필수 보상
- 선택형 서브 에피소드의 발견

### 금지 원칙

- 선택 대화를 읽지 않았다는 이유로 핵심 전투 성능을 영구 손실시키지 않는다.
- 필수 수업·주문·스톡 용량을 선택 대화에 숨기지 않는다.
- 모든 NPC와 반복 대화해야 최적 성장이 가능한 구조를 만들지 않는다.
- 대화를 건너뛴 플레이어를 무관심하거나 잘못된 플레이로 평가하지 않는다.

## 9. DDD 진행 리듬

DDD는 서사를 제거하는 것이 아니라, 서사가 행동과 보상의 흐름을 오래 중단하지 않게 하는 원칙으로 사용한다.

```text
짧은 사건 제시
→ 즉시 목표
→ 이동·조사·전투·회로 활용
→ 결과와 보상
→ 선택형 상세 대화
→ 다음 행동
```

권장 원칙:

- 긴 설명 후 처음 조작하는 구조보다 먼저 작은 행동을 제공한다.
- 하나의 필수 대화 구간에서 너무 많은 인물·설정·고유명사를 소개하지 않는다.
- 플레이어가 행동을 완료하면 즉시 환경 변화, 관계 반응, 기록, 성장 중 하나를 보여준다.
- 상세 설정은 행동 전 강제 설명보다 행동 후 궁금증을 해소하는 방식으로 제공한다.
- 진지한 장면에서는 감정적 핵심을 유지하되 반복 설명을 줄인다.

## 10. 학교생활 적용

### 수업

```text
교수의 한두 문장 과제 설명
→ 목표 카드
→ 즉시 실습
→ 수업 후 교수·학생에게 추가 질문
```

### 현장실습

```text
임무 이유 한 줄 요약
→ 목표·위험 카드
→ 현장 진입
→ 사건 관계자·흔적을 선택 조사
→ 짧은 결과 카드
→ 상세 보고와 인물 반응 선택 열람
```

### 학생 생활

- 핵심 일정 선택은 짧은 설명으로 제시한다.
- 선택한 활동의 인물·학교 배경은 활동 전후 선택 대화로 확장한다.
- 반복 등장 인물은 학년과 관계에 따라 같은 사건을 다르게 해석한다.
- 중요한 감정 장면만 일반 대화창의 비중을 높인다.

## 11. 기록 시스템

스토리를 빠르게 진행한 플레이어도 나중에 내용을 확인할 수 있게 한다.

- 핵심 사건 요약 자동 기록
- 인물별 확인한 대화와 관계 변화 기록
- 현장실습의 목표·결과·발견 활용 기록
- 선택 상세 대화에서 얻은 배경 정보 추가
- 읽지 않은 상세 기록은 메인 진행 완료 조건에 포함하지 않음

기록은 대화를 강제로 다시 재생하기보다 짧은 요약과 관련 인물·사건 연결을 제공하는 방향이 적합하다.

## 12. 제작 범위 가드레일

- 모든 NPC에게 매 사건마다 장문 선택 대화를 작성하지 않는다.
- 필수 대사와 선택 대사를 단순히 중복 작성하지 않는다.
- 선택 상세층을 메인 스토리의 숨겨진 필수 정답 저장소로 만들지 않는다.
- 한 사건에 너무 많은 상세 대화 단계를 만들지 않는다.
- 음성·전용 연출·컷신을 모든 선택 대화에 요구하지 않는다.
- 반복 등장 핵심 교수·학생·소환수와 주요 사건부터 상세층을 우선 적용한다.
- 1인 개발 범위를 고려해 중요 인물과 중요 사건의 선택 대화 밀도를 높이고 일반 NPC는 짧게 유지한다.
- 모든 상황을 대화창으로 처리하지 않는다.
- 중요한 장면이라는 이유만으로 긴 컷신을 반복하지 않는다.

## 13. 현재 확정·보류 구분

### 확정 방향

- 필수 핵심층과 선택형 상세층 분리
- 핵심 대화 후 즉시 조작권 반환
- NPC에게 다시 말 걸면 상세 내용 확인
- 메인 진행에 필요한 정보는 핵심층에서 모두 제공
- 선택 대화를 보지 않아도 기본 성장·진행에 불이익 없음
- 핵심 사건 요약은 기록에 자동 저장
- 일반 사건은 `짧은 대사 + 목표 카드`
- 긴급 상황은 `경고 + 긴급 목표 카드`
- 중요한 감정·관계 장면은 일반 대화창
- 완료 보고는 `짧은 결과 카드 + 선택형 상세 보고`

### 추후 세부 설계

- 필수 대화와 목표 카드의 실제 문장 길이
- 상세 대화 표시 아이콘과 UI
- 자동 진행·대사 속도·건너뛰기 옵션
- 관계도와 선택 대화 해금 기준
- 기록 화면의 구조
- 선택 대화 보상의 정확한 범위
- 목표 카드의 정확한 레이아웃과 표시 시간
