## GM-00-23 — 충전 대상 변경 시 진행도 보존과 전환 지연

### 채택안

`진행도 유지 + 전환 지연`

### 최신 규칙

- 전투 중 충전 대상을 다른 준비 스톡으로 변경할 수 있다.
- 기존 대상의 다음 스톡 1회분 충전 진행도는 초기화하지 않고 대상별로 보존한다.
- 전환 요청 시 현재 대상의 충전을 즉시 정지하고 진행도를 저장한다.
- 짧은 전환 지연 동안에는 어떤 대상도 충전하지 않는다.
- 전환 완료 후 새 대상에 저장된 진행도가 있다면 해당 지점부터 충전을 재개한다.
- 여러 준비 대상이 각자의 부분 충전 진행도를 보유할 수 있다.
- 부분 진행도 비축은 허용하지만 대상 변경마다 전환 지연을 지불한다.
- 자동 충전 대상은 한 번에 1종만 유지한다.
- 소환수는 플레이어의 허가 없이 충전 대상을 변경하지 않는다.
- 현재 대상이 최대 스톡에 도달해도 다른 대상으로 자동 전환하지 않는다.

### 전환 중 처리

```text
기존 대상 충전
→ 전환 요청
→ 기존 진행도 저장
→ 충전 정지
→ 전환 지연
→ 새 대상의 저장 진행도부터 재개
```

- 전환 지연 동안 플레이어·소환수의 자동 생산 기여는 적용되지 않는다.
- 전환 지연 중 직접 시전과 전투는 정상적으로 진행한다.
- 이미 완성되어 있던 스톡은 전환 중에도 사용할 수 있다.
- 전환 지연의 실제 시간은 터치 전투 PoC에서 결정한다.

상태: `CONFIRMED`

최신 책임 원본: `docs/planning/STOCK_TARGET_SWITCH_SYSTEM.md`

## GM-00-24 — 피격 시 진행도 보존과 자동 재개

### 채택안

`진행도 전부 보존 + 일시정지 + 자동 재개`

### 최신 규칙

- 스톡 자동 충전 중 플레이어가 실제 체력 피해를 받으면 현재 진행도를 그대로 보존한다.
- 충전 대상 전환 중 실제 체력 피해를 받으면 전환 게이지 진행도를 그대로 보존한다.
- 체력 피해 직후 충전 또는 전환 진행을 일시정지한다.
- 정지 종료 후 별도 입력 없이 기존 진행 위치부터 자동으로 재개한다.
- 진행도를 감소시키거나 초기화하지 않는다.
- 이미 완성된 스톡은 피격 정지 중에도 정상적으로 사용할 수 있다.
- 피격 정지 중에는 기본 자동 충전, 플레이어·소환수 생산 기여와 능동 충전 보너스를 적용하지 않는다.
- 피격 정지 중 발생한 충전 보너스는 종료 후 소급 적립하지 않는다.

상태: `CONFIRMED`

최신 책임 원본: `docs/planning/STOCK_HIT_PAUSE_SYSTEM.md`

## GM-00-25 — 완전 차단 공격은 피격 정지 미발생

### 채택안

`플레이어 체력이 실제로 감소했을 때만 피격 정지`

### 최신 규칙

- 피격 정지 판정은 공격 접촉이나 피격 연출이 아니라 플레이어 체력의 실제 감소를 기준으로 한다.
- 소환수, 보호막, 회피, 무적 또는 상쇄로 최종 체력 피해가 0이 되면 충전과 전환을 계속 진행한다.
- 방어·보호막 적용 후에도 플레이어 체력이 1 이상 감소하면 피격 정지를 적용한다.
- 소환수가 공격을 완전히 대신 맞은 경우 플레이어 스톡 충전은 정지하지 않는다.
- 보호막이 피해를 전부 흡수한 경우 스톡 충전·전환은 정지하지 않는다.
- 경직이나 피격 연출이 발생했더라도 체력 감소가 없다면 정지하지 않는다.
- 지속 피해와 환경 피해도 플레이어 체력을 실제로 감소시키면 정지 판정 대상이다.

### 판정 흐름

```text
공격 판정
→ 소환수·보호막·회피·무적·상쇄 적용
→ 최종 플레이어 체력 피해 계산

최종 피해 0
→ 충전·전환 유지

최종 피해 1 이상
→ 진행도 보존
→ 피격 정지
→ 자동 재개
```

상태: `CONFIRMED`

최신 책임 원본: `docs/planning/STOCK_HIT_PAUSE_SYSTEM.md`

## GM-00-26 — 피해량과 무관한 고정 피격 정지시간

### 채택안

`실제 체력 피해가 발생하면 피해량과 무관하게 동일한 정지시간 적용`

### 최신 규칙

- 최종 체력 피해가 1 이상이면 피격 정지를 발생시킨다.
- 체력 피해량, 최대 체력 대비 피해 비율, 공격 등급과 관계없이 정지시간은 동일하다.
- 작은 피해와 보스 강타에 서로 다른 스톡 정지시간을 적용하지 않는다.
- 큰 피해의 위협은 체력 손실, 경직, 넉백과 연출 등 공격 자체의 결과로 표현한다.
- 피해량에 따른 추가 충전 지연은 적용하지 않는다.
- 연속 피해 중 추가 피해의 크기도 타이머 갱신량에 영향을 주지 않는다.

상태: `CONFIRMED`

최신 책임 원본: `docs/planning/STOCK_HIT_PAUSE_SYSTEM.md`

## GM-00-27 — 0.5초 피격 정지와 연속 정지 1.0초 상한

### 채택안

`기본 0.5초 정지 + 추가 피해 시 0.5초 갱신 + 첫 피해부터 최대 1.0초`

### 최신 규칙

- 실제 체력 피해가 발생하면 충전 또는 전환을 0.5초 정지한다.
- 정지 중 추가 체력 피해가 발생하면 별도의 정지시간을 더하지 않고 남은 정지시간을 다시 0.5초로 갱신한다.
- 갱신된 종료 시점은 첫 체력 피해 시점부터 1.0초를 넘을 수 없다.
- 하나의 연속 피해 체인에서 충전·전환 정지는 최대 1.0초다.
- 진행도는 첫 피해와 추가 피해 모두에서 전부 보존한다.
- 첫 피해부터 1.0초가 지나면 현재 연속 피해 체인의 정지는 종료된다.
- 정지가 완전히 종료된 뒤 새 체력 피해가 발생하면 새로운 연속 피해 체인을 시작한다.

### 계산식

```text
갱신된 종료 시점
= min(추가 피해 시점 + 0.5초, 첫 피해 시점 + 1.0초)
```

### 예시

```text
0.00초: 첫 피해
→ 종료 예정 0.50초

0.30초: 추가 피해
→ 종료 예정 0.80초

0.70초: 추가 피해
→ 계산상 1.20초
→ 체인 상한으로 1.00초에 종료
```

### 설계 의도

- 개별 피격의 방해 의미를 명확하게 유지한다.
- 다단 공격과 연속 피해가 충전을 무기한 정지시키는 상황을 방지한다.
- 진행도 손실과 반복 재시작 조작은 만들지 않는다.
- 피해량과 공격 등급에 따른 별도 정지시간 체계를 만들지 않는다.

상태: `CONFIRMED`

최신 책임 원본: `docs/planning/STOCK_HIT_PAUSE_SYSTEM.md`

## 최신 스톡 충전 순환

```text
지정 대상 1종 충전
→ 회로 수 기반 기준 충전시간 적용
→ 플레이어 행동과 소환수 생산 지원으로 가속
→ 필요 시 다른 준비 스톡으로 전환 요청
→ 기존 진행도 보존
→ 전환 지연 동안 충전 정지
→ 새 대상의 저장 진행도부터 재개
→ 공격을 완전히 차단하면 충전·전환 유지
→ 실제 체력 피해 발생 시 현재 진행도 보존
→ 0.5초 피격 정지
→ 정지 중 추가 피해 시 0.5초로 갱신
→ 첫 피해부터 최대 1.0초 정지
→ 정지 종료 후 자동 재개
```

## 후속 미해결 결정

1. 지속 피해의 반복 틱을 각각 독립 피해 사건으로 볼 것인가, 일정 시간창으로 묶을 것인가.
2. 한 공격의 다단 히트를 각각 독립 피해 사건으로 볼 것인가, 공격 단위로 묶을 것인가.
3. 수호·동조 능력치가 0.5초 피격 정지시간 또는 1.0초 상한을 감소시키는가.
4. 전환 지연의 실제 초 단위 값은 얼마인가.
5. 전환 지연이 생산 능력치 또는 별도 성장으로 감소하는가.
6. 전환 지연 중 다시 대상을 변경하면 지연을 어떻게 처리하는가.
7. 플레이어·소환수 생산 능력치의 최종 계산식은 무엇인가.
8. 최소 충전시간 하한은 얼마인가.
9. 연결·분기·합류를 준비 용량과 충전시간 계산에서 독립 회로로 취급하는가.
10. 전체 준비 용량의 초기값과 성장 증가량은 얼마인가.
