## GM-00-23 — 충전 대상 변경 시 진행도 보존과 전환 지연

### 채택안

`진행도 유지 + 전환 지연`

### 최신 규칙

- 전투 중 충전 대상을 다른 준비 스톡으로 변경할 수 있다.
- 기존 대상의 다음 스톡 1회분 충전 진행도는 초기화하지 않고 대상별로 보존한다.
- 전환 요청 시 현재 대상의 충전을 즉시 정지하고 진행도를 저장한다.
- 짧은 전환 지연 동안에는 어떤 대상도 충전하지 않는다.
- 전환 완료 후 새 대상에 저장된 진행도가 있다면 해당 지점부터 충전을 재개한다.
- 여러 준비 대상이 각자의 부분 충전 진행도를 보유할 수 있다.
- 부분 진행도 비축은 허용하지만 대상 변경마다 전환 지연을 지불한다.
- 자동 충전 대상은 기존 결정대로 한 번에 1종만 유지한다.
- 소환수는 플레이어의 허가 없이 충전 대상을 변경하지 않는다.
- 현재 대상이 최대 스톡에 도달해도 다른 대상으로 자동 전환하지 않는다.

### 전환 중 처리

```text
기존 대상 충전
→ 전환 요청
→ 기존 진행도 저장
→ 충전 정지
→ 전환 지연
→ 새 대상의 저장 진행도부터 재개
```

- 전환 지연 동안 플레이어·소환수의 자동 생산 기여는 적용되지 않는다.
- 전환 지연 중 직접 시전과 전투는 정상적으로 진행한다.
- 이미 완성되어 있던 스톡은 전환 중에도 사용할 수 있다.
- 전환 지연의 실제 시간은 터치 전투 PoC에서 결정한다.

### 설계 의도

- 잘못된 대상 선택이나 전황 변화로 충전 진행도를 잃는 스트레스를 방지한다.
- 전투 중 전략 변경을 허용한다.
- 잦은 대상 변경에는 시간 비용을 부여해 사실상의 다중 동시 충전을 막는다.
- 소환수의 생산 지원은 활성 대상 하나에 집중되도록 유지한다.

상태: `CONFIRMED`

## GM-00-24 — 피격 시 진행도 보존과 짧은 일시정지

### 채택안

`짧은 일시정지 + 진행도 전부 보존 + 자동 재개`

### 최신 규칙

- 스톡 자동 충전 중 플레이어가 피격되면 현재 진행도를 그대로 보존한다.
- 충전 대상 전환 지연 중 피격되면 전환 게이지 진행도를 그대로 보존한다.
- 피격 직후 충전 또는 전환 진행을 짧게 정지한다.
- 정지 종료 후 별도 입력 없이 기존 진행 위치부터 자동으로 재개한다.
- 진행도를 감소시키거나 초기화하지 않는다.
- 이미 완성된 스톡은 피격 정지 중에도 정상적으로 사용할 수 있다.
- 피격 정지 중에는 기본 자동 충전, 플레이어·소환수 생산 기여와 능동 충전 보너스를 적용하지 않는다.
- 피격 정지 중 발생한 충전 보너스는 종료 후 소급 적립하지 않는다.

### 연속 피격 처리

```text
첫 피격
→ 단일 피격 정지 타이머 시작

정지 중 추가 피격
→ 별도 타이머 추가 없음
→ 기존 단일 타이머만 갱신 또는 제한적으로 연장
```

- 피격 횟수마다 정지 시간을 단순 합산하지 않는다.
- 동시에 여러 정지 타이머를 만들지 않는다.
- 연속 피격 중에도 진행도는 전부 보존한다.
- 정확한 갱신 방식과 최대 연장 한도는 PoC에서 결정한다.

### 설계 의도

- 피격 회피, 위치 선정과 소환수 수호에 전투적 가치를 부여한다.
- 모바일 전투에서 충전 진행도 손실로 인한 불쾌감은 만들지 않는다.
- 연속 피격으로 스톡 생산이 사실상 영구 정지되는 상황을 방지한다.
- 피격 후 충전을 다시 시작하기 위한 추가 조작을 요구하지 않는다.

상태: `CONFIRMED`

최신 책임 원본: `docs/planning/STOCK_HIT_PAUSE_SYSTEM.md`

## 최신 스톡 충전 순환

```text
지정 대상 1종 충전
→ 회로 수 기반 기준 충전시간 적용
→ 플레이어 행동과 소환수 생산 지원으로 가속
→ 필요 시 다른 준비 스톡으로 전환 요청
→ 기존 진행도 보존
→ 짧은 전환 지연 동안 충전 정지
→ 새 대상의 저장 진행도부터 재개
→ 충전 또는 전환 중 피격 시 현재 진행도 보존
→ 짧은 피격 정지
→ 정지 종료 후 자동 재개
```

## 후속 미해결 결정

1. 소환수·보호막이 완전히 막은 공격도 피격 정지를 발생시키는가.
2. 피격 정지의 실제 초 단위 값은 얼마인가.
3. 정지 중 추가 피격이 타이머를 초기화하는가, 일부 연장하는가.
4. 연속 피격 시 최대 정지 한도는 얼마인가.
5. 전환 지연의 실제 초 단위 값은 얼마인가.
6. 전환 지연이 생산 능력치 또는 별도 성장으로 감소하는가.
7. 전환 지연 중 다시 대상을 변경하면 지연을 어떻게 처리하는가.
8. 플레이어·소환수 생산 능력치의 최종 계산식은 무엇인가.
9. 최소 충전시간 하한은 얼마인가.
10. 연결·분기·합류를 준비 용량과 충전시간 계산에서 독립 회로로 취급하는가.
11. 전체 준비 용량의 초기값과 성장 증가량은 얼마인가.
