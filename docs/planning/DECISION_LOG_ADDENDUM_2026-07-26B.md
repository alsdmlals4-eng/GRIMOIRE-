## GM-00-23 — 충전 대상 변경 시 진행도 보존과 전환 지연

### 채택안

`진행도 유지 + 전환 지연`

### 최신 규칙

- 전투 중 충전 대상을 다른 준비 스톡으로 변경할 수 있다.
- 기존 대상의 다음 스톡 1회분 충전 진행도는 초기화하지 않고 대상별로 보존한다.
- 전환 요청 시 현재 대상의 충전을 즉시 정지하고 진행도를 저장한다.
- 짧은 전환 지연 동안에는 어떤 대상도 충전하지 않는다.
- 전환 완료 후 새 대상에 저장된 진행도가 있다면 해당 지점부터 충전을 재개한다.
- 여러 준비 대상이 각자의 부분 충전 진행도를 보유할 수 있다.
- 부분 진행도 비축은 허용하지만 대상 변경마다 전환 지연을 지불한다.
- 자동 충전 대상은 기존 결정대로 한 번에 1종만 유지한다.
- 소환수는 플레이어의 허가 없이 충전 대상을 변경하지 않는다.
- 현재 대상이 최대 스톡에 도달해도 다른 대상으로 자동 전환하지 않는다.

### 전환 중 처리

```text
기존 대상 충전
→ 전환 요청
→ 기존 진행도 저장
→ 충전 정지
→ 전환 지연
→ 새 대상의 저장 진행도부터 재개
```

- 전환 지연 동안 플레이어·소환수의 자동 생산 기여는 적용되지 않는다.
- 전환 지연 중 직접 시전과 전투는 정상적으로 진행한다.
- 이미 완성되어 있던 스톡은 전환 중에도 사용할 수 있다.
- 전환 지연의 실제 시간은 터치 전투 PoC에서 결정한다.

### 설계 의도

- 잘못된 대상 선택이나 전황 변화로 충전 진행도를 잃는 스트레스를 방지한다.
- 전투 중 전략 변경을 허용한다.
- 잦은 대상 변경에는 시간 비용을 부여해 사실상의 다중 동시 충전을 막는다.
- 소환수의 생산 지원은 활성 대상 하나에 집중되도록 유지한다.

상태: `CONFIRMED`

최신 책임 원본: `docs/planning/STOCK_TARGET_SWITCH_SYSTEM.md`

## GM-00-24 — 피격 시 진행도 보존과 짧은 일시정지

### 채택안

`짧은 일시정지 + 진행도 전부 보존 + 자동 재개`

### 최신 규칙

- 스톡 자동 충전 중 플레이어가 실제 체력 피해를 받으면 현재 진행도를 그대로 보존한다.
- 충전 대상 전환 지연 중 실제 체력 피해를 받으면 전환 게이지 진행도를 그대로 보존한다.
- 체력 피해 직후 충전 또는 전환 진행을 짧게 정지한다.
- 정지 종료 후 별도 입력 없이 기존 진행 위치부터 자동으로 재개한다.
- 진행도를 감소시키거나 초기화하지 않는다.
- 이미 완성된 스톡은 피격 정지 중에도 정상적으로 사용할 수 있다.
- 피격 정지 중에는 기본 자동 충전, 플레이어·소환수 생산 기여와 능동 충전 보너스를 적용하지 않는다.
- 피격 정지 중 발생한 충전 보너스는 종료 후 소급 적립하지 않는다.

### 연속 피해 처리

```text
첫 체력 피해
→ 단일 피격 정지 타이머 시작

정지 중 추가 체력 피해
→ 별도 타이머 추가 없음
→ 기존 단일 타이머만 갱신 또는 제한적으로 연장
```

- 피해 횟수마다 정지 시간을 단순 합산하지 않는다.
- 동시에 여러 정지 타이머를 만들지 않는다.
- 연속 피해 중에도 진행도는 전부 보존한다.
- 정확한 갱신 방식과 최대 연장 한도는 PoC에서 결정한다.

### 설계 의도

- 피격 회피, 위치 선정과 소환수 수호에 전투적 가치를 부여한다.
- 모바일 전투에서 충전 진행도 손실로 인한 불쾌감은 만들지 않는다.
- 연속 피해로 스톡 생산이 사실상 영구 정지되는 상황을 방지한다.
- 피격 후 충전을 다시 시작하기 위한 추가 조작을 요구하지 않는다.

상태: `CONFIRMED`

최신 책임 원본: `docs/planning/STOCK_HIT_PAUSE_SYSTEM.md`

## GM-00-25 — 완전 차단 공격은 피격 정지 미발생

### 채택안

`플레이어 체력이 실제로 감소했을 때만 피격 정지`

### 최신 규칙

- 피격 정지 판정은 공격 접촉이나 피격 연출이 아니라 플레이어 체력의 실제 감소를 기준으로 한다.
- 소환수, 보호막, 회피, 무적 또는 상쇄로 최종 체력 피해가 0이 되면 충전과 전환을 계속 진행한다.
- 방어·보호막 적용 후에도 플레이어 체력이 1 이상 감소하면 GM-00-24의 피격 정지를 적용한다.
- 소환수가 공격을 완전히 대신 맞은 경우 플레이어 스톡 충전은 정지하지 않는다.
- 보호막이 피해를 전부 흡수한 경우 스톡 충전·전환은 정지하지 않는다.
- 경직이나 피격 연출이 발생했더라도 체력 감소가 없다면 정지하지 않는다.
- 지속 피해와 환경 피해도 플레이어 체력을 실제로 감소시키면 정지 판정 대상이다.

### 판정 흐름

```text
공격 판정
→ 소환수·보호막·회피·무적·상쇄 적용
→ 최종 플레이어 체력 피해 계산

최종 피해 0
→ 충전·전환 유지

최종 피해 1 이상
→ 진행도 보존
→ 짧은 피격 정지
→ 자동 재개
```

### 설계 의도

- 소환수 수호와 보호막의 성공을 스톡 충전 안정성으로 보상한다.
- 체력 피해 여부라는 단일 기준으로 판정을 명확하게 만든다.
- 완전 방어에 성공했는데 충전이 끊기는 불쾌감을 제거한다.
- 부분 방어는 피해 감소 효과를 유지하지만 충전 정지까지 무효화하지 않는다.

상태: `CONFIRMED`

최신 책임 원본: `docs/planning/STOCK_HIT_PAUSE_SYSTEM.md`

## GM-00-26 — 피해량과 무관한 고정 피격 정지시간

### 채택안

`실제 체력 피해가 발생하면 피해량과 무관하게 동일한 짧은 정지시간 적용`

### 최신 규칙

- 최종 체력 피해가 1 이상이면 피격 정지를 발생시킨다.
- 체력 피해량, 최대 체력 대비 피해 비율, 공격 등급과 관계없이 정지시간은 동일하다.
- 작은 피해와 보스 강타에 서로 다른 스톡 정지시간을 적용하지 않는다.
- 큰 피해의 위협은 체력 손실, 경직, 넉백과 연출 등 공격 자체의 결과로 표현한다.
- 피해량에 따른 추가 충전 지연은 적용하지 않는다.
- 실제 고정 정지시간의 초 단위 값은 PoC에서 확정한다.
- 연속 피해 중 추가 피해의 크기도 단일 정지 타이머 갱신량에 영향을 주지 않는다.

### 판정 흐름

```text
최종 체력 피해 1
→ 고정된 짧은 피격 정지

최종 체력 피해가 큰 강타
→ 같은 고정 피격 정지
```

### 설계 의도

- 체력 손실과 충전 지연이 동시에 커지는 이중 처벌을 방지한다.
- 피해량을 매번 확인하지 않아도 피격 정지 결과를 즉시 예측하게 한다.
- 방어력과 최대 체력 성장 이후에도 동일한 전투 규칙을 유지한다.
- 모바일 전투 UI에서 복수 정지 등급과 추가 설명을 제거한다.

상태: `CONFIRMED`

최신 책임 원본: `docs/planning/STOCK_HIT_PAUSE_SYSTEM.md`

## 최신 스톡 충전 순환

```text
지정 대상 1종 충전
→ 회로 수 기반 기준 충전시간 적용
→ 플레이어 행동과 소환수 생산 지원으로 가속
→ 필요 시 다른 준비 스톡으로 전환 요청
→ 기존 진행도 보존
→ 짧은 전환 지연 동안 충전 정지
→ 새 대상의 저장 진행도부터 재개
→ 공격을 완전히 차단하면 충전·전환 유지
→ 실제 체력 피해 발생 시 현재 진행도 보존
→ 피해량과 무관한 고정 피격 정지
→ 정지 종료 후 자동 재개
```

## 후속 미해결 결정

1. 고정 피격 정지의 실제 초 단위 값은 얼마인가.
2. 정지 중 추가 체력 피해가 타이머를 초기화하는가, 일부 연장하는가.
3. 연속 피해 시 최대 정지 한도는 얼마인가.
4. 지속 피해의 다단 판정을 단일 피해 사건으로 묶는 시간창은 얼마인가.
5. 수호·동조 능력치가 고정 피격 정지시간을 감소시키는가.
6. 전환 지연의 실제 초 단위 값은 얼마인가.
7. 전환 지연이 생산 능력치 또는 별도 성장으로 감소하는가.
8. 전환 지연 중 다시 대상을 변경하면 지연을 어떻게 처리하는가.
9. 플레이어·소환수 생산 능력치의 최종 계산식은 무엇인가.
10. 최소 충전시간 하한은 얼마인가.
11. 연결·분기·합류를 준비 용량과 충전시간 계산에서 독립 회로로 취급하는가.
12. 전체 준비 용량의 초기값과 성장 증가량은 얼마인가.
