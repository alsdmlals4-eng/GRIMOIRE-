# Spell 마나 시스템 — 초기 설계

- 상태: `PLANNING_IN_PROGRESS`

이 문서는 Spell의 마나 회복, 소비 절감, 회로 기반 자원 운용 원칙을 기록한다. 구체적인 수치와 공식은 PoC 전까지 확정하지 않는다.

## 2. 채택 구조

마나는 다음 세 경로를 함께 사용한다.

```text
기본 자동 회복
+
플레이 행동에 따른 추가 회복·환급
+
마나 회복 메인과 마나 절감 보조
```

목적은 마나 고갈 후 아무것도 못 하는 교착을 막으면서, 플레이어가 회로를 정확하게 그리고 주문 구성을 잘할수록 더 능동적인 전투 리듬을 얻도록 하는 것이다.

## 3. 기본 자동 회복

- 마나는 전투 중 천천히 자동 회복된다.
- 자동 회복은 초보자와 실패 상황을 위한 최소 복구 안전망이다.
- 자동 회복만 기다리는 행동이 최적이 되지 않도록 회복 속도는 제한한다.
- 마나가 완전히 고갈되어도 다음 행동으로 복귀할 수 있어야 한다.
- 회로 작성 중 감속 시간과 자동 회복의 관계는 PoC에서 검증한다.

## 4. 플레이 행동 보너스

다음 행동은 추가 마나 회복, 사용 마나 환급, 다음 주문 비용 감소 중 하나로 보상할 수 있다.

- 정확한 회로 작성
- 적 공격을 적절한 주문으로 대응
- 방어·반격 성공
- 주문 연계 또는 조합 성공
- 적 약점에 맞는 회로 사용
- 소환수와 협동 회로를 안정적으로 완성

### 가드레일

- 행동 보너스는 기본 주문 사용을 위한 필수 조건이 아니다.
- 실수한 플레이어가 마나 회복 방법까지 잃는 하향 나선을 만들지 않는다.
- 정확 판정 보상은 효율 상승이지 생존권이나 기본 발동권이 아니다.
- 회복 경로를 지나치게 많이 노출해 UI를 복잡하게 만들지 않는다.

## 5. 마나 회복 회로

마나 회복은 `메인 회로` 후보로 취급한다.

```text
마나 회복 메인
+
형상·전달
=
마나 회복 주문
```

형상·전달에 따른 예시 후보:

- 자기 자신: 즉시 또는 지속 자기 회복
- 오라: 주변 소환수와 회복 공유
- 범위: 특정 영역의 마나 흐름 회복
- 흡수형 전달: 적 또는 잔류 마력에서 회수

개별 형상·효과는 확정 목록이 아니다.

### 설계 원칙

- 공짜 회복 버튼이 아니라 작성 시간과 회로 공간을 사용하는 선택이다.
- 회복 회로를 그리는 동안 공격 주문을 늦추는 기회비용이 생긴다.
- 기본 회복 회로는 넓은 판정으로 사용 가능하게 한다.
- 정확 입력은 추가 회복이나 지속시간으로 보상할 수 있다.
- 숙련한 회복 주문은 자동스펠 후보가 될 수 있으나 무한 자동 회복은 금지한다.

## 6. 마나 절감 회로

마나 절감은 `보조 회로` 후보로 취급한다.

```text
메인 1개
+
형상·전달
+
절감 보조
=
소비 마나를 낮춘 주문
```

### 역할 후보

- 전체 주문 비용 소폭 감소
- 특정 회로 구간 비용 감소
- 다음 한 번의 주문 비용 감소
- 정확 입력 시 절감률 추가 증가
- 소환수가 작성한 회로 구간의 비용 경감

### 핵심 트레이드오프

```text
절감 보조를 추가한다.
→ 마나 비용은 감소한다.
→ 회로 작성 시간과 구성 공간은 증가한다.
→ 다른 보조 회로를 넣을 자리가 줄어든다.
```

절감 회로는 단순한 상위 호환 강화가 아니라 위력·작성 시간·마나 효율 사이의 선택을 만든다.

## 7. 단계별 해금과 자동화

### 초반

- 기본 자동 회복 사용
- 메인+형상·전달 직접 입력 학습
- 마나 회복 메인의 초기 해금 시점은 개별 목록 확정 때 결정

### 초중반

- 마나 절감 보조를 포함한 보조 회로가 단계적으로 해금
- 숙련한 메인+형상·전달은 자동화 가능
- 플레이어는 절감 보조를 직접 그려 자원 운용을 학습

### 성장 이후

- 숙련한 절감 보조는 소환수가 자동작성할 수 있음
- 등록·숙련한 회복 주문과 절감 주문은 자동스펠 후보
- 자동스펠도 기존 마나 비용, 회복량, 중첩 제한을 그대로 적용

## 8. 무한 순환 방지 가드레일

- 회복 회로 자체에도 최소 마나, 작성 시간 또는 다른 기회비용을 적용한다.
- 절감률은 주문 비용을 0 이하로 만들지 않는다.
- 회복과 절감을 반복 연결해 순마나가 무한 증가하지 않게 한다.
- 동일 절감 보조 중첩에는 효율 감소 또는 연결 제한을 검토한다.
- 자동화된 회복 주문이 전투 판단을 완전히 대체하지 않게 한다.
- 소환수와 자동스펠만으로 무한 회복하는 구조를 허용하지 않는다.
- 조건부 자동스펠이 마나가 부족할 때 회복 주문만 무한 반복하지 않게 한다.

## 9. 플레이 경험 목표

```text
마나가 부족하다.
→ 기본 자동 회복으로 최소 복귀를 보장받는다.
→ 마나 회복 메인 주문을 직접 또는 자동스펠로 사용할지 판단한다.
→ 절감 보조를 넣어 장기 효율을 높일지 결정한다.
→ 정확 입력과 적절한 대응으로 추가 마나 이득을 얻는다.
→ 다시 상위 주문을 준비한다.
```

마나는 단순 쿨다운 대체 자원이 아니라 어떤 회로를 지금 그리고 어떤 주문을 나중에 준비할지 결정하게 하는 전투 리듬 자원이다.

## 10. PoC 검증 항목

| 가설 | 최소 검증물 | 통과 신호 |
|---|---|---|
| 기본 회복이 교착을 막는다 | 자동 회복이 있는 마나 바 | 고갈 후 다시 행동으로 복귀함 |
| 행동 보너스가 강제되지 않고 즐겁다 | 정확 입력 시 소량 환급 | 실패해도 복구 가능하고 정확 입력을 다시 노림 |
| 회복 메인이 실제 선택을 만든다 | 공격·회복 메인 각 1종 | 회복 타이밍을 고민하고 이유를 설명함 |
| 절감 보조가 상위 호환이 아니다 | 절감 포함·미포함 주문 | 위력·속도·효율 사이에서 선택이 나뉨 |
| 자동화가 무한 순환을 만들지 않는다 | 소환수+자동스펠+절감 테스트 | 반복 운용으로 마나가 무제한 증가하지 않음 |

## 11. 비확정 항목

- 기본 자동 회복 속도
- 행동 보너스 회복량과 환급률
- 마나 회복 메인의 초기 해금 시점
- 회복 주문의 비용과 회복량
- 절감 보조의 절감률
- 보조 회로 중첩 제한
- 마나 최대치
- 회로 작성 중 회복 여부
- 소환수가 회복·절감 회로를 지원하는 정확한 범위
- 자동스펠의 회복 주문 발동 조건

위 값은 실제 터치 전투 PoC에서 조정한다.
