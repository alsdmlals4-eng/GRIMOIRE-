## 2. 채택 구조

마나는 다음 세 경로를 함께 사용한다.

```text
기본 자동 회복
+
플레이 행동에 따른 추가 회복·환급
+
마나 회복 메인 회로와 마나 절감 보조 회로 후보
```

목적은 마나 고갈 후 아무것도 못 하는 교착을 막으면서, 플레이어가 회로를 정확하게 그리고 주문 구성을 잘할수록 더 능동적인 전투 리듬을 얻도록 하는 것이다.

마나 회복을 메인 회로, 마나 절감을 보조 회로로 두는 것은 현재 방향이며, 개별 회로 명칭·형태·세부 효과는 아직 확정하지 않는다.

---

## 3. 기본 자동 회복

- 마나는 전투 중 천천히 자동 회복된다.
- 자동 회복은 초보자와 실패 상황을 위한 최소 복구 안전망이다.
- 자동 회복만 기다리는 행동이 최적이 되지 않도록 회복 속도는 제한한다.
- 마나가 완전히 고갈되어도 다음 행동으로 복귀할 수 있어야 한다.
- 회로 작성 중 감속 시간과 자동 회복의 관계는 PoC에서 검증한다.

---

## 4. 플레이 행동 보너스

다음 행동은 추가 마나 회복, 사용 마나 환급, 다음 주문 비용 감소 중 하나로 보상할 수 있다.

- 정확한 회로 작성
- 적 공격을 적절한 주문으로 대응
- 방어·반격 성공
- 주문 연계 또는 조합 성공
- 적 약점에 맞는 회로 사용
- 동료와 협동 회로를 안정적으로 완성

### 가드레일

- 행동 보너스는 기본 주문 사용을 위한 필수 조건이 아니다.
- 실수한 플레이어가 마나를 회복할 방법까지 잃는 하향 나선을 만들지 않는다.
- 정확 판정 보상은 효율 상승이지 생존권이나 기본 발동권이 아니다.
- 회복 경로를 지나치게 많이 노출해 UI를 복잡하게 만들지 않는다.

---

## 5. 마나 회복 메인 회로 후보

마나 회복은 주문의 목적 자체가 자원 복구이므로, 현재 문법에서는 `메인 회로` 후보로 둔다.

### 역할 후보

- 즉시 마나 일부 회복
- 일정 시간 마나 회복 속도 증가
- 정확한 회로 성공 시 추가 마나 생성
- 적의 마력 또는 잔류 에너지 흡수
- 동료와 연결해 공동 마나 회복

### 설계 원칙

- 공짜 회복 버튼이 아니라 작성 시간과 회로 공간을 사용하는 선택이다.
- 회복 회로를 그리는 동안 공격 주문을 늦추는 기회비용이 생긴다.
- 기본 회복 회로는 넓은 판정으로 사용 가능하게 하고, 정확 입력은 추가 회복으로 보상한다.
- 회복 주문에 확대·지속·증폭 같은 보조 회로 후보를 연결하면 회복 방식이 달라질 수 있다.
- 마나 회복을 메인 회로로 두는 방향은 확정했지만, 세부 회복 회로 종류와 수치는 미확정이다.

### 문맥 조합 예시 후보

```text
마나 회복 메인 + 지속 보조
→ 일정 시간 회복

마나 회복 메인 + 확대 보조
→ 동료 또는 주변 대상과 회복 공유 후보

마나 회복 메인 + 증폭 보조
→ 더 큰 회복, 대신 더 높은 비용·작성시간 후보
```

위 예시는 문법 설명용이며 확정 주문이 아니다.

---

## 6. 마나 절감 보조 회로 후보

마나 절감은 다른 주문의 소비 비용을 바꾸므로, 현재 문법에서는 `보조 회로` 후보로 둔다.

### 역할 후보

- 전체 주문 비용 소폭 감소
- 특정 속성·기능 회로 비용 감소
- 다음 한 번의 주문 비용 감소
- 정확 입력 시 절감률 추가 증가
- 동료가 작성한 회로 구간의 비용 경감

### 핵심 트레이드오프

```text
절감 보조 회로를 추가한다.
→ 마나 비용은 감소한다.
→ 회로 작성 시간과 구성 공간은 증가한다.
→ 공격·범위·지속 보조 회로를 넣을 자리가 줄어들 수 있다.
```

절감 회로는 단순한 상위 호환 강화가 아니라, 주문 위력·작성 시간·마나 효율 사이의 선택을 만든다.

### 문맥 조합 예시 후보

```text
공격 메인 + 절감 보조
→ 효율형 공격 주문

방어 메인 + 절감 보조
→ 반복 사용하기 쉬운 방어 주문

탐색 메인 + 절감 보조
→ 장시간 탐색에 적합한 저비용 주문
```

위 예시는 방향 설명용이며 확정 주문이 아니다.

---

## 7. 고급 자원 변형 후보

다음은 메인·보조 2계층을 확장할 수 있는 후반 후보이며 아직 확정하지 않는다.

- 공격 주문에 흡수 보조를 연결해 적중 시 소량 마나 회복
- 체력 회복과 마나 회복 메인을 결합해 자원 변환
- 조건·기동 회로로 방어 성공 시 마나 환급
- 동료 회로와 연결해 회복량 분담 또는 전달

이러한 변형은 무한 순환과 필수 조합 문제를 검증한 뒤 제한적으로 허용한다.

---

## 8. 무한 순환 방지 가드레일

- 회복 회로 자체에도 최소 마나 또는 다른 자원 비용을 검토한다.
- 절감률은 주문 비용을 0 이하로 만들지 않는다.
- 회복 메인과 절감 보조를 반복 연결해 순마나가 무한 증가하지 않게 한다.
- 동일 보조 회로 중첩에는 효율 감소 또는 연결 제한을 검토한다.
- 자동화된 회복 회로가 전투 판단을 완전히 대체하지 않게 한다.
- 동료가 회복·절감 회로 전체를 자동 완성해 무한 운용하는 구조를 허용하지 않는다.
- 정확 판정 환급과 절감 효과를 합쳐 사용 비용보다 회수량이 계속 커지지 않게 한다.

---

## 9. 플레이 경험 목표

```text
마나가 부족하다.
→ 기다리기만 하지 않고 마나 회복 메인 주문을 선택할 수 있다.
→ 공격을 늦추고 자원을 회복할지 판단한다.
→ 다른 주문에 절감 보조를 연결해 장기 효율을 높일지 결정한다.
→ 정확한 작성과 적절한 대응으로 추가 마나 이득을 얻는다.
→ 다시 상위 조합 주문을 준비한다.
```

마나는 단순 쿨다운 대체 자원이 아니라, 어떤 메인 주문을 지금 선택하고 어떤 보조 회로를 붙일지 결정하게 하는 전투 리듬 자원이다.

## 10. PoC 검증 항목

| 가설 | 최소 검증물 | 통과 신호 |
|---|---|---|
| 기본 회복이 교착을 막는다 | 자동 회복이 있는 마나 바 | 고갈 후 기다림만으로 이탈하지 않고 다시 행동함 |
| 행동 보너스가 강제되지 않고 즐겁다 | 정확 입력 시 소량 환급 | 실패해도 복구 가능하고 정확 입력을 다시 노림 |
| 회복 메인 회로가 실제 선택을 만든다 | 공격 메인과 회복 메인 각 1종 | 회복 타이밍을 고민하고 이유를 설명함 |
| 절감 보조가 상위 호환이 아니다 | 동일 주문의 절감 포함·미포함 버전 | 위력·속도·효율 사이에서 상황별 선택이 나뉨 |
| 문맥별 보조 효과를 이해한다 | 공격·방어에 같은 절감 보조 적용 | 보조 회로의 역할을 예측함 |
| 무한 순환이 발생하지 않는다 | 회복+절감 조합 테스트 | 반복 사용으로 마나가 무제한 증가하지 않음 |
