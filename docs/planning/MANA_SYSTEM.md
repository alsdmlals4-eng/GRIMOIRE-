# Spell 마나 시스템 — 초기 설계

## 1. 문서 상태

- 상태: `PLANNING_IN_PROGRESS`
- 결정 상태: `CONFIRMED_CORE_DIRECTION`
- 기준 브랜치: `gpt/planning-spell-20260725`
- 기준 날짜: 2026-07-26
- 상위 책임 원본: `docs/planning/SPELL_GAME_DESIGN.md`
- 회로 문법: `docs/planning/CIRCUIT_SYSTEM.md`

이 문서는 Spell의 직접 시전 마나 회복, 소비 절감과 회로 기반 자원 운용 원칙을 기록한다. 스톡은 마나와 독립된 공용 준비 용량 시스템을 사용한다.

## 2. 채택 구조

마나는 직접 회로 시전에만 적용하며 다음 경로를 함께 사용한다.

```text
기본 자동 회복
+
플레이 행동에 따른 추가 회복·환급
+
마나 회복 메인과 마나 절감 보조
```

스톡은 별도 구조다.

```text
완성 주문·하위 회로 스톡
→ 최대·현재 마나를 사용하지 않음
→ 공용 스톡 준비 용량만 사용
→ 시간과 생산 효율로 빈 스톡 충전
```

목적은 마나 고갈 후 아무것도 못 하는 교착을 막으면서, 직접 시전과 스톡 운용의 역할을 명확히 분리하는 것이다.

## 3. 기본 자동 회복

- 마나는 전투 중 천천히 자동 회복된다.
- 자동 회복은 초보자와 실패 상황을 위한 최소 복구 안전망이다.
- 자동 회복만 기다리는 행동이 최적이 되지 않도록 회복 속도는 제한한다.
- 마나가 완전히 고갈되어도 다음 직접 시전으로 복귀할 수 있어야 한다.
- 회로 작성 중 감속 시간과 자동 회복의 관계는 PoC에서 검증한다.

## 4. 플레이 행동 보너스

다음 행동은 추가 마나 회복, 사용 마나 환급, 다음 직접 시전 비용 감소 중 하나로 보상할 수 있다.

- 정확한 회로 작성
- 적 공격을 적절한 주문으로 대응
- 방어·반격 성공
- 주문 연계 또는 조합 성공
- 적 약점에 맞는 회로 사용
- 소환수의 전투·수호·동조 행동 성공

### 가드레일

- 행동 보너스는 기본 주문 사용을 위한 필수 조건이 아니다.
- 실수한 플레이어가 마나 회복 방법까지 잃는 하향 나선을 만들지 않는다.
- 정확 판정 보상은 효율 상승이지 생존권이나 기본 발동권이 아니다.
- 회복 경로를 지나치게 많이 노출해 UI를 복잡하게 만들지 않는다.
- 마나 행동 보너스와 스톡 충전 보너스는 UI에서 구분한다.

## 5. 마나 회복 회로

마나 회복은 `메인 회로` 후보로 취급한다.

```text
마나 회복 메인
+
형상·전달
=
마나 회복 주문
```

형상·전달에 따른 예시 후보:

- 자기 자신: 즉시 또는 지속 자기 회복
- 오라: 주변 소환수와 회복 공유
- 범위: 특정 영역의 마나 흐름 회복
- 흡수형 전달: 적 또는 잔류 마력에서 회수

개별 형상·효과는 확정 목록이 아니다.

### 설계 원칙

- 공짜 회복 버튼이 아니라 직접 작성 시간과 회로 공간을 사용하는 선택이다.
- 회복 회로를 그리는 동안 공격 주문을 늦추는 기회비용이 생긴다.
- 기본 회복 회로는 넓은 판정으로 사용 가능하게 한다.
- 정확 입력은 추가 회복이나 지속시간으로 보상할 수 있다.
- 숙련한 회복 주문은 스톡화할 수 있지만, 스톡 사용은 마나를 회복할 수 있어도 스톡 자체를 직접 복제하지 않는다.

## 6. 마나 절감 회로

마나 절감은 `보조 회로` 후보로 취급한다.

```text
메인 1개
+
형상·전달
+
절감 보조
=
소비 마나를 낮춘 직접 시전 주문
```

### 역할 후보

- 전체 직접 시전 비용 소폭 감소
- 특정 회로 구간 비용 감소
- 다음 한 번의 직접 주문 비용 감소
- 정확 입력 시 절감률 추가 증가

### 핵심 트레이드오프

```text
절감 보조를 추가한다.
→ 직접 시전 마나 비용은 감소한다.
→ 회로 작성 시간과 구성 공간은 증가한다.
→ 다른 보조 회로를 넣을 자리가 줄어든다.
```

절감 회로는 단순한 상위 호환 강화가 아니라 위력·작성 시간·마나 효율 사이의 선택을 만든다.

절감 보조는 스톡 준비 용량, 스톡 충전 시간, 스톡 사용량에는 영향을 주지 않는다.

## 7. 폐기된 스톡 최대 마나 예약

### 이전 규칙

```text
완성 주문 스톡 준비
→ 주문 기존 비용의 50%를 최대 마나에서 예약
```

상태: `SUPERSEDED`

### 최신 규칙

- 완성 주문 스톡과 하위 회로 스톡 모두 최대 마나를 예약하지 않는다.
- 스톡 준비 시 현재 마나를 선불로 소모하지 않는다.
- 스톡 발동·적용·충전 시 추가 마나를 소모하지 않는다.
- 스톡 제약은 회로 개수 기반 공용 준비 용량만 사용한다.
- 직접 회로 시전만 마나를 소비한다.

따라서 스톡 편성으로 플레이어의 직접 시전용 최대 마나가 감소하지 않는다.

## 8. 단계별 해금과 자동화

### 초반

- 기본 자동 회복 사용
- 메인+형상·전달 직접 입력 학습
- 마나 회복 메인의 초기 해금 시점은 개별 목록 확정 때 결정

### 초중반

- 마나 절감 보조를 포함한 보조 회로가 단계적으로 해금
- 숙련한 메인+형상·전달은 하위 회로 스톡화 가능
- 플레이어는 절감 보조를 직접 그려 자원 운용을 학습

### 성장 이후

- 성장 기준 이하의 회복 주문과 절감 회로는 스톡화 가능
- 반복 회로 자동완성은 하위 회로 스톡이 담당
- 소환수는 회로 작성 대신 지정 스톡 생산을 지원
- 현재 단계의 상위 회로와 신규 조합은 직접 입력

## 9. 무한 순환 방지 가드레일

- 회복 회로 자체에도 최소 마나, 작성 시간 또는 다른 기회비용을 적용한다.
- 절감률은 직접 시전 주문 비용을 0 이하로 만들지 않는다.
- 회복과 절감을 반복 연결해 직접 시전 마나가 무한 증가하지 않게 한다.
- 동일 절감 보조 중첩에는 효율 감소 또는 연결 제한을 검토한다.
- 스톡화된 마나 회복 주문이 스톡 생산 속도를 직접 높이지 않게 한다.
- 마나 회복·절감 효과가 공용 스톡 준비 용량을 늘리지 않게 한다.
- 자동 충전 속도와 마나 회복량의 교차 밸런스를 검증한다.

## 10. 플레이 경험 목표

```text
직접 시전
→ 마나를 사용해 신규 주문·즉석 변형·상위 회로 운용
→ 회복·절감 회로로 장기 효율 조정

스톡
→ 공용 준비 용량 안에서 반복 주문·하위 회로 사전 편성
→ 한 번 터치로 사용
→ 시간과 생산 지원으로 재충전
```

마나는 직접 시전 리듬을 조절하고, 스톡 준비 용량은 자동화 구성과 편의성의 한도를 결정한다.

## 11. PoC 검증 항목

| 가설 | 최소 검증물 | 통과 신호 |
|---|---|---|
| 기본 회복이 교착을 막는다 | 자동 회복이 있는 마나 바 | 고갈 후 다시 직접 행동으로 복귀함 |
| 행동 보너스가 강제되지 않고 즐겁다 | 정확 입력 시 소량 환급 | 실패해도 복구 가능하고 정확 입력을 다시 노림 |
| 회복 메인이 실제 선택을 만든다 | 공격·회복 메인 각 1종 | 회복 타이밍을 고민하고 이유를 설명함 |
| 절감 보조가 상위 호환이 아니다 | 절감 포함·미포함 직접 주문 | 위력·속도·효율 사이에서 선택이 나뉨 |
| 마나와 스톡 구분이 명확하다 | 직접 시전·스톡 병행 UI | 직접 시전만 마나를 사용한다고 이해함 |
| 무한 순환이 없다 | 회복 스톡+소환수+절감 테스트 | 마나와 스톡이 서로 무제한 증식하지 않음 |
