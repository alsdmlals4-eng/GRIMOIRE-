# Spell 소환수 시스템 — 초기 방향

## 1. 문서 상태

- 상태: `PLANNING_IN_PROGRESS`
- 방향 상태: `DIRECTION_CONFIRMED`
- 기본 전개: `ONE_PRE_SUMMONED_CONFIRMED`
- 회로 직접 작성: `SUPERSEDED`
- 스톡 생산 지원: `CONFIRMED_DIRECTION`
- 세부 규칙 상태: `PROVISIONAL`
- 기준 브랜치: `gpt/planning-spell-20260725`
- 기준 날짜: 2026-07-26
- 관련 결정: `GM-00-10`, `GM-00-13`, `GM-00-14`, `GM-00-16`, `GM-00-19-A`

이 문서는 기존 동료 시스템을 소환수 시스템으로 승계하는 방향을 기록한다. 최신 결정에 따라 소환수는 회로를 직접 작성하지 않으며, 해당 자동화 책임은 하위 회로 스톡으로 통합한다.

## 2. 핵심 전환

기존의 상시 동료 개념을 `소환수` 또는 소환된 마법적 존재로 대체한다.

```text
기존 동료
→ 상시 파티원처럼 보일 위험

소환수
→ 플레이어가 마법으로 구현·호출한 전투 협력자
→ 전투·수호와 스톡 생산 효율을 지원
```

소환수의 핵심 역할:

- 플레이어가 회로를 그리는 동안 적을 공격하거나 방해한다.
- 수호 스탠스에서 플레이어의 회로 작성 시간을 확보한다.
- 지정한 완성 주문 또는 하위 회로 스톡의 자동 충전 속도를 높인다.
- 직접 시전, 정확 입력, 방어·반격 등으로 얻는 능동 충전 보너스를 증폭할 수 있다.
- 능력치·적성·스탠스에 따라 전투와 스톡 생산 기여도가 달라진다.

### 폐기된 역할

- 지정 회로 구간 직접 작성
- 플레이어와 회로 구간 동시 작성
- 숙련 보조 회로 자동작성
- 회로 완성 자체를 소환수가 대행하는 협동 시전

상태: `SUPERSEDED`

반복 회로의 자동완성은 `하위 회로 스톡`이 전담한다.

## 3. 기본 전개 방식

### 3.1 전투 시작 전 1체 준비

플레이어는 기본 소환수 1체를 전투 전에 선택하고 미리 소환해 둔다.

```text
전투 준비
→ 기본 소환수 1체 선택
→ 소환 상태로 전투 시작
→ 시작 즉시 전투·수호·스톡 생산 지원
```

- 기본 1체는 전투 시작 시 이미 전개되어 있다.
- 매 전투 시작 직후 동일한 소환 회로를 반복해서 그리게 하지 않는다.
- 기본 소환수 전개는 초반 난도와 직접 드로잉 부담을 완화하는 안전망이다.
- 시작 연출은 가능하지만 반복 입력이나 긴 준비시간을 요구하지 않는다.
- 소환수는 전투 시작부터 플레이어가 지정한 스탠스로 행동한다.

### 3.2 아직 확정하지 않은 범위

- 편성 목록에 여러 소환수를 넣고 전투 전에 1체를 선택할지 여부
- 전투 중 교체 또는 추가 소환 가능 여부
- 성장 후 동시 전개 수가 증가하는지 여부
- 추가 소환수가 일시적 주문인지 상시 전개인지 여부

현재 확정된 것은 `기본 1체를 미리 소환한 상태로 전투를 시작한다`는 원칙이다.

## 4. 마기카로기아 참고 원칙

참고할 구조:

1. 소환 존재는 제한된 전투 공간에서 기능하는 마법적 구현물이다.
2. 외부 생물을 그대로 부르는 것뿐 아니라 술자의 이미지가 형상화된 존재일 수 있다.
3. 소환 존재는 고유 능력으로 술자의 주문 운용을 돕는다.
4. 술자의 역량을 넘는 소환 수나 강도를 제한하는 용량 개념이 존재한다.
5. 소환 존재와 주문의 계열·영역이 맞을 때 더 높은 지원 효율을 낼 수 있다.

그대로 복제하지 않을 요소:

- 원작의 카테고리와 명칭을 직접 사용하지 않는다.
- TRPG의 라운드·판정 규칙을 모바일 실시간 전투에 그대로 이식하지 않는다.
- 소환수별 역할을 고정 타입으로 잠그지 않는다.
- 무작위 판정 실패를 중심 재미로 삼지 않는다.
- 원작의 주문 자동 성공을 회로 직접 작성 대행으로 변환하지 않는다.

Spell에서는 주문 보조를 `스톡 생산량`, `충전 속도`, `능동 충전 보너스`로 변형한다.

## 5. 소환수의 정체성

### 5.1 외형·서사

- 플레이어의 마법, 기억, 별자리, 계약, 기록에서 구현된 존재
- 같은 기능을 가진 소환수라도 외형과 성격이 다를 수 있음
- 세계관적 출처는 추후 세계관 설계에서 확정

### 5.2 능력치

고정 역할 타입을 두지 않고 능력치로 효율 차이를 만든다.

잠정 능력치 후보:

| 능력치 | 영향 |
|---|---|
| 전투 | 공격, 적 방해, 대상 처리 효율 |
| 수호 | 피해 차단, 플레이어 보호, 회로 작성 시간 확보 |
| 생산 | 지정 스톡의 기본 자동 충전 속도와 생산량 |
| 동조 | 직접 시전·정확 입력·연계에서 얻는 충전 보너스 증폭 |
| 지속 | 소환 유지, 연속 지원, 재행동 간격 |

명칭과 개수는 아직 확정하지 않는다. 기존의 `회로 작성 능력치`는 스톡 생산 또는 동조 능력치로 승계한다.

### 5.3 고유 능력·적성

소환수는 역할 타입 대신 고유 능력과 스톡 적성을 가진다.

예시 후보:

- 완성 주문 스톡 충전 속도 증가
- 하위 회로 스톡 충전 속도 증가
- 특정 회로 계열 스톡의 생산량 증가
- 정확 판정 시 지정 스톡 충전 보너스 증가
- 방어·반격 성공 시 충전량 추가
- 회로 작성 중 플레이어 보호

적성은 해당 행동을 금지하는 자격 제한보다 효율 차이를 만드는 방향을 우선한다.

## 6. 스탠스

잠정 스탠스:

- 전투: 공격과 적 방해 우선
- 수호: 플레이어 보호와 회로 작성 시간 확보
- 생산: 지정 스톡의 자동 충전과 생산 효율 우선
- 동조: 직접 시전·정확 입력에서 발생하는 능동 충전 보너스 강화

스탠스는 전투 중 변경할 수 있지만 현재 행동 정리 또는 짧은 전환 시간이 존재한다.

`회로 지원`과 `협동 작성` 스탠스는 폐기하고 생산·동조 스탠스로 대체한다. 정확한 스탠스 개수와 명칭은 PoC에서 검증한다.

## 7. 스톡 생산 역할

### 7.1 기본 자동 충전

- 플레이어가 지정한 스톡 대상 1종만 자동 충전한다.
- 소환수의 생산 능력치는 해당 대상의 충전 속도 또는 단위 시간당 생산량을 높인다.
- 소환수는 플레이어 허가 없이 충전 대상을 변경하지 않는다.

### 7.2 능동 충전 보조

다음 행동에서 발생하는 충전 보너스를 소환수가 증폭할 수 있다.

- 직접 회로 시전
- 정확한 회로 완성
- 방어·반격 성공
- 주문 연계 성공
- 소환수 자신의 적 방해 또는 보호 성공

### 7.3 스톡 종류와 적성

소환수는 다음 대상에 서로 다른 효율을 가질 수 있다.

- 완성 주문 스톡
- 하위 회로 스톡
- 특정 메인·형상·보조·조건 계열 회로 스톡

이는 고정 직업이 아니라 생산 효율 차이다. 모든 소환수는 기본적으로 두 스톡 종류를 지원할 수 있는 방향을 우선한다.

## 8. 회로 자동화와의 책임 경계

```text
하위 회로 스톡
→ 회로 자동 배치·연결

소환수
→ 스톡 생산량·충전 속도 증가
→ 전투·수호 지원
```

- 소환수는 현재 회로판에 선이나 기호를 직접 작성하지 않는다.
- 소환수는 하위 회로 스톡을 더 빠르게 생산하여 간접적으로 자동완성을 지원한다.
- 회로 선택, 삽입 위치, 연결 방식, 최종 기동은 플레이어가 담당한다.
- 이 경계로 소환수와 하위 회로 스톡의 기능 중복을 제거한다.

## 9. 소환 용량 후보

소환수의 수와 강도를 무제한으로 늘리지 않기 위해 `소환 용량` 또는 유사한 제한을 검토한다.

후보 방식:

- 전투에 동시에 존재 가능한 소환수 수 제한
- 강한 소환수일수록 더 많은 용량 사용
- 플레이어 성장으로 용량 증가

기본 소환수 1체와 전체 스톡 준비 한도는 우선 독립 성장축으로 둔다. 소환수는 스톡 한도 자체보다 생산 효율에 영향을 주는 방향을 우선한다.

## 10. 가드레일

- 소환수가 모든 주문 판단을 대신하지 않는다.
- 소환수 수집이 회로 그리기와 주문 조합보다 중요한 핵심으로 역전되지 않게 한다.
- 고등급 소환수가 없으면 기본 전투가 불가능한 구조를 만들지 않는다.
- 소환수 적성은 강제 직업 타입보다 효율과 개성으로 표현한다.
- 소환수가 회로를 직접 자동완성하지 않는다.
- 소환수 생산 능력만으로 스톡 충전 속도가 무제한 증가하지 않게 한다.
- 소환수의 생산량과 전체 스톡 한도가 함께 과도하게 성장하지 않게 한다.
- 기본 소환수 없이도 직접 시전은 가능하게 한다.

## 11. 미해결 사항

1. 전투 전에 선택할 수 있는 소환수 편성 목록은 몇 체인가.
2. 전투 중 교체 또는 추가 소환을 허용하는가.
3. 소환수 성장은 레벨, 계약, 스톡 적성 중 무엇을 중심으로 하는가.
4. 추가 소환을 위한 용량과 비용은 어떻게 결정하는가.
5. 소환수의 세계관적 정체성은 무엇인가.
6. 스톡 생산 능력치가 충전 속도, 충전량, 둘 모두에 영향을 주는가.
7. 완성 주문 스톡과 하위 회로 스톡에 대한 생산 적성을 분리하는가.
