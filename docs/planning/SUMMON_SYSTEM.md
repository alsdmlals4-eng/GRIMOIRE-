## 2. 핵심 전환

기존의 상시 동료 개념을 `소환수` 또는 소환된 마법적 존재로 대체한다.

```text
기존 동료
→ 상시 파티원처럼 보일 위험

소환수
→ 플레이어가 마법으로 구현·호출한 회로 협력자
→ 전투와 주문 설계에 직접 연결
```

소환수는 단순 자동 공격 펫이 아니다.

- 플레이어가 회로를 그리는 동안 전투를 보조한다.
- 지정된 회로 구간을 대신 작성한다.
- 숙련한 보조 회로를 자동화한다.
- 능력치와 플레이어가 지정한 스탠스에 따라 행동 우선순위가 달라진다.
- 등록된 주문의 자동스펠 운용을 보조할 수 있다.

- 무작위 판정 실패를 중심 재미로 삼지 않는다.

## 4. 소환수의 정체성

소환수는 다음 세 층을 가진다.

### 4.1 외형·서사

- 플레이어의 마법, 기억, 별자리, 계약, 기록에서 구현된 존재
- 같은 기능을 가진 소환수라도 외형과 성격이 다를 수 있음
- 소환수의 세계관적 출처는 추후 세계관 설계에서 확정

### 4.2 능력치

기존 동료의 고정 타입 폐기 원칙을 유지한다.

잠정 능력치 후보:

| 능력치 | 영향 |
|---|---|
| 전투 | 공격, 수호, 적 방해 효율 |
| 회로 | 자동작성 속도와 담당 가능한 회로 난도 |
| 동조 | 플레이어와 동시 작성 및 자동스펠 협력 효율 |
| 지속 | 소환 유지, 연속 지원, 재행동 간격 |

명칭과 개수는 미확정이다.

### 4.3 고유 능력·적성

소환수는 역할 타입 대신 고유 능력과 회로 적성을 가진다.

예시 후보:

- 특정 보조 회로 자동작성 속도 증가
- 특정 조건 회로를 더 안정적으로 유지
- 플레이어가 정확 판정을 냈을 때 추가 지원
- 자동스펠의 재사용 간격 또는 마나 효율 개선
- 회로 작성 중 플레이어 보호

적성은 해당 행동을 못 하게 막는 자격 제한보다 효율 차이를 만드는 방향을 우선한다.

## 5. 스탠스 승계

기존 동료 스탠스 구조를 소환수에게 승계한다.

잠정 스탠스:

- 전투: 적 공격과 방해 우선
- 수호: 플레이어 보호와 회로 작성 시간 확보
- 회로 지원: 숙련한 회로 자동작성 우선
- 협동: 플레이어와 서로 다른 회로 구간을 동시에 작성

스탠스는 전투 중 변경할 수 있지만 현재 행동 정리 또는 짧은 전환 시간이 존재한다.

## 6. 회로 자동화 역할

### 6.1 초반

- 소환수는 전투 보호와 간단한 보조 행동 중심
- 플레이어는 `메인 + 형상·전달`을 직접 학습

### 6.2 성장 이후

- 숙련한 `메인 + 형상·전달`은 시스템 자동화 가능
- 보조 회로가 해금되면 플레이어가 직접 추가
- 소환수 성장 후 숙련한 보조 회로 일부를 대신 작성 가능

### 6.3 중반 이후

- 조건·기동 회로가 추가됨
- 소환수가 보조 회로를 작성하고 플레이어가 조건·기동을 직접 설계하거나 반대로 분담 가능
- 최종 주문 선택과 중요한 기동 판단은 플레이어가 담당

## 7. 소환 용량 후보

소환수의 수와 강도를 무제한으로 늘리지 않기 위해 `소환 용량` 또는 유사한 제한을 검토한다.

후보 방식:

- 전투에 동시에 존재 가능한 소환수 수 제한
- 강한 소환수일수록 더 많은 용량 사용
- 자동스펠 슬롯과 소환수 지원 능력이 같은 용량을 경쟁
- 플레이어 성장으로 용량 증가

정확한 편성 수와 공식은 미확정이다.

## 8. 자동스펠과의 관계

소환수는 자동스펠을 독립적으로 발명하거나 선택하지 않는다.

```text
플레이어
→ 주문 발견·등록
→ 자동스펠 장착·규칙 지정

소환수
→ 장착된 자동스펠의 회로 준비·기동 보조
→ 능력치와 적성에 따라 효율 변동
```

자동스펠의 완전 자동 발동 범위는 별도 문서에서 결정한다.

## 9. 가드레일

- 소환수가 모든 주문 판단을 대신하지 않는다.
- 소환수 수집이 회로 그리기보다 더 중요한 핵심으로 역전되지 않는다.
- 고등급 소환수가 없으면 기본 전투가 불가능한 구조를 만들지 않는다.
- 소환수 적성은 강제 직업 타입보다 효율과 개성으로 표현한다.
- 자동작성 가능한 회로는 플레이어가 먼저 발견·학습·숙련한 회로로 제한한다.
- 소환수와 자동스펠만으로 전투가 완전 방치형이 되지 않게 한다.

## 10. 미해결 사항

1. 소환수는 전투마다 다시 소환하는가, 전투 시작부터 존재하는가.
2. 한 번에 몇 체를 편성하고 몇 체가 전장에 나오는가.
3. 소환수 성장은 레벨, 계약, 회로 학습 중 무엇을 중심으로 하는가.
4. 소환 용량과 자동스펠 슬롯을 같은 자원으로 묶을 것인가.
5. 소환수의 세계관적 정체성은 원형, 정령, 별의 사역마, 기록의 화신 중 무엇인가.
