## 2. 최신 2계층 구조

```text
메인 동반 소환수
= 항상 같은 개체가 플레이어와 동행
= 학습·관계·일상·현장 동행·마도서 기록

전투 보조 소환수
= 전투 준비 또는 전투 중 호출
= 공격·견제·수호·지정 충전 등 전투 지원
```

### 메인 동반 소환수

- 수업, 연습, 일상, 실습, 복귀, 기록에 계속 등장한다.
- 관계와 공동 학습의 중심이다.
- 플레이어가 이미 얻은 정보의 관찰점을 환기할 수 있다.
- 정답 주문, 최적 조합, 필수 정보 독점, 주력 전투 대행은 금지한다.

### 전투 보조 소환수

- 전투에서만 호출해 지원받는 전술 존재다.
- 전투 종료 후 기본적으로 해제한다.
- 공격, 견제, 수호, 충전, 동조 적성을 가질 수 있다.
- 기본 AI와 사전 설정을 사용해 플레이어가 주문 작성에 집중하도록 한다.

## 3. 대체된 이전 전개 방식

이전 방향:

```text
전투 준비
→ 기본 소환수 1체 선택
→ 미리 소환된 상태로 전투 시작
```

최신 방향:

```text
항상 동행하는 메인 동반 소환수 1체
+
전투에서 호출하는 보조 소환수
```

판정: `SUPERSEDED_BY_GM-MASCOT-01`

메인 동반 소환수는 전투 편성 슬롯이 아니며, 전투 보조 소환수는 상시 파티원이 아니다.

---

## 4. 전투 보조 소환수 역할 후보

| 역할 | 책임 |
|---|---|
| 공격 | 적 피해, 약한 적 정리 |
| 견제 | 이동·행동·시야 방해 |
| 수호 | 피해 차단, 작성 시간 확보 |
| 충전 | 플레이어가 지정한 스톡 1종 생산·충전 보조 |
| 동조 | 직접 시전·정확 입력·방어 성공의 능동 보상 증폭 |

한 소환수가 모든 역할을 최고 수준으로 수행하지 않는다.

### 잠정 능력치 후보

| 능력치 | 영향 |
|---|---|
| 전투 | 공격과 적 처리 효율 |
| 견제 | 행동 방해와 시간 확보 |
| 수호 | 피해 차단과 작성 안전성 |
| 생산 | 지정 스톡 충전 속도·생산량 |
| 동조 | 능동 충전 보너스 증폭 |
| 지속 | 소환 유지와 재행동 간격 |

명칭과 수치는 `PLAYTEST_TUNING_REQUIRED`다.

---

## 5. 스톡 생산 책임

### 허용

- 플레이어가 지정한 스톡 대상 1종의 충전 보조
- 직접 시전·정확 입력·방어·연계 성공의 충전 보너스 증폭
- 특정 글자 계열 또는 스톡 종류에 대한 효율 차이

### 금지

- 소환수가 충전 대상을 자의적으로 변경
- 소환수가 하위 글자 스톡을 직접 배치·연결
- 생산 능력만으로 충전 속도가 무제한 증가
- 완성 주문 스톡이 직접 작성의 완전한 상위 호환이 되는 구조

완성 주문 스톡의 존재와 보조 소환수 충전 역할은 CORE_POC 이후 다시 판정한다.

## 6. 회로·주문 책임 경계

```text
플레이어
→ 상황 판단
→ 메인·보조 선택
→ 글자 직접 작성 또는 스톡 삽입
→ 위치·대상·기동 결정

하위 글자 스톡
→ 숙련 반복 글자의 자동 배치 후보

전투 보조 소환수
→ 공격·견제·수호·지정 충전

메인 동반 소환수
→ 학습 반응·관계·현장 동행·기록
```

모든 소환수에 공통으로 금지한다.

- 글자·회로 직접 작성
- 보조 글자 자동 선택
- 회로 자동 연결
- 주문 자동 설계·기동
- 문제 정답 제시

---

## 7. 소환 방식 후보

- 전투 전에 편성한 후보 중 호출
- 소환 비용, 재사용 대기시간, 유지 비용, 소환 용량 중 최소 하나로 제한
- 반복 소환 문양 입력은 직접 주문 작성 피로와 겹치므로 초기 범위에서 제외
- 전투 중 교체, 동시 전개 수, 편성 수는 `UNRESOLVED`

초기 CORE_POC는 전투 보조 소환수 1체만 사용한다.

## 8. 성장 방향

### 메인 동반 소환수

- 관계
- 기억과 기원
- 반응·대화
- 마도서 기록 기능
- 외형·연출 변화
- 제한적인 안전·편의 지원

### 전투 보조 소환수

- 공격·견제·수호·충전·동조 적성
- 유지 시간과 재사용 대기
- 특정 글자 계열 효율
- 편성 비용 또는 소환 용량
- 고유 지원 능력

두 성장축은 별도 책임으로 유지한다.

---

## 9. 모바일 가드레일

- 메인 동반 소환수는 상시 전투 명령 UI를 사용하지 않는다.
- 보조 소환수 호출은 한 번의 명확한 입력을 우선한다.
- 이동·조준·스탠스·충전 대상·직접 작성을 모두 동시에 수동 제어하지 않는다.
- 보조 소환수는 기본 AI로 행동한다.
- 소환수 UI가 주문 작성 영역을 가리지 않는다.
- 소환수 조작이 주문 설계보다 더 큰 인지 부하를 만들면 축소한다.

## 10. CORE_POC 참조

포함 후보:

- 메인 동반 소환수 1체의 짧은 반응과 결과 기록
- 전투 보조 소환수 1체의 수호 또는 견제
- 보조 소환수 유무에 따른 작성 시간·피격·완주율 비교

제외:

- 다중 편성
- 복잡한 스탠스 전환
- 완성 주문 스톡 자동 충전
- 소환수 진화·희귀도 경제
- 소환수별 장문 관계 분기

---

## 11. 보호 결정

- 메인 동반 소환수는 항상 같은 개체가 동행한다.
- 전투 보조 소환수는 전투에서 호출한다.
- 두 계층은 별도 슬롯과 성장 책임을 가진다.
- 직접 시전은 소환수 없이도 가능하다.
- 소환수 수집이 주문 설계보다 중요한 핵심으로 역전되지 않는다.
- 고등급 보조 소환수가 없으면 기본 전투가 불가능한 구조를 만들지 않는다.
- 소환수는 글자·회로·조합 판단을 대행하지 않는다.
