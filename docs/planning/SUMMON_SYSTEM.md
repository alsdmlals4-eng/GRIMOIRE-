# Spell 소환수 시스템 — 초기 방향

## 1. 문서 상태

- 상태: `PLANNING_IN_PROGRESS`
- 방향 상태: `DIRECTION_CONFIRMED`
- 기본 전개 방식: `ONE_PRE_SUMMONED_CONFIRMED`
- 세부 편성·추가 소환 규칙: `PROVISIONAL`
- 기준 브랜치: `gpt/planning-spell-20260725`
- 기준 날짜: 2026-07-25
- 관련 결정: `GM-00-10`, `GM-00-13`

이 문서는 기존 동료 시스템을 소환수 시스템으로 승계하는 방향을 기록한다. 소환수의 최종 명칭, 전체 편성 수, 성장 방식, 추가 소환 규칙과 획득 방식은 아직 확정하지 않는다.

## 2. 핵심 전환

기존의 상시 동료 개념을 `소환수` 또는 소환된 마법적 존재로 대체한다.

```text
기존 동료
→ 상시 파티원처럼 보일 위험

소환수
→ 플레이어가 마법으로 구현·호출한 회로 협력자
→ 전투과 주문 설계에 직접 연결
```

소환수는 단순 자동 공격 펫이 아니다.

- 플레이어가 회로를 그리는 동안 전투를 보조한다.
- 지정된 회로 구간을 대신 작성한다.
- 숙련한 보조 회로를 자동화한다.
- 능력치와 플레이어가 지정한 스탠스에 따라 행동 우선순위가 달라진다.
- 등록된 주문의 자동스펠 운용을 보조할 수 있다.

## 3. 기본 전개 방식

### 3.1 전투 시작 전 1체 준비

플레이어는 기본 소환수 1체를 전투 전에 선택하고 미리 소환해 둔다.

```text
전투 준비
→ 기본 소환수 1체 선택
→ 소환 상태로 전투 시작
→ 시작 즉시 전투·수호·회로 지원 가능
```

- 기본 1체는 전투 시작 시 이미 전개되어 있다.
- 매 전투 시작 직후 동일한 소환 회로를 반복해서 그리게 하지 않는다.
- 기본 소환수 전개는 피로도 완화와 초반 난도 보조를 위한 안전망이다.
- 시작 시점의 소환 연출은 가능하지만, 반복적인 입력이나 긴 준비시간을 요구하지 않는다.
- 기본 소환수 1체는 전투 시작부터 플레이어가 지정한 스탠스로 행동한다.

### 3.2 아직 확정하지 않은 범위

- 편성 목록에 여러 소환수를 넣고 전투 전에 1체를 선택할지 여부
- 전투 중 교체 또는 추가 소환 가능 여부
- 성장 후 동시 전개 수가 증가하는지 여부
- 추가 소환수가 일시적 주문인지 상시 전개인지 여부

현재 확정된 것은 `기본 1체를 미리 소환한 상태로 전투를 시작한다`는 원칙이다.

## 4. 마기카로기아 참고 원칙

참고할 구조:

1. 소환 존재는 제한된 전투 공간에서 기능하는 마법적 구현물이다.
2. 외부 세계의 생물을 그대로 부르는 것뿐 아니라 술자의 이미지가 형상화된 존재일 수 있다.
3. 소환 존재는 고유 능력으로 술자의 주문 사용을 돕는다.
4. 술자의 역량을 넘는 소환 수나 강도를 제한하는 용량 개념이 존재한다.
5. 소환 존재와 주문의 계열·영역이 맞을 때 더 높은 자동화 효율을 낼 수 있다.

그대로 복제하지 않을 요소:

- 원작의 카테고리와 명칭을 직접 사용하지 않는다.
- TRPG의 라운드·판정 규칙을 모바일 전투에 그대로 이식하지 않는다.
- 소환수별 역할을 전투형·회로형처럼 고정 타입으로 잠그지 않는다.
- 무작위 판정 실패를 중심 재미로 삼지 않는다.

## 5. 소환수의 정체성

소환수는 다음 세 층을 가진다.

### 5.1 외형·서사

- 플레이어의 마법, 기억, 별자리, 계약, 기록에서 구현된 존재
- 같은 기능을 가진 소환수라도 외형과 성격이 다를 수 있음
- 소환수의 세계관적 출처는 추후 세계관 설계에서 확정

### 5.2 능력치

기존 동료의 고정 타입 폐기 원칙을 유지한다.

잠정 능력치 후보:

| 능력치 | 영향 |
|---|---|
| 전투 | 공격, 수호, 적 방해 효율 |
| 회로 | 자동작성 속도와 담당 가능한 회로 난도 |
| 동조 | 플레이어와 동시 작성 및 자동스펠 협력 효율 |
| 지속 | 연속 지원, 재행동 간격, 추가 소환 유지 후보 |

명칭과 개수는 미확정이다.

### 5.3 고유 능력·적성

소환수는 역할 타입 대신 고유 능력과 회로 적성을 가진다.

예시 후보:

- 특정 보조 회로 자동작성 속도 증가
- 특정 조건 회로를 더 안정적으로 유지
- 플레이어가 정확 판정을 냈을 때 추가 지원
- 자동스펠의 스톡 준비 또는 발동 효율 개선
- 회로 작성 중 플레이어 보호

적성은 해당 행동을 못 하게 막는 자격 제한보다 효율 차이를 만드는 방향을 우선한다.

## 6. 스탠스 승계

기존 동료 스탠스 구조를 소환수에게 승계한다.

잠정 스탠스:

- 전투: 적 공격과 방해 우선
- 수호: 플레이어 보호와 회로 작성 시간 확보
- 회로 지원: 숙련한 회로 자동작성 우선
- 협동: 플레이어와 서로 다른 회로 구간을 동시에 작성

스탠스는 전투 중 변경할 수 있지만 현재 행동 정리 또는 짧은 전환 시간이 존재한다.

## 7. 회로 자동화 역할

### 7.1 초반

- 소환수는 전투 시작부터 전개되어 보호와 간단한 보조 행동을 수행한다.
- 플레이어는 `메인 + 형상·전달`을 직접 학습한다.

### 7.2 성장 이후

- 숙련한 `메인 + 형상·전달`은 시스템 자동화 가능하다.
- 보조 회로가 해금되면 플레이어가 직접 추가한다.
- 소환수 성장 후 숙련한 보조 회로 일부를 대신 작성할 수 있다.

### 7.3 중반 이후

- 조건·기동 회로가 추가된다.
- 소환수가 보조 회로를 작성하고 플레이어가 조건·기동을 직접 설계하거나 반대로 분담할 수 있다.
- 최종 주문 선택과 중요한 기동 판단은 플레이어가 담당한다.

## 8. 소환 용량 후보

기본 전개 1체를 넘는 추가 소환과 강도를 무제한으로 늘리지 않기 위해 `소환 용량` 또는 유사한 제한을 검토한다.

후보 방식:

- 기본 전개 1체는 별도 기본 슬롯으로 보장
- 추가 소환수 또는 강한 소환 효과가 용량 사용
- 강한 소환수일수록 더 많은 용량 사용
- 플레이어 성장으로 용량 증가
- 자동스펠 스톡 수와 소환 용량은 기본적으로 독립 성장축으로 관리

소환수와 자동스펠을 같은 자원으로 직접 경쟁시키면 피로도 완화 기능끼리 충돌할 수 있으므로, 현재는 독립 관리가 우선안이다. 정확한 편성 수와 공식은 미확정이다.

## 9. 자동스펠 스톡과의 관계

소환수는 자동스펠을 독립적으로 발명하거나 선택하지 않는다.

```text
플레이어
→ 주문 발견·등록
→ 자동스펠 스톡 준비
→ 원터치 또는 조건부 발동 방식 지정

소환수
→ 장착된 자동스펠의 회로 준비·기동 보조
→ 능력치와 적성에 따라 효율 변동
```

- 소환수는 자동스펠 스톡을 임의로 다른 주문으로 바꾸지 않는다.
- 조건부 자동스펠은 플레이어가 정한 조건과 스톡 범위 안에서만 발동한다.
- 소환수 성장 효과가 스톡 최대치를 직접 대체하지 않도록 한다.
- 소환수가 스톡 재충전에 관여할지는 후속 결정으로 남긴다.

## 10. 가드레일

- 소환수가 모든 주문 판단을 대신하지 않는다.
- 소환수 수집이 회로 그리기보다 더 중요한 핵심으로 역전되지 않는다.
- 고등급 소환수가 없으면 기본 전투가 불가능한 구조를 만들지 않는다.
- 기본 1체 전개는 특정 희귀 소환수 보유를 요구하지 않는다.
- 소환수 적성은 강제 직업 타입보다 효율과 개성으로 표현한다.
- 자동작성 가능한 회로는 플레이어가 먼저 발견·학습·숙련한 회로로 제한한다.
- 소환수와 자동스펠 스톡만으로 전투가 완전 방치형이 되지 않게 한다.
- 전투 시작마다 동일한 소환 입력을 반복시키지 않는다.

## 12. 미해결 사항

1. 전투 전에 여러 소환수 중 1체를 선택하는 편성 구조인가.
2. 전투 중 소환수 교체를 허용하는가.
3. 추가 소환수는 별도 주문으로 일시 소환할 수 있는가.
4. 성장 후 동시 전개 수를 늘릴 것인가, 기본 1체를 끝까지 유지할 것인가.
5. 소환수 성장은 레벨, 계약, 회로 학습 중 무엇을 중심으로 하는가.
6. 소환수의 세계관적 정체성은 정령, 별의 사역마, 기록의 화신 등 어떤 방향인가.
