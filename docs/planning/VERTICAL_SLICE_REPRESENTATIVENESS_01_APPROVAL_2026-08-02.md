## 승인 문장

> 46–53분 Internal Vertical Slice에서는 반복 가능한 핵심 시스템을 실제 플레이로 구현한다. 1학년 데모와 3학년 본편의 장기 진행은 전환 카드·수강 후보·마도서 연구 방향 등 명확히 표시한 압축 Mock으로 표현한다.

## 실제 구현 범위

```text
문자 의미 학습·직접 작성
→ 교내 비전투 응용
→ 대표 재료·제작 미니게임
→ 자유일정 선택
→ 단일 강적 현장 전투·환경 책임
→ 결과·부작용·발견 기록
→ 학기말 평가 축약 출력
```

필수 실제 플레이:

1. `흐름` 메인 문자 직접 작성.
2. `집중` 또는 `분산` 보조 문법.
3. 교내 일상 또는 축제의 비전투 응용.
4. 재료 식별·촉매 배합·안정화 중 대표 제작 미니게임 최소 1개.
5. 휴식·준비·교류·현장실습 중 최소 2축의 자유일정 선택.
6. 강한 적 1개체 중심 전투와 환경 보존·책임 선택.
7. 마도서의 상황·의도·결과·부작용·발견 기록.
8. 숨김 평가 Ledger를 실제 사건 로그와 연결한 학기말 평가 축약 출력.

## 압축 Mock 범위

- 2·3학기 수강 후보와 다계열 확장.
- 2·3학년 전문화·상급 연구·책임 규모 확장.
- 학년별 Curriculum Map과 장기 마도서 연구 방향.
- Year-One Demo와 Full Game의 후속 질문 및 저장 승계 후보.

Mock은 다음 상태를 명확히 표시한다.

```text
PREVIEW
FUTURE TERM
LOCKED IN INTERNAL SLICE
NOT PLAYABLE IN CURRENT BUILD
```

실제 6~8 Chapter 또는 3년 분량이 구현된 것처럼 오인시키지 않는다.

## 대표성 통과 조건

- 핵심 약속: `배운 문자를 직접 설계해 비전투와 현장에서 다른 방식으로 세계를 바꾼다`를 실제로 체험한다.
- 제작물이 공격력 구매가 아니라 상황 해법·부작용·대가를 바꾸는 준비 수단임을 이해한다.
- 학기 중 숫자 점수 없이도 학기말 평가 근거를 납득한다.
- 특정 계열 하나만이 정답이라는 인상을 주지 않는다.
- 목표 46분·콘텐츠 상한 53분·하드 상한 60분을 유지한다.
- 직접 작성 성공 횟수·재작성 횟수·손 피로·판독 실패율은 사람·Mobile 테스트에서 검증한다.
- 중단복귀 시 작성 Draft·전투 상태·결과 적용 Ledger가 손실되거나 중복되지 않는다.

## 적대적 보호 규칙

- 장기 만족감을 Mock만으로 검증 완료했다고 주장하지 않는다.
- 축약 학기말 평가는 실제 1년 누적 평가의 UX·감정 곡선을 완전히 증명하지 않는다.
- Vertical Slice 통과 전 Year-One Demo 대량 콘텐츠 제작 금지.
- Mobile UX Flow와 Writing/Battle Wireframe 승인 전 제품 구현 금지.
- Mock 화면 수·자유일정 필수 축·작성 횟수·통과 임계값은 `TEST_VALUE`다.
