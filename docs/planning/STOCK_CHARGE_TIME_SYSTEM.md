# Spell 스톡 충전시간 시스템 — 최신 책임 원본

- 상태: `PLANNING_IN_PROGRESS`
- 결정 상태: `CONFIRMED_WITH_MAGIC_LETTER_REINTERPRETATION`

- 관련 결정: `GM-00-22`, `GM-00-24`, `GM-CIRCUIT-01`
- 상위 스톡 시스템: `docs/planning/STOCK_SYSTEM.md`

이 문서는 완성 주문 스톡과 하위 글자 스톡의 기본 충전시간을 정의한다. 기존의 `기능 회로 수`는 최신 문법에서 **기능 마법 글자 수**로 해석한다.

## 1. 기본 공식

스톡 1회분의 기본 충전시간은 저장된 기능 마법 글자 수에 따라 완만하게 증가한다.

```text
1글자
→ 기준 충전시간 1.0단위

추가 글자 1개마다
→ 기준 충전시간 +0.5단위
```

공식:

```text
기준 충전시간(n)
= 1.0 + 0.5 × (n - 1)
= 0.5n + 0.5
```

- `n`은 스톡 1회분에 저장된 기능 마법 글자 수다.
- `n`은 1 이상의 정수다.
- `1.0단위`는 밸런싱용 상대 시간 단위다.
- 실제 초 단위 환산값은 전투 PoC에서 결정한다.

## 2. 하위 글자 스톡

하위 회로 스톡은 기능 마법 글자 하나를 저장하므로 항상 1글자 기준이다.

```text
하위 글자 스톡 1회분
= 1글자
= 기준 충전시간 1.0단위
```

글자의 역할·계열·입력 획수에 따른 별도 기본 가중치는 두지 않는다. 계열별 난이도 차이는 학습·숙련·마나·효과 데이터에서 다룰 수 있다.

## 3. 완성 주문 스톡

완성 주문 스톡은 설계도에 포함된 메인 글자와 보조 글자의 총수를 기준으로 한다.

| 기능 글자 수 | 기준 충전시간 |
|---:|---:|
| 1 | 1.0단위 |
| 2 | 1.5단위 |
| 3 | 2.0단위 |
| 4 | 2.5단위 |
| 5 | 3.0단위 |
| 6 | 3.5단위 |

예시:

```text
불꽃 메인
= 1글자 기본 주문
= 기준 충전시간 1.0단위
```

```text
불꽃 메인 + 투사체 형상 + 발사 전달
= 3글자 주문
= 기준 충전시간 2.0단위
```

```text
불꽃 메인 + 투사체 + 발사 + 확대 + 분열 + 추적
= 6글자 주문
= 기준 충전시간 3.5단위
```

메인 글자 하나만으로 주문이 성립하므로 완성 주문 스톡의 최소 구성은 1글자다.

## 4. 완만한 증가를 사용하는 이유

- 다수 보조 글자 주문이 기본 주문과 같은 속도로 재생산되는 문제를 방지한다.
- 준비 용량과 충전시간이 동시에 과도하게 가파르게 증가하지 않게 한다.
- 메인 단독 기본 주문은 빠르게 순환시킬 수 있다.
- 하위 글자 스톡과 고위 완성 주문 스톡의 운용 차이를 만든다.
- 주문 문장이 길어질수록 생산 시간이 증가한다는 직관을 제공한다.

## 5. 플레이어와 소환수 생산 기여

위 공식은 능력치 적용 전의 기준 충전시간이다.

```text
기준 충전시간
→ 플레이어 생산 능력치 적용
→ 소환수 생산 능력치 적용
→ 능동 행동 충전 보너스 적용
→ 실제 충전시간 결정
```

현재 확정된 범위:

- 플레이어와 소환수 능력치는 실제 충전시간을 줄이거나 진행량을 높일 수 있다.
- 직접 시전, 정확 입력, 방어·반격, 주문 연계는 추가 충전 기여를 제공한다.
- 자동 충전 대상은 한 번에 1종이다.
- 소환수는 충전 대상을 임의로 바꾸지 않는다.

아직 확정하지 않은 범위:

- 충전시간 감소식과 진행량 증가식 중 어느 방식을 사용할지
- 플레이어와 소환수 기여의 합산·곱연산 방식
- 최소 충전시간 하한
- 능동 충전 보너스 수치

## 6. 충전 단위와 수량

충전시간은 스톡 1회분을 다시 생산하는 데 필요한 시간이다.

```text
동일 주문 스톡 현재 0/3
→ 1회분 충전 완료
→ 1/3
→ 다음 1회분 충전 시작
```

지정 대상의 빈 스톡을 1회분씩 순차 충전한다. 동시 다중 충전은 사용하지 않는다.

## 7. 피격 시 처리

피격으로 글자 수나 기준 충전시간을 다시 계산하지 않는다.

```text
다음 스톡 65% 충전
→ 직접 피해 발생
→ 65% 진행도 보존
→ 비례 일시정지
→ 정지 종료 후 65%부터 자동 재개
```

- 피격 정지는 영구 비용이 아니라 일시 정지다.
- 정지 중 플레이어·소환수 생산 기여와 능동 보너스는 적용되지 않는다.
- 지속 피해 틱은 충전·전환을 정지시키지 않는다.
- 자세한 규칙은 `STOCK_HIT_PAUSE_SYSTEM.md`를 따른다.

## 8. 가드레일

- 글자 수는 `STOCK_CAPACITY_SYSTEM.md`와 같은 기능 마법 글자 기준을 사용한다.
- 선 길이·획수·시각 장식으로 충전시간을 늘리지 않는다.
- 메인 글자 하나에 독립 효과를 과도하게 압축해 글자 수 비용을 우회하지 않는다.
- 보조 글자 수가 늘어난 고위 주문의 생산 차이가 성장 후 완전히 사라지지 않게 한다.
- 생산 능력치와 전체 준비 용량이 동시에 과도하게 증가하지 않게 한다.
- 피격으로 충전 진행도를 삭제하지 않는다.

## 9. UI 필수 정보

- 각 스톡의 기능 마법 글자 수
- 메인 글자와 보조 글자 구성
- 1회분 기준 충전시간
- 능력치 적용 후 예상 실제 충전시간
- 현재/최대 스톡 수량
- 다음 1회분 충전 진행도
- 플레이어와 소환수의 생산 기여
- 피격 정지와 자동 재개 상태

| 가설 | 최소 검증물 | 통과 신호 |
|---|---|---|
| 메인 단독 주문의 빠른 순환이 이해된다 | 1글자 스톡 반복 | 기본 주문을 즉응용으로 사용 |

## 11. 미해결 사항

1. 1.0단위를 실제 몇 초로 환산하는가.
2. 플레이어·소환수 생산 능력치 계산식은 무엇인가.
3. 최소 충전시간 하한은 얼마인가.
4. 충전 대상 전환 지연의 실제 시간은 얼마인가.
5. 같은 보조 글자를 반복한 주문의 글자 수와 효과는 어떻게 계산하는가.
