# Spell 스톡 충전시간 시스템 — 최신 책임 원본

## 문서 상태

- 상태: `PLANNING_IN_PROGRESS`
- 결정 상태: `CONFIRMED`
- 기준 날짜: 2026-07-26
- 관련 결정: `GM-00-22`
- 상위 스톡 시스템: `docs/planning/STOCK_SYSTEM.md`
- 준비 용량 시스템: `docs/planning/STOCK_CAPACITY_SYSTEM.md`

이 문서는 완성 주문 스톡과 하위 회로 스톡의 기본 충전시간 계산 방식을 정의한다. 충전시간과 관련해 기존 문서의 미해결 항목과 충돌할 경우 이 문서가 우선한다.

## 1. 충전시간 기본 원칙

스톡 1회분의 기본 충전시간은 저장된 기능 회로 수에 따라 완만하게 증가한다.

```text
1회로
→ 기준 충전시간 1.0단위

추가 회로 1개마다
→ 기준 충전시간 +0.5단위
```

공식:

```text
기준 충전시간(n)
= 1.0 + 0.5 × (n - 1)
= 0.5n + 0.5
```

- `n`은 스톡 1회분에 저장된 기능 회로 수다.
- `n`은 1 이상의 정수다.
- `1.0단위`는 실제 1시간을 뜻하지 않는 밸런싱용 상대 시간 단위다.
- 실제 초 단위 환산값은 터치 전투 PoC에서 결정한다.

## 2. 하위 회로 스톡

하위 회로 스톡은 기능 회로 하나를 저장하므로 항상 1회로 기준을 사용한다.

```text
하위 회로 스톡 1회분
= 1회로
= 기준 충전시간 1.0단위
```

회로 종류와 무관하게 하나의 기능 회로 블록이면 동일한 기본 충전시간을 사용한다. 개별 회로 등급이나 입력 획수에 따른 추가 시간은 두지 않는다.

## 3. 완성 주문 스톡

완성 주문 스톡은 설계도에 포함된 기능 회로 수를 기준으로 충전시간을 계산한다.

| 구성 회로 수 | 기준 충전시간 |
|---:|---:|
| 1 | 1.0단위 |
| 2 | 1.5단위 |
| 3 | 2.0단위 |
| 4 | 2.5단위 |
| 5 | 3.0단위 |
| 6 | 3.5단위 |

예시:

```text
공격 메인 + 투사체 형상
= 2회로 주문
= 기준 충전시간 1.5단위
```

```text
공격 메인 + 투사체 형상 + 분열 보조 + 지연 조건
= 4회로 주문
= 기준 충전시간 2.5단위
```

고위 주문은 공용 준비 용량을 더 많이 사용하고 충전시간도 길어지지만, 회로 수에 정비례하지 않고 추가 회로당 0.5단위만 증가한다.

## 4. 완만한 증가를 사용하는 이유

- 고위 주문이 1회로 주문과 같은 속도로 재생산되는 문제를 방지한다.
- 회로 수에 정비례하는 과도한 이중 제약을 피한다.
- 공용 준비 용량을 핵심 편성 제약으로 유지한다.
- 하위 회로 스톡의 빠른 순환과 완성 주문 스톡의 즉시성을 구분한다.
- 주문이 복잡해질수록 생산시간이 늘어난다는 직관을 제공한다.

## 5. 플레이어와 소환수 생산 기여

위 공식은 능력치 적용 전의 `기준 충전시간`을 계산한다.

```text
기준 충전시간
→ 플레이어 생산 능력치 적용
→ 소환수 생산 능력치 적용
→ 능동 행동 충전 보너스 적용
→ 실제 충전시간 결정
```

현재 확정된 범위:

- 플레이어와 소환수 능력치는 실제 충전시간을 단축하거나 진행량을 높일 수 있다.
- 직접 시전, 정확 입력, 방어·반격, 주문 연계는 추가 충전 기여를 제공한다.
- 자동 충전 대상은 한 번에 1종이다.

아직 확정하지 않은 범위:

- 생산 능력치를 충전시간 감소식으로 적용할지 진행량 증가식으로 적용할지
- 플레이어와 소환수 기여를 합산할지 곱연산할지
- 최소 충전시간 하한
- 능동 충전 보너스의 정확한 수치

## 6. 충전 단위와 스톡 수량

충전시간은 스톡 1회분을 다시 생산하는 데 필요한 기준 시간이다.

```text
동일 주문 스톡 최대 3개
현재 0/3
→ 1회분 충전 완료
→ 1/3
→ 다음 1회분 충전 시작
```

현재는 지정 대상의 빈 스톡을 1회분씩 순차 충전하는 방향을 기준으로 한다. 동시 다중 충전은 사용하지 않는다.

## 7. 가드레일

- 회로 수는 `STOCK_CAPACITY_SYSTEM.md`와 동일한 기능 회로 블록 기준을 사용한다.
- 선 길이, 획수, 시각 장식으로 충전시간을 늘리지 않는다.
- 하나의 회로에 독립 효과를 압축해 준비 용량과 충전시간을 동시에 우회하지 않게 한다.
- 생산 능력치가 성장해 고위 주문의 회로 수 차이가 무의미해지지 않게 한다.
- 최소 충전시간 하한을 PoC에서 검증한다.
- 공용 준비 용량과 생산 속도가 동시에 과도하게 증가하지 않게 한다.

## 8. UI 필수 정보

- 각 스톡의 구성 회로 수
- 1회분 기준 충전시간
- 현재 능력치가 적용된 예상 실제 충전시간
- 현재/최대 스톡 수량
- 다음 스톡 1회분의 충전 진행도
- 플레이어와 소환수의 충전 기여도

## 9. PoC 검증 항목

| 가설 | 최소 검증물 | 통과 신호 |
|---|---|---|
| 추가 회로당 0.5단위 증가가 이해된다 | 1~4회로 스톡 비교 | 회로 수가 많을수록 느리지만 과도하지 않다고 인식 |
| 고위 주문에 적절한 재사용 간격이 생긴다 | 2회로·5회로 주문 비교 | 고위 주문을 비장의 대응으로 사용 |
| 회로 스톡 순환이 충분히 빠르다 | 1회로 스톡 반복 사용 | 상위 주문 조합 피로가 감소 |
| 생산 능력치가 공식을 무효화하지 않는다 | 기본·성장 상태 비교 | 성장 후에도 회로 수 차이가 체감됨 |

## 10. 미해결 사항

1. 기준 충전시간 1.0단위를 실제 몇 초로 환산하는가.
2. 플레이어·소환수 생산 능력치의 최종 계산식은 무엇인가.
3. 최소 충전시간 하한은 얼마인가.
4. 피격 시 자동 충전이 유지·감속·중단되는가.
5. 충전 대상은 전투 중 언제 변경할 수 있는가.
