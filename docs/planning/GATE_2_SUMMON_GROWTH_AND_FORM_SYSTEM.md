# 스펠 Gate 2 소환수 성장·형상·탑승 구조

## 1. 문서 상태

- 상위 결정: `GM-MASCOT-01`
- 성장 결정: `GM-SUMMON-GROWTH-01`
- 사용자 승인: 2026-07-27
- 상태: `MAIN_SUMMON_GROWTH_AND_FORM_SELECTION_CONFIRMED_DIRECTION`
- 제품 단계: `PROTOTYPE_AND_VERTICAL_SLICE`
- Gate 1: `APPROVED`
- 프로젝트 코어: `CORE_CONFIRMED`
- 실행 프로필: `PLANNING_ONLY_PROFILE`
- Vertical Slice 런타임 범위: `INITIAL_MAIN_FORM_AND_ONE_COMBAT_SUPPORT_ONLY`
- 구현: `NOT_STARTED`
- 다음 차단 결정: `ART-STYLE-01`

> **메인 동반 소환수는 원소와 정령성이 중심인 하나의 고정된 존재이며, 장기적으로 네 단계의 성장을 통해 크기와 모습이 변화한다. 플레이어는 해금한 현재 단계 이하의 형상 중 원하는 모습을 선택해 동행시킬 수 있고, 후반에는 제한된 탑승 기능을 해금한다.**

---

## 2. 시각 방향

### 공통 방향

- `원소 + 정령` 우선
- 동물 형상은 가능하지만 전체 소환수를 동물형으로 고정하지 않음
- 원소 에너지·마력 문양·빛의 흐름·안개·결정·부유 파츠 등을 사용
- 생물과 정령의 경계가 느껴지는 실루엣
- 단순 펫보다 세계관의 마력 존재로 인식되어야 함

### 메인 동반 소환수

- 현재 대표 레퍼런스는 신비한 늑대형 정령수 계열
- 늑대형은 이 개체의 유력 방향이지 전체 소환수 종족 규칙이 아님
- 정확한 원소·대표색·이름·기원·문양은 `ART-STYLE-01`과 세계관 작업에서 확정

### 전투 보조 소환수

- 메인 동반자와 같은 세계관의 원소·정령 시각 언어 사용
- 동물형 정령수·비인간 원소체·갑주형 정령 등 다양한 방식 허용
- 역할이 먼저 읽히도록 실루엣과 효과를 설계

---

## 3. 메인 동반 소환수 성장

### 장기 4단계 프레임

| 단계 | 방향 | 핵심 변화 |
|---|---|---|
| 1단계 | 유체·초기 정령 | 작고 친근함, 학교 동행 중심 |
| 2단계 | 성장체 | 체격 증가, 원소 문양·파츠 강화 |
| 3단계 | 성숙체 | 위엄과 상징성 강화, 현장 존재감 증가 |
| 4단계 | 각성·탑승 가능체 | 대형화, 전용 탑승 형상과 장기 보상 |

정확한 단계명과 최종 외형은 아직 확정하지 않는다.

### 성장 책임

- 관계 단계
- 기억·기원 해금
- 반응·대화 변화
- 마도서 기록 기능 확장
- 외형·연출 변화
- 제한적인 안전·편의 기능
- 후반 탑승 기능

공격력·희귀도 상승만으로 성장 의미를 만들지 않는다.

---

## 4. 실제 성장과 표시 형상 분리

```text
actual_growth_stage
= 능력·관계·기억·기능의 실제 해금 단계

display_form_stage
= 플레이어가 현재 표시하도록 선택한 형상 단계
```

규칙:

- 표시 형상은 `1단계 이상 ~ actual_growth_stage 이하`
- 상위 단계 도달 후에도 이전 단계 형상을 잃지 않음
- 능력과 기능은 actual_growth_stage 기준
- 표시 형상은 코스메틱·애착 선택
- UI에서 실제 성장과 표시 형상을 별도 항목으로 보여 줌

예:

```text
실제 성장 = 3단계
해금 형상 = 1 / 2 / 3단계
현재 표시 = 1단계
실제 기능 = 3단계
```

### 상위 힘의 시각 표현

하위 형상으로 상위 능력을 사용할 때 혼동을 줄이기 위해 다음 중 하나를 사용할 수 있다.

- 실제 성장 단계의 문양이 일시적으로 발광
- 원소 오라와 파츠가 능력 발동 중 잠시 확장
- UI에 실제 성장 단계 표시

정확한 FX 규칙은 `ART-BIBLE-01`에서 확정한다.

## 5. 탑승

### 확정 방향

- 메인 동반 소환수의 장기 성장 보상
- 탑승 가능한 상위 형상 해금 후 사용
- 하위 표시 형상 사용 중에도 탑승 시 전용 탑승 형상으로 자동 전환 가능

### 우선 구현 순서

```text
연출형 탑승
→ 특정 구간형 탑승
→ 필요성이 검증된 경우 자유 이동형 탑승 재검토
```

허용 후보:

- 현장실습 진입·귀환 연출
- 특정 지역의 짧은 이동 구간
- 장애물 돌파·특수 이동
- 합동 주문 또는 대표 이벤트

초기 제외:

- Vertical Slice 탑승 구현
- 학교 실내 상시 탑승
- 모든 대화·시험·전투에 탑승 상태 대응
- 자유 탐색을 위한 대형 맵 제작
- 탑승 전용 복잡한 전투 시스템

---

## 6. 전투 보조 소환수 경계

### 확정

- 전투에서 호출되는 전술 지원 존재
- 원소·정령 중심 시각 언어
- 플레이어의 직접 작성 시간을 확보
- Vertical Slice에서는 수호 또는 견제 역할 1체
- 글자 작성·조합 판단·정답 제시 대행 금지

### 비교 후보 — 아직 미확정

- 공격형
- 견제형
- 수호형
- 보조형

위 4역할은 콘셉트 비교용 분류이며 사용자 최종 승인 전 전체 시스템으로 확정하지 않는다.

### 미확정

- 전투 보조 소환수의 성장 단계 수
- 이전 형상 선택 적용
- 탑승 기능
- 희귀도·획득·계약·편성 경제
- 동시 소환 수
- 호출 비용과 재사용 대기

---

## 7. Vertical Slice 범위

### 포함

- 메인 동반 소환수 1체
- 초기 형상 1개
- 필드 소형 전신·대화 반응·현장 동행
- 전투 보조 소환수 1체
- 수호 또는 견제 중 한 역할
- 두 계층의 역할 구분

### 제외

- 메인 소환수 2~4단계 전체 런타임 자산
- 표시 형상 선택 UI의 실제 구현
- 탑승
- 전투 보조 소환수 전체 역할군
- 보조 소환수 성장·진화·형상 선택
- 다수 편성·희귀도 경제

장기 방향은 문서·콘셉트로 보존하되, Slice에서는 직접 작성과 조합 코어보다 먼저 확장하지 않는다.

## 8. 자산 제작 경계

Art Bible과 Asset Specification 전에는 다음만 허용한다.

- 성장 단계 실루엣 비교
- 원소·정령 표현 후보
- 메인 동반자 대표 콘셉트 샷
- 수호 또는 견제 전투 소환수의 역할 실루엣 비교

금지:

- 4단계 전 방향·표정·애니메이션 대량 제작
- 탑승 애니메이션 제작
- 승인되지 않은 전투 소환수 4역할 전체 제작
- 생성 이미지를 최종 런타임 자산으로 간주

## 9. 검증 기준

- 메인 동반자가 동일한 인격과 관계를 유지하며 성장한다고 느껴짐
- 하위 표시 형상 선택이 성능 선택으로 오해되지 않음
- 원소·정령성이 동물 외형보다 우선적으로 읽힘
- 초기 형상만으로도 학습·관계·기록 역할이 전달됨
- 보조 소환수는 메인 동반자와 즉시 구분됨
- 장기 성장·탑승 약속이 Vertical Slice 범위를 팽창시키지 않음
