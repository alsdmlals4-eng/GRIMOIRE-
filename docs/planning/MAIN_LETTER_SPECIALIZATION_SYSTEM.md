## 1. 채택 구조

메인 글자는 `Lv.1~Lv.3`에서 공통 기반을 익히고, `Lv.4~Lv.5`에서 계열별 전문 활용 분기로 성장한다.

```text
Lv.1 입문
→ Lv.2 숙련
→ Lv.3 응용
→ Lv.4 전문 분야 선택
→ Lv.5 선택 분야 심화·개인 연구
```

- Lv.1~Lv.3은 같은 메인 글자를 사용하는 학생이 공통으로 배워야 하는 원리·안전·기본 활용 단계다.
- Lv.4부터 같은 메인 글자라도 학생의 수업·교수·연구·현장실습에 따라 활용 방향이 갈린다.
- Lv.5는 선택한 전문 분야를 졸업 연구와 개인적인 해석으로 완성하는 단계다.
- 전문화는 단순 공격력 특성 선택이 아니라 전투·생활·구조·연구에서 해당 현상을 다루는 방식의 차이다.

## 2. 전문화 분기의 역할

전문화는 다음 요소를 변화시킬 수 있다.

- 메인 단독 기본 발현의 성격
- 특정 보조 글자군과의 결합 안정성
- 마나 효율과 고출력 부담
- 관련 현장실습과 연구 과제
- 교수·학생·소환수와의 계열 사건
- 졸업 연구 주제와 진로
- 같은 문제를 해결하는 방식

전문화가 새로운 보조 글자를 자동 지급하지는 않는다. 전문화는 이미 배운 보조 글자와의 결합 효율 또는 활용 방향을 강화한다.

## 3. 분기 설계 원칙

모든 계열에 동일한 이름의 공격·방어·지원 분기를 복사하지 않는다. 각 계열의 현상적 특성에 맞는 3개 안팎의 전문 분야를 설계한다.

공통 설계 관점 후보:

1. `출력·변화량` — 강한 현상 발생, 빠른 변화, 고출력 운용
2. `제어·정밀` — 세밀한 범위·온도·압력·형태 제어
3. `지속·영역·활용` — 장기간 유지, 공간 관리, 생활·구조·생산 응용

위 세 관점은 분기 이름을 그대로 반복하기 위한 고정 클래스가 아니라 각 메인 계열의 전문 분야를 만드는 설계 기준이다.

### 불꽃 메인 예시

```text
불꽃 Lv.3
├─ 연소·출력 연구
├─ 열 제어·가공 연구
└─ 지속·영역 제어 연구
```

- 연소·출력: 짧고 강한 열량, 점화와 폭발적 발현
- 열 제어·가공: 온도 정밀 제어, 해빙·가공·시설 운용
- 지속·영역: 장시간 열원, 지역 통제, 재해 확산 억제

### 보호 메인 예시

```text
보호 Lv.3
├─ 충격 차단 연구
├─ 정밀 보호·동행 연구
└─ 시설·영역 봉쇄 연구
```

예시는 구조 설명용이며 최종 분기명과 효과는 후속 계열 데이터 설계에서 확정한다.

## 4. Lv.4와 Lv.5

### Lv.4 — 전공 진입

- 하나의 전문 활용 분야를 선택한다.
- 관련 심화 수업·교수 연구실·현장실습이 열린다.
- 전문 분야에 맞는 기본 발현 변형 또는 보조 글자 결합 보정을 얻는다.
- 졸업 연구 후보가 구체화된다.

### Lv.5 — 개인 연구 완성

- Lv.4에서 선택한 분야를 더 깊게 발전시킨다.
- 개인 주문 설계·독립 실습·졸업 발표가 요구된다.
- 정해진 최종 스킬 하나를 지급하기보다 플레이어가 자주 사용한 보조 글자와 활용 기록을 반영하는 방향을 우선한다.
- 교수의 정답을 재현하는 단계가 아니라 자신의 활용 방식을 증명하는 단계다.

## 5. 분기와 학교생활

```text
계열 수업
→ Lv.3 공통 응용
→ 담당 교수 연구 체험
→ 현장실습에서 전문 활용 시도
→ Lv.4 분야 선택
→ 연구실·동료·실습 후보 변화
→ Lv.5 졸업 연구 완성
```

- 같은 메인 계열을 선택한 동급생도 다른 연구실과 활용 방향을 가질 수 있다.
- 라이벌은 같은 분기를 더 잘 쓰거나, 반대 분기로 같은 문제를 해결할 수 있다.
- 선택형 상세 대화를 통해 교수의 연구 철학과 각 전문 분야의 역사·사례를 확인할 수 있다.

## 6. 가드레일

- Lv.4 이전에 전문 분야를 영구 고정하지 않는다.
- 분기를 공격·방어·지원 클래스 선택으로 단순화하지 않는다.
- Lv.4 선택만으로 새로운 주문이 자동 등록되지 않는다.
- 전문 분기가 보조 글자 학습을 대체하지 않는다.
- 한 분기가 모든 상황에서 다른 분기보다 상위 호환이 되지 않게 한다.
- 전투 분기만 명확한 보상을 받고 생활·구조 분기는 약해지는 구조를 피한다.
- 전문 분기로 복수 메인 글자 결합을 허용하지 않는다.

## 7. 추후 결정

- 전문 분기 선택을 변경할 수 있는가
- 변경 가능하다면 비용·기간·연구 진행도 처리는 어떻게 하는가
- 각 메인 글자의 실제 전문 분기 수와 명칭
- Lv.4에서 얻는 기본 발현 변화
- Lv.5 개인 연구 결과의 생성 방식
- 전문 분기가 특정 보조 글자군에 주는 보정
- 졸업 진로와 전문 분기의 연결 방식
