## 권장안 C

### 시간 진행 상태

- `BATTLE_OVERVIEW`
- `SPELL_PANEL_EXPANDED`
- `SPELL_DRAWING`
- `SPELL_RECOGNITION_REVIEW`
- `SPELL_COMBINATION_REVIEW`

플레이어가 직접 판단하거나 입력할 수 있는 동안 적 공격 타이머는 진행한다.

### 시간 정지 상태

- `[구현]` 요청 승인 후 결과 해결 중.
- 마법 시전·피해·환경 변화 연출 중.
- 적 공격 해결·피해 반영 중.
- 보스 페이즈 전환 중.
- 결과 화면 전환 중.
- 튜토리얼 강제 안내·일시정지·창 포커스 상실.
- 기기·인식 시스템이 입력을 막는 동기 처리 구간.

### 접근성 보조

- `작성 보조 감속` 옵션을 제공한다.
- 초기 검토값은 작성 패널 확장 중 `0.5×`이며 최종 배율은 플레이테스트 대상이다.
- 옵션 사용으로 콘텐츠·보상·기록을 제한하지 않는다.
- 감속 중임을 아이콘·문구·게이지 변화로 표시한다.

## 공정성 규칙

1. 시스템 처리 시간이 적 공격 시간을 소모하지 않는다.
2. 인식이 비동기로 처리되며 입력이 계속 가능하면 타이머도 계속 진행한다.
3. 인식·전환 때문에 입력이 강제로 잠기면 타이머를 정지한다.
4. 타이머 0과 `[구현]`이 경합하면 먼저 승인된 이벤트를 먼저 해결한다.
5. 적 공격이 먼저 확정되면 작성 내용을 유지한 채 공격 해결 후 작성 상태로 복귀한다.
6. 마법 시전과 적 공격을 동시에 해결하지 않는다.

## 적대적 검토

- 작성 패널을 열어 시간을 멈추는 악용: 차단.
- 느린 작성자의 불공정: 작성 보조 감속으로 완화.
- 낮은 사양 기기의 인식 지연: 시스템 잠금 시간은 타이머에서 제외.
- 연출 중 연속 피격: 해결 상태에서 타이머 정지.
- 일시정지 후 즉시 공격: 재개 전 짧은 입력 준비 프레임을 두는 것은 구현 검토 대상.
- 감속 옵션이 숨겨짐: 전투 시작 전 설정과 일시정지 메뉴 양쪽에서 접근 가능해야 함.
