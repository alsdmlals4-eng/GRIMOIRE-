# GR-BM-FULL-GAME-CORE-LOOP-20260802-01 — 전체 게임 Core Loop STANDARD Benchmark

## 1. 질문

학교생활·직접 마법 작성·상황 해결·마도서 기록을 어떻게 반복 가능한 전체 게임 구조로 연결할 것인가?

## 2. 비교 기준

- 학교생활이 실제 선택과 관계를 만드는가.
- 배운 요소가 현장·전투·탐험에서 사용되는가.
- 결과가 다음 학습과 콘텐츠에 환류하는가.
- 반복 작업과 피로를 억제하는가.
- 새 규칙·글자 추가 시 제작 비용을 통제하는가.
- GRIMOIRE의 직접 작성과 복수 해법을 보존하는가.

## 3. 공식 사례

### Persona 5 Royal — 학생 생활과 제한된 시간 선택

공식 사이트는 수업·학교 행사·방과 후 활동과 괴도 활동이 한 해의 이중생활을 구성한다고 설명한다.

출처:
- https://asia.sega.com/persona-remaster/p5r/kr/

적용:
- `ADAPT`: 제한된 일정 선택이 관계·준비·사건 접근을 바꾸는 구조.
- `REJECT`: 1년 전체 달력, 다수 반복 생활 액션, Mobile Vertical Slice에 과도한 일상 메뉴.

### Fire Emblem: Three Houses — 교육·관계·전투의 교대

Nintendo 공식 설명은 사관학교에서 학생의 재능을 육성하고 관계를 쌓은 뒤 과제 전투로 이어지는 구조를 제시한다.

출처:
- https://www.nintendo.com/en-gb/Games/Nintendo-Switch-games/Fire-Emblem-Three-Houses-1175482.html
- https://www.nintendo.com/au/news-and-articles/fire-emblem-three-houses-101/

적용:
- `ADAPT`: 학습 목표→준비 활동→현장 적용→성장 결과의 주기.
- `ADAPT`: 자유 활동에서 선택형 전투·훈련을 제공하되 다른 활동과 기회비용을 공유하는 구조.
- `REJECT`: 광대한 허브 반복 순회, 다수 유닛 육성, Activity Point 최적화 작업.

### Atelier Ryza — 배운 제작 요소가 탐험·전투에 재투입

공식 매뉴얼은 탐험·채집·합성·전투가 이어지고, 합성 결과가 탐험과 전투에 사용된다고 설명한다.

출처:

적용:
- `ADAPT`: 수업에서 배운 글자와 발견이 다음 상황 해결 능력을 넓히는 순환.
- `ADAPT`: 숲·야외 공간의 실전 활동에서 배운 요소를 시험하고 다시 기록으로 환류.
- `REJECT`: 대량 재료 인벤토리, 반복 채집, 레시피·품질 수치 중심 제작 경제.

Nintendo 공식 소개는 규칙 자체가 상호작용 가능한 블록으로 존재하고, 이를 바꾸면 레벨의 작동 방식이 변한다고 설명한다.

- `REJECT`: 모든 규칙을 자유롭게 재작성하는 무제한 조합 공간과 퍼즐별 완전 수작업 검증.

## 4. 구조 후보

### A. 학기형 학습 나선 — 권장

```text
새 원리 학습
→ 제한된 자유일정으로 준비·관계·현장실습 선택
→ 시험·학교 행사에서 통제된 응용
→ 현장 사건에서 복합 적용
→ 마도서 복기·발견
→ 다음 원리와 더 어려운 상황 개방
```

장점:
- 현재 Slice가 전체 게임의 축소판이 된다.
- 학교와 현장이 서로 필요해진다.
- 새 글자를 커리큘럼 단위로 제한해 조합 폭증을 통제한다.
- 서사 성장과 시스템 성장을 같은 주기로 묶기 쉽다.
- 자유일정의 선택형 실습 전투로 배운 글자를 자발적으로 시험할 수 있다.

위험:
- 매 장의 수업·시험·현장이 공식처럼 반복될 수 있다.
- 일정 선택이 단순 버프 또는 전투 보상 최적화로 축소될 수 있다.

### B. 학교 허브 + 사건 의뢰형

```text
학교에서 학습·준비
→ 여러 사건 중 선택
→ 현장 해결
→ 보상·기록·관계 변화
→ 새로운 사건과 글자 개방
```

장점:
- 사건 선택과 재플레이성이 높다.
- 콘텐츠를 독립 에피소드로 추가하기 쉽다.

위험:
- 학교생활이 메뉴 허브가 될 가능성이 높다.
- 장학생 성장선과 학기 평가가 약해진다.
- 플레이어가 유리한 사건만 골라 성장 최적화를 할 수 있다.

### C. 반복 학기·Roguelite형

```text
학기 시작 빌드 선택
→ 제한 일정과 무작위 사건
→ 시험·현장
→ 실패·졸업 결과
→ 영구 발견을 가지고 새 학기 재시작
```

장점:
- 높은 반복성과 조합 실험.
- 부분 성공과 실패를 구조적으로 수용.

위험:
- 현재의 연속 서사·관계·책임 기록과 충돌한다.
- 직접 작성 반복 피로가 커진다.
- Save·밸런스·무작위 콘텐츠 제작 범위가 크게 증가한다.

- 명시적 규칙 변화와 원인 설명.
- 배운 구성요소의 여러 콘텐츠 재사용.
- 자유일정에서 휴식·준비·교류·현장실습 중 선택.
- 현장실습은 숲·훈련장·전투 공간에서 상황 해결형 전투를 제공.

적응:

- 한 학기 전체가 아니라 Chapter 단위 압축.
- 자유일정은 소수의 의미 있는 선택만 제공.
- 새 글자는 Chapter마다 제한적으로 추가.
- 선택형 실습 전투는 일정 슬롯 1개를 소비하고 기존 장소·적 변형을 우선 재사용.
- 반복 전투의 보상은 첫 완료·새 조건 발견 중심으로 제한.

거부:

- 대규모 학교 자유 탐색 반복.
- 대량 재료 파밍·레시피 경제.
- 완전 무작위 학기 반복.
- 무제한 규칙 조합.
- 자유일정의 무한 전투 파밍.
- 선택형 전투에 핵심 글자·필수정보·유일 해법 독점.

## 6. 프로젝트 추론

A안은 기존 Vertical Slice를 폐기하지 않고 본편의 첫 학습 나선으로 승격한다. 자유일정 현장실습은 학교에서 배운 글자를 자발적으로 실전 검증할 수 있게 하지만, 보상 효율이 다른 활동을 압도하면 학기형 선택 구조가 무너진다.

따라서 다음 후속 설계가 필수다.

- Chapter 내부 기능과 순서 변주.
- 자유일정 창의 수와 현장실습 개방 조건.
- 휴식·준비·교류·현장실습의 동등 규모 효용.
- 실습 전투의 길이·보상·반복 감쇠 `TEST_VALUE`.
- Vertical Slice에 선택형 전투를 실제 포함할지 대표성 재검증.

이 문서는 비교 근거와 승인 추적 문서이며, 세부 수치의 런타임·사람 검증을 증명하지 않는다.
