# GR-BM-FULL-GAME-CORE-LOOP-20260802-01 — 전체 게임 Core Loop STANDARD Benchmark

## 1. 질문

학교생활·직접 마법 작성·상황 해결·마도서 기록을 어떻게 반복 가능한 전체 게임 구조로 연결할 것인가?

## 2. 비교 기준

- 학교생활이 실제 선택과 관계를 만드는가.
- 배운 요소가 현장·전투·탐험에서 사용되는가.
- 결과가 다음 학습과 콘텐츠에 환류하는가.
- 반복 작업과 피로를 억제하는가.
- 새 규칙·글자 추가 시 제작 비용을 통제하는가.
- GRIMOIRE의 직접 작성과 복수 해법을 보존하는가.

## 3. 공식 사례

### Persona 5 Royal — 학생 생활과 제한된 시간 선택

공식 사이트는 수업·학교 행사·방과 후 활동과 괴도 활동이 한 해의 이중생활을 구성한다고 설명한다.

- https://asia.sega.com/persona-remaster/p5r/kr/

- `ADAPT`: 제한된 일정 선택이 관계·준비·사건 접근을 바꾸는 구조.
- `REJECT`: 1년 전체 달력, 다수 반복 생활 액션, Mobile Vertical Slice에 과도한 일상 메뉴.

Nintendo 공식 설명은 사관학교에서 학생의 재능을 육성하고 관계를 쌓은 뒤 과제 전투로 이어지는 구조를 제시한다.

- `REJECT`: 광대한 허브 반복 순회, 다수 유닛 육성, Activity Point 최적화 작업.

### Atelier Ryza — 배운 제작 요소가 탐험·전투에 재투입

공식 매뉴얼은 탐험·채집·합성·전투가 이어지고, 합성 결과가 탐험과 전투에 사용된다고 설명한다.

- `REJECT`: 모든 규칙을 자유롭게 재작성하는 무제한 조합 공간과 퍼즐별 완전 수작업 검증.

## 4. 구조 후보

### A. 학기형 학습 나선 — 권장

```text
새 원리 학습
→ 제한된 자유일정으로 준비·관계 선택
→ 시험·학교 행사에서 통제된 응용
→ 현장 사건에서 복합 적용
→ 마도서 복기·발견
→ 다음 원리와 더 어려운 상황 개방
```

장점:
- 현재 Slice가 전체 게임의 축소판이 된다.
- 학교와 현장이 서로 필요해진다.
- 새 글자를 커리큘럼 단위로 제한해 조합 폭증을 통제한다.
- 서사 성장과 시스템 성장을 같은 주기로 묶기 쉽다.

위험:
- 매 장의 수업·시험·현장이 공식처럼 반복될 수 있다.
- 일정 선택이 단순 버프 선택으로 축소될 수 있다.

### B. 학교 허브 + 사건 의뢰형

```text
학교에서 학습·준비
→ 여러 사건 중 선택
→ 현장 해결
→ 보상·기록·관계 변화
→ 새로운 사건과 글자 개방
```

장점:
- 사건 선택과 재플레이성이 높다.
- 콘텐츠를 독립 에피소드로 추가하기 쉽다.

위험:
- 학교생활이 메뉴 허브가 될 가능성이 높다.
- 장학생 성장선과 학기 평가가 약해진다.
- 플레이어가 유리한 사건만 골라 성장 최적화를 할 수 있다.

### C. 반복 학기·Roguelite형

```text
학기 시작 빌드 선택
→ 제한 일정과 무작위 사건
→ 시험·현장
→ 실패·졸업 결과
→ 영구 발견을 가지고 새 학기 재시작
```

장점:
- 높은 반복성과 조합 실험.
- 부분 성공과 실패를 구조적으로 수용.

위험:
- 현재의 연속 서사·관계·책임 기록과 충돌한다.
- 직접 작성 반복 피로가 커진다.
- Save·밸런스·무작위 콘텐츠 제작 범위가 크게 증가한다.

## 5. 권장 판정

```yaml
recommended: A_ACADEMIC_SPIRAL
adopt:
  - 학습→준비→통제된 응용→현장 적용→복기→다음 학습
  - 일정 선택의 기회비용
  - 명시적 규칙 변화와 원인 설명
  - 배운 구성요소의 여러 콘텐츠 재사용
adapt:
  - 한 학기 전체가 아니라 Chapter 단위 압축
  - 자유일정은 소수의 의미 있는 선택만 제공
  - 새 글자는 Chapter마다 제한적으로 추가
reject:
  - 대규모 학교 자유 탐색 반복
  - 대량 재료 파밍·레시피 경제
  - 완전 무작위 학기 반복
  - 무제한 규칙 조합
```

## 6. 프로젝트 추론

A안은 기존 Vertical Slice를 폐기하지 않고 본편의 첫 학습 나선으로 승격할 수 있는 유일한 후보에 가깝다. 다만 각 Chapter가 같은 `수업→시험→현장` 순서를 그대로 복제하지 않도록 콘텐츠 리듬 변주 규칙이 후속으로 필요하다.
