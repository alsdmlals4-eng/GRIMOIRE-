## 2. 결정 질문

> GRIMOIRE가 직접 글자를 쓰는 마법 판타지를 유지하면서도 입력 피로와 오인식을 통제하고, 작은 글자 문법으로 수업·시험·축제·현장에서 서로 다른 복수 해법을 제공하며, 학교생활 선택과 마도서 기록을 45~50분 데모 안에서 의미 있게 연결하려면 어떤 계약을 채택해야 하는가?

## 3. 비교축

1. 직접 입력이 판타지를 강화하는가, 단순 조작 장벽이 되는가
2. 조합 결과의 원인과 대가가 읽히는가
3. 복수 해법이 실제 선택인지 정답 숨기기인지
4. 학교·자유일정이 다음 핵심 세션에 환류하는가
5. 기록이 완성 답안 저장인지 발견 과정의 기억인지
6. 데모 제작량과 플레이 시간이 통제되는가

## 6. 프로젝트 계약

### 6.1 직접 작성 빈도 예산

Vertical Slice 필수 성공 작성은 다음 7개 순간을 기본으로 한다.

1. 수업: `흐름`
2. 수업: `집중`
3. 수업: `분산`
4. 시험: 선택 조합 1회
5. 축제: 선택 조합 1회
6. 현장 전투: 선택 조합 1회
7. 현장 환경: 선택 조합 1회

계약:

- 정상 완주 필수 성공 작성: 7회
- 안내형 복구를 포함한 목표 상한: 10회
- 같은 문제 안에서 이미 확인된 동일 글자를 다시 사용할 때는 확인된 글자 토큰을 선택할 수 있다.
- 중요한 결정 순간에는 최종 조합을 직접 작성하거나 직접 작성한 글자를 명시적으로 조립한다.
- 자동 시전, 무확인 자동 보정, 후보 목록만으로 신규 글자 해금은 금지한다.

### 6.2 입력 책임 분리

```text
획 입력
→ 인식 후보
→ 사용자 확인·부분 수정
→ 글자 의미 확정
→ 조합
→ 상황 경향 미리보기
→ 명시적 시전
→ 세계 변화
→ 원인·대가 설명
```

- 입력 불일치는 설계 실패 점수에 합산하지 않는다.
- 낮은 확신 후보는 자동 선택하지 않는다.
- Undo·취소·재작성은 자원을 소모하지 않는다.
- 시전 이후에만 마나·횟수·상황 결과를 소비한다.

### 6.3 조합 규모

- Slice 글자: 메인 1, 보조 2
- 기본 조합: 메인 단독, 메인+집중, 메인+분산
- 다중 보조 동시 사용: Slice 제외
- 순서 의존 문법: Slice 제외
- 완성 주문 스톡: Slice 제외
- 문제별 유효 해법: 최소 2개
- 모든 문제의 단일 종합 점수: 금지

### 6.4 자유일정

- 자유일정은 정확히 3회다.
- 한 슬롯에서 중심 행동 1개만 선택한다.
- 휴식·준비·교류는 서로 다른 편의를 제공하지만 필수 성공률을 독점하지 않는다.
- 선택 효과는 해당 다음 핵심 세션을 주로 보조하고 장기 누적 최적 루트를 만들지 않는다.
- 관계 선택도 짧은 기계적 보조 또는 해석 차이를 가질 수 있으나 필수 정보는 공통 경로에서 제공한다.

### 6.5 마도서 기록

마도서는 다음을 기록한다.

```text
상황
→ 사용한 글자와 조합
→ 의도
→ 실제 결과
→ 부작용·포기한 것
→ 새로 발견한 활용
→ 플레이어가 붙인 이름
```

- 자동 최적 조합 추천을 제공하지 않는다.
- 같은 기록을 클릭해 완성 주문을 자동 시전하지 않는다.
- 재사용 시에는 구성 글자의 숙련·확인 상태를 보여 주되 현재 상황 검증을 다시 거친다.

## 7. 채택·배제 요약

### ADOPT

- 직접 그리는 행위와 세계 변화의 연결
- 작은 문법에서 복수 해법
- 자유일정의 관계·준비·회복 환류
- 결과 과정과 책임을 기록하는 마도서

### ADAPT

- 입력 압박을 감속·확인·Undo로 완화
- 조합 폭을 3개 기본 결과로 제한
- 학교생활을 3회의 짧은 선택으로 압축
- 해결법 비교를 점수 경쟁이 아닌 성향·대가 기록으로 전환

### REJECT

- 대형 학교 허브 노동
- 복잡한 캘린더 최적화
- 수십 개 원소·수정자 조합
- 순서 의존 주문 문법
- 완성 주문 자동 시전 스톡
- 게임패드만으로 신규 글자를 그리는 대체 입력 약속

## 8. 결론

권장안 `흐름 / 집중 / 분산`, 3회 자유일정, 수호형 보조 소환수, PC 마우스·펜 작성, 46분 목표·53분 콘텐츠 상한은 유지한다.

벤치마킹으로 추가 확정할 핵심은 다음과 같다.

- 필수 성공 직접 작성 7회, 목표 상한 10회
- 같은 문제의 확인된 글자는 토큰 재선택 가능
- 입력 수정은 자원 소모 없음
- 마도서는 과정·대가·발견 기록이며 자동 주문 스톡이 아님
- 자유일정 효과는 다음 세션 중심이며 누적 최적 루트를 만들지 않음
- Gamepad는 `DEFERRED / NOT_PROMISED`
