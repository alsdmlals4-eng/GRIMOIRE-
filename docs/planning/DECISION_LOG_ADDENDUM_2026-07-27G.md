## GM-CURVE-01 — 첫 마법부터 첫 숙련 자동화까지

### 질문

첫 5분, 첫 수업, 첫 주문 설계, 첫 현장실습, 첫 발견과 첫 숙련 자동화를 어떤 순서와 감정 곡선으로 제공할 것인가?

### 제안안

1. 사건으로 즉시 시작한 뒤 수업으로 복귀
2. 짧은 수업에서 바로 마법 사용·설계
3. 학교생활과 인물 소개 후 첫 수업

### 사용자 결정

- 채택: 2번 `짧은 수업에서 바로 마법 사용·설계`

### 확정 방향

```text
학교 도착·현재 목표 소개
→ 교수의 짧은 시범
→ 첫 메인 글자 직접 작성
→ 세계가 변하는 결과 확인
→ 보조 글자 하나로 작은 설계 선택
→ 짧은 일상·관계 장면
→ 첫 모의 현장실습에서 응용
→ 새 활용 발견·마도서 기록

```

핵심 문장:

> 먼저 마법이 작동하는 기쁨을 주고, 곧바로 내가 설계했다는 감각을 주며, 실전에서 응용한 뒤 숙련된 반복만 자동화한다.

## 첫 5분 책임

첫 5분 안에 다음 경험을 순서대로 제공한다.

1. 마법학교 학생이라는 역할과 현재 목표 이해
2. 메인 글자 직접 작성
3. 작성 직후 눈에 보이는 현상 변화
4. 보조 글자 하나를 통한 결과 변형
5. 플레이어 선택에 따라 다른 결과 발생

첫 5분 종료 시 플레이어가 이해해야 하는 내용:

- 메인 글자는 핵심 현상을 만든다.
- 보조 글자는 현상의 작동 방식을 바꾼다.
- 직접 작성과 선택이 세계 변화로 이어진다.

정확한 시간은 `PLAYTEST_TUNING_REQUIRED`다.

## 첫 온보딩 세션

첫 10~15분 온보딩은 여러 정규 Session Loop를 압축해 맛보게 하는 예외 구간이다.

```text
짧은 수업
→ 작은 설계 과제
→ 짧은 관계 장면
→ 모의 현장실습
→ 복귀·마도서 기록
```

이후 정규 세션에는 수업·일상·실습을 모두 강제로 넣지 않는다.

## 첫 발견

- 배운 메인·보조 글자를 플레이어가 의도적으로 조합한다.
- 새로운 상황에서 유효하게 작동한 활용을 발견으로 기록한다.
- 한 가지 정답 레시피만 강제하지 않는다.
- 성공한 활용은 마도서에 주문 또는 활용 기록으로 남긴다.

목표 감정: `내가 알아낸 주문이다`

## 첫 숙련 자동화

첫 자동화는 `하위 글자 스톡`으로 시작한다.

```text
직접 작성
→ 서로 다른 상황에서 반복 사용
→ 역할과 결과 이해
→ 안정적 재현
→ 숙련 인정
→ 숙련 보조 글자의 하위 글자 스톡 후보 해금
```

보호 원칙:

- 첫 5분에 스톡을 지급하지 않는다.
- 수동 작성 경험 없이 자동화를 먼저 공개하지 않는다.
- 단순 사용 횟수만으로 해금하지 않는다.
- 스톡은 주문 전체가 아니라 숙련 반복 보조 하나만 줄인다.
- 완성 주문 스톡은 직접 작성·조합·발견을 충분히 이해한 이후로 미룬다.
- 정확한 요구량과 공개 시점은 `PLAYTEST_TUNING_REQUIRED`다.
