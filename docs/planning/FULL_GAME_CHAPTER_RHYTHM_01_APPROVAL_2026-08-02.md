## 2. 승인된 Chapter 기능 계약

각 학습 나선 Chapter는 다음 다섯 기능을 가진다.

```text
발견·학습
선택·준비
통제된 응용
실전·책임 선택
복기·다음 질문
```

이 다섯 항목은 고정된 장면 종류가 아니라 **플레이 기능**이다.

- `발견·학습`: 새 원리·상황·오류를 이해한다.
- `선택·준비`: 휴식·준비·교류·현장실습 중 현재 문제에 대한 태도와 준비를 선택한다.
- `통제된 응용`: 시험·축제·공동연구·훈련·구조 작업처럼 실패 비용이 통제된 공간에서 배운 원리를 시험한다.
- `실전·책임 선택`: 실제 인물·생태·시설·관계에 결과와 대가가 남는 문제를 해결한다.
- `복기·다음 질문`: 마도서와 인물 반응을 통해 원인·부작용·포기한 것을 정리하고 다음 Chapter의 질문을 연다.

## 3. 순서·형태 변주 규칙

- 모든 Chapter에 `발견·학습`, `실전·책임 선택`, `복기·다음 질문`이 최소 한 번 존재한다.
- `선택·준비`와 `통제된 응용`의 횟수는 Chapter 목적과 길이에 따라 달라질 수 있다.
- 자유일정 창은 Chapter당 `1~3회 후보`이며 정확한 개수는 `TEST_VALUE`다.
- 모든 자유일정 창에서 휴식·준비·교류·현장실습 네 선택을 전부 제공할 의무는 없다.
- 현장실습은 학교 허가·안전·공간·서사 상태가 맞을 때만 열린다.
- 메인 현장 사건이 먼저 발생하고, 학교에서 원인을 배우고, 다시 대응하는 역순 Chapter를 허용한다.
- 시험·축제·대회·공동연구·탐사·구조·교류전은 모두 `통제된 응용`의 서로 다른 표현이 될 수 있다.
- 인접한 두 Chapter가 완전히 동일한 장면 순서를 복제하지 않는다.
- 같은 콘텐츠 형식이 인접 Chapter의 같은 위치에 반복되면 명시적 서사 이유와 차별화된 상황 질문이 필요하다.

## 4. Chapter 기획 카드 필수 필드

향후 각 Chapter 문서에는 다음을 명시한다.

1. Chapter의 새 상황 질문.
2. 새로 배우거나 재해석하는 마법 원리.
3. 다섯 기능을 담당하는 장면.
4. 자유일정 창과 제공 선택지.
5. 선택형 현장실습의 개방 여부와 이유.
6. 통제된 응용과 메인 현장 사건의 차이.
7. 책임 선택과 보존하지 못한 대상.
8. 마도서 복기와 다음 질문.
9. 재사용 Asset과 신규 제작 Asset.
10. Mobile 세션 중단·복귀 Anchor 후보.

기능 담당 장면이 없거나, 같은 장면이 근거 없이 여러 기능을 대신하면 기획 감사에서 누락으로 판정한다.

## 5. 대표 변주 예시

```text
표준형
수업 → 자유일정 → 시험 → 현장 → 복기

조사형
현장 이상 징후 → 학교 조사 → 교류/실습 → 공동 해결 → 복기

사고형
축제 준비 → 사고 → 현장 대응 → 사후 수업 → 마도서 재해석

재도전형
실습 실패 → 원인 분석 → 새 글자 학습 → 재도전 → 평가
```

위 순서는 구조 예시이며 승인된 본편 Chapter 목록이 아니다.

## 6. 자유일정 현장실습과 관계

- 현장실습은 `선택·준비` 또는 `통제된 응용` 기능을 담당할 수 있다.
- 메인 현장 사건의 `실전·책임 선택` 기능을 대체하지 않는다.
- 같은 실습 전투를 반복해 Chapter 기능을 채운 것으로 처리하지 않는다.
- Chapter 질문과 연결되지 않는 전투는 추가하지 않는다.
- 정확한 개방 횟수·길이·보상·반복 감쇠는 후속 성장·경제 결정까지 `TEST_VALUE`다.

## 7. 적대적 검토와 보호 규칙

### 반복 공식 위험

보정:
- 기능은 고정하지만 장면 순서·형태·비중을 바꾼다.
- 인접 Chapter의 전체 순서 복제를 금지한다.

### 변주로 인한 혼란 위험

보정:
- 각 Chapter 시작부에 현재 질문과 가까운 목표를 제시한다.
- Chapter 기획 카드에서 다섯 기능의 담당 장면을 추적한다.
- 복기에서 무엇을 배우고 무엇이 다음 질문으로 넘어가는지 명시한다.

### 제작량 폭증 위험

보정:
- 새 장면 형식보다 기존 학교·숲·온실·전투장 상태 변형을 우선한다.
- 순서를 바꾸는 것과 새 Asset을 만드는 것을 동일시하지 않는다.
- 한 Chapter에 모든 콘텐츠 형식을 넣지 않는다.

### Mobile 세션 단절 위험

보정:
- 각 기능 전환점은 Save/Resume Anchor 후보로 취급한다.
- 정확한 기능별 시간은 전체 본편 범위와 Mobile 세션 결정에서 검증한다.

## 8. 거부한 대안

- 고정 주차·달력형을 전체 Chapter 기본 구조로 사용하지 않는다.
- 모든 Chapter를 사건 우선→학교 회귀 순서로 강제하지 않는다.
- 수업→시험→축제→현장을 매 Chapter 동일하게 반복하지 않는다.
- 자유일정을 Activity Point 최적화 메뉴로 만들지 않는다.
