## 2. 승인된 Chapter 기능 계약

각 학습 나선 Chapter는 다음 다섯 기능을 가진다.

```text
발견·학습
선택·준비
통제된 응용
실전·책임 선택
복기·다음 질문
```

- `발견·학습`: 수업·연구·사건 관찰을 통해 새 문자 원리와 오류를 이해하고 가볍게 작성한다.
- `선택·준비`: 휴식·준비·교류·현장실습 중 현재 문제에 대한 태도와 준비를 고른다.
- `통제된 응용`: 축제·일상 사건·공동연구·훈련·구조 작업에서 비전투 또는 낮은 위험으로 문자를 응용한다.
- `실전·책임 선택`: 현장실습·메인 사건에서 실제 인물·생태·시설에 결과와 대가가 남는 문제를 해결한다.
- `복기·다음 질문`: 마도서와 교수 피드백으로 결과·부작용·포기한 것을 정리하고 다음 질문을 연다.

별도 시험은 Chapter 필수 기능이나 콘텐츠 형식이 아니다.

## 3. 순서·형태 변주 규칙

- 모든 Chapter에 `발견·학습`, `실전·책임 선택`, `복기·다음 질문`이 최소 한 번 존재한다.
- `선택·준비`와 `통제된 응용`의 횟수는 Chapter 목적과 길이에 따라 달라질 수 있다.
- 자유일정 창은 Chapter당 `1~3회 후보 / TEST_VALUE`다.
- 모든 자유일정 창에서 네 선택을 전부 제공할 의무는 없다.
- 현장실습은 허가·안전·공간·서사 상태가 맞을 때만 열린다.
- 메인 현장 사건이 먼저 발생하고 학교에서 원인을 배운 뒤 재대응하는 역순 Chapter를 허용한다.
- 축제·일상 사건·대회·공동연구·탐사·구조·교류전은 `통제된 응용`의 서로 다른 표현이 될 수 있다.
- 인접 Chapter가 완전히 동일한 장면 순서를 복제하지 않는다.
- 별도 시험장·시험 전용 미니게임으로 통제된 응용을 반복하지 않는다.

## 4. Chapter 기획 카드 필수 필드

1. Chapter의 새 상황 질문.
2. 새로 배우거나 재해석하는 마법 원리.
3. 다섯 기능을 담당하는 장면.
4. 수업의 문자 학습·가벼운 작성 연습.
5. 자유일정 창과 제공 선택지.
6. 축제·일상 이벤트의 비전투 응용.
7. 선택형 현장실습의 개방 여부와 이유.
8. 현장 수행의 책임 선택과 보존하지 못한 대상.
9. 마도서 복기·교수 누적 평가와 다음 질문.
10. 재사용/신규 Asset 및 Mobile Save/Resume Anchor 후보.

## 5. 대표 변주 예시

```text
표준형
수업 → 자유일정 → 일상 응용 → 현장실습 → 복기

조사형
현장 이상 징후 → 학교 조사·문자 연습 → 교류/실습 → 공동 해결 → 복기

사고형
축제 준비·비전투 응용 → 사고 → 현장 대응 → 사후 수업 → 마도서 재해석

재도전형
현장실습 실패 → 원인 분석 → 새 문자 연습 → 다른 맥락에서 응용 → 재도전·누적 평가
```

위 순서는 구조 예시이며 승인된 본편 Chapter 목록이 아니다.

## 6. 자유일정 현장실습과 누적 평가

- 현장실습은 `선택·준비`, `통제된 응용`, `실전·책임 선택` 중 문맥에 맞는 기능을 담당할 수 있다.
- 선택형 현장실습이 메인 사건의 세계 변화와 책임을 대체하지 않는다.
- 같은 실습 전투 반복으로 Chapter 기능이나 성장 증거를 모두 채울 수 없다.
- 축제·일상 이벤트의 비전투 응용도 계열 성장과 평가에 실제로 기여한다.
- 평가·개방 횟수·길이·보상·감쇠는 후속 결정 전까지 `TEST_VALUE`다.

## 7. 적대적 보호 규칙

- 기능은 고정하지만 장면 순서·형태·비중을 바꿔 반복 공식을 막는다.
- 각 Chapter 시작부에 현재 질문과 가까운 목표를 제시해 변주 혼란을 막는다.
- 새 장면 형식보다 기존 학교·숲·온실·전투장 상태 변형을 우선한다.
- 기능 전환점은 Mobile Save/Resume Anchor 후보로 취급한다.
- 별도 시험 제거가 평가 부재로 이어지지 않도록 활동 포트폴리오와 교수 피드백을 유지한다.
- 현장실습 성적이 축제·일상·복기보다 항상 우월한 평가가 되지 않도록 한다.

## 8. 거부한 대안

- 고정 주차·달력형을 전체 Chapter 기본 구조로 사용하지 않는다.
- 모든 Chapter를 사건 우선→학교 회귀 순서로 강제하지 않는다.
- 수업→시험→축제→현장을 반복하지 않는다.
- 별도 시험 Chapter·시험장·시험 전용 미니게임을 두지 않는다.
- 자유일정을 Activity Point 최적화 메뉴로 만들지 않는다.
