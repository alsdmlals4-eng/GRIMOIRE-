## 2. 핵심 세계 문장

```text
학교가 가르치는 정식은 절대진리가 아니라 오랜 실패를 거쳐 검증된 안전한 선례다.
현장에서는 장소·역사·정령·사람이 만든 문맥을 읽어야 하며,
충분한 근거와 책임 아래 기존 상태를 개정할 수 있다.
```

GRIMOIRE의 주인공은 숨은 진짜 정답이나 혈통을 발견해서 세계를 구하는 존재가 아니다. 플레이어의 저자성은 관찰, 기록, 설명, 선택, 실패 복기, 관계, 책임의 누적으로 만들어진다.

## 3. 마법 세계의 네 층

### 3.1 원문

`원문`은 자연·생명·인과처럼 세계가 쉽게 양보하지 않는 깊은 제약이다.

- 학생이 직접 편집하는 소스코드가 아니다.
- 고대의 유일한 정답 문서나 숨은 치트키로 사용하지 않는다.
- 3학년의 고급 연구에서도 원문의 경계는 세계 재작성에 대한 책임을 제한한다.

### 3.2 정식

`정식`은 학교와 이전 마법사들이 축적한 검증된 주문 선례다.

- 안전성과 재현성이 높다.
- 당시 조건에서 검증된 선례이지 모든 장소의 영원한 정답이 아니다.
- 정식의 가치와 표준화의 가치를 서사적으로 부정하지 않는다.

### 3.3 문맥

`문맥`은 같은 주문의 의미와 결과를 달라지게 만드는 현재 조건이다.

- 장소의 물리 상태
- 지역의 역사
- 정령 생태
- 사람과 공동체의 선택
- 현재 위험과 시간 압력
- 과거 개정이 남긴 흔적

### 3.4 개정

`개정`은 충분한 문맥 증거를 근거로 기존 세계 상태를 지속적으로 바꾸는 행위다.

- 일반 주문보다 결과와 책임이 무겁다.
- 다른 사람의 선택, 생명, 이미 발생한 역사를 마음대로 삭제하는 기능이 아니다.
- 실패 기록을 지우는 리셋 도구가 아니다.
- 1학년 Chapter 7의 첫 개정은 세계 전체가 아니라 `서리꽃 온실`의 제한된 관계·상태를 대상으로 한다.

## 4. 마도서의 세계관 역할

마도서는 정답 데이터베이스가 아니라 플레이어의 **개인 선례집**이다.

```text
사용한 의미
→ 당시 문맥
→ 실제 결과
→ 보존한 것과 포기한 것
→ 실패·부분성공·부작용
→ 새로 배운 원리
→ 후속 개정의 근거
```

마도서는 자동 해법을 출력하지 않는다. 동반자도 마도서를 통해 정답을 제공하지 않는다.

## 5. 1학년 세 교육 계열

### 5.1 유동학 — FLOW

이동·전달·순환·경로를 다룬다.

- 1학년 최초 기초 계열이다.
- 수로, 기류, 운반, 순환, 압력 흐름에 강하다.
- 항상 가장 안전하거나 가장 효율적인 상위호환 계열은 아니다.

### 5.2 변성학 — HEAT

온도·상태·물질 변화를 다룬다.

- 가열·냉각·상태 변화·재료 반응의 원리를 학습한다.
- 연구·제작과 현장 환경 문제에 연결한다.
- 공격 마법 전용 계열로 축소하지 않는다.

### 5.3 결계학 — PROTECT

보호·격리·압력 유지·경계 형성을 다룬다.

- 생명·시설 보호와 위험 분리에 강하다.
- 방어 전용 숫자 계열로 축소하지 않는다.
- 무엇을 보호하고 무엇을 경계 밖에 둘지에 책임이 따른다.

### 5.4 공통 조율 문법

`FOCUS / DISPERSE`는 특정 계열이 아니라 세 계열 모두가 사용하는 공통 보조 문법이다.

계열은 정치·윤리 성향과 1:1로 대응하지 않는다. `결계학=보수`, `변성학=진보`처럼 고정하지 않는다. 공통 사건과 장소를 계열별 원리·대가로 재해석하며 별도 캠페인을 만들지 않는다.

## 6. 주요인물

### 6.1 플레이어 — 이름 고정 없음

```yaml
role: 장학생 학생 / 마도서 저자
starting_pressure: 평가와 현장실습에서 자신의 해법을 증명해야 한다
arc: 정답 복제 -> 문맥 관찰 -> 책임 있는 개정의 저자
chosen_one_bloodline: FORBIDDEN
```

플레이어가 특별한 이유는 혈통이나 예언이 아니라 3년간 축적한 관찰과 책임이다.

### 6.2 마렌 — 지도 교수

```yaml
character_id: GR-C-PROFESSOR
name: 마렌
values: 안전 / 설명 가능성 / 창의성 / 책임
role: 지도자 / 평가자 / 후반의 동료 검증자
answer_delivery: FORBIDDEN
```

마렌은 과거 자신이 승인한, 당시에는 안전했던 개정이 장기적으로 한 지역의 정령 순환을 끊어 버린 경험이 있다. 그래서 학생에게 정답을 직접 주기보다 결과 원인을 설명하게 한다.

- 1학년: 안전선과 질문을 제공한다.
- 2학년: 플레이어의 개정이 사회적 선례가 되는 위험을 함께 검증한다.
- 3학년: 학생을 통제하는 교수가 아니라 개정을 반대검증하고 책임을 함께 지는 동료 마법사로 이동한다.

### 6.3 카시안 — 핵심 동급생

```yaml
character_id: GR-C-PEER
name: 카시안
values: 정식 / 속도 / 재현성 / 검증
role: 경쟁자 / 협력자 / 반대검증자
```

카시안은 틀린 라이벌이 아니다. 긴급 상황에서 표준화된 정식을 빠르고 안전하게 사용해 플레이어보다 먼저 사람을 구할 수 있어야 한다.

- 1학년: 정석의 강점을 증명하면서 플레이어와 경쟁한다.
- 2학년: 표준으로 해결할 수 없는 문맥을 직접 경험한다.
- 3학년: 플레이어의 새 원리를 안전한 정식으로 만들기 위한 반대검증자가 된다.

### 6.4 네아 — 메인 정령 동반자

```yaml
character_id: GR-C-COMPANION
name: 네아
initial_form: 작은 늑대형 원소 정령수
role: 감정 / 문맥 반응 / 공동 발견 / 기록 연결
oracle_behavior: FORBIDDEN
```

- 1학년: 불안·안도·불일치 같은 감각 반응을 보여 준다.
- 2학년: 장소와 정령이 가진 기억에 더 강하게 반응한다.
- 3학년: 인간 기록에서 누락된 과거 개정의 흔적을 증언할 수 있다.
- 끝까지 구체 주문 조합이나 정답을 말하지 않는다.

### 6.5 에일린 — 현장복원 마법사

```yaml
character_id: GR-C-AILEEN
name: 에일린
role: 학교 밖 현장복원 관점
first_major_role: Year-One Ch6 서리꽃 온실
```

에일린은 학교가 틀렸다고 주장하는 반학교 캐릭터가 아니다. 검증된 선례가 실제 주민·시설·정령에게 어떤 비용으로 작동하는지를 보여 준다.

### 6.6 모트 — 기록원

```yaml
character_id: GR-C-MOTT
name: 모트
role: 기록 접근 / 금지 지식 / 개정 사고의 역사
```

처음에는 위험한 지식을 막는 보수적 인물처럼 보이지만, 금지 기록에는 실제 대형 개정 사고의 근거가 있다. 핵심 갈등은 `금지냐 공개냐`의 단순 이분법이 아니라 누가 어떤 근거와 책임으로 지식에 접근할 수 있는가이다.

## 7. 세력

### 7.1 마도학원 정식위원회

- 검증된 선례, 교육 품질, 안전 기준을 보존한다.
- 악의적 권위주의 집단으로 단순화하지 않는다.
- 플레이어의 새 원리를 공용 정식으로 채택할지 검증하는 역할을 가진다.

### 7.2 현장복원단

- 사고·생태·시설 복구를 담당한다.
- 현장 문맥과 즉시 책임을 우선한다.
- 학교의 정식이 실제 현장에서 어떤 비용을 갖는지 보여 준다.

### 7.3 정령협약망

- 단일 중앙정부가 아니라 지역별 정령·인간 공동체를 잇는 느슨한 협의 구조다.
- 정령을 단일 종족·단일 정치의 목소리로 만들지 않는다.
- 지역마다 인간과 정령의 관계가 다를 수 있다.

### 7.4 개방서고 연합

- 마법 지식과 개정 권한이 소수 기관에 독점되는 문제를 제기한다.
- 신중한 연구자와 위험한 급진파가 함께 존재한다.
- 세력 전체를 영웅 또는 악당으로 고정하지 않는다.

플레이어는 네 세력 중 하나를 골라 별도 캠페인으로 분기하지 않는다. 공통 사건에서 각 세력이 서로 다른 비용, 증거, 보호 대상을 주장하도록 한다.

## 8. 3년 서사 질문

### 8.1 1학년 — 정답은 왜 맞는가?

```text
정답 복제
→ 상황 해석
→ 복수 원리 비교
→ 실패·부분성공 복기
→ 실제 현장 책임
→ 첫 독자 원리
→ 제한된 첫 세계 개정
```

승인된 7 Chapter / `2·2·3` 구조를 그대로 사용한다. `서리꽃 온실의 심장`은 1학년의 큰 현장 사건이고 Chapter 7에서 그 증거를 바탕으로 첫 작은 개정을 작성한다.

### 8.2 2학년 — 누가 세계를 바꿀 권리가 있는가?

1학년의 개정이 학교의 성공 사례로 소개되면서, 다른 학생이나 기관이 결과만 복제하려는 문제가 발생한다.

- 주민, 정령, 학교, 복원단이 서로 다른 `안전`을 주장한다.
- 전문화는 반복 시전 자동 잠금이 아니라 수강·증거·관심을 바탕으로 명시적으로 선택한다.
- 학년말 목표는 혼자 만든 정답이 아니라 이해관계자가 결과와 비용을 아는 상태에서 합의한 **첫 공동 개정**이다.

### 8.3 3학년 — 무엇을 바꾸지 않을 책임이 있는가?

고급 연구에서 플레이어는 안정된 세계 상태 중 일부도 과거의 오래된 개정이 겹쳐 굳어진 결과임을 배운다. 그러나 `모든 현실은 마음대로 편집 가능하다`는 결론으로 가지 않는다.

- 자연적 제약
- 생명
- 타인의 선택
- 이미 발생한 역사
- 설명할 수 없는 장기 영향

위 요소는 개정의 경계가 된다.

졸업 위기는 오래된 여러 개정이 서로 충돌하면서 발생한다. 최종 선택은 세력 선택이 아니라 3년의 마도서 증거를 사용해 **무엇을 보존하고, 무엇을 되돌리고, 무엇을 새로 쓸지** 설계하는 것이다.

결말은 숨은 선악 점수 하나가 아니라 반복적으로 보여 준 원리, 대가, 관계, 보존 대상의 조합으로 후일담이 달라진다.

## 11. 적대검토

- **정식 무가치화 위험:** 카시안과 정식위원회가 실제 안전·속도·재현성의 가치를 증명해야 한다.
- **현장 만능주의 위험:** 문맥을 읽었다고 모든 위험을 해결할 수 없으며 원문·생명·타인의 선택이 경계로 남는다.
- **네아 오라클 위험:** 감각 반응과 증언만 허용하고 주문 해법은 금지한다.
- **세력 콘텐츠 폭증:** 세력별 캠페인 대신 공통 사건의 상충 관점으로 제한한다.
