- 마도서가 결과뿐 아니라 의도·부작용·발견을 기록.
- 동반 정령이 정답을 알려주지 않고 감정·불안정을 반응.

## 4. 발견된 공백

### P1 — 작업 순서 충돌

`START_HERE`, `ACTIVE_CONTEXT`, Sheet는 Smartphone Writing/Battle Wireframe을 다음 작업으로 지정했다. 그러나 장기 반복 행동·성장·보상이 미확정이어서 화면이 게임 규칙을 선결정할 위험이 있다.

교정:

```text
FULL-GAME-STRUCTURE-01
→ Vertical Slice 대표성 재검증
→ Mobile UX·Wireframe
```

### P2-01 — Macro Loop 없음

현재 `12_핵심루프`는 자유일정·작성·검증·시전·기록의 단계를 나열하지만, 플레이어가 왜 다음 주·다음 장·다음 학기를 계속하는지 정의하지 않는다.

### P2-02 — 글자 확장 규칙 없음

Slice의 `흐름 / 집중 / 분산` 이후 무엇을 어떤 순서로 배우며, 새 글자가 기존 글자와 어떤 새 판단을 만드는지 미정이다.

### P2-03 — 성장축과 선택 비용 불완전

`정밀 / 안정 / 표현 / 책임`, 관계, 동반자 4단계 방향은 있으나 실제 획득·선택·잠금·상충 규칙이 없다.

### P2-04 — 경제·소모처 불완전

현재 자원은 일정과 글자 기록 중심이다. 마나 외 장기 자원, 보상 사용처, 반복 플레이의 인플레이션 방지 원칙이 없다.

### P2-05 — 콘텐츠 확장 단위 없음

수업·시험·축제·현장실습은 한 Slice로만 정의됐다. 본편에서 장·학기·과목·사건이 어떤 템플릿으로 추가되는지 미정이다.

### P2-06 — 실패와 평가의 장기 영향 없음

개별 상황의 부분 성공·피해 결과는 있으나 장학금, 관계, 학업 평가, 다음 일정에 어떤 영향을 주는지 미정이다.

### P2-07 — 본편 범위와 종결 조건 없음

한 학기인지 학년인지, 몇 개의 핵심 글자·현장 사건·보스가 필요한지, 어디서 완결되는지 미정이다.
