## GM-WORLD-01 — 세계관 기본 틀

### 채택안

`마법학교 + 현장실습 + 성장 모험`

### 확정 규칙

- 플레이어는 마법학교에서 회로 마법을 배우는 학생이다.
- 학교는 수업·교류·준비·숙련·자격 상승의 중심 허브다.
- 실제 전투·탐험·주문 발견은 학교 밖 현장실습에서 주로 발생한다.
- 학교생활과 외부 지역 모험을 반복하는 성장 구조를 사용한다.
- 현장실습은 마법 생태 조사, 재해 안정화, 유적 해석, 마법 사고 해결, 구조·봉인·복구 등을 포함할 수 있다.
- 적 처치만을 유일한 해결 방식으로 사용하지 않는다.

상태: `DIRECTION_CONFIRMED`

## GM-WORLD-02 — 비밀학과 중심 서사 제외

### 사용자 결정

`비밀학과 쪽은 굳이 사용하지 않고, 회로의 활용으로 자유롭게 추가한다.`

### 확정 규칙

- 비밀학과·삭제된 학과·학교 내부 음모를 세계관의 필수 중심축으로 사용하지 않는다.
- 플레이어가 특별히 선택된 비밀학과 학생이어야 할 필요가 없다.
- 개별 지역 사건, 유적, 위험한 연구에 비밀이 존재할 수는 있다.
- 모든 장기 서사가 학교의 은폐된 음모로 수렴하지 않는다.
- 금지 회로나 위험한 연구는 선택적 사건·고난도 콘텐츠로 사용할 수 있지만 세계관 코어는 아니다.

상태: `CONFIRMED`

## GM-WORLD-03 — 회로의 활용 중심 콘텐츠 확장

### 핵심 방향

```text
기초 회로 학습
→ 현장 문제와 환경 관찰
→ 형상·전달·보조·조건과 자유롭게 조합
→ 새로운 활용 발견
→ 주문 설계도로 등록
→ 숙련 후 스톡화
```

### 확정 규칙

- 신규 콘텐츠는 숨겨진 학과나 새로운 마법 체계를 계속 추가하는 방식에만 의존하지 않는다.
- 이미 배운 회로도 목적·대상·환경·연결 방식에 따라 새로운 결과를 낼 수 있다.
- 회로는 스킬 조각이 아니라 마법 현상을 구성하는 문법으로 취급한다.
- 새로운 지역은 기존 회로의 새로운 활용 조건을 제공할 수 있다.
- 플레이어가 현장에서 유효한 활용을 증명하면 마도서 설계도로 등록한다.
- 반복 가능성과 안전성이 확보된 활용은 숙련·스톡화 단계로 연결된다.

상태: `DIRECTION_CONFIRMED`

## 세계관–시스템 대응

| 시스템 | 세계관 의미 |
|---|---|
| 직접 회로 작성 | 원리를 이해한 학생의 현장 즉석 대응 |
| 주문 발견 | 새로운 회로 활용의 실증 |
| 마도서 등록 | 발견한 활용을 공식 설계도로 기록 |
| 하위 회로 스톡 | 숙련·표준화된 반복 회로 |
| 완성 주문 스톡 | 검증된 주문의 사전 준비 |
| 소환수 | 실습을 지원하는 계약형 마법 존재 |
| 공용 준비 용량 | 전투 전 안정적으로 유지 가능한 준비 한계 |
| 현장실습 | 지식을 실제 문제 해결 능력으로 전환하는 과정 |

## 현재 미해결 세계관 결정

1. 학교의 규모와 위치: 단일 명문학교 / 마법학교 도시 / 여러 학교 중 하나
2. 주인공의 입학 형태: 신입생 / 편입생 / 견습 연구생
3. 성장 표시: 학년제 / 자격 등급제 / 혼합형
4. 현장실습 선택 방식: 학교 배정 / 학생 선택 / 혼합형
5. 장기 갈등: 마법 재해 / 마법 생태 충돌 / 학교·기관 경쟁 / 기타
6. 전투 외 회로 활용의 실제 플레이 범위
