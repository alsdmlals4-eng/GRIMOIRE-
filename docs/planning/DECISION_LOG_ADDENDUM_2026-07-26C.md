## GM-00-30 — 지속 피해는 스톡 충전을 정지시키지 않음

### 채택안

`B — 지속 피해는 피격 정지를 발생시키지 않고, 별도 상태이상이 스톡 충전에 영향을 줌`

### 확정 규칙

- 화상·독·출혈 등 상태효과 기반 지속 피해 틱은 체력을 감소시킨다.
- 지속 피해 틱은 직접 피해의 0.25초 피해 집계에 포함하지 않는다.
- 지속 피해 틱으로 스톡 자동 충전이나 충전 대상 전환을 정지하지 않는다.
- 지속 피해는 체력 압박과 회복 자원 소모에 집중한다.
- 스톡 충전 방해는 별도의 상태이상 효과가 담당한다.
- 하나의 상태가 지속 피해와 스톡 방해를 함께 가질 수는 있지만 두 효과를 독립적으로 계산한다.

### 역할 분리

```text
직접 피해
→ 0.25초 실제 체력 손실 비율에 따른 피격 정지

지속 피해
→ 체력 감소
→ 스톡 정지 없음

스톡 방해 상태이상
→ 충전 속도·충전 봉인·대상 전환 등에 직접 영향
```

### 설계 의도

- 작은 지속 피해가 반복적으로 충전을 끊는 문제를 방지한다.
- 직접 피해와 지속 피해의 전투 역할을 구분한다.
- 상태이상 설계를 통해 스톡 충전 방해를 명시적이고 읽기 쉽게 제공한다.
- 부분 방어와 지속 피해 면역의 가치를 각각 다른 축에서 표현한다.

## 상태이상–스톡 연동 방향

현재 확정된 것은 `별도 상태이상이 스톡 충전에 영향을 줄 수 있다`는 방향이다.

후보 영향 축:

1. 충전 속도 감소
2. 충전 일시 봉인
3. 충전 대상 전환 지연 증가 또는 전환 제한
4. 직접 시전·정확 입력 등 능동 충전 기여 억제
5. 플레이어 또는 소환수의 생산 기여 감소

어떤 상태이상에 어떤 축을 배정할지는 다음 결정으로 남긴다.

## 후속 미해결 결정

1. 상태이상별 스톡 영향 축을 어떻게 배정하는가.
2. 충전 봉인 중 이미 완성된 스톡 사용을 허용하는가.
3. 상태이상 중첩과 충전 속도 최소 하한을 어떻게 처리하는가.
4. 수호·동조 능력치가 스톡 방해 상태를 저항·해제할 수 있는가.
5. 직접 피해와 지속 피해가 동시에 발생하는 복합 공격의 데이터 분류 규칙은 무엇인가.
