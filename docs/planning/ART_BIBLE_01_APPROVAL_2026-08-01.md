## 4. 최종 시각 언어

### 배경

- `SOFT_STORYBOOK_ENVIRONMENT`.
- 고정 장면 기반 3/4 공간.
- 회화 질감은 유지하되 플레이 영역과 목표 주변 세부 밀도를 낮춘다.
- 수업·시험·축제는 공용 학교 장면의 조명·장식·NPC·상태 변형으로 제작한다.

### 캐릭터

- `CLEAN_ANIME_CEL_CHARACTER_OVER_STORYBOOK_BACKGROUND`.
- 배경보다 선명한 외곽과 제한된 셀 명암.
- SD·반신·전투 Cut-in은 머리 실루엣·대표색·의상 핵심 파츠·얼굴 특징을 공유한다.

### UI

- `NAVY_GOLD_MAGIC_ACADEMY_FRAME`.
- 짙은 네이비 반투명 면, 얇은 금색·황동 테두리, 제한된 모서리 장식.
- 본문·버튼·수치는 높은 한글 가독성의 고딕계 서체 방향.
- 제목·장식 라벨에만 제한적으로 세리프계 방향을 사용한다.
- 실제 Font와 라이선스는 `ASSET-SPEC-01`에서 확정한다.

### 마법 FX

- 글자 획은 가장 밝고 선명한 정보.
- `흐름`은 방향·경로, `집중`은 좁은 코어·강한 밀도, `분산`은 넓은 파동·낮은 밀도로 구분한다.
- 전체 화면 블룸·안개·종이 질감으로 글자·대상·위험을 가리지 않는다.

## 6. 주인공 시각 키

- Slice 주인공은 커스터마이즈형이 아닌 고정 캐릭터 1명이다.
- 잠긴 기준판의 짙은 머리색, 단정한 학생 실루엣, 네이비 제복, 금색 포인트를 보호한다.
- SD와 반신은 같은 앞머리·눈·외투·하의 실루엣 관계를 사용한다.
- 기준 이미지의 픽셀 단위 얼굴을 복제하는 것이 아니라 별도 Character Sheet에서 정확한 얼굴 구조를 확정한다.
- 플레이어 이름 입력 여부와 서사 이름은 `NAMING-PASS-01`로 분리하며 Art Bible 승인 조건이 아니다.

## 7. 동반 정령·수호 소환수

### 메인 동반 정령

- 작은 늑대형 초기 형상 1개.
- 흰색·옅은 청색, 둥근 얼굴, 큰 귀·꼬리·작은 원소광.
- Slice에서 성장 2~4단계·탑승 자산을 만들지 않는다.
- 공식 이름은 `NAMING-PASS-01`에서 세계 명명 규칙과 함께 확정한다.

### 수호형 보조 소환수

- 메인 동반자보다 각진 수호 실루엣.
- 전장 상시 몸체가 아니라 상태 배지와 짧은 보호 Cut-in/FX로 표현한다.
- 전투당 제한된 보호 역할만 검증하며 다역할 편성 자산을 만들지 않는다.

## 8. 전투 화면 최종 규칙

```text
상단·중앙 = 강한 적 1개체·환경 목표·공격 예고
좌측 하단 = 주인공 얼굴 초상 1개·HP·마나·상태
좌측 보조 = 동반 정령·수호 소환수 상태 배지
우측 = 축소형 작성 Rail → 행동 시 확장형 작성 Panel
```

- 파티 선택·다중 아군 초상은 Vertical Slice 범위에 포함하지 않는다.
- 우측 작성 패널은 항상 전체 크기로 열어 두지 않는다.
- 적 실루엣과 공격 예고는 작성 중에도 유지한다.
- `1.0× / 감속 / 정지`를 숫자·아이콘·문구로 표시한다.
- 일반 적은 단일 페이즈이며, 보스 변형은 별도 Gate 이전에 제작하지 않는다.

## 9. 화면별 계약

### Field

월드가 화면 대부분을 차지하고 HUD는 목표·상태의 최소 정보만 제공한다. PC 화면에 영구 가상 조이스틱을 표시하지 않는다.

### Dialogue

같은 장소 배경 위 기본 화자 1명, 필요 시 2명까지. 표정만으로 필수 정보를 전달하지 않는다.

### Writing

현재 대상·목표·위험을 유지하며 캔버스·후보·조합·비용·확정을 우선한다.

### Battle

별도 전술 전투장이지만 Field의 장소·사건·색·오브젝트 인과를 계승한다. 아군 몸체 상시 배치 규칙은 사용하지 않는다.

### Result·Return

획득량보다 무엇이 왜 바뀌었는지를 먼저 보여주고 원래 장소 변화로 복귀한다.

### Grimoire

전통 장비 인벤토리가 아니라 상황·글자·의도·결과·부작용·발견을 관리한다. 자동 최적 추천·기록 클릭 자동 시전 금지.

### Main

학교 전경·마도서·빛나는 글자·동반 정령 중 1~2개 상징을 사용하는 최소 시작 화면. 수집형 로비 UI 금지.

## 11. Slice 제작 상한

- 학교 공용 기반 장면 + 수업·시험·축제 상태 변형.
- 현장 기반 장면 + 같은 사건의 별도 전술 전투장.
- 주인공 SD·반신·초상 최소 세트.
- 교수·동급생 필드 SD와 핵심 반신.
- 일반 NPC는 필드 SD 또는 배경 군중.
- 메인 동반 정령 초기 형상 1개.
- 수호형 보조 소환수 1체의 배지·짧은 Cut-in/FX.
- 글자 `흐름 / 집중 / 분산`.
- 공용 Panel·Button·Icon·Text 계층.

## 12. 금지
