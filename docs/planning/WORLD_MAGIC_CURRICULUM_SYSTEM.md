## 1. 핵심 방향

학교의 마법 수업은 **현상·물질·개념 중심의 메인 글자 계열**을 기준으로 나눈다.

```text
메인 글자 계열 수업
→ 계열의 현상·원리 이해
→ 메인 글자 습득
→ 메인 글자 레벨 성장
→ 계열과 잘 맞는 보조 글자 습득
→ 여러 보조 글자 조합
→ 현장실습에서 실제 활용
```

수업은 완성 주문을 통째로 지급하는 목록이 아니다. 학생은 수업에서 글자와 문법을 배우고, 현장에서 자신의 조합을 성공시켜 주문을 발견한다.

## 2. 메인 글자 계열 분류

메인 글자는 공격·방어·회복 같은 기능이 아니라 세계에 발생시키는 **현상·물질·개념**으로 분류한다.

후보 방향:

- 열·불꽃
- 물·유동
- 바람·압력
- 빛
- 힘·충격
- 생명·회복
- 보호·차단
- 이동·공간
- 감지
- 소환
- 변환

위 계열 수와 명칭은 후보이며 최종 과목 목록은 추후 확정한다.

```text
불꽃 메인 글자
→ 공격: 화염탄
→ 생활: 난방
→ 구조: 해빙
→ 생산: 재료 가공
```

기능은 계열 분류가 아니라 배운 글자를 어떤 상황에 활용했는지 나타낸다.

## 3. 수업의 세 층

### 3.1 공통 문법 과목

모든 학생이 필수로 배우는 기초 과목이다.

- 마법 글자의 기본 획과 판독
- 회로 연결·방향·안전 규칙
- 마력 흐름과 직접 시전
- 기본 안정화
- 형상·전달의 공통 원리
- 마도서 기록과 스톡화 기초

공통 문법 과목은 특정 메인 계열에 속하지 않는 보편 보조 글자를 가르친다.

### 3.2 메인 글자 계열 과목

각 과목은 하나의 메인 글자 또는 밀접한 메인 글자군을 중심으로 구성한다.

과목의 기본 구성:

1. 계열 현상의 원리와 위험
2. 메인 글자의 기본 발현
3. 메인 글자의 현재 레벨과 성장 과제
4. 계열 대표 보조 글자
5. 생활·연구·전투 활용 사례
6. 계열 담당 교수와 연구 과제
7. 관련 현장실습과 평가

예시:

```text
열·불꽃 계열
→ 불꽃 메인 글자
→ 집중·확대·지속·점화·안정화 보조
→ 난방·가공·해빙·전투·재해 진압 활용
```

```text
보호·차단 계열
→ 보호 메인 글자
→ 고정·확대·지속·반사·조건 보조
→ 개인 방어·시설 보호·봉쇄·구조 활용
```

### 3.3 응용·융합 실습

이미 배운 메인 글자와 다른 수업에서 배운 보조 글자를 자유롭게 조합한다.

```text
열 계열의 메인 글자
+
전달 문법 수업의 추적 보조
+
보호 계열 수업의 고정 보조
→ 새로운 현장 활용 실험
```

응용 실습은 정해진 주문을 따라 하는 방식보다 목표와 제한 조건을 주고 학생이 조합을 설계하는 방식으로 운영한다.

## 4. 메인 글자 레벨

각 메인 글자는 독립적인 레벨을 가진다.

```text
불꽃 메인 Lv.3
물 메인 Lv.1
보호 메인 Lv.2
```

- 플레이어 전체 레벨과 별개다.
- 학년 상승만으로 자동 레벨업하지 않는다.
- 같은 학년이라도 수강·연구·현장실습 선택에 따라 계열별 레벨이 달라진다.
- 여러 계열을 넓게 배우거나 소수 계열을 깊게 연구할 수 있다.

### 기획 기본값

| 단계 | 의미 |
|---:|---|
| Lv.0 | 미습득 |
| Lv.1 | 입문 — 메인 단독 기본 발현 |
| Lv.2 | 숙련 — 안정성·효율·재현성 향상 |
| Lv.3 | 응용 — 보조 조합과 현장 활용 확대 |
| Lv.4 | 심화 — 고난도 문법과 상위 활용 연구 |
| Lv.5 | 전공·연구 — 개인 해석과 졸업 연구 수준 |

`Lv.0~Lv.5`는 `PLANNING_DEFAULT`이며 정확한 상한과 수치는 후속 데이터 설계에서 조정할 수 있다.

## 5. 메인 레벨 성장 과정

```text
이론 수업
→ 직접 작성 훈련
→ 기본 발현의 안정적 재현
→ 관련 보조 글자 조합
→ 현장 활용 성공
→ 보고·시험·연구 인증
→ 메인 글자 레벨 상승
```

레벨 상승 요소 후보:

- `이해도`: 수업·교수 연구·기록 분석
- `숙련도`: 직접 작성·반복 시전·모의 실습
- `활용 기록`: 서로 다른 현장 문제 해결
- `인증`: 과제·시험·발표·교수 평가

반복 수업만으로 최고 레벨을 달성하지 않는다. 상위 레벨일수록 현장 검증과 독립 연구의 비중이 커진다.

## 6. 레벨이 성장시키는 것

메인 글자 레벨은 단순 공격력 증가가 아니다.

- 메인 단독 기본 발현의 출력·정밀도·활용 범위
- 안정성과 재현성
- 마나 효율과 고출력 부담
- 다수 보조 글자를 안정적으로 받아들이는 수용력
- 상급 현장실습과 연구 과제 접근
- 계열별 교수·학생·소환수 사건
- 졸업 연구와 전문 진로

높은 메인 레벨이 보조 글자의 기능을 자동으로 지급하지는 않는다.

```text
불꽃 메인 Lv.5
≠ 추적·확대·분열 자동 습득
```

메인 레벨은 현상 이해와 수용력을 성장시키고, 보조 글자는 별도의 수업과 활용으로 배운다.

## 7. 학년별 수업 역할

### 1학년 — 넓게 배우는 기초

- 공통 마법 글자 문법
- 여러 기초 메인 계열의 입문 수업
- 여러 계열을 Lv.1로 습득
- 관심 계열 일부를 Lv.2까지 성장
- 메인 글자 하나로 기본 주문 발동
- 소수의 형상·전달·안정 보조 글자
- 안전한 학교 시설과 인근 지역 실습

1학년은 특정 계열을 너무 빨리 영구 선택하게 하지 않는다.

### 2학년 — 선택과 전문화

- 관심 계열의 중급 수업 선택
- 선택 계열을 Lv.3 중심으로 성장
- 일부 핵심 계열의 Lv.4 진입 후보
- 계열 전용 보조 글자
- 조건·순서·복합 연결 문법
- 다른 계열 보조 글자의 교차 응용
- 교수 연구·공동 실습·교류전

2학년부터 수강 선택이 해결 방식, 관계, 연구 주제와 전문 분야에 본격적으로 영향을 준다.

### 3학년 — 독립 설계와 연구

- 전공 계열 Lv.4~Lv.5 연구
- 고급 기본 발현과 다수 보조 글자의 복합 주문
- 독립 연구와 주문 설계
- 후배 지도와 공동 프로젝트
- 졸업 현장실습·연구 발표

3학년은 정답 주문을 배우기보다 자신이 선택한 계열과 보조 문법으로 문제를 해결하고 결과를 설명한다.

## 8. 하나의 수업 진행 구조

```text
핵심 이론 설명
→ 메인 글자 시범
→ 직접 따라 쓰기
→ 메인 단독 기본 주문 발동
→ 현재 레벨 과제 확인
→ 관련 보조 글자 실습
→ 제한 조건이 있는 응용 과제
→ 자유 일정의 반복 연구
→ 현장실습에서 검증
→ 보고·평가·레벨 인증
```

필수 설명은 짧게 제공하고, 교수에게 다시 말을 걸면 계열 역사·세부 원리·연구 사례를 선택형 상세 대화로 들을 수 있다.

## 9. 글자 습득·주문 발견 단계

| 단계 | 의미 |
|---|---|
| 관찰 | 교수 시범과 원리 이해 |
| 모사 | 안내선을 따라 글자 작성 |
| 기본 발동 | 메인 글자 단독 주문 성공 |
| 레벨 성장 | 이론·숙련·활용·인증 누적 |
| 조합 | 관련 보조 글자와 결합 |
| 활용 | 현장 문제에 맞게 변형 |
| 등록 | 성공한 주문을 마도서 설계도로 기록 |
| 숙련 | 반복 사용으로 안정화 |
| 스톡화 | 기준 이하의 숙련 글자·주문을 준비 가능 |

수업을 수강하거나 메인 레벨이 올랐다는 이유만으로 완성 주문이 자동 등록되지는 않는다.

## 10. 수업 선택과 성장

수업 선택은 다음을 연다.

- 해당 계열의 메인 글자와 레벨 성장 기회
- 관련 보조 글자
- 담당 교수의 연구 과제
- 동급생·라이벌과의 공동 활동
- 관련 현장실습 후보
- 현장 문제의 추가 해결 관점
- 전문 분야와 졸업 후 진로
- 계열별 소환수 적성 또는 지원 후보

핵심 문법과 최소한의 기본 메인 글자는 필수 교육으로 보장한다. 선택 수업을 잘못 골랐다는 이유로 메인 진행이 막히지 않는다.

## 11. 자유 일정과 수업

한 학기의 자유 일정 10회 중 일부를 수업·연구에 사용할 수 있다.

- 한 번의 수강으로 계열의 모든 내용을 끝내지 않는다.
- 같은 계열 수업을 반복하면 입문→숙련→응용→심화→연구 단계가 열린다.
- 다른 계열 수업을 들으면 조합 가능한 글자의 폭이 넓어진다.
- 수업 외 관계·휴식·소환수·현장 준비도 의미 있는 경쟁 선택으로 유지한다.
- 레벨 상승에 필요한 현장실습과 시험은 자유 일정 밖의 고정 사건과도 연결될 수 있다.

정확한 필수·선택 수업의 일정 비용과 비율은 후속 설계에서 정한다.

## 12. 가드레일

- 수업을 완성 주문 구매 메뉴로 만들지 않는다.
- 메인 레벨을 단순 공격력 배율 하나로 만들지 않는다.
- 수업 버튼 반복만으로 최고 레벨을 달성하지 않는다.
- 메인 계열마다 동일한 보조 글자를 이름만 바꿔 중복 생산하지 않는다.
- 모든 보조 글자를 계열 전용으로 잠그지 않는다.
- 1학년 초반에 전문 계열을 영구 고정하지 않는다.
- 특정 수업이나 낮은 계열 레벨 때문에 핵심 진행이 불가능해지지 않게 한다.
- 메인 레벨이 보조 글자 습득·주문 발견·현장 판단을 대체하지 않게 한다.
- 모든 메인 글자를 한 회차에 최고 레벨로 만들 수 있게 하지 않는다.

## 13. 추후 결정

- 최종 메인 글자 계열과 과목명
- 정확한 최대 레벨과 레벨별 수치
- 레벨별 기본 발현 변화
- 레벨별 안전 보조 글자 수용 범위
- Lv.4~Lv.5의 선형 성장 또는 전문 분기
- 학년별 필수 계열과 선택 계열 수
- 공통 보조 글자와 계열 전용 보조 글자의 비율
- 수업 1회의 자유 일정 비용
- 완성 주문 스톡에 적용되는 메인 레벨 기준
- 보조 글자의 레벨·숙련 구조
