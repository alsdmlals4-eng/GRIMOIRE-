## 1. 핵심 방향

학교의 마법 수업은 **메인 글자 계열**을 기준으로 나눈다.

```text
메인 글자 계열 수업
→ 계열의 현상·원리 이해
→ 메인 글자 습득
→ 계열과 잘 맞는 보조 글자 습득
→ 기본 주문 실습
→ 여러 보조 글자 조합
→ 현장실습에서 실제 활용
```

수업은 완성 주문을 통째로 지급하는 목록이 아니다. 학생은 수업에서 글자와 문법을 배우고, 현장에서 자신만의 조합을 성공시켜 주문을 발견한다.

## 2. 수업의 세 층

### 2.1 공통 문법 과목

모든 학생이 필수로 배우는 기초 과목이다.

- 마법 글자의 기본 획과 판독
- 회로 연결·방향·안전 규칙
- 마력 흐름과 직접 시전
- 기본 안정화
- 형상·전달의 공통 원리
- 마도서 기록과 스톡화 기초

공통 문법 과목은 특정 메인 계열에 속하지 않는 보편 보조 글자를 가르친다.

### 2.2 메인 글자 계열 과목

각 과목은 하나의 메인 글자 또는 밀접한 메인 글자군을 중심으로 구성한다.

과목의 기본 구성:

1. 계열 현상의 원리와 위험
2. 메인 글자의 기본 발현
3. 계열 대표 보조 글자
4. 생활·연구·전투 활용 사례
5. 계열 담당 교수와 연구 과제
6. 관련 현장실습과 평가

예시 형식:

```text
열·불꽃 계열
→ 불꽃 메인 글자
→ 집중·확대·지속·점화·안정화 보조
→ 난방·가공·해빙·전투·재해 진압 활용
```

```text
보호·차단 계열
→ 보호 메인 글자
→ 고정·확대·지속·반사·조건 보조
→ 개인 방어·시설 보호·봉쇄·구조 활용
```

위 계열명과 글자는 예시이며 최종 과목 목록은 추후 확정한다.

### 2.3 응용·융합 실습

이미 배운 메인 글자와 다른 수업에서 배운 보조 글자를 자유롭게 조합한다.

```text
열 계열의 메인 글자
+
전달 문법 수업의 추적 보조
+
보호 계열 수업의 고정 보조
→ 새로운 현장 활용 실험
```

응용 실습은 정해진 정답 주문을 따라 하는 수업보다, 목표와 제한 조건을 주고 학생이 조합을 설계하는 방식이 적합하다.

## 3. 학년별 수업 역할

### 1학년 — 넓게 배우는 기초

- 공통 마법 글자 문법
- 여러 기초 메인 계열의 입문 수업
- 메인 글자 하나로 기본 주문 발동
- 소수의 형상·전달·안정 보조 글자
- 안전한 학교 시설과 인근 지역 실습

1학년은 특정 계열을 너무 빨리 영구 선택하게 하지 않는다. 여러 계열을 경험하고 자신의 적성을 발견하게 한다.

### 2학년 — 선택과 전문화

- 관심 계열의 중급 수업 선택
- 계열 전용 보조 글자
- 조건·순서·복합 연결 문법
- 다른 계열의 보조 글자를 가져오는 교차 응용
- 교수 연구·공동 실습·교류전

2학년부터 수강 선택이 현장 해결 방식, 관계, 연구 주제와 전문 분야에 본격적으로 영향을 준다.

### 3학년 — 독립 설계와 연구

- 상위 메인 글자 또는 고급 기본 발현
- 다수 보조 글자의 복합 주문
- 독립 연구와 주문 설계
- 후배 지도와 공동 프로젝트
- 졸업 현장실습·연구 발표

3학년은 과목에서 정답 주문을 배우기보다, 자신이 선택한 계열과 보조 문법으로 문제를 해결하고 결과를 설명하는 단계다.

## 4. 하나의 수업 진행 구조

```text
핵심 이론 설명
→ 메인 글자 시범
→ 직접 따라 쓰기
→ 메인 글자만으로 기본 주문 발동
→ 관련 보조 글자 실습
→ 제한 조건이 있는 응용 과제
→ 자유 일정의 반복 연구
→ 현장실습에서 검증
→ 마도서 등록·평가
```

필수 설명은 짧게 제공하고, 교수에게 다시 말을 걸면 계열 역사·세부 원리·연구 사례를 선택형 상세 대화로 들을 수 있다.

## 5. 습득 단계

| 단계 | 의미 |
|---|---|
| 관찰 | 교수 시범과 원리 이해 |
| 모사 | 안내선을 따라 글자 작성 |
| 기본 발동 | 메인 글자 단독 주문 성공 |
| 조합 | 관련 보조 글자와 결합 |
| 활용 | 현장 문제에 맞게 변형 |
| 등록 | 성공한 주문을 마도서 설계도로 기록 |
| 숙련 | 반복 사용으로 안정화 |
| 스톡화 | 기준 이하의 숙련 글자·주문을 준비 가능 |

수업을 수강했다는 이유만으로 모든 완성 주문이 자동 등록되지는 않는다.

## 6. 수업 선택과 성장

수업 선택은 단순 스탯 증가 외에 다음을 연다.

- 해당 계열의 메인 글자와 보조 글자
- 담당 교수의 연구 과제
- 동급생·라이벌과의 공동 활동
- 관련 현장실습 후보
- 현장 문제의 추가 해결 관점
- 마법사 사회의 전문 분야와 진로
- 계열별 소환수 적성 또는 지원 후보

핵심 문법과 최소한의 기본 메인 글자는 필수 교육으로 보장한다. 선택 수업을 잘못 골랐다는 이유로 메인 진행이 막히지 않는다.

## 7. 자유 일정과 수업

한 학기의 자유 일정 10회 중 일부를 수업·연구에 사용할 수 있다.

- 한 번의 수강으로 모든 내용을 끝내지 않는다.
- 같은 계열 수업을 반복하면 기초→응용→연구 단계가 열린다.
- 다른 계열 수업을 들으면 조합 가능한 글자의 폭이 넓어진다.
- 수업 외의 관계·휴식·소환수·현장 준비도 경쟁하는 의미 있는 선택으로 유지한다.

정확한 필수 수업과 선택 수업의 일정 비용·비율은 후속 설계에서 정한다.

## 8. 가드레일

- 수업을 완성 주문 구매 메뉴로 만들지 않는다.
- 메인 계열마다 동일한 보조 글자를 이름만 바꿔 중복 생산하지 않는다.
- 모든 보조 글자를 계열 전용으로 잠그지 않는다.
- 1학년 초반에 전문 계열을 영구 고정하지 않는다.
- 특정 수업을 놓치면 핵심 진행이 불가능해지는 구조를 만들지 않는다.
- 수업 수강만으로 주문 발견·마도서 등록·숙련이 모두 자동 완료되지 않게 한다.
- 교수 설명보다 현장 활용과 플레이어 조합을 성장의 핵심으로 유지한다.

## 9. 추후 결정

- 메인 글자 계열의 최종 분류와 과목명
- 학년별 필수 계열과 선택 계열 수
- 공통 보조 글자와 계열 전용 보조 글자의 비율
- 하나의 계열 수업에서 배우는 메인 글자 수
- 수업 1회가 자유 일정 1회를 소비하는지 여부
- 수강 반복 단계와 평가 방식
- 계열별 교수·학생·소환수 구성
