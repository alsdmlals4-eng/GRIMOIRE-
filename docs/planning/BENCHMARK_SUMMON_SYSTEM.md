# Spell 소환수 벤치마킹 — 마기카로기아 참고

## 1. 문서 상태

- 상태: `REFERENCE_REVIEWED`
- 기준 날짜: 2026-07-25
- 대상: `마도서대전 RPG 마기카로기아`
- 목적: Spell의 기존 동료 시스템을 소환수 시스템으로 전환할 때 참고할 구조 추출

이 문서는 공개된 공식 웹사이트, 공식 FAQ와 정오표에서 확인할 수 있는 내용만 근거로 사용한다. 기본 룰북 전체 세부 규칙은 공개 웹 문서만으로 확인할 수 없으므로, 확인되지 않은 사항은 추정하지 않는다.

## 2. 공식 자료에서 확인한 구조

### 2.1 원형은 소환·사역되는 마법적 존재

공식 정오표는 기본 룰북에 열 종류의 원형 카테고리가 수록된다고 설명한다. 각 카테고리는 정령, 악몽, 마검, 기사, 처녀, 전차, 마왕, 군단, 왕국, 마신 등으로 구분된다.

Spell에 적용할 때는 이 명칭과 분류를 복제하지 않고, 소환 존재가 서로 다른 외형·능력·강도를 가질 수 있다는 구조만 참고한다.

### 2.2 제한된 전투 공간에서 기능

공식 FAQ는 소환 마법이 제한된 공간인 `주권/마법 전투 영역` 안에서 원형이라는 제한된 기능을 사용하도록 설계되어 있다고 설명한다. 또한 원형은 반드시 다른 세계에서 불려오는 것이 아니라 술자의 이미지가 구현되는 경우도 많다고 설명한다.

Spell 적용 후보:

- 소환수를 일반적인 동물 펫보다 플레이어의 마법·기억·별자리·계약이 구현된 존재로 설정
- 전장 또는 마법 회로 영역 안에서 기능하는 존재로 처리
- 소환수 외형을 주문 계통과 플레이어 서사에 연결

### 2.3 소환 존재가 주문 사용을 보조

공식 FAQ의 `캐스트` 능력 설명에서는 원형이 주문 사용 횟수를 늘리고, 자신의 영역과 맞는 주문 판정을 자동 성공시킬 수 있다고 설명한다. 다만 소환 직후 모든 소환을 연쇄적으로 자동화하는 것은 제한된다.

Spell 적용 후보:

- 소환수의 회로 적성과 주문 계열이 맞으면 자동작성·자동스펠 효율 상승
- 소환 직후 즉시 모든 고급 자동화를 수행하지 않고 준비 시간이나 전환 시간 적용
- 소환수가 주문 선택을 대신하지 않고 등록된 주문을 보조

### 2.4 술자의 역량에 따른 수 제한

공식 FAQ는 술자의 근원력 제한을 넘어 원형을 소환하면 기존 원형 중 하나가 소멸하는 규칙을 설명한다.

Spell 적용 후보:

- 소환 가능한 수와 강도를 제한하는 `소환 용량` 도입
- 강한 소환수, 다수 소환수, 고급 자동스펠이 같은 용량을 경쟁하는 방식 검토
- 정확한 공식은 모바일 전투 PoC 이후 결정

## 3. ADOPT / ADAPT / AVOID

### ADOPT

- 소환 존재가 주문을 보조하는 구조
- 술자의 마법이 구현된 존재라는 정체성
- 소환 능력과 주문 계열의 상호작용
- 소환 수와 강도를 제한하는 용량 개념

### ADAPT

- TRPG의 원형 카테고리 → Spell의 개별 소환수 외형·능력·적성
- 판정 자동 성공 → 숙련 회로 자동작성 속도·안정성 보너스
- 라운드별 소환 단계 → 실시간 전투의 준비 시간·전환 시간
- 영역 일치 → 회로 적성 및 자동스펠 효율

### AVOID

- 원작 카테고리와 용어의 직접 사용
- 주사위 판정과 무작위 실패 중심 구조
- 소환수 역할을 고정 직업 타입으로 잠그는 구조
- 강한 소환수 획득이 기본 전투의 필수 조건이 되는 구조
- 자동화가 플레이어의 주문 선택과 회로 발견을 대신하는 구조

## 4. Spell 권장 방향

```text
소환수
= 플레이어의 마법이 구현된 전투·회로 협력자

능력치·적성
= 어떤 작업을 얼마나 잘하는가

스탠스
= 현재 어떤 작업을 우선하는가

소환 용량
= 동시에 운용 가능한 수와 강도의 한계
```

기존 동료 시스템의 능력치·스탠스·전환 제약은 유지하되, 상시 파티원이 아니라 소환된 마법적 존재라는 정체성으로 변경한다.

## 5. 미확인·미확정 범위

- 기본 룰북에 수록된 원형 각 카테고리의 전체 능력
- 모든 추가 룰과 보충 자료의 소환 관련 세부 규칙
- Spell 소환수의 정확한 카테고리 수
- Spell 소환수의 전투 지속시간과 소환 절차
- Spell에서 사용할 최종 세계관 용어
