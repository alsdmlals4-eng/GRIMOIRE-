## GM-CIRCUIT-02 — 메인 글자 계열 분류

### 채택안

`A — 현상·물질·개념 중심`

### 확정 방향

- 메인 글자 계열은 공격·방어·회복 같은 기능이 아니라 세계에 발생시키는 현상·물질·개념을 기준으로 분류한다.
- 열·불꽃, 물·유동, 바람·압력, 빛, 힘·충격, 생명·회복, 보호·차단, 이동·공간, 감지, 소환, 변환 등을 후보 방향으로 둔다.
- 실제 계열 수와 명칭은 후속 데이터 설계에서 확정한다.
- 공격·생활·구조·탐색·생산은 같은 메인 글자를 어떻게 활용했는지 나타내는 용도다.
- 하나의 메인 글자가 여러 문제 해결 역할을 가질 수 있어야 한다.

상태: `DIRECTION_CONFIRMED`

## GM-CIRCUIT-03 — 메인 글자별 레벨 성장

### 채택안

`메인 글자마다 독립 레벨을 두고 수업·훈련·현장 활용으로 성장`

### 확정 방향

- 각 메인 글자는 플레이어 전체 레벨과 별개의 독립 숙련 레벨을 가진다.
- 학년 상승만으로 자동 레벨업하지 않는다.
- 레벨은 이론 학습, 직접 작성 훈련, 보조 글자 조합, 현장 활용 성공, 보고·시험·연구 인증으로 상승한다.
- 레벨 상승은 기본 발현, 안정성, 마나 효율, 보조 글자 수용력, 활용 범위를 성장시킨다.
- 메인 레벨이 올라도 보조 글자의 기능을 자동으로 얻지 않는다.
- 메인 레벨은 기능 글자 수 계산에서 여전히 글자 1개로 취급한다.
- 다계열을 넓게 배우는 성장과 소수 계열을 깊게 연구하는 성장을 모두 허용한다.
- 특정 계열의 낮은 레벨 때문에 메인 진행이 영구 차단되지 않게 한다.

### 기획 기본값

```text
Lv.0 미습득
Lv.1 입문
Lv.2 숙련
Lv.3 응용
Lv.4 심화
Lv.5 전공·연구
```

- `Lv.0~Lv.5`는 `PLANNING_DEFAULT`이며 정확한 최대 레벨과 수치는 후속 설계에서 조정할 수 있다.
- 1학년은 여러 계열 Lv.1과 관심 계열 Lv.2, 2학년은 전문 계열 Lv.3~4, 3학년은 전공 계열 Lv.4~5를 권장 성장 곡선으로 둔다.
- 학년은 선수 과목과 안전 승인에 영향을 주지만 절대 레벨 상한은 아니다.

### 가드레일

- 단순 공격력 배율만 상승시키지 않는다.
- 수업 버튼 반복만으로 최고 레벨을 달성하지 않는다.
- 모든 메인 글자를 한 회차에 최고 레벨로 만들 수 있게 하지 않는다.
- 메인 레벨이 보조 글자 학습과 주문 발견을 대체하지 않는다.
- 레벨이 올라가도 복수 메인 글자 결합은 허용하지 않는다.
- 메인 글자 레벨로 스톡의 기능 글자 수를 부풀리지 않는다.

상태: `DIRECTION_CONFIRMED_WITH_PLANNING_DEFAULT`

책임 원본: `docs/planning/MAIN_LETTER_LEVEL_SYSTEM.md`

## 후속 미해결 결정

1. Lv.4~Lv.5는 선형 성장인가, 전문 분기로 나뉘는가.
2. 각 메인 글자의 기본 발현과 레벨별 변화는 무엇인가.
3. 레벨별 안전 보조 글자 수용 범위는 얼마인가.
4. 메인 레벨이 완성 주문 스톡에 어느 시점 기준으로 적용되는가.
5. 보조 글자에도 독립 레벨을 둘 것인가, 숙련 등급만 둘 것인가.
6. 학년별 필수 계열과 선택 계열 수는 몇 개인가.
