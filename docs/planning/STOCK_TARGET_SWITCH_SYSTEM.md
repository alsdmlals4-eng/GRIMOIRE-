# Spell 스톡 충전 대상 전환 시스템 — 최신 책임 원본

## 문서 상태

- 상태: `PLANNING_IN_PROGRESS`
- 결정 상태: `CONFIRMED`
- 기준 날짜: 2026-07-26
- 관련 결정: `GM-00-23`
- 상위 스톡 시스템: `docs/planning/STOCK_SYSTEM.md`
- 충전시간 시스템: `docs/planning/STOCK_CHARGE_TIME_SYSTEM.md`

이 문서는 전투 중 자동 충전 대상을 변경하는 방식, 진행도 보존과 전환 지연을 정의한다. 충전 대상 전환과 관련해 기존 문서의 미해결 항목과 충돌할 경우 이 문서가 우선한다.

## 1. 핵심 결정

전투 중 충전 대상은 변경할 수 있다.

```text
기존 스톡 충전 중
→ 새로운 충전 대상 선택
→ 기존 대상의 진행도 보존
→ 짧은 전환 지연 발생
→ 전환 완료 후 새 대상 충전 시작 또는 재개
```

- 충전 진행도를 초기화하지 않는다.
- 충전 대상은 계속 한 번에 1종만 유지한다.
- 전환 지연 동안에는 기존 대상과 새 대상 모두 충전되지 않는다.
- 전환 완료 후 새 대상에 저장된 진행도가 있다면 그 지점부터 재개한다.
- 전환 대상과 시점은 플레이어가 결정한다.

## 2. 대상별 진행도 보존

각 스톡 대상은 자신의 `다음 1회분 충전 진행도`를 별도로 보존한다.

예시:

```text
화염탄 스톡
→ 다음 1회분 70% 충전

결계 스톡으로 전환
→ 화염탄 70% 진행도 보존
→ 전환 지연
→ 결계의 저장 진행도부터 충전

다시 화염탄으로 전환
→ 전환 지연
→ 보존된 70%부터 재개
```

- 보존되는 것은 해당 대상의 다음 스톡 1회분 진행도다.
- 이미 완성된 스톡 수량은 그대로 유지된다.
- 여러 준비 대상이 각자 부분 진행도를 보유할 수 있다.
- 부분 진행도 비축은 허용하지만, 대상 변경마다 전환 지연을 지불한다.

## 3. 전환 지연

전환 지연은 잦은 대상 교체를 제한하는 시간 비용이다.

```text
전환 요청
→ 현재 충전 즉시 정지
→ 진행도 저장
→ 전환 지연 게이지 진행
→ 새 대상 활성화
```

전환 지연 중:

- 자동 충전 진행 없음
- 플레이어·소환수 생산 기여 적용 없음
- 직접 시전·정확 입력 등의 능동 충전 보너스는 새 대상에 즉시 적립되지 않음
- 전투와 직접 회로 시전은 정상 진행
- 완성되어 있던 기존 스톡은 정상 사용 가능

전환 지연의 실제 시간은 아직 확정하지 않는다. 터치 전투 PoC에서 짧지만 체감 가능한 값으로 검증한다.

## 4. 충전 대상 범위

전환 대상으로 선택할 수 있는 것은 현재 전투 준비 용량에 편성된 스톡뿐이다.

대상 후보:

- 완성 주문 스톡
- 하위 회로 스톡

다음은 선택할 수 없다.

- 전투 준비에 편성하지 않은 주문·회로
- 아직 스톡화 조건을 충족하지 않은 주문·회로
- 최대 스톡이 모두 채워져 추가 생산이 불필요한 대상

현재 대상이 최대치에 도달하면 자동으로 다른 대상으로 넘어가지 않는다. 충전은 정지하며 플레이어가 다음 대상을 직접 선택한다.

## 5. 플레이어와 소환수 책임

```text
플레이어
→ 충전 대상 선택과 변경
→ 전환 시점 판단

소환수
→ 활성화된 대상의 충전 효율 지원
→ 전환 대상을 임의로 변경하지 않음
```

소환수의 생산 능력치와 스탠스는 전환 완료 후 활성화된 대상에만 적용된다.

## 6. UI 필수 정보

- 현재 충전 대상 강조
- 현재 대상의 다음 1회분 충전 진행도
- 준비된 다른 대상들의 저장 진행도
- 전환 요청 대상 표시
- 전환 지연 게이지
- 전환 중 충전이 정지된다는 표시
- 최대치에 도달한 대상 표시
- 전환 완료 후 재개될 진행도 미리보기

진행도 보존이 명확히 보이지 않으면 플레이어가 전환으로 진행도를 잃었다고 오해할 수 있으므로, 비활성 대상에도 저장 진행도를 표시해야 한다.

## 7. 가드레일

- 전환 시 충전 진행도를 삭제하지 않는다.
- 전환 지연을 무시하고 여러 대상을 동시에 충전하지 않는다.
- 소환수가 플레이어 허가 없이 대상을 바꾸지 않는다.
- 전환 중 발생한 충전 보너스를 중복 적립하지 않는다.
- 최대치에 도달했다고 임의의 다른 스톡을 자동 생산하지 않는다.
- 전환 지연이 지나치게 길어 전략 변경을 억제하지 않게 한다.
- 전환 지연이 지나치게 짧아 부분 진행도 비축이 사실상 무비용이 되지 않게 한다.

## 8. PoC 검증 항목

| 가설 | 최소 검증물 | 통과 신호 |
|---|---|---|
| 진행도 보존이 전환 스트레스를 줄인다 | 두 스톡 간 50% 이상 진행도 전환 | 손실 불안 없이 상황에 맞춰 전환 |
| 전환 지연이 잦은 교체를 억제한다 | 지연 있음·없음 비교 | 한 대상을 집중하되 필요 시 전환 |
| 부분 진행도 비축이 과도하지 않다 | 세 대상 순환 전환 테스트 | 다중 충전처럼 느껴지지 않음 |
| UI가 저장 진행도를 설명한다 | 비활성 대상 진행도 표시 | 복귀 시 어디서 재개되는지 예측 |
| 소환수 역할이 유지된다 | 생산 지원 전후 비교 | 활성 대상 충전 보조자로 인식 |

## 9. 미해결 사항

1. 전환 지연의 실제 초 단위 값은 얼마인가.
2. 전환 지연이 플레이어·소환수 능력치로 감소하는가.
3. 전환 지연 중 다른 대상으로 다시 변경하면 지연을 어떻게 처리하는가.
4. 피격 시 전환 지연과 자동 충전이 유지·감속·중단되는가.
5. 전환 조작을 전투 화면에서 어떤 UI로 제공하는가.
