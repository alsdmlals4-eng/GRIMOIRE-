## 1. 채택 구조

Spell의 정규 교육 기간은 **3년제, 학년당 2학기, 총 6학기**다.

```text
1학년 1학기
→ 1학년 2학기
→ 학년 승급
→ 2학년 1학기
→ 2학년 2학기
→ 학년 승급
→ 3학년 1학기
→ 3학년 2학기
→ 졸업 실습·평가·진로
```

- 학년은 큰 성장 단계다.
- 학기는 수업·활동·현장실습을 선택하는 반복 단위다.
- 총 6학기는 학교생활의 성장 감각을 제공하면서 1인 개발 범위를 통제하기 위한 구조다.
- 정확한 학기별 활동 수, 임무 수와 플레이 시간은 후속 콘텐츠 설계에서 확정한다.

## 2. 학년별 역할

### 1학년 — 적응과 기초

핵심 목표:

- 학교 규칙과 생활 적응
- 기초 회로 문법 습득
- 직접 회로 작성과 안전 규칙
- 기본 소환수 계약·교감
- 인근 마을·숲·학교 시설 중심의 초급 현장실습
- 동급생·교수·라이벌 관계 형성

권장 회로 범위:

```text
메인 회로
+
형상·전달 기초
+
낮은 복잡도의 직접 조합
```

1학년은 튜토리얼만 담당하는 짧은 구간이 아니다. 학교생활, 첫 인간관계와 기초 회로 활용의 재미가 완결된 성장 단계로 구성한다.

### 2학년 — 전문화와 확장

핵심 목표:

- 선택 수업과 연구 분야 확대
- 보조 회로와 복잡한 연결 방식
- 조건·기동 회로의 도입 후보
- 소환수 운용과 스톡 활용 심화
- 도시·유적·마법 생태 지역의 중급 현장실습
- 공동 실습, 대회, 다른 학교와의 교류
- 플레이어 성장 성향과 전문 분야 구체화

2학년부터는 같은 문제를 서로 다른 수업·관계·회로 활용 방식으로 해결하는 선택의 차이를 본격적으로 보여준다.

### 3학년 — 독립 판단과 졸업

핵심 목표:

- 상위 회로 조합과 독립적인 설계
- 고위험 현장실습과 장기 임무
- 교수가 정답을 제공하지 않는 문제 해결
- 후배·동급생·민간인·지역에 대한 책임 확대
- 졸업 연구·발표·실기·종합 현장실습
- 전문 분야와 졸업 후 진로 결정

3학년의 성장은 단순 화력 상승보다 **자율성·책임·문제의 복잡도 증가**로 표현한다.

## 3. 학기 리듬

각 학기는 다음 공통 골격을 사용한다.

```text
학기 시작
→ 필수 수업과 주요 사건 제시
→ 선택 수업·자율활동·관계 활동
→ 소규모 학교 사건
→ 중간 현장실습
→ 성장·관계·활용 결과 누적
→ 학기 핵심 실습 또는 발표
→ 결과 보고와 다음 학기 전환
```

학년의 두 번째 학기는 학년말 평가와 승급 사건을 포함한다.

```text
1학년 2학기 종료
→ 2학년 승급 평가

2학년 2학기 종료
→ 3학년 승급 평가

3학년 2학기 종료
→ 졸업 종합 평가와 진로
```

## 4. 학년별 해금 방향

| 구분 | 1학년 | 2학년 | 3학년 |
|---|---|---|---|
| 회로 | 기초 문법 | 보조·조건·복합 활용 | 상위 조합·독립 설계 |
| 현장 | 학교 인근 | 도시·유적·중위험 지역 | 고위험·장기·독립 임무 |
| 관계 | 동급생·교수와 첫 관계 | 전문 분야 협력·경쟁 | 후배 지도·진로·장기 관계 |
| 소환수 | 기본 계약·운용 | 적성·스탠스 심화 | 고난도 협력·종합 운용 |
| 스톡 | 기본 등록·사용 | 편성·충전 전략 심화 | 고난도 직접 시전과 병행 |
| 책임 | 자신과 조별 과제 | 팀·시설·지역 문제 | 민간인·지역·후배·진로 |

정확한 회로 해금 시점은 회로 시스템 설계와 PoC 결과에 따라 조정할 수 있다. 표는 세계관과 성장 단계의 방향을 나타낸다.

## 5. 승급과 실패 처리

- 1학년과 2학년 종료 시 학년 승급 평가를 진행한다.
- 3학년 종료 시 졸업 종합 평가를 진행한다.
- 필수 수업, 최소 현장실습, 회로 활용 실기와 안전성 평가를 기본 축으로 사용한다.
- 부족한 항목은 보충 수업·재시험·추가 실습으로 회복 가능하다.
- 특정 선택 수업이나 빌드 때문에 메인 진행이 영구 차단되지 않게 한다.
- 낮은 평가는 보상·관계·진로 선택에 영향을 줄 수 있으나 반복적인 게임오버 장치로 사용하지 않는다.

## 6. 방학과 학기 사이

방학은 별도의 대규모 자유생활 시뮬레이션으로 만들지 않는다.

사용 후보:

- 짧은 귀향·학교 잔류 선택
- 보충 수업과 개인 연구
- 특정 인물의 짧은 관계 사건
- 다음 학기 준비와 스톡·소환수 정비
- 선택형 특별 현장실습
- 이전 학기 결과 요약

방학 콘텐츠의 분량과 필수 여부는 후속 설계에서 정한다.

## 7. 제작 범위 가드레일

- 각 학기를 완전히 새로운 게임처럼 만들지 않는다.
- 매 학년 학교 맵 전체를 새로 제작하지 않는다.
- 학기마다 모든 교수·학생에게 신규 장기 분기를 만들지 않는다.
- 6학기 모두에 세계 멸망급 사건을 배치하지 않는다.
- 1학년을 긴 튜토리얼로만 소비하지 않는다.
- 3학년에서 갑자기 학교생활을 버리고 전투만 진행하지 않는다.
- 학년 수를 늘려 콘텐츠 부족을 해결하지 않는다.
- 학기별 콘텐츠 밀도는 핵심 교수·동급생·현장실습을 재활용하며 점진적으로 확장한다.

## 8. 추후 결정

- 한 학기당 선택 활동 횟수
- 학기별 필수·선택 수업 비율
- 학기별 핵심 현장실습 개수
- 방학의 길이와 선택 콘텐츠 범위
- 학년별 회로·스톡·소환수의 정확한 해금 시점
- 3학년 졸업 평가와 진로·엔딩 구조
