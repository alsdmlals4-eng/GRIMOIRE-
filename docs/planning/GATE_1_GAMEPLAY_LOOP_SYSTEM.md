# 스펠 Gate 1 게임플레이 Loop 구조

## 문서 상태

- 프로젝트: `스펠` (임시)
- 제품 단계: `CONCEPT_APPROVAL`
- 실행 프로필: `PLANNING_ONLY_PROFILE`
- Work Mode: `PLAN`
- 결정 ID: `GM-LOOP-01`
- 상태: `LOOP_STRUCTURE_CONFIRMED_FOR_GATE_1`
- 사용자 승인: 2026-07-27
- Gate 1 전체: `UNVERIFIED`
- 구현: `NOT_STARTED`

이 문서는 스펠의 Micro Loop, 전투 Loop, 세션 Loop, 학기 Loop, 고정 중요 일정과 자유 일정의 관계를 책임진다.

## 1. 기본 Core Loop

```text
수업
→ 마법 글자·원리·설계법 학습

교내 연습
→ 안전한 환경에서 직접 작성·조합·사용

자유일정·일상
→ 휴식·관계·정보·동행·준비 누적

시험·학교행사
→ 이해를 증명하고 마법을 표현·생활에 활용

현장실습
→ 실전 문제와 전투에서 응용·변형·발견

복귀·정리
→ 주문·활용법·실패 원인·관계 결과 기록

다음 수업·연구
→ 실전과 평가에서 드러난 부족함 재학습
```

핵심 문장:

> 수업에서 알고, 연습에서 할 수 있게 되고, 시험에서 이해를 증명하고, 축제에서 자유롭게 표현하며, 현장실습에서 다르게 써 보고, 자유일정과 일상에서 그 경험의 관계와 의미를 누적한다.

## 2. 일정 구조

일정은 `고정 핵심 사건 + 자유 일정` 혼합형이다.

### 고정 핵심 사건

- 학기 시작
- 필수 기초 수업
- 시험·평가
- 학교축제·행사
- 중간·주요 현장실습
- 발표·진급·학기 종료

### 자유 일정

- 복습·연구
- 교내 연습
- 휴식·컨디션 회복
- 관계·일상
- 축제 준비
- 현장 조사·실습 준비
- 메인 동반 소환수와 교류
- 전투 보조 소환수 훈련

### 자유 일정 보호 결정

- 중요 일정 사이에는 자유일정 1회를 기본 완충 단위로 둔다.
- 자유일정 한 슬롯에서는 중심 행동 1개만 선택한다.
- `휴식`은 유효한 정식 선택이다.
- 어떤 자유일정 선택도 필수 진행을 영구 차단하지 않는다.
- 필수 정보나 정답을 특정 자유일정에만 숨기지 않는다.
- 자유일정 결과는 작은 보정·관계·정보·준비 차이를 만든다.
- 모든 자유일정에 독립 대형 미니게임을 만들지 않는다.

## 3. Micro Loop

```text
상황 관찰
→ 필요한 현상 결정
→ 메인 글자 선택
→ 보조 글자 선택
→ 직접 작성 또는 숙련 스톡 삽입
→ 주문 기동
→ 결과 확인
→ 성공·실패 원인 이해
→ 재설계
```

플레이어 결정:

- 어떤 현상이 필요한가
- 어떤 보조 효과가 필요한가
- 직접 쓸 것인가 숙련 반복을 스톡으로 줄일 것인가
- 짧고 안전한 주문인가 복잡하고 강한 주문인가

## 4. 전투 Loop

```text
현장 파악
→ 첫 주문으로 적·환경 반응 확인
→ 이동·방어·전투 보조 소환수로 작성 시간 확보
→ 주문 유지·변형·교체
→ 직접 작성과 스톡 우선순위 결정
→ 목표 해결
→ 결과와 실패 원인 기록
```

보호 경계:

- 전투 보조 소환수는 글자 작성·조합 결정을 대행하지 않는다.
- 스톡과 자동화가 설계 판단을 제거하지 않는다.
- 실시간 압박은 `완전 정지 / 감속 / 실시간` 비교 후 확정한다.

## 5. 세션 Loop

### 수업·연습 세션

```text
원리 소개
→ 첫 작성
→ 결과 확인
→ 보조 변형
→ 안전한 문제 해결
→ 정리
```

### 시험 세션

```text
제한 조건 확인
→ 문제 관찰
→ 주문 설계
→ 직접 작성
→ 평가
→ 실패 원인·교수 피드백
```

시험은 정답 하나를 재생하는 장면이 아니라 이해를 증명하는 장면이다.

### 학교축제 세션

```text
활동 선택
→ 준비·관계 장면
→ 비전투 마법 활용
→ 작은 문제 발생
→ 자유로운 주문 설계
→ 축제 결과·관계 변화
```

축제는 전투와 무관한 컷신이 아니라 동일한 마법 문법의 표현·생활 활용을 보여준다.

### 현장실습 세션

```text
브리핑
→ 관찰
→ 전투 문제
→ 환경·구조 문제
→ 주문 재설계
→ 새로운 활용 발견
→ 귀환·기록
```

현장실습은 배운 주문을 그대로 재생하는 시험이 아니다.

### 자유일정 세션

```text
다음 중요 일정 확인
→ 행동 3~4개 확인
→ 행동 1개 선택
→ 짧은 플레이·대화·정리
→ 상태·관계·정보·준비 결과 저장
```

자유일정은 중요 일정 사이의 피로를 줄이고 다음 선택을 준비한다.

## 6. 학기 Loop

```text
학기 시작
→ 기초 수업·연습
→ 자유 일정
→ 시험·평가
→ 자유 일정
→ 학교축제·행사
→ 자유 일정
→ 주요 현장실습
→ 복귀·보충·연구
→ 학기 평가
→ 다음 학기
```

3년·6학기와 정확한 일정 수는 `CHANGEABLE_SHELL_SCOPE_RISK`다. Vertical Slice에서는 축약 학기형으로 이 구조만 증명한다.

## 7. Vertical Slice 적용

책임 원본: `docs/planning/GATE_1_VERTICAL_SLICE_CONTRACT.md`

```text
첫 수업·교내 연습
→ 자유일정 A
→ 첫 실기시험
→ 자유일정 B
→ 학교축제
→ 자유일정 C
→ 첫 현장실습
→ 귀환·마도서 기록
```

각 중요 일정은 대표 플레이 문제 1개만 가진다. 자유일정은 총 3회이며 한 슬롯에서 행동 1개만 선택한다.

## 8. 저장·복귀

필수 체크포인트:

- 각 중요 일정 시작 전
- 자유일정 선택 전과 완료 후
- 현장실습 진입 전
- 현장실습 내 안전한 문제 전환 지점
- 귀환·기록 완료 후

복귀 시 다음이 즉시 보여야 한다.

- 현재 목표와 다음 중요 일정
- 선택한 자유일정 결과
- 보유 글자와 숙련 상태
- 소환수 준비 상태
- 최근 발견·실패 원인

## 9. 보상 순환

- 수업: 새 원리와 글자
- 연습: 안전한 이해와 조합 비교
- 자유일정: 회복·준비·관계·정보
- 시험: 이해 증명과 피드백
- 축제: 표현·관계·비전투 활용 기록
- 현장실습: 새로운 활용과 실전 발견
- 복귀: 마도서·다음 학습 목표

## 10. 보호 경계

- 수업은 완성 주문 상점이 아니다.
- 시험은 정답 하나를 요구하는 암기 검사가 아니다.
- 학교축제는 플레이와 단절된 컷신이 아니다.
- 현장실습은 배운 주문 그대로 재생하는 시험이 아니다.
- 자유일정은 필수 진행을 막는 호감도·피로도 함정이 아니다.
- 휴식은 손해 전용 선택이 아니다.
- 한 세션에 모든 콘텐츠를 강제로 넣지 않는다.
- 스톡·소환수·자동화가 설계 판단을 제거하지 않는다.
- 필수 정보는 관계·선택형 대화·자유일정에만 숨기지 않는다.
