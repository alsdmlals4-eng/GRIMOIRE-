# 스펠 Gate 2 캐릭터 표현 구조

## 1. 문서 상태

- 결정 ID: `GM-CHARACTER-PRESENTATION-01`
- 사용자 승인: 2026-07-27
- 승인 근거: 추천 확정안 두 번째 인게임 이미지와 후속 확인
- 상태: `SD_FIELD_HALF_BODY_DIALOGUE_SEPARATE_TACTICAL_BATTLE_CONFIRMED`
- 제품 단계: `PROTOTYPE_AND_VERTICAL_SLICE`
- Gate 1: `APPROVED`
- 프로젝트 코어: `CORE_CONFIRMED`
- 실행 프로필: `PLANNING_ONLY_PROFILE`
- 구현: `NOT_STARTED`
- 이미지 대량 제작: `BLOCKED_BY_ART_STYLE_AND_ASSET_SPEC`
- 다음 차단 결정: `ART-STYLE-01`

> **학교·자유일정·비전투 탐색에서는 3.5~4등신 SD 캐릭터를 사용하고, 대화에서는 같은 장소 배경 위에 반신 일러스트를 표시한다. 전투는 별도의 고정 3/4 전술 전투장으로 전환하되 필드와 동일한 SD 비율과 기본 디자인을 재사용한다.**

---

## 2. 화면별 표현

### 필드·학교생활

```text
3.5~4등신 SD 캐릭터
+ 고정·장면 기반 3/4 배경
+ 짧은 이동·상호작용·반응
```

- 수업·시험 준비·자유일정·축제·현장 관찰에 사용
- 작은 모바일 화면에서도 인물과 메인 동반 소환수를 식별할 수 있어야 함
- 자유 이동형 대형 맵을 전제로 하지 않음

### 대화

```text
기존 장소 배경 유지
+ 캐릭터 반신 일러스트
+ 이름·대화창
+ 필요 시 메인 동반 소환수 반응 슬롯
```

- 기본 화자 1명, 필요한 경우 2명까지 강조
- 반신 일러스트가 장소와 사건의 연속성을 끊지 않음
- 필수 정보는 표정·음성만으로 전달하지 않고 텍스트·아이콘 병행

### 전투

```text
필드에서 전투 진입
→ 별도 고정 3/4 전술 전투장
→ 필드와 동일한 3.5~4등신 SD 비율
→ 전투용 최소 상태 추가
```

- 전투 전용으로 체형·의상·얼굴 구조를 다시 설계하지 않음
- 필드 SD의 기본 골격과 실루엣을 재사용
- 전투장에서 플레이어·적·환경 목표·보조 소환수를 동시에 확인

---

## 3. 캐릭터 일관성 규칙

필드 SD와 대화 반신은 다음 식별 요소를 공유한다.

- 머리 실루엣
- 대표색
- 의상 핵심 파츠
- 얼굴 특징
- 마법 도구 또는 소지품
- 학교 소속·전공을 보여주는 문양

SD 비율 때문에 세부를 생략해도 핵심 특징을 다른 장식으로 임의 대체하지 않는다.

---

## 4. Vertical Slice 자산 예산 원칙

정확한 수량은 `ASSET-SPEC-01`에서 확정한다. 현재 보호 상한은 다음과 같다.

### 주인공

- 필드: 대기·짧은 이동·상호작용
- 전투: 대기·이동 또는 회피·주문 반응·피격
- 대화: 기본·긍정·부정 중심 소수 표정

### 교수·핵심 관계 인물

- 필드: 대기·짧은 반응
- 대화: 반신과 소수 표정
- 전투 자산: 실제 전투 참여자에게만 허용

### 일반 NPC

- 필드 SD 또는 배경 군중 처리
- 대화 반신은 핵심 대사가 있는 인물만 제작

### 금지

- 모든 NPC의 반신 일러스트
- 캐릭터별 고프레임 필드·전투 애니메이션
- 필드와 전투의 별도 체형·별도 의상 세트
- 모든 대화의 전신 일러스트
- 화면비별 캐릭터 자산 재제작

---

## 5. 소환수 표현 슬롯

### 메인 동반 소환수

- 필드 소형 전신
- 대화용 작은 반응 초상 또는 반응 연출
- 현장·전투에서 관찰·경고·관계 반응
- 초기 Slice에서는 초기 성장 형상 1개만 런타임 필수

### 전투 보조 소환수

- 전투 전용 명확한 실루엣
- 수호 또는 견제 역할을 한눈에 구분
- 대화 반신은 초기 Slice에서 만들지 않음

---

## 6. 전투 전환 연속성

필드와 전투 화면이 분리되더라도 같은 사건으로 읽혀야 한다.

- 필드의 장소 색·건축·핵심 오브젝트를 전투장에 계승
- 전투 진입 전 관찰한 대상과 동일한 식별 요소 유지
- 전투 결과의 손상·복구·구조 상태를 필드 복귀 후 반영
- 전투 전환은 짧고 반복 가능한 연출 사용
- 전투장 전용 장문 서사·탐색·별도 성장 시스템 추가 금지

---

## 7. 이미지 기준안의 지위

사용자가 승인한 두 번째 인게임 예상 이미지는 다음을 고정한다.

- 필드 SD
- 대화 반신
- 별도 3/4 전술 전투장
- 전투 화면의 마법 작성 오버레이
- 전투 종료 후 필드 복귀

상태: `USER_APPROVED_VISUAL_REFERENCE`

이미지가 확정하지 않는 것:

- 실제 그림체
- 주인공 외모와 의상
- 색상 팔레트
- UI 최종 배치
- 내부 해상도
- 정확한 애니메이션·표정 수량

---

## 8. 검증 기준

- 필드 SD와 대화 반신이 같은 인물로 즉시 인식됨
- 필드와 전투 SD가 동일한 자산 체계로 느껴짐
- 전투 전환 후에도 장소·목표·대상을 잃지 않음
- 작은 화면에서 플레이어·적·환경 목표·보조 소환수가 구분됨
- 대화 초상이 텍스트 가독성을 방해하지 않음
- 필드·전투·대화 자산 비용이 `ASSET-SPEC-01` 예산 안에 들어감
