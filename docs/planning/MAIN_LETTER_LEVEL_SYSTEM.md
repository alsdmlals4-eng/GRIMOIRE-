## 1. 계열 분류 확정

메인 글자 계열은 **현상·물질·개념 중심**으로 분류한다.

```text
메인 글자 계열
→ 세계에 어떤 현상·물질·개념을 발생시키거나 변화시키는가
```

후보 방향:

- 열·불꽃
- 물·유동
- 바람·압력
- 빛
- 힘·충격
- 생명·회복
- 보호·차단
- 이동·공간
- 감지
- 소환
- 변환

위 목록은 분류 방향을 설명하는 후보이며 최종 과목 수와 명칭은 추후 확정한다.

기능 중심인 `공격·방어·회복·탐색`은 메인 계열이 아니라 **같은 메인 글자를 어떻게 활용했는지 나타내는 용도**로 취급한다.

```text
불꽃 메인 글자
→ 공격: 화염탄
→ 생활: 난방
→ 구조: 해빙
→ 생산: 재료 가공
```

## 2. 메인 글자별 독립 레벨

모든 메인 글자는 각각 독립적인 숙련 레벨을 가진다.

```text
불꽃 메인 Lv.3
물 메인 Lv.1
보호 메인 Lv.2
```

- 메인 글자 레벨은 플레이어의 전체 레벨과 별개다.
- 학년과도 1:1로 고정하지 않는다.
- 같은 학년 학생이라도 수강·연구·실습 선택에 따라 계열별 레벨이 달라진다.
- 여러 계열을 넓게 배우는 성장과 소수 계열을 깊게 연구하는 성장이 모두 가능하다.
- 필수 교육으로 기본 진행에 필요한 최소 메인 글자를 보장한다.

## 3. 레벨 단계 — 기획 기본값

레벨 구조는 우선 `Lv.0~Lv.5`를 `PLANNING_DEFAULT`로 사용한다.

| 단계 | 학습 상태 | 핵심 의미 |
|---:|---|---|
| Lv.0 | 미습득 | 글자를 이해하지 못하거나 안정적으로 작성할 수 없음 |
| Lv.1 | 입문 | 메인 글자 단독의 기본 발현 가능 |
| Lv.2 | 숙련 | 기본 발현의 안정성·효율·재현성 향상 |
| Lv.3 | 응용 | 여러 보조 글자와의 조합 및 현장 활용 확대 |
| Lv.4 | 심화 | 고출력·고난도 보조 문법과 상위 활용 연구 |
| Lv.5 | 전공·연구 | 개인 해석·전문 활용·졸업 연구 수준 |

정확한 최대 레벨과 레벨별 수치는 후속 데이터 설계에서 조정할 수 있다. 다만 **메인 글자도 수업과 실전으로 지속 성장한다**는 구조는 유지한다.

## 4. 레벨이 성장시키는 요소

메인 글자 레벨은 단순 공격력 배율 하나가 아니다.

### 4.1 기본 발현

- 메인 글자만 사용했을 때 발생하는 기본 주문의 출력
- 기본 발현의 범위·지속·정밀도 후보
- 생활·구조·연구에서 사용할 수 있는 기본 활용 범위

### 4.2 안정성과 마나 효율

- 같은 결과를 더 안정적으로 재현
- 직접 작성 오차에 대한 보정 또는 성공 허용 범위 후보
- 마나 낭비와 폭주 위험 감소
- 고출력 사용 시 부담 완화

### 4.3 보조 글자 수용력

레벨이 높을수록 더 많은 보조 글자를 안정적으로 받아들일 수 있다.

```text
낮은 레벨 메인
→ 짧고 단순한 주문에 적합
→ 보조 글자가 많아질수록 불안정·비효율 위험

높은 레벨 메인
→ 다수 보조 글자를 안정적으로 연결
→ 복합 주문과 고위 활용에 적합
```

정확한 보조 글자 권장 수와 과부하 패널티는 추후 결정한다. 현재는 절대 슬롯 제한보다 **안전 수용 범위와 복잡도 부담**으로 표현하는 방향을 우선한다.

### 4.4 활용과 해석

- 계열별 새로운 기본 발현 후보
- 같은 메인 글자의 전투·생활·구조·탐사 활용 확대
- 상급 현장실습과 연구 과제 접근
- 교수·학생·소환수와의 계열별 연구 이벤트
- 졸업 연구와 전문 진로의 기반

## 5. 레벨 상승 조건

메인 글자 레벨은 경험치만 반복 획득해 자동 상승하지 않는다.

```text
이론 수업
+
직접 작성 훈련
+
보조 글자 조합
+
현장 활용 성공
+
보고·시험·연구 인증
= 메인 글자 레벨 상승
```

### 성장 자원 후보

1. `이해도` — 수업·교수 연구·기록 분석
2. `숙련도` — 직접 작성·반복 시전·모의 실습
3. `활용 기록` — 현장에서 서로 다른 문제 해결
4. `인증` — 과제·시험·발표·교수 평가

레벨 상승마다 모든 항목을 동일하게 요구할 필요는 없다.

- Lv.1은 수업과 기본 발동으로 획득 가능
- Lv.2는 반복 훈련과 안정적인 재현이 중요
- Lv.3은 현장 활용과 보조 조합 검증이 중요
- Lv.4는 심화 수업·교수 연구·고난도 실습이 중요
- Lv.5는 독립 연구·졸업 실습·발표가 중요

## 6. 학년과의 관계

### 1학년

- 여러 기초 계열을 Lv.1로 습득
- 관심 계열 일부를 Lv.2까지 성장
- 메인 단독 기본 발현과 소수 보조 조합 학습

### 2학년

- 선택 계열을 Lv.3 중심으로 전문화
- 일부 핵심 계열은 Lv.4 진입 가능
- 계열 전용 보조와 교차 계열 응용 확대

### 3학년

- 전공 계열의 Lv.4~Lv.5 연구
- 다수 보조 글자와 독립 주문 설계
- 졸업 실습·연구·진로에 전문 계열 반영

이는 권장 성장 곡선이며, 학년이 레벨을 자동 지급하거나 절대 상한으로 막는 규칙은 아니다. 학교는 안전과 선수 과목을 이유로 상위 수업·실습 접근을 제한할 수 있다.

## 7. 넓은 학습과 깊은 전문화

### 다계열형

```text
불꽃 Lv.2 + 물 Lv.2 + 보호 Lv.2 + 감지 Lv.2
```

- 다양한 현장 문제에 대응
- 많은 실습 후보와 보조 조합 확보
- 고위 단일 계열 주문은 상대적으로 늦게 성장

### 전문형

```text
불꽃 Lv.5 + 보호 Lv.2 + 감지 Lv.1
```

- 특정 계열의 기본 발현과 고위 조합이 강함
- 교수 연구·전공 실습·진로가 선명해짐
- 다른 계열 문제에는 동료·보조 글자·준비로 보완 필요

어느 한쪽이 정답이 되지 않도록 현장실습과 졸업 평가에서 폭과 깊이를 각각 다른 방식으로 인정한다.

## 8. 보조 글자와의 책임 경계

메인 글자 레벨이 올라도 보조 글자의 기능을 자동으로 얻지 않는다.

```text
불꽃 메인 Lv.5
≠ 추적·확대·분열 자동 보유
```

- 메인 레벨은 현상의 이해·기본 발현·안정적인 수용력을 성장시킨다.
- 보조 글자는 형상·전달·행동·조건 등 구체적인 주문 문법을 추가한다.
- 보조 글자는 별도의 수업·연구·현장 활용을 통해 습득·숙련한다.
- 높은 메인 레벨만으로 모든 주문 조합이 완성되지 않는다.

## 9. 스톡과 레벨

- 메인 글자의 레벨이 올라가도 기능 글자 수는 여전히 1개로 계산한다.
- `불꽃 메인 Lv.1`과 `불꽃 메인 Lv.5`는 준비 용량 계산상 모두 메인 글자 1개다.
- 완성 주문 스톡의 준비 용량·충전시간은 기능 글자 수 기준을 유지한다.
- 높은 레벨의 출력과 안정성이 스톡 주문에 언제 반영되는지는 추후 확정한다.
- 레벨만 올랐다는 이유로 미발견 주문이 자동 등록되지는 않는다.

## 10. 실패와 보충

- 레벨 시험 실패는 글자 상실이나 영구 봉인으로 처리하지 않는다.
- 부족한 이론은 보충 수업, 부족한 실전은 재실습으로 회복한다.
- 현장 실패는 활용 기록과 교수 피드백으로 다음 성장 경로를 제공한다.
- 한 계열의 낮은 레벨 때문에 메인 스토리를 영구 차단하지 않는다.
- 상위 계열 실습은 동료·교수 지원이나 대체 해결법을 제공할 수 있다.

## 11. 가드레일

- 메인 글자 레벨을 단순 피해량 배율 하나로 축소하지 않는다.
- 메인 레벨 상승이 보조 글자 습득을 대체하지 않게 한다.
- 학년 상승만으로 모든 메인 글자가 자동 레벨업하지 않게 한다.
- 반복 수업 버튼만 눌러 최고 레벨을 달성하지 않게 한다.
- 낮은 레벨 계열을 완전히 무가치하게 만들지 않는다.
- 모든 메인 글자를 한 회차에 최고 레벨로 만들 수 있게 설계하지 않는다.
- 메인 글자 레벨이 기능 글자 수·스톡 용량을 임의로 부풀리지 않게 한다.
- 최고 레벨을 세계관상 만능·완전한 마법으로 표현하지 않는다.

## 12. 확정·보류 구분

### 확정 방향

- 메인 글자 계열은 현상·물질·개념 중심
- 메인 글자마다 독립 레벨 보유
- 공부·훈련·현장 활용·평가로 성장
- 레벨은 기본 발현·안정성·효율·보조 수용력·활용 범위를 성장
- 메인 레벨과 보조 글자 습득은 별도 축
- 학년이 오를수록 선택 계열을 깊게 연구

### 기획 기본값

- `Lv.0~Lv.5` 5단계
- 1학년 Lv.1~2, 2학년 Lv.3 중심, 3학년 Lv.4~5 중심 성장 곡선

### 추후 결정

- 정확한 최대 레벨과 경험·인증 수치
- 레벨별 기본 발현 변화
- 레벨별 안전 보조 글자 수용 범위
- 과부하·불안정·마나 효율 공식
- 완성 주문 스톡에 적용되는 메인 레벨 시점
- Lv.4~5의 선형 성장 또는 전문 분기 여부
- 보조 글자 자체의 레벨·숙련 구조
