## GM-WORLD-11 — 학년별 현장실습 자율성

### 채택안

`C — 학년에 따라 자율성이 증가하는 혼합형`

### 확정 방향

```text
1학년
→ 학교 지정 실습 중심

2학년
→ 필수 지정 실습 + 선택형 실습

3학년
→ 학생 제안형 실습 + 학교 위험 승인
```

- 1학년은 지역·목표·감독자·기본 팀을 학교가 지정한다.
- 학교가 임무는 정하지만 현장 해결법은 플레이어가 선택한다.
- 2학년은 학기 핵심 실습을 유지하면서 수강 계열·관계·연구에 따른 선택 실습을 제공한다.
- 3학년은 주제·지역·팀·접근법을 학생이 제안하고 학교가 위험·안전 기준을 승인한다.
- 학년 상승은 난이도뿐 아니라 선택 권한과 책임의 증가로 표현한다.
- 선택형 실습은 전문성·관계·주문 발견·진로 차이를 만들지만 메인 진행을 영구 차단하지 않는다.

상태: `DIRECTION_CONFIRMED`

## GM-CIRCUIT-01 — 마법 글자 기반 주문 문법

### 채택안

`메인 회로 하나만으로 주문이 성립하고, 다수의 보조 회로가 주문을 강화·확장`

### 확정 방향

```text
마법 글자
→ 마법적 의미를 가진 기능 단위

회로
→ 글자의 위치·연결·순서를 구성한 문법

주문
→ 메인 글자 1개 + 보조 글자 0개 이상
```

- 메인 글자 하나만 정확히 작성해도 가장 단순한 기본 주문이 성립한다.
- 메인 글자는 고유한 기본 발현을 가진다.
- 형상·전달 글자는 더 이상 주문 성립의 필수 조건이 아니다.
- 복수 메인 글자는 사용하지 않는다.
- 기존 형상·전달·일반 보조·조건·기동은 보조 글자의 하위 역할로 통합한다.
- 보조 글자가 늘수록 출력·규모·지속·행동·효율·안정·조건 등 주문의 총 기능과 복잡도가 확대된다.
- 보조 글자가 많아지면 직접 작성 시간, 마나 부담, 준비 용량과 충전시간도 증가한다.
- 기존 `초반 최소 문법 = 메인 + 형상·전달`은 `SUPERSEDED_BY_GM-CIRCUIT-01`이다.
- 기존 스톡의 기능 회로 수는 기능 마법 글자 수로 재해석한다.

상태: `DIRECTION_CONFIRMED`

책임 원본: `docs/planning/MAGIC_LETTER_CIRCUIT_SYSTEM.md`

## GM-WORLD-12 — 메인 글자 계열 수업

### 채택안

`수업 강의를 메인 글자 기준 계열로 나누고, 해당 계열의 메인·보조 글자를 함께 학습`

### 확정 방향

- 학교 과목은 메인 글자 계열을 중심으로 구성한다.
- 각 계열 수업은 현상 원리, 메인 글자, 기본 발현, 계열 대표 보조 글자, 활용과 위험을 가르친다.
- 공통 문법 수업은 연결·안전·형상·전달·안정화 같은 보편 보조 글자를 가르친다.
- 응용·융합 실습에서는 한 계열의 메인 글자와 다른 수업에서 배운 보조 글자를 조합할 수 있다.
- 수업은 완성 주문을 자동 지급하지 않는다.
- 수업에서 글자와 활용 가능성을 배우고, 현장에서 실제 조합을 성공시켜 마도서에 주문을 등록한다.
- 1학년은 여러 기초 계열을 넓게 경험하고, 2학년부터 선택·전문화, 3학년은 독립 설계와 졸업 연구로 발전한다.

상태: `DIRECTION_CONFIRMED`

책임 원본: `docs/planning/WORLD_MAGIC_CURRICULUM_SYSTEM.md`
