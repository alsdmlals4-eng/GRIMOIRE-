## 승인 문장

> 부분 성공과 실패는 사건의 실제 결과·부작용·발견으로 세계와 마도서에 남지만, 학기 중 성적이나 감점은 공개하지 않는다. 내부적으로 작은 감점만 누적하고 학기 종료 시 전체 활동과 함께 종합 평가한다.

## 핵심 흐름

```text
사건·수업·일상·축제·연구·제작·현장 결과
→ 보존/손실/부작용/발견 기록
→ 내부 학기 평가에 작은 보정치 누적
→ 학기 중 숫자·예상등급·장학 게이지 비공개
→ 이후 활동에서 새 긍정 증거와 발견 축적
→ 학기 종료 시 포트폴리오 종합 평가와 근거 사건 설명
```

## 결과 태그의 역할

결과 태그는 즉시 처벌 수치가 아니라 다음을 위한 설명 데이터다.

- 어떤 대상을 지켰고 무엇을 잃었는지.
- 어떤 부작용·변질·대체 활용이 발생했는지.
- 어떤 관계·장소·연구 질문이 생겼는지.
- 학기말 평가가 어떤 사건을 근거로 삼는지.
- 후속 수업·교류·연구·제작·현장 콘텐츠를 어떻게 변주할지.

관계·장소 반응은 자연스럽게 발생할 수 있지만 즉시 관계 수치 하락·콘텐츠 폐쇄·장학 경고로 표현하지 않는다.

## 숨김 평가 규칙

- 사건별 감점은 작고 상한이 있다.
- 학기 총감점에도 상한을 둔다.
- 단일 실패가 학기 등급이나 장학 유지 여부를 결정하지 못한다.
- 같은 실패 반복은 무한 누적 감점 대신 반복 패턴으로 학기말 코멘트에 반영한다.
- 긍정 증거는 학습·비전투 응용·현장 수행·제작/연구·복기에서 얻는다.
- 회복 콘텐츠는 감점 삭제권이 아니라 새로운 긍정 증거·발견·대체 해법을 제공한다.
- 정확한 감점·상한·가중치·등급 경계는 `TEST_VALUE`다.

## 학기말 평가 출력

학기말에는 다음을 제공한다.

- 종합 평가 결과.
- 교수의 평가 문장.
- 강점과 보완점.
- 평가에 영향을 준 대표 사건과 행동.
- 다음 학기 수강·연구·전문화 후보.

내부 원점수와 사건별 감점표를 그대로 보여주지 않는다. 단, 결과가 설명 불가능한 블랙박스가 되지 않도록 대표 근거는 반드시 제시한다.

## 진행·콘텐츠 보호

- 학기 중 즉시 장학 박탈 없음.
- 실패로 메인 진행·필수 수강·핵심 관계를 영구 차단하지 않음.
- 낮은 학기말 평가에도 보완 학습과 다음 학기 회복 경로 제공.
- 저장 불러오기를 하지 않아도 정상 완주 가능.
- 재료·화폐·미니게임 반복으로 평가를 구매하거나 감점을 직접 제거할 수 없음.
