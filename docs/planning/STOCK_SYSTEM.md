# Spell 스톡 시스템 — 최신 책임 원본

## 문서 상태

- 상태: `PLANNING_IN_PROGRESS`
- 결정 상태: `CONFIRMED_DIRECTION`
- 기준 날짜: 2026-07-26
- 관련 결정: `GM-00-12`, `GM-00-14`~`GM-00-32`
- 준비 용량: `docs/planning/STOCK_CAPACITY_SYSTEM.md`
- 충전시간: `docs/planning/STOCK_CHARGE_TIME_SYSTEM.md`
- 대상 전환: `docs/planning/STOCK_TARGET_SWITCH_SYSTEM.md`
- 직접 피해 정지: `docs/planning/STOCK_HIT_PAUSE_SYSTEM.md`
- 상태이상 연동: `docs/planning/STATUS_EFFECT_STOCK_SYSTEM.md`

이 문서는 완성 주문 스톡, 하위 회로 스톡, 공용 준비 용량, 지정 대상 충전, 직접 피해 정지와 상태이상 연동의 최신 상위 규칙을 정의한다.

## 1. 자동화 구조

기존 조건부 자동발동은 폐기한다.

```text
성장으로 일정 이하 단계의 주문·회로 스톡화 가능
→ 전투 전에 공용 준비 용량 안에서 편성
→ 전투 중 플레이어가 터치해 사용·적용
→ 지정 대상 1종 자동 충전
→ 행동과 소환수 생산 지원으로 가속
```

- 주문과 회로의 사용 시점은 플레이어가 결정한다.
- 신규 발견·즉석 변형·상위 회로 판단은 직접 시전이 담당한다.

## 2. 스톡의 두 종류

### 완성 주문 스톡

```text
저장 주문 터치
→ 등록된 설계도 전체 즉시 기동
→ 스톡 1개 소비
```

### 하위 회로 스톡

```text
상위 주문 작성 중 하위 회로 스톡 터치
→ 숙련 회로 한 구간 자동 배치·연결
→ 스톡 1개 소비
```

| 종류 | 터치 결과 | 플레이어 책임 |
|---|---|---|
| 완성 주문 | 주문 전체 기동 | 사용 시점·대상·전투 판단 |
| 하위 회로 | 회로 한 구간 자동완성 | 상위 회로·연결·최종 기동 |

스톡이 없어도 직접 회로 시전은 가능하다.

## 3. 성장과 스톡화

- 이미 학습·숙련했고 성장 기준 이하인 주문·회로만 스톡화한다.
- 현재 성장 단계의 신규·상위 회로는 직접 작성한다.
- 성장했다고 모든 하위 주문·회로가 자동 장착되지는 않는다.
- 편성 대상과 수량은 플레이어가 결정한다.

## 4. 공용 준비 용량

```text
하위 회로 스톡 1개
= 준비 용량 1

완성 주문 스톡 1개
= 설계도 기능 회로 수
```

- 두 스톡은 하나의 공용 준비 용량을 공유한다.
- 동일 주문·회로를 반복 편성할 수 있다.
- 주문별·회로별 별도 최대 보유량은 두지 않는다.
- 플레이어 성장에 따라 전체 준비 용량이 증가한다.
- 기능 회로 블록 수를 계산하며 선 길이·획수·장식은 계산하지 않는다.

## 5. 마나와 분리

기존의 `완성 주문 비용 50% 최대 마나 예약`은 `SUPERSEDED`다.

- 스톡은 최대 마나를 예약하지 않는다.
- 준비·발동·적용·충전에 마나를 소비하지 않는다.
- 직접 회로 시전만 마나 소비·회복·절감 시스템을 사용한다.

## 6. 기준 충전시간

```text
기준 충전시간(n)
= 1.0 + 0.5 × (n - 1)
```

| 기능 회로 수 | 기준 충전시간 |
|---:|---:|
| 1 | 1.0단위 |
| 2 | 1.5단위 |
| 3 | 2.0단위 |
| 4 | 2.5단위 |
| 5 | 3.0단위 |

- 하위 회로 스톡은 1.0단위다.
- 완성 주문은 구성 기능 회로 수를 사용한다.
- `1.0단위`의 실제 초 환산값은 미확정이다.
- 같은 대상의 빈 스톡은 1회분씩 순차 충전한다.

## 7. 지정 대상 자동 충전

```text
지정 대상 1종
→ 기본 자동 충전
→ 플레이어 생산 기여
→ 소환수 생산 기여
→ 능동 행동 보너스
```

- 다른 준비 대상은 동시에 충전하지 않는다.
- 소환수는 회로를 작성하지 않고 생산량·충전 속도를 지원한다.
- 소환수는 플레이어 허가 없이 충전 대상을 변경하지 않는다.

능동 기여 후보:

- 직접 회로 시전
- 정확한 회로 완성
- 방어·반격 성공
- 주문 연계 성공
- 소환수 공격·수호·동조 성공

## 8. 충전 대상 전환

```text
다른 준비 대상 선택
→ 현재 진행도 대상별 보존
→ 전환 지연 동안 모든 충전 정지
→ 새 대상의 저장 진행도부터 재개
```

- 현재 대상이 최대치에 도달해도 자동 전환하지 않는다.
- 전환 지연시간과 전환 중 재변경 규칙은 미확정이다.

## 9. 직접 피해에 따른 충전 정지

스톡 정지는 공격 접촉이나 타격 수가 아니라 **직접 피해로 실제 감소한 체력**을 기준으로 한다.

```text
최종 직접 피해 0
→ 충전·전환 계속

직접 피해 발생
→ 0.25초 동안 직접 피해 손실 합산
→ 최대 체력 대비 손실 비율 r 계산
→ clamp(r × 3.0, 0.10초, 0.80초) 정지
→ 진행도 전부 보존
→ 자동 재개
```

- 같은 총 직접 피해라면 단발·다단 공격은 같은 정지시간을 목표로 한다.
- 각 타격에 최소 정지시간을 반복 적용하지 않는다.
- 완전 방어·보호막·회피·무적으로 최종 피해가 0이면 정지하지 않는다.
- 부분 방어는 직접 피해가 줄어든 만큼 정지시간도 감소한다.
- 정지 중 자동 충전·생산 기여·능동 보너스는 적용하지 않는다.
- 완성된 스톡은 정지 중에도 사용할 수 있다.

## 10. 지속 피해 제외

화상·독·출혈 등 지속 피해 틱은 체력을 감소시키지만 직접 피해 정지 계산에는 포함하지 않는다.

```text
지속 피해 틱
→ 체력 감소
→ 충전·전환 정지 없음
```

- 지속 피해는 체력 압박과 회복 자원 소모를 담당한다.
- 작은 틱이 반복적으로 충전을 끊지 않게 한다.
- 직접 피해와 지속 피해가 함께 있는 공격은 데이터상 두 효과를 분리한다.

## 11. 상태이상 기반 스톡 방해

상태이상 기반 스톡 방해는 두 축으로 제한한다.

### 마력 교란 — 생산 방해

```text
마력 교란
→ 스톡 충전 속도 30% 감소
→ 실제 충전 속도 70%
→ 동일 상태 중첩 없음
→ 재적용 시 지속시간 갱신
```

- 자동 충전은 계속한다.
- 충전 대상과 진행도를 유지한다.
- 이미 완성된 스톡은 사용할 수 있다.
- 30% 감속은 `PLANNING_DEFAULT`이며 PoC에서 조정할 수 있다.
- 기획 구조로는 `충전 지속`, `진행도 보존`, `중첩 없음`을 유지한다.

### 주문 봉인 — 사용 방해

```text
주문 봉인
→ 완성 주문 스톡 사용 불가
→ 하위 회로 스톡 사용 불가
→ 자동 충전과 생산 기여 계속
→ 보유량과 진행도 유지
```

- 충전 대상 전환도 정상적으로 허용한다.
- 봉인 중 완성된 스톡은 한도까지 저장한다.
- 봉인 해제 후 별도 복구 입력 없이 즉시 사용할 수 있다.
- 직접 회로 시전까지 차단하는 상위 봉인의 필요 여부는 미확정이다.

### 사용하지 않는 상태

```text
회로 혼선
→ 충전 대상 전환 지연 증가 또는 전환 제한
```

상태: `REMOVED_BY_GM-00-31`

- 상태이상 기반 대상 전환 방해는 도입하지 않는다.
- 마력 교란과 주문 봉인이 동시에 적용되면 독립적으로 동작한다.
- 상태이상으로 충전 진행도나 보유 스톡을 삭제하지 않는다.

## 12. 책임 경계

```text
직접 시전
→ 마나·발견·즉석 변형·정확 입력

완성 주문 스톡
→ 저장 주문 원터치 기동

하위 회로 스톡
→ 숙련 회로 원터치 자동완성

소환수
→ 전투·수호·스톡 생산 지원

직접 피해
→ 체력 손실 비율에 따른 짧은 충전 정지

지속 피해
→ 체력 압박, 충전 정지 없음

마력 교란
→ 스톡 충전 감속

주문 봉인
→ 보유 스톡 사용 차단
```

## 13. 전투 흐름

```text
전투 전
→ 공용 준비 용량 안에서 주문·회로 스톡 편성
→ 기본 소환수 전개

전투 중
→ 하위 회로 스톡으로 반복 구간 자동완성
→ 직접 입력으로 상위 회로 구성
→ 완성 주문 스톡으로 즉시 대응
→ 지정 스톡 1종 자동 충전
→ 필요 시 진행도 보존 후 대상 전환
→ 직접 피해 시 손실 비율에 따른 짧은 정지
→ 지속 피해 중에는 충전 계속
→ 마력 교란 시 충전 속도 감소
→ 주문 봉인 시 스톡 사용만 불가
```

## 14. 가드레일

- 조건부 자동발동을 재도입하지 않는다.
- 스톡 사용 시점은 플레이어가 결정한다.
- 소환수 회로 직접 작성을 재도입하지 않는다.
- 스톡에 마나 예약·발동 비용·개별 보유 상한을 추가하지 않는다.
- 전환·직접 피해·상태이상으로 진행도를 삭제하지 않는다.
- 지속 피해 틱으로 충전·전환을 정지하지 않는다.
- 마력 교란으로 충전을 완전히 정지시키지 않는다.
- 동일한 마력 교란을 중첩해 충전 속도를 계속 낮추지 않는다.
- 주문 봉인 중 자동 충전을 정지하거나 보유 스톡을 삭제하지 않는다.
- 회로 혼선이나 상태이상 기반 전환 방해를 재도입하지 않는다.
- 직접 피해 정지는 0.10~0.80초 범위를 유지한다.

- 주문 봉인의 스톡 버튼 비활성화와 남은 시간
- 봉인 중에도 충전 진행도와 보유량이 유지되는 표시
- 플레이어와 소환수 생산 기여도

## 16. 미해결 기획 사항

1. 주문 봉인이 직접 회로 시전까지 차단하는 별도 상위 효과가 필요한가.
2. 수호·동조 능력치가 마력 교란·주문 봉인을 저항하거나 해제하는가.
3. 전환 지연시간과 전환 중 재변경 규칙은 무엇인가.
4. 기준 충전시간 1.0단위의 실제 초 환산값은 무엇인가.
5. 플레이어·소환수 생산 능력치 계산식은 무엇인가.
6. 연결·분기·합류를 독립 기능 회로로 계산하는가.
7. 전체 준비 용량 초기값과 성장량은 무엇인가.
