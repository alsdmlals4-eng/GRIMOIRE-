## 1. 자동스펠 개념의 최신 변경

기존의 `원터치 자동스펠 + 조건부 자동발동` 혼합 구조를 폐기한다.

### 이전 구조

- 원터치 자동스펠
- 체력, 피격, 적 수 등의 조건을 만족하면 자동으로 발동하는 조건부 자동스펠

상태: `SUPERSEDED`

### 최신 구조

자동화 기능은 모두 `스톡`으로 통합한다.

```text
성장으로 일정 이하 단계의 주문·회로 자동화 가능
→ 전투 전에 공용 준비 용량 안에서 스톡 배정
→ 전투 중 한 번의 터치로 사용 또는 적용
→ 지정 대상 1종 자동 충전
→ 플레이어 행동과 소환수 생산 지원으로 충전 가속
```

- 조건을 만족했다고 주문이 임의로 자동 발동하지 않는다.
- 주문 사용 시점과 회로 적용 시점은 플레이어가 결정한다.
- 스톡은 반복 입력 피로를 줄이지만 전투 판단을 제거하지 않는다.

## 2. 스톡의 두 종류

### 2.1 완성 주문 스톡

마도서에 등록되고 숙련 조건을 만족한 완성 주문을 저장한 사용량이다.

```text
완성 주문 스톡 선택
→ 한 번 터치
→ 저장된 주문 즉시 기동
→ 해당 주문 스톡 1개 소비
```

- 신규 주문 발견과 즉석 변형은 불가능하다.
- 등록된 설계도를 그대로 사용한다.
- 같은 주문에 여러 스톡을 준비하거나 여러 주문에 분산할 수 있다.
- 스톡이 없어도 직접 회로를 그려 시전할 수 있다.

### 2.2 하위 회로 스톡

플레이어 성장 기준보다 낮은 단계이며 이미 학습·숙련한 회로를 저장한 자동완성 사용량이다.

```text
상위 주문 회로 작성 중
→ 저장된 하위 회로 스톡 터치
→ 해당 회로가 현재 회로판에 자동 배치·연결
→ 회로 스톡 1개 소비
```

대상 후보:

- 메인 회로
- 형상·전달 회로
- 숙련된 저단계 보조 회로
- 추후 성장 기준을 만족한 하위 조건·기동 회로

개별 자동화 허용 단계와 목록은 아직 확정하지 않는다.

### 역할 차이

| 스톡 종류 | 한 번 터치 결과 | 플레이어가 계속 담당하는 것 |
|---|---|---|
| 완성 주문 스톡 | 저장된 주문 전체 즉시 기동 | 사용 시점, 대상, 전투 판단 |
| 하위 회로 스톡 | 현재 주문에 회로 한 구간 자동완성 | 상위 회로, 연결 방식, 즉석 조합, 최종 기동 |

## 3. 성장과 스톡화 기준

플레이어가 성장할수록 `자동화 가능 단계`가 상승한다.

```text
초반
→ 메인 + 형상·전달 직접 작성

숙련 이후
→ 낮은 단계 메인·형상·전달을 회로 스톡으로 사용 가능

중반
→ 낮은 단계 완성 주문을 주문 스톡으로 사용
→ 새로 해금된 보조·조건 회로는 직접 작성

후반
→ 성장 기준 이하의 하위 주문·회로는 스톡화
→ 현재 성장 단계의 상위 회로와 신규 조합에 직접 입력 집중
```

- 성장했다고 모든 하위 주문이 자동으로 장착되지는 않는다.
- 자동화 가능해진 주문과 회로 중 무엇을 준비할지는 플레이어가 선택한다.
- 강한 최신 주문과 현재 학습 중인 상위 회로는 직접 조작 영역으로 남긴다.
- 자동화 가능 단계의 명칭과 산정 공식은 미확정이다.

## 4. 주문·회로별 스톡과 지정 충전

스톡은 공용 탄약이 아니라 전투 전에 지정한 주문 또는 회로의 준비된 사용량이다.

```text
스톡 대상 지정
→ 공용 준비 용량 안에서 최대 스톡 배정
→ 전투 중 지정 대상의 빈 스톡 충전
→ 사용 시 스톡 1개 소비
```

- 각 주문·회로는 현재 스톡과 최대 스톡을 가진다.
- 플레이어 성장에 따라 전체 스톡 준비 용량이 증가한다.
- 자동 충전은 플레이어가 지정한 대상 1종만 동시에 진행한다.
- 충전 대상을 바꿀 수 있는 시점과 전환 제약은 미확정이다.

## 5. 스톡의 단일 제약

### 폐기된 규칙

완성 주문 스톡이 주문 비용의 50%를 최대 마나에서 예약하는 규칙은 폐기한다.

```text
완성 주문 스톡 준비
→ 최대 마나 50% 예약
```

상태: `SUPERSEDED`

### 최신 규칙

```text
스톡 제약
= 공용 스톡 준비 용량만 사용
```

- 완성 주문 스톡과 하위 회로 스톡 모두 최대 마나를 예약하지 않는다.
- 스톡 준비 시 현재 마나를 선불로 지불하지 않는다.
- 스톡을 발동하거나 회로를 적용할 때 추가 마나를 소비하지 않는다.
- 빈 스톡의 자동·능동 충전에도 마나를 소모하지 않는다.
- 직접 회로 시전만 기존 마나 소비·회복·절감 시스템을 사용한다.

하위 회로는 플레이어가 직접 터치해 조합해야 하고, 완성 주문은 구성 회로 수만큼 공용 준비 용량을 사용하므로 추가 마나 제약을 두지 않는다.

## 6. 공용 스톡 준비 용량

```text
하위 회로 스톡 1개 비용
= 준비 용량 1

완성 주문 스톡 1개 비용
= 설계도에 포함된 기능 회로 수
```

고위 주문은 회로 수가 많으므로 자연스럽게 더 많은 준비 용량을 사용한다. 세부 계산은 `STOCK_CAPACITY_SYSTEM.md`를 따른다.

## 7. 자동 충전과 능동 충전

최신 구조는 `지정 대상 1종 자동 충전 + 능동 행동 보너스 + 소환수 생산 지원`이다.

### 7.1 기본 자동 충전

- 전투 중 지정한 주문 또는 회로의 빈 스톡만 자동으로 충전된다.
- 다른 준비 대상은 충전되지 않는다.
- 기본 속도는 플레이어의 스톡 관련 능력치에 비례할 수 있다.
- 충전은 마나가 아니라 시간과 생산 효율을 사용한다.

### 7.2 소환수 생산 지원

소환수는 회로를 직접 작성하지 않는다. 대신 지정 스톡의 생산량 또는 충전 속도를 높인다.

```text
지정 대상 실제 충전 효율
= 기본 충전
+ 플레이어 기여
+ 소환수 생산 기여
```

- 소환수의 생산·동조·지속 관련 능력치가 충전 효율에 영향을 줄 수 있다.
- 소환수 스탠스에 따라 생산 지원 우선순위를 높일 수 있다.
- 소환수는 플레이어 허가 없이 충전 대상을 변경하지 않는다.
- 정확한 능력치 명칭, 계수, 상한은 미확정이다.

### 7.3 능동 충전 기여

다음 행동은 지정 대상의 자동 충전을 추가로 가속한다.

- 직접 회로 시전
- 정확한 회로 완성
- 방어·반격 성공
- 주문 연계 성공
- 소환수의 공격·수호·동조 행동 성공

정확 입력은 추가 보상이며, 정확 판정을 놓쳐도 기본 자동 충전은 유지한다.

## 8. 책임 경계

```text
직접 시전
→ 마나 소비·회복·절감
→ 신규 발견·즉석 변형·정확 입력 보상

하위 회로 스톡
→ 회로 자동 배치·연결
→ 공용 준비 용량 사용

완성 주문 스톡
→ 저장된 주문 즉시 기동
→ 구성 회로 수만큼 공용 준비 용량 사용

소환수
→ 스톡 생산량·충전 속도 강화
→ 전투·수호 지원
```

- 소환수의 회로 직접 작성과 협동 작성은 폐기한다.
- 반복 회로 자동완성은 하위 회로 스톡이 전담한다.
- 소환수는 스톡을 더 빠르게 생산하여 간접 지원한다.
- 회로 선택, 삽입 위치, 연결 방식, 최종 기동은 플레이어가 담당한다.

## 9. 전투 흐름

```text
전투 전
→ 전체 준비 용량 안에서 완성 주문·하위 회로 스톡 선택
→ 기본 소환수 전개
→ 최대 마나는 감소하지 않음

전투 중
→ 하위 회로 스톡으로 반복 회로 자동완성
→ 직접 입력으로 상위 회로와 연결·조건 구성
→ 완성 주문 스톡으로 필요한 순간 즉시 시전
→ 지정한 스톡 1종 자동 충전
→ 플레이어 행동과 소환수 생산 지원으로 충전 가속
→ 직접 시전은 별도 마나 시스템 사용
```

## 10. 가드레일

- 조건부 자동발동을 사용하지 않는다.
- 스톡 사용 시점은 플레이어가 결정한다.
- 하위 회로 스톡이 상위 회로 학습과 신규 조합을 대신하지 않게 한다.
- 성장으로 자동화 가능한 범위가 늘어도 현재 단계의 신규 회로는 직접 익히게 한다.
- 고위 주문은 구성 회로 수만큼 많은 준비 용량을 사용한다.
- 회로 하나에 여러 독립 효과를 압축해 준비 용량을 우회하지 않게 한다.
- 마나 회복·절감 회로는 직접 시전 마나에만 영향을 주며 스톡을 복제하지 않는다.
- 자동 충전 속도와 전체 준비 용량이 함께 과도하게 성장하지 않게 한다.
- 소환수 성장만으로 직접 시전이 무가치해지지 않게 한다.
- 소환수 생산량과 전체 스톡 준비 용량이 함께 폭증하지 않게 한다.
- 스톡에 마나 예약이나 발동 마나 비용을 다시 추가하지 않는다.

- 각 대상의 현재/최대 스톡
- 하위 회로 스톡의 용량 비용 1

- 자동 충전 진행도
- 플레이어와 소환수의 생산 기여도
- 하위 회로 스톡의 자동 삽입 위치 미리보기
- 스톡이 최대 마나를 감소시키지 않는다는 안내

예약 마나와 예약 후 최대 마나 표시는 제거한다.

## 13. 미해결 사항

1. 충전 대상을 전투 중 언제 변경할 수 있는가.
2. 완성 주문과 하위 회로의 충전 시간을 같은 공식으로 계산하는가.
3. 소환수 생산 능력치가 충전 속도, 단위 시간당 충전량, 둘 모두에 영향을 주는가.
4. 피격 시 자동 충전이 유지·감속·중단되는가.
5. 연결·분기·합류를 준비 용량 계산에서 독립 회로로 취급하는가.
6. 전체 준비 용량의 초기값과 성장 증가량은 얼마인가.
7. 주문·회로별 개별 최대 보유량을 추가로 둘 것인가, 공용 용량만 사용할 것인가.
