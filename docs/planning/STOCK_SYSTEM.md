# Spell 스톡 시스템 — 최신 책임 원본

## 문서 상태

- 상태: `PLANNING_IN_PROGRESS`
- 결정 상태: `CONFIRMED_DIRECTION`
- 기준 날짜: 2026-07-26
- 관련 결정: `GM-00-12`, `GM-00-14`, `GM-00-15`, `GM-00-16`
- 이전 문서: `docs/planning/AUTO_SPELL_SYSTEM.md`

이 문서는 자동스펠의 주문별 스톡, 최대 마나 예약, 자동·능동 충전에 관한 최신 책임 원본이다. 충돌 시 이 문서가 우선한다.

## 1. 주문별 스톡

스톡은 공용 탄약이 아니라 전투 전에 지정한 자동스펠의 준비된 사용량이다.

```text
자동스펠 지정
→ 해당 주문의 스톡 수 배정
→ 전투 중 지정 주문의 사용량 충전
→ 발동 시 스톡 1개 소비
```

- 자동스펠마다 현재 스톡과 최대 스톡을 가진다.
- 같은 주문에 여러 스톡을 준비하거나 여러 주문에 분산할 수 있다.
- 플레이어 성장에 따라 전체 스톡 준비 한도가 증가한다.
- 플레이어가 전투 중 충전할 주문을 지정할 수 있다.
- 스톡이 없어도 직접 회로 시전은 가능하다.

## 2. 최대 마나 예약

스톡 한 칸을 준비하면 해당 주문의 기존 마나 소모량 중 50%를 최대 마나에서 예약한다.

```text
스톡 1개 예약 마나
= 주문 기존 마나 비용 × 50%
```

예시:

```text
기본 최대 마나 100
기존 비용 20인 주문을 2스톡 준비
예약 마나 20
실전 최대 마나 80
```

현행 운용 해석:

- 스톡 편성이 유지되는 동안 예약 마나는 잠긴다.
- 스톡을 사용해 빈 칸이 되어도 예약치는 유지된다.
- 빈 칸은 예약된 용량을 기반으로 다시 충전된다.
- 자동스펠 발동 때 동일 비용을 다시 전액 지불하는 이중 비용은 적용하지 않는다.
- 편성을 해제하면 예약 마나는 최대 마나로 돌아온다.

50%는 확정 방향이며 소수점 처리와 절감 보조의 적용 순서는 PoC에서 검증한다.

## 3. 자동 충전과 능동 충전

최신 구조는 `자동 충전 + 능동 행동 보너스`다. 이는 이전의 `시간 경과만으로는 충전되지 않는다`는 규칙을 대체한다.

### 자동 충전

- 전투 중 지정 주문의 빈 스톡이 자동으로 충전된다.
- 충전 속도는 플레이어 능력치와 소환수 능력치에 비례한다.
- 정확한 능력치 명칭, 계수, 상한은 미확정이다.

```text
실제 충전 속도
= 기본 속도
+ 플레이어 기여
+ 소환수 기여
```

### 능동 충전 기여

다음 행동은 자동 충전을 가속한다.

- 직접 회로 시전
- 정확한 회로 완성
- 방어·반격 성공
- 주문 연계 성공
- 소환수 회로 지원과 동조 행동

정확 입력은 추가 보상이며, 정확 판정을 놓쳐도 기본 자동 충전은 유지한다.

## 4. 소환수 역할

- 기본 소환수 1체는 전투 시작부터 스톡 충전을 보조할 수 있다.
- 회로·동조·지속 관련 능력치가 충전 속도에 영향을 줄 수 있다.
- 스탠스에 따라 충전 지원 우선순위를 조절할 수 있다.
- 충전 주문 선택은 플레이어가 담당한다.

## 5. 전투 흐름

```text
전투 전 스톡 배정
→ 최대 마나 일부 예약
→ 준비 스톡 사용
→ 지정 주문 자동 충전
→ 직접 시전과 소환수 지원으로 충전 가속
→ 스톡 재생성
```

## 6. 가드레일

- 스톡을 많이 준비할수록 직접 시전에 사용할 최대 마나가 줄어든다.
- 강한 주문은 예약 마나의 절대량이 크다.
- 조건부 자동스펠이 자동 충전보다 빠르게 반복되는 순환을 막는다.
- 마나 회복 주문과 절감 보조를 통한 무한 순환을 막는다.
- 자동 충전 속도와 전체 스톡 수가 함께 과도하게 성장하지 않게 한다.
- 소환수 성장만으로 직접 시전이 무가치해지지 않게 한다.

## 7. UI 필수 정보

- 주문별 현재/최대 스톡
- 스톡 한 칸당 예약 마나
- 전체 예약 마나와 예약 후 최대 마나
- 현재 충전 대상
- 자동 충전 진행도
- 플레이어·소환수의 충전 기여

## 8. 미해결 사항

1. 동시에 자동 충전되는 주문은 지정한 1종뿐인가, 여러 종인가.
2. 충전 대상을 전투 중 언제든 변경할 수 있는가.
3. 주문별 최대 스톡과 전체 한도를 어떻게 나누는가.
4. 절감 보조가 스톡 예약 마나에 적용되는가.
5. 피격 시 자동 충전이 유지·감속·중단되는가.
