이 문서는 완성 주문 스톡, 하위 회로 스톡, 공용 준비 용량, 지정 대상 충전과 소환수 생산 지원에 관한 최신 책임 원본이다. 세부 규칙이 충돌하면 각 하위 책임 원본의 최신 결정이 우선한다.

## 1. 자동화 구조

기존의 `원터치 자동스펠 + 조건부 자동발동` 혼합 구조는 폐기한다.

상태: `SUPERSEDED`

```text
성장으로 일정 이하 단계의 주문·회로 자동화 가능
→ 전투 전에 공용 준비 용량 안에서 스톡 배정
→ 전투 중 한 번의 터치로 사용 또는 적용
→ 지정 대상 1종 자동 충전
→ 플레이어 행동과 소환수 생산 지원으로 충전 가속
```

- 조건을 만족했다고 주문이 임의로 발동하지 않는다.
- 주문 사용 시점과 회로 적용 시점은 플레이어가 결정한다.
- 자동화는 반복 입력을 줄이지만 신규 조합과 전투 판단을 제거하지 않는다.

## 2. 스톡의 두 종류

### 2.1 완성 주문 스톡

마도서에 등록되고 숙련 조건을 만족한 완성 주문의 저장 사용량이다.

```text
완성 주문 스톡 터치
→ 등록된 설계도 전체 기동
→ 스톡 1개 소비
```

- 신규 주문 발견과 즉석 변형은 불가능하다.
- 같은 주문에 여러 스톡을 준비하거나 여러 주문에 분산할 수 있다.
- 스톡이 없어도 직접 회로를 그려 시전할 수 있다.

### 2.2 하위 회로 스톡

성장 기준 이하이며 이미 학습·숙련한 회로 한 구간의 자동완성 사용량이다.

```text
상위 주문 작성 중
→ 하위 회로 스톡 터치
→ 해당 회로를 현재 회로판에 자동 배치·연결
→ 스톡 1개 소비
```

후보 범위:

- 메인 회로
- 형상·전달 회로
- 숙련된 저단계 보조 회로
- 성장 기준을 만족한 하위 조건·기동 회로

| 종류 | 터치 결과 | 플레이어가 담당하는 것 |
|---|---|---|
| 완성 주문 스톡 | 저장 주문 전체 기동 | 사용 시점, 대상, 전투 판단 |
| 하위 회로 스톡 | 회로 한 구간 자동완성 | 상위 회로, 연결, 즉석 조합, 최종 기동 |

## 3. 성장과 스톡화 기준

```text
초반
→ 메인 + 형상·전달 직접 작성

숙련 이후
→ 낮은 단계 회로를 하위 회로 스톡으로 준비

중반 이후
→ 낮은 단계 완성 주문을 주문 스톡으로 준비
→ 새로 해금된 상위 회로는 직접 작성
```

- 성장했다고 모든 하위 주문·회로가 자동 장착되지는 않는다.
- 자동화 자격을 얻은 항목 중 실제 편성은 플레이어가 선택한다.
- 현재 성장 단계의 신규·상위 회로는 직접 조작 영역으로 유지한다.

## 4. 공용 준비 용량과 단일 제약

스톡의 유일한 편성 제약은 공용 준비 용량이다.

```text
하위 회로 스톡 1개
= 준비 용량 1

완성 주문 스톡 1개
= 설계도에 포함된 기능 회로 수
```

- 동일 주문이나 회로를 여러 번 편성할 수 있다.
- 주문별·회로별 별도 최대 보유량은 두지 않는다.
- 플레이어 성장에 따라 전체 공용 준비 용량이 증가한다.
- 선 길이·획수·장식이 아니라 기능 회로 블록 수만 계산한다.
- 고위 주문은 회로 수가 많아 자연스럽게 더 많은 용량을 사용한다.

### 폐기된 마나 예약

```text
완성 주문 스톡
→ 주문 비용의 50%만큼 최대 마나 예약
```

상태: `SUPERSEDED`

최신 규칙:

- 완성 주문과 하위 회로 스톡 모두 최대 마나를 예약하지 않는다.
- 준비 시 현재 마나를 선불로 소비하지 않는다.
- 발동·적용·충전에 추가 마나를 소비하지 않는다.
- 직접 회로 시전만 마나 소비·회복·절감 시스템을 사용한다.

## 5. 충전시간

스톡 1회분의 기준 충전시간은 기능 회로 수에 따라 완만하게 증가한다.

```text
기준 충전시간(n)
= 1.0 + 0.5 × (n - 1)
```

| 기능 회로 수 | 기준 충전시간 |
|---:|---:|
| 1 | 1.0단위 |
| 2 | 1.5단위 |
| 3 | 2.0단위 |
| 4 | 2.5단위 |
| 5 | 3.0단위 |

- 하위 회로 스톡은 1.0단위를 사용한다.
- 완성 주문 스톡은 설계도의 기능 회로 수를 사용한다.
- `1.0단위`는 실제 1시간이 아닌 상대 시간 단위다.
- 동일 대상의 빈 스톡은 1회분씩 순차 충전한다.

## 6. 지정 대상 자동 충전

```text
지정 대상 1종
→ 기본 자동 충전
→ 플레이어 생산 능력치
→ 소환수 생산 능력치
→ 능동 행동 보너스
```

- 전투 중 지정한 주문 또는 회로의 빈 스톡만 충전한다.
- 다른 준비 대상은 동시에 충전하지 않는다.
- 충전은 마나가 아니라 시간과 생산 효율을 사용한다.
- 소환수는 회로를 작성하지 않고 스톡 생산량·충전 속도를 높인다.
- 소환수는 플레이어 허가 없이 충전 대상을 변경하지 않는다.

능동 충전 기여 후보:

- 직접 회로 시전
- 정확한 회로 완성
- 방어·반격 성공
- 주문 연계 성공
- 소환수의 공격·수호·동조 행동 성공

## 7. 충전 대상 전환

```text
현재 대상 충전
→ 다른 준비 대상 선택
→ 현재 진행도 보존
→ 전환 지연 동안 모든 충전 정지
→ 새 대상의 저장 진행도부터 재개
```

- 각 준비 대상은 다음 스톡 1회분의 진행도를 별도로 보존한다.
- 현재 대상이 최대치에 도달해도 자동으로 다른 대상으로 넘어가지 않는다.
- 전환 지연의 실제 시간과 전환 중 재변경 규칙은 미확정이다.

## 8. 실제 체력 피해 시 일시정지

피격 정지는 공격 접촉이나 타격 횟수가 아니라 **최종 체력 손실**을 기준으로 한다.

```text
최종 체력 피해 0
→ 충전·전환 유지

최종 체력 피해 발생
→ 0.25초 피해 집계 구간의 실제 체력 손실 합산
→ 최대 체력 대비 손실 비율 r 계산
→ clamp(r × 3.0, 0.10초, 0.80초) 적용
→ 진행도 전부 보존
→ 자동 재개
```

피해 0 사례:

- 소환수가 공격을 완전히 대신 맞음
- 보호막이 피해를 전부 흡수함
- 회피·무적·상쇄로 최종 피해가 0이 됨
- 피격 연출만 있고 체력이 감소하지 않음

최신 원칙:

- 타격 횟수를 정지시간에 직접 사용하지 않는다.
- 같은 총 체력 손실이면 단발 공격과 다단 공격은 같은 정지시간을 목표로 한다.
- 절대 체력값이 아니라 최대 체력 대비 실제 손실 비율을 사용한다.
- 부분 방어는 실제 손실을 줄인 만큼 정지시간도 줄인다.
- 정지 중에는 자동 충전, 플레이어·소환수 생산 기여와 능동 보너스를 적용하지 않는다.
- 이미 완성된 스톡은 정지 중에도 사용할 수 있다.
- 정지 종료 후 별도 입력 없이 자동 재개한다.

### 폐기된 고정 규칙

```text
피격당 0.5초 정지
→ 추가 피격 시 0.5초 갱신
→ 첫 피격부터 최대 1.0초
```

상태: `SUPERSEDED_BY_GM-00-28`

### 확정 계산식

```text
r = 0.25초 피해 집계 구간의 실제 체력 손실 합계 / 집계 시작 시 최대 체력
정지시간 = clamp(r × 3.0, 0.10초, 0.80초)
```

| 최대 체력 대비 손실 | 정지시간 |
|---:|---:|
| 1% | 0.10초 |
| 5% | 0.15초 |
| 10% | 0.30초 |
| 20% | 0.60초 |
| 30% 이상 | 0.80초 |

- 같은 0.25초 구간의 다단 피해는 실제 체력 손실을 합산해 한 번 계산한다.
- 각 타격에 최소 0.10초를 반복 적용하지 않는다.
- 집계 중 추가 피해가 발생하면 누적 손실 비율로 현재 정지 종료 시점을 재계산한다.
- 집계 구간 종료 후 발생한 피해는 새 집계로 처리한다.

## 9. 책임 경계

```text
직접 시전
→ 마나 소비·회복·절감
→ 신규 발견·즉석 변형·정확 입력 보상

하위 회로 스톡
→ 반복 회로 자동 배치·연결

완성 주문 스톡
→ 저장된 주문 즉시 기동

소환수
→ 전투·수호
→ 지정 스톡 생산량·충전 속도 강화
```

- 소환수의 회로 직접 작성과 협동 작성은 폐기한다.
- 반복 회로 자동완성은 하위 회로 스톡이 전담한다.
- 회로 선택, 삽입 위치, 연결 방식과 최종 기동은 플레이어가 담당한다.

## 10. 전투 흐름

```text
전투 전
→ 공용 준비 용량 안에서 주문·회로 스톡 편성
→ 기본 소환수 전개

전투 중
→ 하위 회로 스톡으로 반복 구간 자동완성
→ 직접 입력으로 상위 회로와 연결 구성
→ 완성 주문 스톡으로 즉시 대응
→ 지정 스톡 1종 자동 충전
→ 플레이어 행동과 소환수 생산 지원으로 가속
→ 필요 시 진행도 보존 후 충전 대상 전환
→ 실제 체력 손실 비율에 따른 피격 정지
→ 자동 재개
```

## 11. 가드레일

- 조건부 자동발동을 사용하지 않는다.
- 스톡 사용 시점은 플레이어가 결정한다.
- 하위 회로 스톡이 상위 회로 학습과 신규 조합을 대신하지 않게 한다.
- 회로 하나에 독립 효과를 압축해 준비 용량과 충전시간을 우회하지 않게 한다.
- 자동 충전 속도와 전체 준비 용량이 함께 과도하게 성장하지 않게 한다.
- 소환수 성장만으로 직접 시전이 무가치해지지 않게 한다.
- 전환·피격 시 진행도를 삭제하거나 감소시키지 않는다.
- 실제 체력 피해가 없으면 충전·전환을 정지하지 않는다.
- 타격 횟수를 정지시간에 직접 곱하지 않는다.
- 다단 공격 각 타격에 최소 정지시간을 반복 적용하지 않는다.
- 피해 집계 구간은 0.25초로 유지한다.
- 정지시간은 0.10초 미만 또는 0.80초 초과가 되지 않게 한다.
- 스톡에 마나 예약·발동 마나 비용·개별 보유 상한을 다시 추가하지 않는다.

## 14. 미해결 사항

1. 지속 피해를 어떤 단위로 집계하는가.
2. 수호·동조 능력치가 계산된 정지시간을 추가 감소시키는가.
3. 전환 지연의 실제 초 단위 값은 얼마인가.
4. 전환 지연 중 다시 대상을 변경하면 어떻게 처리하는가.
5. 기준 충전시간 1.0단위를 실제 몇 초로 환산하는가.
6. 소환수 생산 능력치를 어떤 방식으로 적용하는가.
7. 연결·분기·합류를 독립 기능 회로로 취급하는가.
8. 전체 준비 용량의 초기값과 성장 증가량은 얼마인가.
