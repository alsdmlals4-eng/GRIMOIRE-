## 2. 보호된 표현 구조

후보가 달라져도 다음은 유지한다.

- 가로형 `16:9`
- 학교·자유일정·비전투 탐색: 고정·장면 기반 3/4 필드
- 필드 캐릭터: 3.5~4등신 SD
- 대화: 같은 장소 배경 위 반신 일러스트
- 전투: 별도 고정 3/4 전술 전투장
- 전투 캐릭터: 필드 SD 비율·기본 골격 재사용
- 마법 작성: 현재 화면 감속·암전 + 작성 오버레이
- 결과: 원래 필드 장면의 환경 변화로 복귀
- 메인 동반 정령: Slice 초기 형상 1개
- 대량 자산 제작: Art Bible·Asset Specification 전 금지

## 3. 공통 평가 기준

| 기준 | 질문 |
|---|---|
| 글자 판독성 | 획·방향·집중·분산·위험이 배경과 분리되는가 |
| 인물 연속성 | SD와 반신이 같은 인물로 즉시 인식되는가 |
| 학교 분위기 | 수업·축제·생활·현장의 정서 차이를 표현할 수 있는가 |
| 전투 판독성 | 대상·범위·압력원·수호 상태가 작은 화면에서도 읽히는가 |
| 상태 재사용 | 같은 배경의 평상·축제·파손·복구 상태를 효율적으로 만들 수 있는가 |
| 제작 가능성 | 1인 제작이 선·채색·표정·애니메이션 일관성을 유지할 수 있는가 |
| 후속 모바일 | 축소·크롭 후에도 캐릭터와 글자가 뭉개지지 않는가 |
| 고유성 | 흔한 학원 애니메이션 또는 일반 픽셀 RPG로만 보이지 않는가 |

## 4. 후보 A — Soft Storybook Cel 2D Hybrid

### 정의

```text
부드러운 동화책 질감의 2D 배경
+ 선명한 외곽과 제한 셀 명암의 SD 캐릭터
+ 같은 선·얼굴 비율을 사용하는 반신 일러스트
+ 방향·범위 중심의 절제된 마법 FX
```

### 시각 계약 후보

- 배경: 붓결은 보이되 플레이 영역 중앙의 질감 밀도를 낮춘다.
- 캐릭터: 배경보다 선명한 외곽, 2단계 이하 명암 후보.
- SD: 3.5~4등신, 머리·손·소지품 실루엣을 크게 읽힌다.
- 반신: SD의 얼굴 특징·머리 형태·의상 포인트를 확대하고 새 디자인을 추가하지 않는다.
- 전투: 필드 SD 골격을 유지하되 접지 그림자·방향 표시·피격 실루엣을 강화한다.
- 마법: 글자 획과 세계 변화의 색·형태를 분리하며 파티클보다 방향선을 우선한다.
- 환경 상태: 기본 배경 위에 조명·장식·파손·복구 레이어를 교체한다.

### 장점

- 동화적 마법학교와 지적 마법 설계의 분위기를 함께 살린다.
- 반신 대화와 SD의 연결이 자연스럽다.
- 마법 글자 확대 화면에서 선과 질감의 개성을 확보할 수 있다.
- 풀 3D보다 현재 제작 구조와 자산 재사용에 적합하다.

### 위험

- 배경의 회화 질감과 캐릭터의 셀 선이 따로 노는 문제.
- 생성·외주·수작업 자산 사이 질감 일관성 유지 난도.
- 부드러운 색만 사용하면 대상·위험·글자가 묻힐 수 있음.

### 필수 가드레일

- 배경보다 캐릭터와 상호작용 대상의 대비를 우선한다.
- 화면 전체에 종이 질감·안개·광원을 중첩하지 않는다.
- 글자 획 주변에는 명확한 음영 또는 비어 있는 공간을 둔다.
- 대화 반신과 SD의 의상 디테일 수를 별도로 늘리지 않는다.

### 판정

`RECOMMENDED`

## 5. 후보 B — Clean Academy Anime 2D

### 정의

```text
깔끔한 애니메이션풍 선화
+ 평면에 가까운 셀 채색
+ 밝고 명확한 학교 배경
+ UI와 전투 판독성을 우선한 최소 질감
```

### 시각 계약 후보

- 배경: 형태와 원근이 명확한 3/4 일러스트, 작은 장식은 제한.
- 캐릭터: 일정한 선 굵기와 단순한 2단계 셀 명암.
- 반신: 표정과 눈·입 변화 중심, 포즈 수 최소화.
- FX: 기하학적 형태와 높은 대비, 짧은 지속시간.

### 장점

- 필드·전투·UI·마법 글자의 판독성이 가장 안정적이다.
- 스타일 재현과 반복 제작이 비교적 쉽다.
- 후속 모바일 축소 대응이 유리하다.

### 위험

- 일반적인 모바일 학원 RPG 또는 애니메이션풍 게임으로 보일 수 있다.
- 마도서·글자·정령의 신비감이 약해질 수 있다.
- 배경이 기능적 설명 화면처럼 느껴질 수 있다.

### 가드레일

- 글자 문법과 마도서 기록에 고유한 선·도형 언어를 부여한다.
- 교복·학교 건축·정령 실루엣 중 최소 두 축에서 고유성을 확보한다.
- 장식 과잉 대신 의미 기반 문양을 반복 사용한다.

### 판정

`SAFE_ALTERNATIVE`

## 6. 후보 C — Illustrated Pixel Diorama

### 정의

```text
아이소메트릭·3/4 픽셀 필드
+ 큰 실루엣의 SD 캐릭터
+ 별도 고해상도 반신 일러스트
+ 픽셀 기반 전술장과 선명한 범위 표시
```

### 장점

- 학교 장소와 상호작용 지점을 작은 화면에서 명확히 배치할 수 있다.
- 상태 변형과 타일·오브젝트 재사용이 강하다.
- 저사양 PC와 후속 모바일 대응이 유리하다.

### 위험

- 픽셀 SD와 고해상도 반신 사이 동일 인물 연속성이 약해질 수 있다.
- 직접 쓴 글자와 부드러운 획 표현이 픽셀 화면과 충돌할 수 있다.
- 사용자 승인 참고 이미지와 현재 일러스트 중심 방향에서 멀어질 가능성이 있다.
- 픽셀 애니메이션도 프레임·방향 수가 늘면 저비용이 아니다.

### 가드레일

- 필드와 대화의 얼굴·색·의상 키를 엄격히 공유한다.
- 마법 작성 오버레이는 픽셀화하지 않고 독립적인 선 표현을 허용한다.
- 자유 이동 대형 맵으로 범위를 확장하지 않는다.

### 판정

`PRODUCTION_FALLBACK / NOT_RECOMMENDED_AS_FIRST_CHOICE`

## 8. 권장안

`A — Soft Storybook Cel 2D Hybrid`

권장 이유:

1. 승인된 SD 필드·반신 대화·별도 전술장 구조를 가장 자연스럽게 연결한다.
2. `흐름 / 집중 / 분산`의 획과 세계 변화에 회화적 개성과 기하학적 판독성을 동시에 부여할 수 있다.
3. 마법학교·축제·생태 온실의 정서 차이를 배경 상태 변형으로 표현하기 좋다.
4. 풀 3D 품질 경쟁을 피하면서도 일반적인 평면 애니메이션풍보다 고유성을 확보한다.
