## 2. 보호된 표현 구조

승인된 최종 구조는 다음이다.

- 가로형 `16:9`.
- 학교·자유일정·비전투 탐색: 고정·장면 기반 3/4 필드.
- 필드 캐릭터: 3.5~4등신 SD.
- 대화: 같은 장소 배경 위 반신 일러스트.
- 탐색·비전투 마법 작성: 현재 화면 감속·암전 + 작성 Overlay.
- 전투: 별도 고정 3/4 전술 전투장.
- 전투 캐릭터: 필드 SD 비율과 디자인 키 재사용.
- 전투 중 마법 작성: 별도 전투 작성 Overlay.
- 결과: 원래 필드 장면의 환경 변화로 복귀.
- 메인 동반 정령: 작은 늑대형 원소 정령수 초기 형상.
- 수업·시험·축제·현장실습은 같은 배경 언어의 상태 변형으로 표현.

### 화면별 승인 포인트

#### 학교 탐색·자유일정

- 밝은 학교 광장과 교내 생활 인원이 보이는 장면 기반 필드.
- 주인공과 메인 동반 정령을 화면 중심에 함께 배치.
- 목표·다음 일정·마도서·가방·메뉴가 플레이 공간을 가리지 않는 구조.

#### 대화

- 같은 장소 정서를 유지한 실내·교내 배경.
- 반신 일러스트가 감정과 관계를 담당.
- 동반 정령이 장면 안에서 함께 반응.
- 대사창은 네이비·금색 계열 프레임.

#### 직접 글자 작성

- 현재 상황을 완전히 숨기지 않는 감속·암전 Overlay.
- 메인 글자와 보조 글자를 분리해 표시.
- 글자 획은 파랑 또는 상황별 고대비 색으로 표현.
- 비용·목표·취소·발동을 한 화면에서 확인.

#### 전술 전투

- 필드와 분리된 고정 3/4 전투장.
- 필드 SD와 같은 주인공·동료·정령 디자인 키 유지.
- 적의 위치·범위·행동 순서·목표가 읽히는 배치.
- 전투 중 작성은 오렌지·상황색 등으로 배경과 구분 가능하되 Art Bible에서 최종 규칙 확정.

#### 결과·복귀

- 결과는 보상 수치만 고립해 보여 주지 않고 전투장·원래 장소의 변화와 연결.
- 승리·획득·손실을 확인한 뒤 원래 장면으로 복귀.

### 승인 이유

1. 필드 SD·대화 반신·별도 전투장을 가장 자연스럽게 연결한다.
2. 직접 쓴 글자와 마법학교 배경을 동시에 보여 줄 수 있다.
3. 주인공과 정령수의 동일성을 여러 화면에서 유지한다.
4. 수업·시험·축제·현장실습을 같은 화면 언어로 변형할 수 있다.
5. 사용자가 기존 화면 구성과 비교해 직접 승인했다.

### 가드레일

- 승인 원본 이미지 자체를 수정하지 않는다.
- 배경보다 플레이 캐릭터·목표·글자 획의 대비를 우선한다.
- 화면 전체에 종이 질감·안개·Bloom을 중첩하지 않는다.
- 대화 반신에만 신규 의상 디테일을 추가하지 않는다.
- 주인공·동반 정령의 얼굴·색·의상 키를 화면마다 바꾸지 않는다.
- 전투를 일반 모바일 자동 전투 UI로 변형하지 않는다.
- 인벤토리형 generic fantasy UI를 GRIMOIRE 핵심 화면처럼 우선하지 않는다.
